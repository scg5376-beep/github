# 예산 (docs/규칙/발전.md)

- 기준: 5시간 창의 25% 에 해당하는 **토큰 수**. 이 프로젝트 세션 기록에서만 센다(다른 레포와 안 섞임).
- 초과 여유 +10%: 상한에 닿으면 새 바퀴 금지, 하던 바퀴의 검수·배포·기록만. 110%면 즉시 멈춤.
- 「시작해」마다 기준점을 새로 잡고 cap 만큼 진행(한 번에 한 cap).
- cap: `docs/발전/예산.json` (git 제외). 캘리브레이션 전 기본 500만(환산: 입력+출력+캐시쓰기+캐시읽기/10). 운영자 지정은 `python site/_build/budget.py --cap N`.
- 캘리브레이션 기록: ① 2026-09-17 자동(Δ토큰/Δ5시간%) 1%p≈409,385 → cap 10,234,649. 이 값은 다른 세션이 같은 창을 쓰고 있어 과소였다. ② 2026-09-17 운영자 실측 「이번 작업이 6%」 = 환산 7,365,496 토큰 → **1%p ≈ 1,227,583 → cap(25%p) = 30,689,566** (현재값) — 첫 「시작해」 날, 이 프로젝트만 돌아가는 상태에서 5시간 %가 3 이상 오르면 `--calibrate`.
- 참고 실측 2026-09-17: 이 세션 00:00~11:00 환산 178만 토큰. 7일 전체(모든 레포) 입력 1.6억·출력 1,000만 ≈ 주간 87%.
