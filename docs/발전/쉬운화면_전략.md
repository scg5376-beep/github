## 3. 바꿀 것 (시안)

### 첫 화면
- 맨 위 한 줄 질문 「무엇을 하고 싶으세요?」 + **그림 문 6개**(지도에 가게 올리기 · 리뷰 받고 답글 · 인터넷으로 팔기 · 광고 시작 · 단골 만들기 · 수수료·지원금) + 큰 「막혔어요, 물어볼래요」
- 문 아래 찾기 칸 하나, 작은 단추 둘(모르는 말 찾기 · 이번 주 소식)
- 머리: 사이트 이름 + 「묻기」 단추 하나. 플랫폼·채널 줄 없앰

### 따라 하기 글(순서 있는 일)
- 머리: 「← 처음으로」 + 「묻기」 둘만
- 제목 아래 **진행 막대(1 / 3 단계)** + 준비물·시간·돈 세 칸
- **한 화면 = 한 단계 카드**: 단계 번호 · 할 일 한 줄(25자 안팎) · 화면 캡처 1장(누를 곳 빨간 상자) · 설명 1~2문장 · ✓ 팁 한 줄
- 맨 아래 큰 단추 둘: 「막혔어요」 · 「다음 단계 →」
- 단계 9개짜리 글은 3묶음(시작·채우기·마무리)으로 나눠 묶음마다 진행 막대

### 개념·용어 글(순서 없는 일)
- 단계 안내 대신 카드(요점 카드·용어 카드, 이미 적용) + 맨 위 「이것부터 하세요」 단추 하나로 해당 따라 하기 글로

### 지키는 숫자
한 화면 누를 곳 7개 이하 · 첫 화면 문 6개 · 첫 화면에서 따라 하기까지 2번 눌러 도착 · 단추 44px 이상 · 아이콘에 글자 항상

## 4. 결정이 필요한 것
1. 첫 화면 문 6개 이름과 순서(시안 그대로 or 업종 고르기 「식당·카페·미용실·학원」 방식)
2. 따라 하기 글을 「한 화면에 한 단계씩 넘기기」(쪽을 나눔)로 할지 「한 쪽에 단계 카드를 세로로」(지금 시안)로 할지
3. 옆 기둥(코스 목록)·플랫폼 줄을 없애는 것 — 검색 노출용 연결은 글 끝 「다음 단계」와 사이트맵이 대신

## 5. 적용 순서 (확인 뒤)
첫 화면 → 따라 하기 41쪽(단계 카드·진행 막대·다음 단추) → 머리 메뉴 정리(전 페이지) → 개념 글 위쪽 정리 → 검사(check·audit·글자 수·누를 곳 수 실측)
