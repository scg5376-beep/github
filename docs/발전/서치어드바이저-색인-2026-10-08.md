## 추가로 확인된 것 (표에 없던 것)
- `markup-structure` 문서에 `nosourceinfo` 로봇 메타 태그가 있음 — "해당 사이트에 대해 AI로 자동 생성된 출처설명이 제공되지 않습니다." AI브리핑·AI 출처 표기와 관련된 새 태그로 보이나, 우리 사이트 적용 여부는 판단 필요.
- 사이트맵 제한: 하나의 사이트맵에 URL 5만 개 초과 불가, 용량 10MB 초과 불가(request-feed). 우리 사이트 사이트맵이 이 한도 안에 있는지는 이번 조사에서 세어보지 않음(미확인).
- `education-basic`(네이버 웹 검색의 기초) 페이지는 PDF 다운로드 링크로만 구성돼 있어 본문 텍스트를 못 가져옴 — PDF 를 직접 받아야 전문을 볼 수 있음(미확인, 이번 조사에서는 받지 않음).

확인됨   : 수집요청은 우선순위 기반이라 "최소 1일~몇 주" 걸리고 매일 반복 제출해도 소용없음(request-crawl). 색인은 수집과 별개 단계이며 HTML 없는 JS 전용 페이지·소프트 404는 "불용문서"로 색인에서 제외됨(seo-advanced-indexing). IndexNow 는 "색인을 보장하지는 않는다"고 두 문서(indexnow-about, indexnow-faq)에서 명시. robots.txt 응답코드별 처리(2xx/3xx/4xx/5xx), canonical·robots 메타 태그 문법, 웹 검색 미노출의 5가지 공식 원인(robots.txt·noindex·방화벽·웹표준·중복/품질).
미확인   : 수집 요청의 하루 건수 한도(숫자), Yeti 재방문 주기(숫자), 우리 사이트맵이 URL 5만 개·용량 10MB 한도 안에 있는지, `education-basic` PDF 전문, nosourceinfo 태그를 우리 사이트에 적용해야 하는지.
운영자확인필요 : (1) 로그인해서 웹마스터도구 「요청」 화면에 수집요청 하루 한도 숫자가 보이는지 확인. (2) 「SEO 리포트 > 수집 현황」에서 어떤 오류 유형(로봇 비허용/콘텐츠 오류 등)이 실제로 몇 건씩 잡혀 있는지 캡처해서 알려주면 다음 조사가 숫자 기반으로 좁혀짐. (3) 콘텐츠 품질 때문에 색인이 안 되는 건지는 설계자 판단 필요.
