**못 찾은 것**
- 비즈니스/프로페셔널 계정 전용 복구 절차의 별도 공식 문서 — help.instagram.com 안에 전용 페이지가 있을 가능성은 있으나 이번 탐색(링크 목록 1건, WebSearch 2건)으로는 못 찾음. 사유: help.instagram.com 최상위 페이지가 토픽 목록을 전부 노출하지 않고(검색창 기반 구조), WebSearch 결과는 전부 3rd-party 블로그·영상.
- "인스타그램에서 차단을 원할 수도 있는 계정"을 가르는 **구체적 신호(알고리즘)** — 공식 문서는 전반적 조치 체계만 공개하고 탐지 신호의 세부 기준은 공개하지 않음(의도적 비공개로 추정되나 이는 추측이라 "미확인"으로만 적음).
- 위반 횟수별 제한 단계표(2회~10회 이상)가 **Instagram 계정에도 그대로 적용되는지**는 원문이 "이 제한 사항은 일반적으로 Facebook 계정에만 적용"이라고 명시해 미확인.

## 2. 네이버 블로그 체험단 — 신청 방법·효과

| 확인 항목 | 결과 |
|---|---|
| help.naver.com 에 체험단·협찬 "신청 방법" 공식 도움말이 있는가 | WebSearch로 탐색했으나 공식 help.naver.com 페이지를 찾지 못함. 결과는 전부 사설 체험단 중개 플랫폼(태그바이 등) 블로그와 대행사 글 — 즉 "체험단 신청"은 네이버가 운영하는 기능이 아니라 사설 플랫폼이 중개하는 민간 서비스이기 때문으로 보임(이 해석은 추정이라 별도 표시) |
| 체험단·협찬 "표시 의무"(법적 근거)가 이미 창고에 있는가 | 있음 — `site/_src/pages/guide/disclosure.html` 이 공정위 「추천·보증 등에 관한 표시·광고 심사지침」 2025-12 안내서와 2026-06-01 시행 개정안을 이미 근거로 인용 중 (Grep 확인, 89~91행에 출처 URL 포함) |
| 체험단 "효과"(조회수·매출 증가 등) 공식 통계 | 미확인 — 공정위·네이버 어느 쪽도 체험단 효과를 수치로 공표한 공식 자료 없음 |

**결론: 「체험단 신청 방법·효과」는 원문 없음 → 글 안 씀.** 이미 있는 `disclosure.html`의 표시 의무 근거로 충분히 다뤄지고 있고, "신청 방법"·"효과"는 사설 플랫폼 영역이라 공식 원문 기반으로 쓸 내용이 없음.

**새로 저장한 파일 없음** (네이버 블로그 쪽은 이미 창고에 있는 근거를 재확인한 것뿐).

확인됨   : 인스타그램 계정 비활성화·삭제 차이, 이의 제기 가능 여부, 커뮤니티 규정 위반 시 3단계 조치(삭제/배포축소/정보제공), 스트라이크 집계·소멸 규칙(90일/4년/1년), 위반 횟수별 제한 단계표(1~10회 이상, 단 FB 전용), 계정 비활성화 사유(5번째 경고·중대 위반 1회) — 전부 공식 문서 원문 확보·저장. 네이버 체험단 표시 의무는 기존 `disclosure.html` 근거로 이미 충분함을 재확인.
미확인   : 비즈니스/프로페셔널 계정 전용 복구 절차 전용 문서, 인스타그램 전용 위반 횟수별 제한표(FB와 동일 적용되는지), 계정 차단·정지를 가르는 세부 탐지 신호(공식 비공개 추정), 네이버 체험단 "효과" 수치 공식 자료.
운영자확인필요 : (1) 인스타그램 계정 관련 글을 쓸 때 "위반 횟수별 제한표"는 원문이 Facebook 전용이라 적어 Instagram에 그대로 쓰면 안 되는지, 아니면 "참고용"으로만 쓸지 판단 필요. (2) 블로그 체험단 글은 "신청 방법·효과"를 다루지 말고 기존 `disclosure.html`의 표시 의무만 안내하는 방향으로 가도 되는지 확인 필요.
