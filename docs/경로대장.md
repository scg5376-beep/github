- codex MCP: 레포 루트 `.mcp.json` 에 등록 (SECOND-HOME 과 같은 설정, `codex mcp-server`). **세션을 새로 열어야 붙고, 처음 한 번 프로젝트 MCP 승인 프롬프트가 뜬다.** 2026-09-11 세션은 이 파일이 없어서 이미지-코덱스가 못 돌았다
