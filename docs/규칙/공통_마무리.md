## 1. 최종 검수

| 자동 검사 | `cd site && python _build/build.py && python _build/check.py` (`PYTHONIOENCODING=utf-8`) | **오류 0**. 경고는 수를 적는다 |
| 레이아웃 전수 | `python _build/mkurls.py <urls.json>` → `node _build/audit.mjs <urls.json> "320,400,768,1366"` (앞서 `taskkill /F /IM msedge.exe`, `%TEMP%/edge-audit` 삭제) | `pages with issues: 0`. 새 프로필 첫 실행은 동기화 화면이 찍히니 두 번 돌린다 |

## 2. 문서 기록

- `docs/작업일지/YYYY-MM-DD.md` — 운영자가 한 말 **그대로**, 무엇을 했나, 못 한 것과 이유
- `site/docs/검수기록.md` — 검사 수치와 눈으로 본 것
- 설계 결정이 있었으면 `site/docs/설계기준.md` 에 D 번호로. 규칙이 바뀌었으면 `docs/규칙/해당.md` 도
- 새 경로·값·계정은 `docs/경로대장.md`
- 새 도구(스크립트)는 **레포 안**(`site/_build/`)에 둔다. 스크래치패드는 세션이 끝나면 사라진다(2026-09-16 에 생성기 8개를 잃을 뻔함)

## 3. 좀비 프로세스 정리

헤드리스 Edge·node 캡처 스크립트·로컬 서버는 도중에 죽이면 짝이 남는다(Edge 를 먼저 끄면 node 가 소켓을 기다리며 영원히 산다. 2026-09-16 에 실측).

```
cd site
python _build/cleanup.py --dry     # 무엇이 남았나 본다
python _build/cleanup.py           # 이 저장소 것만 끝낸다
python _build/cleanup.py --server  # 8765 로컬 서버까지 끝낼 때
```

- 끝내는 것: `edge-shot`·`edge-ovf`·`edge-audit` 프로필의 msedge, `shot.mjs`·`scroll.mjs`·`audit.mjs`·`diag_shot.mjs` 를 돌리는 node, (`--server`) `http.server 8765`
- **손대지 않는 것**: 다른 프로젝트의 node·python, 코덱스(`codex mcp-server`·`cua_node`), Claude 상태줄, VS Code. 남아 있으면 수만 보고한다. 끝내려면 운영자에게 묻는다
- 예방: 캡처·검사 스크립트는 `timeout 90 node …` 로 감싼다. Edge 는 스크립트가 끝난 **뒤에** `taskkill`
