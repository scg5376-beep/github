## 2. 등급별 만드는 법

### 2-A. AI 인물 영상 (Veo 3.1 / Flow)
- 프롬프트는 공식 5요소 순서: **[카메라] + [주체] + [행동] + [배경] + [스타일·분위기]**, 여기에 렌즈·조명·소리(`SFX:`·`Ambient noise:`)를 더한다(02 §2, A)
- 빼고 싶은 것은 부정문보다 **원하는 장면을 긍정문으로** 구체 묘사(02 §2, A). 어둡게 나온 사고(09-27)는 「bright high-key daylight」 같은 긍정 묘사로 막는다
- 일관성: 기준 사진을 시작 프레임(Frames to Video)으로, 같은 인물을 여러 컷에 재료(Ingredients)로 반복 투입(02 §3, A)
- 컷은 짧게(4초 안팎) 쓰고, 컷마다 여러 번 뽑아 손·얼굴·물리 오류가 없는 것을 고른다. 「AI 티」를 없애는 공식 기법은 **미확인**이라 이 두 가지로만 대응(02 §4)
- 받을 때는 Flow 1080p 업스케일(무료). 더 올리려면 Topaz(유료 → 운영자 승인)

### 2-B. Blender 실사 렌더
- 최종 렌더는 **Cycles**(EEVEE 는 미리보기). 이 PC: RTX 5060 → OptiX 가속 사용(01 §1-1·§5)
- 색 관리 **AgX**, 노출로 밝기, 룩은 후반에서. 중간 저장이 필요하면 EXR(01 §1-3)
- 디노이즈: 애니메이션은 **OIDN**(깜빡임이 적음), 미리보기는 OptiX. Color+Albedo 패스(01 §1-2)
- 실내 조명: 창마다 면광 + **포털 라이트**, 천장 면광은 보조(01 §2)
- 카메라: 실제 초점거리·조리개 값, 모션 블러 켜고 셔터 0.5(= 1/(2×fps)) 근처(01 §1-5). 렌즈 효과(비네트·색수차·글레어)는 **약하게만**
- 「CG 티」 원인: 완벽히 깨끗한 면, 대칭, 날카로운 모서리 → 약간의 먼지·비대칭·모서리 둥글림(베벨)(01 §7)
- 에셋: **Poly Haven(CC0)** 먼저. BlenderKit 무료는 렌더를 광고에 쓰는 것까지 가능(모델 재판매 금지). Fab/Quixel 은 약관 **미확인 → 쓰지 않는다**(01 §4)
- 조경: Scatter on Surface / Distribute Points on Faces, 겹침 방지. 대기감은 볼륨(렌더 시간 늘어남)(01 §3)
- `blender_apt.py`(상자 3D)는 **C 등급**이다. B 등급 제작기는 아직 없다 → 만들 때 이 절을 기준으로

## 3. 영상미·전환 (가장 중요) — 근거 `04-전환영상미.md`
- **멈춘 사진을 쓰지 않는다.** 모든 컷에 카메라 움직임이 있어야 한다. 참고 이미지·기준 사진은 Flow 시작 프레임으로 넣어 **실제 카메라 무빙 영상**으로 바꾼다(사진 확대는 C 등급 최후 수단)
- 무빙 설계(부동산 현업, B): 속도는 **걷는 속도의 절반**, 한 무빙은 5~8초 **일정한 속도**, 흔들림 없는 짐벌·돌리·슬라이더·크레인. 전경–중경–배경 세 층이 보이게 구도(깊이·시차)
- **움직임 방향을 컷끼리 맞춘다.** 한 구간 안의 컷은 같은 방향(예: 모두 오른쪽 트럭, 또는 모두 앞으로 돌리)으로 뽑는다 → 움직이는 도중에 끊으면 전환 효과 없이도 이어진다(모션 매치 컷)
- 휙 밀기는 **두 컷의 움직임 방향·속도가 같을 때만**, 방향성 번짐을 전환 방향에 맞춰(No Film School·PremiumBeat, B). 방향이 다르면 겹침(cross)이나 줌 관통으로
- 매치컷(모양·동작·의미 맞춤)을 전환 효과보다 먼저 찾는다(StudioBinder, B)
- 컷은 각 AI 영상의 **움직임이 붙은 뒤 구간**(보통 1초 이후)에서 잘라 쓴다. 첫 프레임은 멈춰 있어 전환이 끊겨 보인다
- 음악: **섹션이 바뀔 때만 큰 전환**(쿵·플래시), 박자마다 효과를 넣지 않는다(오버싱크가 가장 흔한 실수, C)
- 그레인·헐레이션은 넣더라도 아주 약하게(과용이 싸 보이는 가장 흔한 원인, C)
- Flow 무빙 지시어(A): dolly / tracking(truck) / crane / aerial / slow pan / POV + 「constant speed」「about half walking pace」「stabilized gimbal」「realistic parallax」

## 3-1. 편집 (조립) — 근거 `05-편집강의.md`(현업 편집 강의 10편 정독, 09-27)
> 운영자 2026-09-27: "트레지션효과도 별로야 … 트레지션은 편집강의를 좀 들어서 노하우를 정독하고 정리해" / "말소리들리는것도 별로 인물들 얼굴 잠깐식 등장하는것 별로 효과음도 별로 배경음도 하나로 통일"
- **방→방은 하드 컷.** 컷 지점은 두 컷의 움직임 방향·속도가 비슷한 프레임, 그리고 음악 박자 위
- 전환 효과(디졸브)는 **큰 섹션 경계에만**, 12프레임 안팎(30fps에서 약 0.4초). 끝 화면은 15프레임
- **쓰지 않는 것**: 흰 플래시, 빛 번짐 덮개, 방향이 안 맞는 가짜 휙 밀기·번짐, 동기 없는 줌 펀치(강의 10편 모두 사례 없음, 국내 강사 「보고 나면 뭘 봤는지 기억이 안 남」). `blender_cut.py` 의 flash·light·whip·zoom 은 남겨 두되 **기본으로 쓰지 않는다**
- 가림 전환(문틀·가전)은 물체가 화면 80% 이상을 채울 때만
- 섹션 전환은 **음악 히트(재진입·강박)에 컷을 둔다** — 효과 대신 음악이 전환을 만든다
- 효과음은 한 편에 **1~3번**, 섹션 전환 음악 히트에만. 휙 소리 남발 금지
- **배경음은 곡 하나.** 곡의 쉬는 구간이 길면 박자 단위로 잘라 잇는다(46초 편에서 쉬는 구간 1.2초만 남김)
- **영상 원음은 끈다**(말소리·현장 잡음). 컷표 `"volume":0`
- **인물 얼굴이 스치듯 나오는 컷 금지.** 얼굴이 나오는 장면은 빼는 것이 기본(모자이크 X — 운영자 「차 모자이크도 빼줘」)
- 먼저 무음으로 보고 「소리가 빈 곳」만 표시한 뒤 소리를 설계한다
- 음원은 공개·상업 이용 가능한 것만(Mixkit 무료 라이선스: 「online ads」 허용·표기 의무 없음, `참고/<건>/영상/음원/라이선스.md`)
## 3-2. 편집 교본 — 근거 `06-편집기술심화.md`·`07-레퍼런스해부.md` (운영자 09-27 「너무 초급자수준」 「학습을 먼저하는게어때」)
- 순서 고정: **셀렉트 → 음악 → 컷 배치 → 색 → 전환 → 소리**
- **셀렉트**: `motion_scan.py` 로 움직임이 붙은 구간을 찾고, 앞·가운데·뒤 세 층이 보이는 **가장 넓은 구간**만. 벽에 가까운 좁은 구간·출발 직후·멈춰 가는 끝은 버린다
- **60fps 소스는 반드시 `clip_prep.py` 로 30fps 변환**(Blender 에 그대로 올리면 의도 없는 절반 속도). 속도는 의도해서 정하고, 30fps 맞춤은 **프레임 섞기(framerate)** — 버리기(fps)는 7·7·12 식 떨림(끊김)을 만든다(09-27 측정)
- 방 컷 **3초 안팎**, 같은 방향 컷끼리는 속도 램프(들어올 때 1.35배 → 가운데 0.65배 → 나갈 때 1.55배)로 하드 컷. 방향이 다르면 0.2초 디졸브
- 도입 5초 안에 **스케일(전경·단지)**. 좁은 방을 대표 컷으로 쓰지 않는다. 정지 그래픽(모식도)은 한 장면으로 압축
- 색: `clip_prep` warm 으로 한 톤 통일, 끝 화면 배경은 흐리게·어둡게
- 글자: 상자 없이(`"text_box":false`) 은은한 그러데이션 띠(`overlays` scrim) 위에, 0.2초 페이드. 짧게 여러 장. 상시 워터마크 없음(끝 화면에만 「제작 시안」)
- 검수: 최종 영상에서 **연속 프레임 차이**가 고른지(튀는 값 없음) 재고, 컷 직전이 아직 움직이는 중인지 확인

- **안전 영역(메타 릴스, A)**: 위 14%·아래 35%·좌우 6% 에는 자막·고지·로고를 두지 않는다 → 글자는 화면 높이 **36%~85%** 사이, 좌우 폭 88% 안. `blender_cut.py` 기본 위치가 이 기준(09-27 수정)
- 서체: **Pretendard**(OFL, 상업 이용 가능, 설치됨). 맑은 고딕은 광고 영상 사용 조건을 확인하지 않았으므로 쓰지 않는다(03 §6)

## 4. 색
- 조립(VSE)은 **Standard** 변환(완성 영상에 AgX 를 또 걸면 회색으로 바램, 09-27 실측). 3D 렌더 단계에서만 AgX
- 납품 색 공간 Rec.709(03 §4·§7). 휴대폰·브라우저에서 밝기가 달라 보일 수 있으니 **휴대폰으로 직접 틀어 확인**
- 등급이 섞이면 S 등급 컷의 밝기·화이트밸런스에 맞춘다

## 5. 소리
- 음량: 통합 음량(LUFS)과 최대 레벨을 **재서 기록**한다. 메타·유튜브 광고의 공식 목표 수치는 **미확인**(03 §5) → 한 캠페인 안에서는 같은 값으로 맞춘다
- 음악: 시안은 `sfx_make.py` 임시 음원(「임시 음원」 표기). **발행용 음악은 「유료 광고」까지 허용하는 플랜인지 약관 원문으로 확인한 뒤**에만(Epidemic 엔트리·Artlist Social 은 광고 불가로 보고됨, 03 §5 C등급) → 운영자 확인
