# 공통 — 시작할 때 (모든 일, 순서대로)

> 언제: 운영자 말을 받고 손대기 전. 전역 규칙 1-1 과 같다. 여기서 정한 순서로 읽고, **이번 일에 해당하는 규칙 파일만** 연다.

## 1. 읽는 순서

- [ ] `docs/경로대장.md` — 경로·계정·값. 적혀 있으면 다시 묻지 않는다. 안 맞아 보이면 그때 묻는다
- [ ] `docs/작업일지/` 최근 3일 — 바로 앞에 무엇을 했고 무엇이 열려 있나
- [ ] `docs/중단리포트/` 가 있으면 막힌 것부터 (지금은 없음)
- [ ] `docs/길라잡이.md` 표에서 이번 일의 줄 → 그 규칙 파일들. `docs/규칙/보안.md` 는 언제나
- [ ] 기억(memory)에 관련 항목이 있으면 그 파일·함수·값이 **아직 있는지** 확인하고 쓴다

## 2. 도구 상태 확인 (해당할 때만)

| 일 | 확인 |
|---|---|
| 캡처·레이아웃 검사 | `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8765/` 가 200 인가. 아니면 `cd site && python -m http.server 8765 &` |
| 방법 글 | `site/_build/howto/` 생성기가 있는가(스크래치패드 아님) |
| 원문 받기 | `marketing-doctor/엔진/원문받기/` README |
| 남은 프로세스 | `python site/_build/cleanup.py --dry` — 앞 세션 찌꺼기가 있으면 먼저 정리 |

## 3. 판단이 걸린 일은 내려보내지 않는다

법 금지선·톤 검열·구조 결정·되돌리기 비싼 변경·커밋은 이 세션(설계자)이 직접. 조사·파일 탐색·표 정리는 `서치-소넷`, 이미지는 `이미지-코덱스` (전역 규칙 2).

## 4. 시작 보고 없이 바로 한다

운영자에게 「이제 시작합니다」를 쓰지 않는다. 결정이 갈리는 지점(주소 변경·삭제·돈·계정)만 먼저 묻는다.
