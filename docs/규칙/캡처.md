# 규칙 · 화면 캡처 (플랫폼 화면에 빨간 표시)

> 언제: 방법 글에 「이 화면에서 여기를 누르세요」 그림이 필요할 때. 운영자 2026-09-15 "이런사진이 필요하면 네가 브라우저 제어해서 직접찍어서 빨간표시까지 처리".

## 도구 (전부 `site/_build/`)

| 단계 | 파일 | 하는 일 |
|---|---|---|
| 목록 | `shots.txt` | 한 줄 = `이름 \| 주소 \| 폭x높이 \| 선택자 \| 자르기 \| (선택) 먼저 실행할 JS`. 이 파일이 원본. 캡처를 다시 찍을 땐 여기만 고친다 |
| 찍기 | `shot.mjs` | 헤드리스 Edge **새 프로필**(`%TEMP%/edge-shot`, 로그인 없음)로 열고 선택자 위치를 json 으로 |
| 표시 | `mark.py` | 빨간 둥근 네모 + 번호 동그라미. `--crop x,y,w,h` 또는 `--auto 여백` |
| 한 번에 | `python _build/shots.py [이름 …]` | 목록 전부(또는 이름만) 찍고 표시까지 → `img/shots/이름.png`. 원본 `_이름.png`·json 은 git 제외 |
| 글에 붙이기 | `_build/howto/shots_map.py` → `regen.py` | `(코스, 파일) → {단계: [(이미지, 설명)]}`. 설명은 「화면 이름. ① 누르는 곳」 꼴 |

선택자: CSS 선택자 또는 `text=글자`(그 글자를 품은 가장 작은 요소). 앞에 `^` = 부모 단추(a·button·li)까지, `!` = 스크롤 안 함, `big:` = 가장 큰 것, `box=x,y,w,h` = 좌표 직접.

## 지켜야 할 것

1. **로그인 없이 보이는 화면만** 찍는다. 검색 결과·첫 화면·도움말·로그인 화면까지. 로그인 뒤 화면(내 업체·광고 설정·답글 쓰기)은 운영자 계정이 필요하므로 찍지 않는다 → 운영자가 찍어 주면 가게 이름·번호·아이디를 가리고 쓴다
2. 캡처에 **남의 가게·대행사 광고·개인 계정**이 보이면 자르거나(crop) 안 쓴다. 검색 결과에는 대행사 광고가 자주 끼어든다
3. 웨일 설치 배너·팝업은 `shot.mjs` 가 지우거나 JS 로 닫는다. 남았으면 자른다
4. 화면은 바뀐다. 캡처마다 `shots.txt` 에 주소가 있으니 **바뀌면 다시 찍는다**. 글의 「이 글은 YYYY-MM-DD 기준」이 캡처 날짜도 겸한다
5. 한 캡처에 표시는 셋까지. 번호는 글의 단계 순서와 같게
6. 크기: 폭 1200 으로 찍고 필요한 부분만 자른다. 한 장 300KB 안팎, 총량이 커지면 webp 검토
7. 다 찍으면 **대조표(contact sheet)로 눈으로 본다**. 빈 화면·엉뚱한 요소·접근 거부(쿠팡 윙)·동기화 화면은 자동으로 못 거른다
8. 스크립트는 `timeout 90` 으로 감싸고, Edge 는 스크립트가 끝난 뒤에 `taskkill`. 끝나면 `cleanup.py`(공통_마무리)
