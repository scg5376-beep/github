# 규칙 · 발전 루프 — 잘되는 플랫폼을 보고 사이트를 스스로 키운다

> 언제: 운영자가 「시작해」라고 하면. 운영자 2026-09-17: "홈페이지 자체는 완성되었으니까 이제 다른 플랫폼이랑 계속 비교해가며 디벨롭 … 중간중간 나한테 보여주기식 완성 및 변경을 주지말고 … 하루에 클로드 max 토큰 25%만 사용해서 … 결국 중요한건 사람들이 유입이 있고 활동성이 있어야한다는거야".

## 목표 하나

**유입(검색·공유로 들어오는 사람)과 활동(머물고 다시 오고 따라 하는 것)이 늘게** 사이트를 바꾼다. 예쁘게가 아니라 들어오고 쓰게.

## 예산 — 5시간 창의 25%p

- 운영자 2026-09-17: "총사용량의 25% … 5시간 한도 기준으로 25%만". 앤스로픽은 5시간 창의 토큰 수를 공개하지 않는다(플랜별 배수만). 그래서 토큰이 아니라 **상태줄의 「5시간 %」로 잰다** — 상태줄 스크립트가 `~/.claude/statusline-rate.json` 에 실시간 값을 남긴다
- 「시작해」 → `python site/_build/budget.py --start` (기준점 저장, `docs/발전/예산.json`)
- 매 바퀴 끝 → `python site/_build/budget.py --check` — 기준점에서 **25%p** 올랐으면 종료코드 2 → **그 자리에서 멈추고** 일지에 「예산 소진」. 창이 초기화되면 0부터 다시 센다. 주간 95% 이상이면 무조건 멈춘다
- 예산 안에서도 한 바퀴는 **작게**(개선 하나 → 배포 하나). 큰 개편을 하다가 끊기면 배포 못 한 채 남는다
- 토큰 실측은 `python site/_build/usage.py` (참고용)

## 한 바퀴 (반복)

1. **고른다** — `docs/발전/큐.md` 맨 위 항목 하나(참고 플랫폼 + 볼 관점). 큐가 비면 큐 절을 보고 채운다
2. **본다** — 그 플랫폼의 공개 화면을 헤드리스 Edge 로 찍고(`site/_build/shot.mjs`, 로그인 없음) 무엇이 다른지 **측정 가능한 말**로 적는다: 첫 화면에 몇 초 안에 무엇이 보이나 · 한 화면의 글자 수 · 단추 수 · 글 하나의 길이·소제목 수 · 검색 결과에 어떻게 잡히나(제목·설명·구조화 데이터) · 다시 오게 하는 장치(시리즈·목록·업데이트·구독)
3. **가른다** — 우리와 다른 점 가운데 유입·활동에 닿는 것 하나만 고른다. 근거를 한 줄(무엇을 보고 그렇게 판단했나). 디자인 취향 차이는 고르지 않는다
4. **바꾼다** — 해당 규칙 파일(레이아웃·방법글·설명글·글쓰기·근거) 대로. 보안.md 는 언제나. 자바스크립트·폼·외부 자원·돈은 여전히 금지 — 활동성 장치가 그것을 요구하면 「운영자 결정 필요」로 큐에 남기고 다음 항목으로
5. **검수·배포** — 공통_마무리.md 그대로(검사 0·전수 검사 0·두 폭 캡처·cleanup)
6. **적는다** — `docs/발전/일지.md` 에 한 줄: 날짜 · 참고 플랫폼 · 본 것 · 바꾼 것 · 커밋 · 예산 사용률. 운영자에게 **중간 보고를 보내지 않는다**. 하루 끝에 한 번, 표 하나로

## 무엇을 참고하나 (큐의 재료)

| 종류 | 후보 | 볼 것 |
|---|---|---|
| 정부·공공 안내 | 정부24 · 국세청 홈택스 안내 · 소상공인24 · 서울시 소상공인 | 절차 안내의 순서·상자·표 |
| 플랫폼 자체 교육 | 네이버 비즈니스 스쿨 · 카카오 비즈니스 가이드 · 당근 비즈니스 · 메타 블루프린트 | 코스 구조·진도·완료 표시 |
| 건강·금융 안내(신뢰형) | Healthline · NerdWallet · 토스 피드 | 검토 표시·요약 상자·용어 링크 |
| 커뮤니티 | 아프니까 사장이다(네이버 카페) · 클리앙 소모임 · 레딧 r/smallbusiness | 사람이 왜 돌아오나: 질문·후기·주간 글 |
| 검색 유입 | 구글 서치 콘솔·네이버 서치어드바이저 **우리 데이터**(운영자 화면) | 어떤 검색어로 오나, 어느 글이 안 잡히나 |

- 커뮤니티 기능(댓글·질문·회원)은 정적 사이트로 못 한다. 가장 가까운 것: GitHub Discussions 링크, 이메일 없이 받는 익명 설문 대신 「자가진단」 확장, 주간 업데이트 페이지. 그 이상은 운영자 결정(서버·비용·개인정보)
- **우리 유입 데이터가 없다.** 분석 도구를 안 넣는 원칙이라 서치 콘솔·서치어드바이저 화면을 운영자가 가끔 캡처해 주면 그게 유일한 실측이다. 없으면 「미확인」으로 두고 추측으로 바꾸지 않는다

## 하지 않는 것

- 남의 사이트 글·그림을 옮기지 않는다. 구조와 방법만 배운다
- 근거 없는 사실을 새로 쓰지 않는다(근거.md). 유입을 위해 낚시 제목·과장은 안 한다
- 한 바퀴에 둘 이상을 바꾸지 않는다(무엇이 효과였는지 못 가른다 — 12주 기록 원칙과 같다)
