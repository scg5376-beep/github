# 영상 — AI 인물이 나오는 광고 영상 (2026-09-27)

> 언제 읽나: AI로 사람이 나오는 광고 영상을 만들 때(Flow·Veo·코덱스 이미지·Blender 조립).
> 운영자 2026-09-27: "매 작업마다 규칙누락되지않게 길라잡이로 잘 워크플로우 정리해서 꼬이지않고 각 작업을 완성도있게 완료할 수 있게 해줘"
> 계기: Flow로 글만 넣어 뽑았더니 외국인이 나오고, 화면이 어둡고, 화질이 "90년대 tv같아"(운영자). 그래서 **얼굴을 사진으로 먼저 고정**하고 영상은 그 사진에서 출발한다.

## 카드에 반드시 (세컨페이스 `SECOND-HOME/assets/마스터피스/_시트_템플릿.md` 형식을 따름)

- IDENTITY: 나이·성별·직업, **「Korean」 명시**
- FACE: 얼굴형·눈·코·입·피부·헤어 — 영어 서술문 한 덩어리(`prompt.positive`)
- lock: 컷마다 바뀌면 안 되는 3가지
- 다른 인물과 섞이지 않게 **「NOT <다른 인물>」** 한 줄(movie `docs/부서/촬영/오류대장.md` 09-14 얼굴 복제 사고)
- 실존 연예인 이름·닮은꼴 금지(`SECOND-HOME/assets/마스터피스/_인물_캐스팅_가이드.md` 하드룰)
- 기준 사진 경로(`refs`)는 사진이 나온 뒤 채운다. 사진 파일은 **커밋하지 않는다**(공개 레포, `참고/` 는 ignore)

## 조명·화질 문구 (프롬프트에 항상)

- 밝기: `bright high-key daylight, soft window light, lights on, clean airy apartment-ad look` — 「cinematic·film·evening·moody」 금지(어둡게 나옴, 09-27 실측)
- 선명도: `sharp clean digital photo, 4K commercial shoot, natural skin texture, no airbrushing, shot on Sony A7III 50mm f/1.8` — 「film grain」 **넣지 않는다**(세컨페이스 공통 문구에서 이 광고만 뺌: 90년대 화질 지적)
- 사람: `Korean`, 나이, 표정(밝게 웃음), 의상, 구도(허리 위/전신) 명시

## Flow에 사진 올리기 (파일 선택 창을 못 누르므로)

1. `python marketing-doctor/엔진/영상분석/flow_paste.py <사진폴더>` 를 백그라운드로 켠다
2. 새 탭 `http://127.0.0.1:8766/copy.html?f=<파일>` → 그 탭을 **캡처 한 번**(앞으로 가져옴) → 가운데 클릭 → `window.__r` 가 `COPIED` 인지 확인
3. Flow 탭 오른쪽 입력창 클릭 → `ctrl+v` → 썸네일이 회색에서 사진으로 바뀔 때까지 기다림 → 프롬프트 입력 → **전송 버튼**(오른쪽 아래 화살표)
4. 끝나면 서버를 끈다

- 요청문 첫 줄: `Use the attached image as the exact FIRST FRAME (image-to-video). Generate exactly ONE 8-second vertical 9:16 video with Veo 3.1 - Fast`
- 세 편을 연달아 걸어도 Flow가 대기열로 받는다(09-27 A·B·C 동시 성공). 코덱스만 한 번에 하나
- 함정: 왼쪽 그리드가 늘어나면 입력창 자리가 밀려 **사진 편집 화면이 열린다**. 누르기 전에 `find` 로 입력창 ref 를 새로 받는다

## 코덱스 기준 사진 — 같은 얼굴로 여러 장

- 첫 장(A)을 만든 뒤, 나머지는 `codex exec … -i <A.png> -` 로 A를 붙여 「두 사람 얼굴·머리·옷을 첨부 사진과 똑같이」라고 쓴다(09-27 B·C 모두 같은 얼굴 유지)
- 결과는 답에 적힌 png 경로를 grep 해서 `참고/<건>/영상/마스터피스/` 로 복사

## 편집 톤 — (09-27 폐기, `영상_고품질.md` 3-1 을 따른다) 레퍼런스처럼 (09-27 운영자 「웅장하게 그렇게는 안돼? 그거때문에 블렌더 쓰는건데」)

- 컷을 그냥 잇지 않는다. `blender_cut.py` 전환: 방 사이 `whip`(번짐+휙), 큰 전환 `flash`(흰 번쩍+쿵), 감정 전환 `light`(빛 번짐+반짝), 리듬 바꿈 `slideup`
- 소리가 반이다: `sfx_make.py` 로 배경음(bed·arp)·효과음을 만들어 `bgm`·`sfx` 로 넣는다. 컷은 박자(100BPM, 1.2초=2박)에 맞춘다. 화면 위에 「음악·효과음은 임시 음원」
- 확인: `--still 초,초 폴더` 로 전환 한가운데 프레임을 뽑아 본다 + 2초 단위 소리 크기(끊긴 곳 없는지)
- 근거: 레퍼런스 ① 포레나 브랜드편 컷 경계 프레임 해부(빛 번짐·단색 플래시·세로 밀기·움직임 위 컷)

## 법 표기 (보안·근거 규칙 위에 겹쳐서)

- 인물이 나오는 동안 **「가상인물」 라벨 + 하단 「AI를 기반으로 생성된 가상인물이 포함된 영상입니다」** (추천보증 심사지침 2026-06-01)
- 역·외관·조감도는 AI로 **만들지 않는다**(없는 걸 있는 것처럼 = 허위 소지). 광고주 자료 자리는 회색 자리표시
- Flow 워터마크는 지우지 않는다
- 광고주 자료가 없어 `blender_apt.py` 3D 로 채운 컷은 「3D 연출 이미지 · 실제 세대와 다름」(조경은 「실제 단지와 다름」) + 「3D 시안」 라벨. **시안 확인용이지 발행용이 아니다**(운영자 09-27 "블렌더로 어디까지되나보게")
