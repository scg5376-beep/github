# 규칙 · 보안·개인정보·돈·브랜드 중립 — 모든 일에 겹친다

> 짧으니 매번 읽는다. 자동 검사가 있는 건 번호를 적었다(check.py S·P).

## 절대 금지

1. **돈이 나가는 일** — 유료 API·크레딧·유료 플랜·광고 집행. 승인 없이는 0원. 애드센스는 운영자가 「후일에」로 보류(2026-09-14)
2. **운영자 개인정보** — 이름·전화·이메일·주소·매장명·지역명을 본문·그림·메타·캡처·커밋 메시지에 넣지 않는다(P1 자동 검사). 사업자등록번호·계정·WHOIS 화면은 외부에 공유 금지
3. **브랜드 중립** — 이 사이트는 특정 가게 것이 아니다. 세컨페이스·세종·안경원 실제 정보를 쓰지 않는다. 예시 업종은 미용실·식당·카페·학원(안경원 예시는 전부 교체함). about.html 의 「안경원 한 곳」 한 문장만 운영자가 허용
4. **자바스크립트 없음** — CSP `script-src 'none'`. 폼·입력 없음(S3). 예외 둘: 헤더 검색(구글 GET), 자가진단 라디오(어디로도 안 보냄, `main.diag` 한정)
5. **외부 자원 없음** — 폰트·이미지·iframe 외부 요청 금지. 분석 도구 없음
6. **로그인 금지** — 캡처·원문 받기는 로그인 없는 새 프로필로만. 운영자 계정으로 어디에도 들어가지 않는다
7. **비밀값을 레포에 넣지 않는다**(P4). `verify.json` 의 소유확인 코드처럼 공개돼도 무해한 것만

## 공개 레포 — 민감한 것은 올리지 않는다 (운영자 2026-09-29)
- 이 레포는 **공개**다(sajangmarketing.com 이 GitHub Pages 로 여기서 배포 → 무료 요금제라 비공개 전환 불가). 운영자 「레포에 민감한거 안올라가게만 만들어줘」
- 커밋 전 자동 검사 `.githooks/민감검사.py`(`core.hooksPath=.githooks`): 참고/·광고주자료·운영자대본 경로, 영상·소리·압축·PDF, 5MB 초과, 새 줄의 이메일·구글 드라이브 링크·전화번호·민감어를 막는다
- 민감어 목록은 `.githooks/민감어.local.txt`(레포에 안 올라감). 새 광고주·단지가 생기면 여기에 한 줄 더한다
- 막히면 가리거나 빼고 다시 커밋. `--no-verify` 는 운영자가 직접 시킬 때만
- 이미 공개된 옛 기록(작업일지·경로대장·조사 노트의 광고주명·메일·드라이브 링크)은 지우려면 기록 되돌리기가 필요 → 운영자 결정 대기
