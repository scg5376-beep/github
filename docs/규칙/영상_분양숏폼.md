## 2. 순서
1. **피드백 받기**: 운영자가 「시작하지마」면 받아 적기만(영상-02). 원문은 `docs/작업일지/` 에 그대로
2. **시간표**: `자막_초.txt` + 받아쓰기(faster-whisper small). 어긋나 보이면 20ms 소리 크기로 확인(영상-27)
3. **줄마다 장면표**: 대사 한 줄 = 그림/영상 한 개. 「이 자막이 그림으로 읽히나」 표로 대조(영상-07)
4. **소재**: 실촬영(견본주택 `광고주자료/소재/1-6.mp4` = 84A 한 테이크)·운영자 AI·코덱스 이미지(무료)·힉스필드 AI 영상(크레딧)
5. **AI 영상**: Blender 초안 → 옴니 1.1 Flash(3절)
6. **plan**: `python make_bunyang2.py plan` → 「중복 없음」「없는 소재 없음」 확인
7. **build**(전경): `python make_bunyang2.py build` → AE 렌더 → 소리 섞기(-16 LUFS)
8. **검수**: 고친 곳마다 프레임 캡처로 눈으로 · 음량 · AfterFX 0 · 받아쓰기로 목소리 이음매
9. **전달**: 720p 로 미리보기 전송. 실패하면 폴더 열기(`explorer.exe`)·드라이브
10. **기록**: 작업일지(운영자 말 그대로) · 버그리포트 · 새 금지는 `영상_금지.md` 끝 번호

## 3. 힉스필드 옴니 1.1 Flash (`gemini_omni_flash_1_1`)
- 모드 `reference-to-video`, 9:16, 1080p, 길이 3~10초(정수). **1080p = 초당 4.5 크레딧**(3초 13.5)
- 입력: Blender 초안 `video_references` + 참고 이미지 `image_references`. 올리기: `media_upload` → **파일마다 `curl -X PUT` 따로**(한글 경로는 `PYTHONIOENCODING=utf-8`) → `media_confirm`
- 「preset_recommendation」이 오면 `declined_preset_id` 로 다시(운영자는 옴니 그대로를 원함)
- `nsfw` 는 과금 안 됨 → 문구를 바꿔 다시(영상-21). 끝나면 `jobs_wait` → `result_url` 을 curl 로 받기
- 배속: 3초 → 구간 길이로, 넘치면 뒤를 자름(`PREP` 표). 5.5초 구간은 6초로 받아 1.4배

## 4. ae_reel 효과 사전(`릴.json`)
| 쓰고 싶은 것 | 넣는 것 |
|---|---|
| 줌 블러·휩·흰 번쩍·흐림·**렌즈 블러** | `trans` type `zoom·whip·flash·blur·lens`, 휩 반대 방향 `dir:-1` |
| 까만 배경 | `shots[].src = "black"` |
| 떠오르는 페이지·카드·캐릭터 | `over` + `keys [t,x,y,확대,회전,불투명]`, 그림자 `shadow` |
| 그 그림에 붙은 선·네모 | `draw` + `over:i`, 네모 `closed:1`, 박히듯 `pop:1`, 점선 `dash` |
| 경로 따라 달리는 전동차 | `over` + `parent:지도 i` + `autoOrient:1` + `top:1`(선보다 위), 칸마다 따로 |

## 5. 운영자가 좋다고 한 것(유지)
- 레퍼런스식: 정지 그림도 늘 움직임, 전환은 컷·줌 블러·휩·흰 번쩍·렌즈 블러, 자막은 흐림→선명하게 박힘 + 핵심 낱말 색
- 원테이크(조망·남향, 김포 야경), 창문이 하나씩 금빛으로 켜지는 「선착순 동호지정」, 까만 배경 세 칸(위←·가운데→·아래←)
- 놀란 3D 캐릭터(표정만)·실물형 카드·빨간 테두리 박힘·지도 카드+빛 선+칸 나뉜 전동차
