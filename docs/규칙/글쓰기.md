# 규칙 · 글쓰기(말투·문장) — ko-tone 의 앞장

> 본문 규칙은 `.claude/skills/ko-tone/SKILL.md` 가 전부다. 이 파일은 **순서와 도구**만 적는다. 규칙을 여기에 베끼지 않는다(두 벌이 되면 어긋난다).

## 순서

1. `.claude/skills/ko-tone/SKILL.md` 를 읽는다(S1 금지 → S2 통계 → H 사람 글 규칙 → 점검 순서)
2. 쓴다. 독자는 장사 오래 했고 마케팅은 처음인 사장님(50대 포함). 말하듯, 결론 먼저, 이유는 「-거든요」
3. 다 쓰면 **소리 내어 읽는다**(ko-tone 점검 순서). 검사기 전에 사람 귀가 먼저
4. `python site/_build/check.py` — 걸리면 한도를 건드리지 않고 **문장을 고친다**

## 고치는 방향 (im-not-ai 학습 2026-09-15 에서 가져옴)

- **빼기 전용**: 고칠 때 원문에 없던 비유·상투구·결산 문구를 새로 심지 않는다
- **서법 보존**: 권유(~하세요)를 단정으로, 추측을 확정으로 바꾸지 않는다
- **의미 불변**: 숫자·이름·인용·조건은 글자 그대로
- 연결어미(-고/-며/-지만/-면서/-아서/-어서/-는데) 뒤 쉼표는 쪽당 2회까지(S2-17). 인용문 안은 원문대로
- 「A가 아니라 B」 대구(「아니고」로 바꿔 써도 같은 대구, 2026-09-19 65곳 정정), 「결론적으로·정리하면」, 「~것입니다·~셈이죠」 강조 종결, 「여러분」은 0
- (2026-09-19 im-not-ai 대조로 추가, S1-15) 분열문 「중요한 것은 ~이다」, 「단순한 X를 넘어」, 「크게 세 가지로」·「다음과 같은」, 「~할 때입니다」도 0. 인용문 안은 예외

- 문단은 문장 3개·400자까지(D77). 넘으면 `python site/_build/paras.py --dry` 로 보고 나눈다

## 자주 걸리는 것

| 걸림 | 고침 |
|---|---|
| 퀴즈식 문답(「뭘까요? ~예요.」) | 서술로. 질문은 독자가 실제로 묻는 것만 |
| 편집자 말투(방향만 옮긴다·품이 든다·이 교실) | 일상 말 |
| 「갈래」 | 「코스」 |
| 명사로 끝나는 조각문 | 서술어를 붙인다 |
| 「중요한 것은」「가 아니라」 | 문장을 갈라 단언으로 |
