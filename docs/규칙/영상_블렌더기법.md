## 1. 도구 — `blender_fx.py` 한 개로 5종

```
blender -b -P marketing-doctor/엔진/영상분석/blender_fx.py -- <기법> <설정.json> <출력.mp4> [--scale 0.35]
```

| 기법 | 한 줄 | 어디에 | 입력 | 렌더 시간(RTX 5060, 1080×1920) |
|---|---|---|---|---|
| `dissolve` | 앞 장면이 조각나 빛 알갱이로 날아가고 뒤에서 다음 영상이 드러남 | 고충 → 단지로 넘어가는 순간(「좁은 → 넓은」) | 앞 장면 정지 그림 1장 + 드러날 영상 | 40프레임 약 30초 |
| `map3d` | 기울어진 어두운 지도 위에 강·도로·노선이 빛나는 관으로 그려짐 | 교통 설명 한 장면(5호선·인천2호선) | 좌표 설정(world 단위) | 240프레임 약 2.5분 |
| `gallery` | 흰 벽 액자 사이를 날아 한 액자 속으로 들어가면 그 그림이 화면이 됨 | 첫 장면·장면 사이 넘나들기·끝 화면 | 액자에 걸 정지 그림들 | 48프레임 약 1분 |
| `inkmask` | 노이즈로 번지는 마스크 + 경계 빛으로 앞 영상 → 뒤 영상 | 감성 전환(커튼 → 한강 등) | 앞 영상 + 뒤 영상 | 120프레임 약 40초 |
| `title3d` | 두께·베벨 입체 글자가 돌며 들어오고 빛줄기가 표면을 훑음 | 단지명 공개(선언형 광고의 로고 자리) | 글자·서체 + 선택: 뒤에 번져 들어올 영상 | 60프레임 약 1분 |

- 결과는 **완성 mp4 조각**(30fps, 소리 없음)이다. `blender_cut.py` 컷표에 보통 컷처럼 넣는다.
- 먼저 `--scale 0.35` 로 저해상도 시험 → 6프레임 띠 그림으로 확인 → 본 해상도. 틀린 채로 본 렌더를 걸지 않는다.

## 2. ★ Blender 5.2.1 에서 틀리기 쉬운 것 (실측)

| 증상 | 원인 | 이렇게 |
|---|---|---|
| `BLENDER_EEVEE_NEXT` 오류 | 5.x 에는 `BLENDER_EEVEE` 만 있음 | 엔진 이름은 `BLENDER_EEVEE` |
| 입자가 날지 않고 한꺼번에 줄기만 함 | 5.2 Capture Attribute 의 1번 소켓은 **Selection** | `cap.inputs["c"]` 처럼 **이름으로** 연결 |
| 완성 소재가 회색으로 바램 | AgX 색 변환이 한 번 더 걸림 | `view_transform = "Standard"`, 마스크 렌더는 `Raw` |
| 블룸(`use_bloom`)이 없음 | EEVEE Next 부터 빠짐 | 빛 번짐은 ffmpeg 후처리(가우스 흐림 + screen 섞기)로 |
| 컴포지터 `scene.node_tree` 없음 | 5.x 컴포지터는 노드 그룹 | 되도록 컴포지터를 안 쓰고 재질·ffmpeg 로 처리 |
| 한글 글자 파일 못 읽음 | `C:/Windows/Fonts` 에 Pretendard 는 SemiBold·Medium·Regular 뿐 | 굵기가 더 필요하면 `참고/…/영상/서체/Pretendard/public/static/` |
| 가로 지도가 세로 화면에서 잘림 | 지도는 가로로 김 | `"world":true` 로 3D 전용 좌표를 쓰고, 동서 축을 **세로로** 세운다(서울 위·김포 아래) |

## 3. 법적 선 — 연출이 사실을 넘지 않게

- `map3d`: 계획 노선은 **점선**, 역은 **점선 원**(위치 미정), **단지 표시를 두지 않는다**(역 거리 오인, 판례 2007다59066). 노선이 그려지는 동안 단계 고지를 화면에 붙인다(글자는 `title_render`).
  - **운영자 결정(2026-09-29)**: «역 노선 핀 이런거 예정이라고 이미 표시했는데 안둘이유없지» → 좌하단 「예정」 고지가 붙고 **광고주 입지안내 PDF 에 적힌 위치·이름(예: 시네폴리스역(가칭))** 을 따르면 단지 영상 위에도 역·노선·핀을 둔다. 역 이름에는 「(가칭)」, 노선은 계획이면 점선 그대로.
- `dissolve`·`inkmask` 로 드러나는 한강·풍경이 AI 연출이면 「AI로 만든 연출 영상」, 창밖 한강처럼 조망으로 읽히면 「실제 조망은 세대마다 다름」.
- `title3d`·`gallery` 의 액자 속 그림도 소재 등급(`영상_고품질.md` 0절)을 그대로 따른다. 액자에 걸었다고 C 등급이 발행용이 되지 않는다.
