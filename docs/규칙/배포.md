# 규칙 · 빌드·검사·커밋·배포

## 순서 (한 번에 한 묶음)

```
cd site
set PYTHONIOENCODING=utf-8          (bash: export PYTHONIOENCODING=utf-8)
python _build/build.py              # _src/pages → 페이지·sitemap·feed·404·redirects·css/diag.css
python _build/check.py              # 오류 0 이어야 다음으로
(공통_마무리.md 의 최종 검수)
git add -A && git commit -m "…"     # work 브랜치
git checkout main && git merge --ff-only work && git push origin main && git checkout work
gh run list --limit 1               # 사이트 검사·배포 (GitHub Pages) → success
curl -s -o /dev/null -w "%{http_code}" https://sajangmarketing.com/바뀐주소   # 200
```

- 빌드 결과(`site/*.html`)도 같이 커밋한다. CI 가 다시 빌드·검사하고 오류 1개면 배포하지 않는다
- 커밋 메시지: 한국어, 무엇을 왜, 설계 결정이면 D 번호. 끝에 세션 attribution 두 줄
- `main` 에서 직접 작업하지 않는다. `work` → ff-merge 만
- 커밋은 설계자(이 세션)만. 하위 에이전트는 커밋하지 않는다

## 검사기가 막는 것 (번호는 check.py)

| 번호 | 무엇 |
|---|---|
| S1·T | 금지 표현(tone.json `ban_s1`) — 비유·결말 관용구·강조형 종결·대구·번역투·유행어·기호·메타 발언 |
| S2 | 문장 통계(길이·같은 종결·문두 접속사·가능형·쉼표…) — 방법 글·자가진단·용어는 통계 건너뜀 |
| S2-17 | 연결어미 뒤 쉼표 쪽당 2회 초과 (2026-09-15) |
| T5·T6 | 굵은 글씨 문단당 상한, 강조 상자 쪽당 2개 |
| Q1 | 인용이 창고 원문에 없음 |
| L1 | 끊어진 내부 링크 |
| S3 | form·input·iframe (자가진단 라디오만 예외) |
| P1 | 운영자 개인정보 |

한도 값은 `site/_build/tone.json`·`spec.json` 한 곳에만. 검사에 걸리면 **문장을 고친다**. 한도를 올리는 건 길라잡이.md §2 를 거친다.

## 문제가 생기면

- 배포 CI 실패 → 로그를 보고 로컬에서 같은 오류를 재현해 고친다. `--no-verify`·검사 건너뛰기 금지
- 로컬 서버(`python -m http.server 8765`, site/)는 세션 사이에 죽는다. 캡처 전에 `curl 127.0.0.1:8765` 로 확인
- Windows 콘솔 인코딩 오류(cp949) → `PYTHONIOENCODING=utf-8`, `python -X utf8`
- bash heredoc 에 역슬래시·따옴표가 있으면 깨진다 → 스크립트는 Write 도구로 파일을 만들어 실행 (2026-09-19 B22·B26 재발: 정규식의 backslash-b, backslash-1 이 제어문자로 들어감. 코드 편집은 Edit 도구, 파이썬 안에서는 chr(92))
