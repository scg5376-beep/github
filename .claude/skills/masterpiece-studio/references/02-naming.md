# 네이밍 규칙

## ID
| 유형 | 접두사 | 예 |
|---|---|---|
| 캐릭터 | `CH` | `CH-001` |
| 룩북 | `LB` | `LB-003`, 개별 룩은 `LB-003#L2` |
| 배경 | `BG` | `BG-002` |
| 카메라구도 | `CM` | `CM-004` |
| 원근설정 | `PS` | `PS-002` |
| 레시피 | `RC` | `RC-001` |
| 임시(유형 미정) | `UN` | `UN-이름` |
| 즉석 조합 | `AD` | `AD-아리-20260819` |

번호는 `next_id()` 가 보관함까지 훑어 **재사용하지 않는다.**

## 카드 파일명
`<ID>-<이름슬러그>.md` — 예: `CH-001-아리.md`
슬러그는 한글/영문/숫자/`-`/`_` 만 남기고 공백은 `-` 로.

## 이미지 파일명 (자동 분류의 열쇠)
```
<레시피ID>__<캐릭터ID>__<룩북ID>-<룩키>__<배경ID>__<카메라ID>__<원근ID>__<번호>.png
예) RC-001__CH-001__LB-001-L2__BG-001__CM-002__PS-003__05.png
```
- 구분자는 언더바 **2개**(`__`), 각 파트 내부는 하이픈 1개.
- 같은 이름이 이미 있으면 `_v2`, `_v3` 가 자동으로 붙는다.
- 이 규칙을 어기면 `organize.py` 가 미분류로 잡고 사용자에게 되묻는다.

## 프로젝트 폴더
`outputs/projects/<YYYY-MM-주제>/<레시피ID>/images/`
예: `outputs/projects/2026-08-아리-카페/RC-001/images/`
