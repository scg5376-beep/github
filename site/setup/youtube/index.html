유튜브 가게 채널

채널 만들고 정보 채우고 쇼츠 규칙 알기. 위에서부터 순서대로 하면 돼요. 한 번에 다 안 해도 되고, 한 단계 끝내고 돌아와도 돼요.

1번부터 시작
  1. 채널과 첫 쇼츠무료6분
    • 컴퓨터나 휴대폰 웹에서 유튜브에 로그인하고 프로필 사진을 눌러 「채널…
    • 「새 채널 만들기」를 고르세요
    • 프로필 사진, 채널 이름, 핸들을 정하고 「채널 만들기」를 누르세요
  2. 채널 정보 채우기무료5분
    • 유튜브 스튜디오에 로그인하고 왼쪽 「맞춤설정」 > 「프로필」을 여세요
    • 채널 이름이 가게 이름과 같은지 보고, 다르면 고치세요
    • 「설명」에 가게 소개를 넣으세요
  3. 쇼츠 기준·수익설명6분
    • 어떤 영상이 쇼츠가 되나요?
    • 1분을 넘기면 뭐가 달라지나요?
    • 수익은 언제부터 나나요?

막히면 각 단계 글 아래 「막히면」에 답이 있어요. 다른 세팅은 세팅 순서 전부에 있어요.
