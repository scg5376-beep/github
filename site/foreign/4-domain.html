따라 하기

  1. 이미 도메인이 있으면 등록기관 화면에서 만료일·자동 갱신·등록 이메일을 확인하세요.
  2. 새로 잡을 거면 등록대행자에서 가게 이름으로 .com이 비어 있는지 검색하세요. 외국 손님은 .kr보다 .com이 익숙합니다(이건 저희 판단이고 검색에 유리한 쪽이라는 근거는 없어요).
  3. 등록자 이름·이메일·연락처를 사장님 것으로 넣고 「자동 갱신」을 켜세요. .com 계열은 등록자 정보를 바꾸면 60일 동안 다른 곳으로 못 옮깁니다.
    이유
    도메인은 기간을 정해 빌리는 것이라 만료되면 남이 가져가고 제작업체 명의로 등록됐다가 못 돌려받는 피해가 보도된 적 있어요. 도메인 설명
  4. 등록 확인 메일과 로그인 정보를 보관하세요.
  5. 홈페이지를 올릴 곳을 정하세요. 빌더(월 요금)나 유료 호스팅으로요. GitHub Pages·Vercel 무료 플랜은 약관이 상업 사용을 막습니다.

다 됐는지 확인

  • 도메인 등록자와 이메일이 사장님 것이다
  • 자동 갱신이 켜져 있다

막히면

홈페이지가 꼭 있어야 해요?
아니요. 구글 프로필만으로 외국 손님이 지도로 찾아오는 길은 열렸어요. 인스타그램 판매 기능을 쓰려면 도메인이 필요하고 그 밖에는 선택입니다.

왜 이걸 하는지, 무엇을 근거로 하는지는 도메인은 사는 게 아니고 빌리는 거예요에 있어요.
