# 체크리스트 — 사장님 마케팅 교실

> 기준은 여러 문서에 흩어져 있다(설계기준·ko-tone·로고-기준·조사). **이 파일은 그 전부를 한 장으로 모은 점검표**다.
> 번호는 원 문서의 규칙 번호 그대로. 자동(`check.py`)이 잡는 것은 ⚙, 사람이 봐야 하는 것은 👁.
> 글 하나를 올리기 전에 A·B 를, 사이트를 개편할 때 A~F 전부를 돈다.

## A. 글 쓰기 전 (근거)

- [ ] 👁 R1 창고(`marketing-doctor/지식`)에 있는 사실만 쓴다. 없는 건 「못 찾았어요」
- [ ] 👁 R2 원문을 확보한 것만 A, 발췌·2차는 B 로 "~라고 해요". 큰따옴표는 A 에만
- [ ] ⚙ Q 큰따옴표 `<q>` 는 `원전/원문` 과 글자 단위로 같다
- [ ] 👁 R3 숫자에는 연도·조사 기관·표본. 없으면 안 쓴다
- [ ] 👁 R4 지어낸 경험담 없음. "편집자가 본 경우" 같은 말도 근거 없으면 안 쓴다
- [ ] 👁 R5 이 글의 의미는 하나. 메타는 `cat` 플랫폼/채널 하나, 기준일 한 줄

## B. 글 쓴 뒤 (말투 — ko-tone)

- [ ] ⚙ S1 금지어 0: 비유(자리·셈·무기…), 결말 상투구, 강조형 종결(뜻이에요·이유예요·것입니다), "아니라" 대구, 번역투, 잉여 피동, 유행어, 기호 `! — :`, 메타 발언, 내부 용어, **접속사 뒤 쉼표(S1-11)**, 양비론(S1-12)
- [ ] ⚙ S2 통계: 합쇼체 ≤40%·입니다 ≤15%, 같은 어미 연속 ≤3, 문장 길이 편차 ≥30%, 20자 미만 ≤25%, 쉼표 문장 ≤40%, 3항 나열 ≤2, 문두 접속사 ≤5, 반복 서술어 ≤3, "할 수 있" ≤5, 문장 ≤55자, 문단 ≤5문장
- [ ] ⚙ S3 이용자 지적: 강조 부사 ≤3, "것 같아요" ≤3, "-적" 한 문장 1, 괄호 영어 ≤2, 명사화 ≤5, 자문자답 0
- [ ] 👁 T 소리 내어 읽기: 사람이 말하는 순서인가. 매끈해서 누가 썼는지 모르겠으면 「내가 본 것」 한 줄을 넣는다
- [ ] 👁 T 과소 서술: 지운 문장에 있던 주어·목적어·숫자·정도가 남아 있는가(ko-tone 6-1)
- [ ] 👁 T 해요체 특유: "~하시면 돼요" 반복, 과한 친절, 어린이 말투가 됐는가

## C. 페이지 모양 (설계기준 D)

- [ ] ⚙ D1~4 18px · 행간 1.75 · 폭 720(흰 판) · 대비 7:1
- [ ] ⚙ D8/D19 색은 남색 하나 + 플랫폼 색 8 + 그림 채움 3. 그라데이션·보라·그림자 카드 없음
- [ ] ⚙ D9 Pretendard 자체 호스팅, 외부 요청 0
- [ ] ⚙ D10 순서: 게시판 표시 → 제목 → 요약 → 메타 줄 → 목차(h2≥3) → 본문 → 「내일 해 볼 수 있는 것」 → 다음 글 → 근거
- [ ] ⚙ D11 강조 상자 ≤2, 종류 하나
- [ ] ⚙ D12 표 ≤3열
- [ ] ⚙ D13~D18·D23·D26 두 기둥(글), 첫 화면은 대표 글 + 카드 격자, 플랫폼 페이지, 채널 앵커, 「준비 중」 표시
- [ ] 👁 처음 온 사람 기준: 첫 화면에서 3초 안에 「글 목록·검색·기초 과정」이 보이는가. 문·타일·설명 표를 첫 화면에 쌓지 않는다
- [ ] 👁 400px 에서 가로 스크롤 0 (`ovf.mjs` 또는 캡처)
- [ ] 👁 1280/1366 캡처를 눈으로: 경계·여백·정렬

## D. 근거 표시·메타 (R·M·H)

- [ ] ⚙ M1 제목 ≤ 40자, M2 설명 50~160자, 설명 ≠ 제목
- [ ] ⚙ R2 메타 줄: 발행·수정·근거 등급·읽는 시간
- [ ] ⚙ H 제목 계층 h1 하나, h2 순서
