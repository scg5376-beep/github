## 확인됨

- Paul Rand 원문(효과 7원칙: 식별성·가시성·사용성·기억성·보편성·내구성·시대초월성, 단색·초소형 재현 가능해야 함) — paulrand.design 공식 페이지 직접 확인
- 토스 로고 리뉴얼 3대 기준(Uniqueness·Meaningful·Newness) — toss.im 공식 아티클 직접 확인
- Pretendard 폰트는 SIL OFL 1.1, 로고 포함 상업적 결과물에 라이선스 승계 의무 없이 사용 가능 — GitHub 공식 LICENSE 파일 직접 확인
- Android Adaptive Icon 안전영역(66×66dp/108×108dp 캔버스) — Android Developers 공식 문서 경유 확인
- 상표법 제33조 제1항 6호 "간단하고 흔히 있는 표장"은 식별력 없음으로 등록 거절 대상 — 조문 취지는 복수 법률 매체 일치
