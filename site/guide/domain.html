빌리는 거예요

한국인터넷정보센터 안내에 따르면 도메인 등록은 수수료를 내고 일정 기간 보유하는 거예요. 만료되면 남이 가져갈 수 있어요. 자동 갱신을 켜 두고, 등록에 쓴 이메일을 계속 확인할 수 있게 해 두는 게 첫째예요.

종류누가 관리하나어디서 등록하나
.kr, .co.kr, 한글.kr한국인터넷진흥원진흥원과 계약한 등록대행자
.com, .net, .shop 등ICANN 체계ICANN 인가 등록기관. 국내 대행사도 있어요

.kr은 진흥원 사이트가 아니고 등록대행자 홈페이지에서 신청한다고 해요. .com 계열은 등록자 이름이나 이메일을 바꾸면 60일 동안 다른 등록기관으로 못 옮긴다고 전해져요. 도메인 탈취를 막으려는 규정이에요. 누가 먼저 잡았느냐로 다툼이 생기면 인터넷주소분쟁조정위원회에 조정을 신청할 수 있다고 하고요.

상호와 도메인은 별개예요. 도메인을 잡았다고 상표권이 생기지 않아요. 상표는 특허청 문제이고 이 사이트에는 아직 그 글이 없어요.

공식 출처가 이렇게 나누는 건 아니고, 고를 때 헷갈리지 않게 저희가 나눈 거예요.

네이버 모두는 2025년 6월 26일에 끝났어요. 독립된 출처 넷이 같은 날짜예요. 모두로 홈페이지를 가졌던 가게는 이미 없어진 상태예요. 빌더 요금은 자주 바뀌어서 여기 숫자를 옮기지 않아요. 요금 페이지를 직접 보세요.

공짜 호스팅은 장사에 못 써요

직접 구축을 고른 사장님이 흔히 듣는 말이 GitHub Pages나 Vercel은 공짜라는 거예요. 약관이 막아요. GitHub Pages는 온라인 비즈니스나 이커머스 같은 상거래 목적으로 쓸 수 없다고 하고, Vercel의 무료 플랜은 비상업적 개인 용도로 제한된다고 전해져요. 가게 홈페이지는 상업 사용이에요. 공짜 플랜에 올렸다가 내려가면 손님이 못 들어와요.

이 사이트는 GitHub Pages에 있어요. 물건을 팔지 않는 교육 사이트라 약관에 걸리지 않아요. 가게 홈페이지와는 경우가 달라요.

  • 네이버와 구글에 알리기. 내 홈페이지가 검색에 보이려면
  • 팔 거면 신고. 온라인으로 팔기 전에 닫아야 할 것 여섯
  • 첫 화면에 표시할 것 여섯. 위 글에 법 원문이 있어요

모르는 것

.kr과 .com 가운데 무엇이 검색에 유리한지는 근거 있는 자료를 못 찾았어요. 그래서 적지 않아요. 요금, 기간 단위, 필요 서류도 원문을 못 봐서 적지 않았어요.

내일 해 볼 수 있는 것 이미 도메인이 있으면 등록기관 화면에서 만료일과 자동 갱신 여부를 확인해 보세요. 등록에 쓴 이메일이 지금도 열리는지도요. 이 둘로 도메인을 잃는 경우가 가장 흔해요.
