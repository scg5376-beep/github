내 홈페이지가 검색에 보이려면

홈페이지를 만들었는데 검색에 안 나온다는 말을 자주 들어요. 네이버와 구글이 그 이유를 공식 가이드에 적어 뒀어요. 그 가운데 가게 홈페이지에 해당하는 것만 골라 점검표로 만들었어요.

이 사이트 자체도 이 점검표대로 만들었고요.

등록과 노출의 관계

네이버 서치어드바이저, 「검색엔진 최적화의 목적」 네이버 웹 검색은 웹 수집 로봇이 자동으로 수집한 사이트 정보를 반영하여 노출하고 있습니다. 따라서 검색 등록 절차는 존재하지 않습니다.

대행사가 파는 "네이버 사이트 등록"은 노출을 만들어 주지 않아요. 등록과 소유확인의 쓸모는 따로 있어요. 내 사이트가 얼마나 수집되고 색인되는지를 보고서로 보는 것(편집자 주).

구글도 같은 말을 하고요.

구글 검색센터, 「검색 기술 요구사항」 누가 뭐라고 하든 검색결과에 페이지가 표시되게 하는 데에는 비용이 들지 않습니다. 페이지가 최소 기술 요구사항을 충족하기만 하면 Google 검색의 색인 생성 대상이 됩니다.

페이지 제목

네이버 서치어드바이저, 「HTML 마크업 가이드」 사이트 내의 모든 페이지를 동일한 제목으로 넣지 마세요. 페이지 콘텐츠에 맞는 고유한 제목을 기입해야 검색 사용자가 여러분의 콘텐츠를 찾을 가능성이 높아집니다.

빌더로 만든 사이트는 모든 페이지 제목이 "○○ 홈페이지" 하나인 경우가 흔해요. 이 문장에 정면으로 걸리죠. 메인 페이지 제목은 브랜드명으로 쓰세요.

개별 페이지 제목은 그 페이지가 무슨 내용인지 설명하는 문구로요. 메인에 "○○동 맛집 | 배달 | 예약 | 회식"처럼 낱말을 붙이는 건 반대 방향이에요.

오픈그래프

같은 문서 오픈 그래프 태그는 사이트가 소셜 미디어로 공유될 때 우선적으로 활용되는 정보입니다. 그러나 네이버 검색 로봇도 해당 정보의 내용을 동시에 활용하여 페이지 분석 및 노출에 사용하는 경우가 있으므로, 가급적 같이 기입하시는 것을 권장합니다.

카카오톡 공유용으로만 알려진 태그인데 검색에도 쓰인다는 얘기예요. 대표 이미지의 기준도 적혀 있어요. 150×150보다

클 것. 5,000바이트 이상일 것.

가로세로 비율이 3:1을 넘지 않을 것. 그 페이지를 대표하는 고유한 그림일 것. 모든 페이지에 로고 하나를 넣어 두면 쓰이지 않을 수 있어요.

사이트 여러 개

네이버 서치어드바이저, 「검색엔진 최적화의 목적」 검색 노출량을 늘이기 위하여 동일한 콘텐츠로 구성된 여러 개의 사이트를 개설하는 경우가 있습니다. 이 경우 검색 노출에 불이익을 받을 수 있으니 유의하세요.

"지점마다 사이트를 따로 만들라"는 조언이 여기에 걸려요.

안 보일 때 확인 순서

  • 주소가 호스트 단위인가. 스마트스토어 주소나 카페 게시판 주소는 등록이 안 돼요
  • 소유확인 메타태그가 head 안에 있는가. body 안이나 frame 안은 검증에서 빠져요
  • 방화벽이나 robots.txt가 네이버 로봇(Yeti)과 구글 로봇을 막고 있지 않은가
  • 메인 페이지가 자바스크립트나 meta refresh로 넘어가지 않는가. HTTP 리다이렉트만 지원돼요
  • 페이지 제목이 다 다른가
  • 사이트맵과 RSS를 냈는가. RSS에는 본문 전체를 담으라고 적혀 있어요
  • 일주일이 지났는가. 네이버는 로봇 방문 뒤 최대 1주일 안에 반영된다고 안내해요
  • noindex나 nofollow가 붙어 있지 않은가
  • 글자가 자바스크립트로만 그려지지 않는가
네이버 서치어드바이저, 「사이트 등록 및 소유확인」 페이지 내의 모든 콘텐츠가 자바스크립트로 로딩되는 구조인지 확인하세요. 대부분의 검색엔진은 표준 HTML 마크업을 사용하여 콘텐츠를 제공하는 것을 권장합니다.

AI로 만든 사이트가 여기 걸리는 경우가 있어요. 화면에는 보이는데 검색로봇에게는 빈 페이지거든요.

robots.txt 오해

구글 검색센터, 「검색 기술 요구사항」 robots.txt 파일로 Googlebot을 차단하면 크롤링은 차단되지만, 페이지의 URL이 검색결과에 계속 표시될 수 있습니다. Google에서 페이지의 색인을 생성하지 않도록 하려면 noindex를 사용하여 Google이 URL을 크롤링하도록 허용합니다.

"검색에서 빼려면 robots.txt로 막으면 된다"는 오해가 부정된 대목이에요.
