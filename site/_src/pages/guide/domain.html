빌리는 것

한국인터넷정보센터 안내에 따르면 도메인 등록은 수수료를 내고 일정 기간 보유하는 거예요. 만료되면 남이 가져갈 수 있어요. 자동 갱신을 켜 두고, 등록에 쓴 이메일을 계속 확인할 수 있게 해 두는 게 첫째예요.

.kr은 진흥원 사이트가 아니고 등록대행자 홈페이지에서 신청한다고 해요. .com 계열은 등록자 이름이나 이메일을 바꾸면 60일 동안 다른 곳으로 못 옮긴다고 해요. 도메인 탈취를 막으려는 규정이에요. 누가 먼저 잡았느냐로 다툼이 생기면 인터넷주소분쟁조정위원회에 조정을 신청할 수 있다고 하고요.

상호와 도메인은 별개예요. 도메인을 잡았다고 상표권이 생기지 않아요. 상표는 특허청 문제이고 이 사이트에는 아직 그 글이 없어요.

공짜 호스팅 약관

직접 구축을 고른 사장님이 흔히 듣는 말이 GitHub Pages나 Vercel은 공짜라는 거예요. 약관이 막아요. GitHub Pages는 온라인 비즈니스나 이커머스 같은 상거래 목적으로 쓸 수 없다고 해요. Vercel의 무료 플랜은 비상업적 개인 용도로 제한된다고 하고요. 가게 홈페이지는 상업 사용이에요.

공짜 플랜에 올렸다가 내려가면 손님이 못 들어와요.

이 사이트는 GitHub Pages에 있어요. 물건을 팔지 않는 교육 사이트라 약관에 걸리지 않아요. 가게 홈페이지와는 경우가 달라요.
