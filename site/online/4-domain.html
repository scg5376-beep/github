쇼핑몰 도메인 내 명의로 등록하는 방법

도메인은 사장님 명의, 사장님 이메일로 등록하고 자동 갱신을 켭니다. 장터에서만 팔 사장님도 인스타그램 판매 기능이 도메인을 요구하니 한 번 읽어 두세요.

발행 2026-09-13수정 2026-09-19읽는 시간 약 3분

준비물
  • 사업자등록증
  • 결제 카드
  • 사장님이 계속 쓰는 이메일
걸리는 시간
30분
돈
연 요금(등록대행자마다 다름)

따라 하기

  1. 이미 도메인이 있으면 등록기관 화면에서 만료일·자동 갱신·등록 이메일을 확인하세요. 등록 이메일이 제작업체 것이거나 안 쓰는 메일이면 지금 바꿉니다. 만료 안내가 그 메일로 가요.
    왜 이렇게 하나요
    도메인은 수수료를 내고 일정 기간 보유하는 것이라 만료되면 남이 가져가요. 제작업체 명의로 등록해 두고 이전을 거부하는 피해가 하루 10건 넘게 접수된 적이 있다고 보도됐어요. 도메인 설명
  2. 등록자 이름이 제작업체 명의면 사장님 명의로 이전을 요구하세요. .com 계열은 등록자 정보를 바꾸면 60일 동안 다른 곳으로 못 옮깁니다.
  3. 새로 잡을 거면 등록대행자 사이트에서 가게 이름으로 .kr과 .com이 비어 있는지 검색하세요. .kr은 한국인터넷정보센터와 계약한 등록대행자에서, .com은 ICANN 인가 등록기관(국내 대행사 포함)에서 등록합니다.
  4. 등록할 때 등록자 이름·이메일·연락처를 사장님 것으로 넣고 「자동 갱신」을 켜세요. 결제 카드도 사장님 것으로요.
  5. 등록 확인 메일을 받아 보관하세요. 등록기관 로그인 정보도 사장님만 아는 곳에 적어 둡니다.
  6. 홈페이지를 올릴 곳을 정하세요. 빌더(월 요금), 오픈마켓(수수료), 직접 구축(호스팅비) 가운데 하나입니다. GitHub Pages나 Vercel 무료 플랜은 약관이 상업 사용을 막으니 가게에는 쓰지 않습니다.
    왜 이렇게 하나요
    GitHub Pages는 상거래 목적으로 쓸 수 없고 Vercel 무료 플랜도 비상업 용도로 제한돼요. 공짜 플랜에 올렸다가 내려가면 손님이 못 들어옵니다. 도메인 설명
  7. 주소가 https로 열리는지 확인하세요. 빌더와 호스팅은 설정에서 보안 인증서를 켭니다.

다 됐는지 확인

  • 도메인 등록자와 이메일이 사장님 것이다
  • 자동 갱신이 켜져 있고 만료일을 적어 두었다
  • 홈페이지를 올릴 곳을 정했다

막히면

제작업체가 도메인을 안 넘겨줘요
등록기관에 등록자 정보를 확인하고 계약서에 도메인 명의 조항이 있는지 보세요. 안 되면 인터넷주소분쟁조정위원회에 조정을 신청할 수 있습니다.
.kr과 .com 중 뭐가 좋아요?
검색에 유리한 쪽이 있다는 근거 자료를 못 찾았어요. 손님이 외우기 쉬운 쪽으로 정하세요.

왜 이걸 하는지, 무엇을 근거로 하는지는 도메인은 기간을 정해 빌리는 거예요에 있어요.
