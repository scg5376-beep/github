# site/ — 사장님용 마케팅 교육 사이트

> 이 레포의 **세 번째 프로젝트**다. 루트(마스터피스)·`marketing-doctor/`(지식창고)와 규칙을 섞지 않는다.
> **본문의 사실은 전부 `marketing-doctor/지식/` 에서 가져온다.** 여기서 새 사실을 만들지 않는다.

## 무엇인가

도메인 하나에 올리는 **정적 HTML 사이트**. 소상공인 사장님(50대 이상 포함)이
SEO·GEO 같은 말을 **그림으로** 이해하고 내일 할 일 하나를 가져가게 한다.

- 프레임워크 없음. `index.html` + 주제별 `.html` + `css/style.css`
- 그림은 인라인 SVG. **실제 화면 캡처는 안 쓴다** — 남의 가게 상호가 찍힌다
  (`marketing-doctor/콘텐츠/전달규칙.md` "남의 매장을 예로 들지 않는다")
- 배포: GitHub Actions → GitHub Pages (`.github/workflows/pages.yml`)

## 지키는 것

| 규칙 | 근거 |
|---|---|
| 출처 없는 숫자를 쓰지 않는다. 등급을 페이지 끝에 표시한다 | `marketing-doctor/지식/출처등급.md` |
| 큰따옴표 = 원문 그대로(A). "~라고 합니다" = 2차 자료(B) | 같은 파일 |
| 상호·지역·전화번호를 넣지 않는다. 예시 가게 이름은 지어낸 것만 | `marketing-doctor/CLAUDE.md` 절대 규칙 2 |
| 겁주지 않는다 · 비법이라 하지 않는다 · 단정하지 않는다 | `marketing-doctor/콘텐츠/전달규칙.md` |
| 글자 20px 이상 · 한 페이지에 한 가지 · 문단 3줄 · 표 3열 이하 | 같은 파일 「형식」 |
| 영어 약어는 처음 한 번만 풀고 그다음은 우리말 | 같은 파일 「용어」 |

## 상업 이용 주의

GitHub Pages 무료 호스팅은 **상거래 목적**에 못 쓴다고 전해진다
(`marketing-doctor/지식/홈페이지/홈페이지-어디서-시작하나.md`, B등급).
