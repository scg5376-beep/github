> **무료로 되는 걸 먼저 한다** (`메타-무료로-하는-법.md`).
> 그다음에 이 파일을 본다. 여기는 **돈이 실제로 나가는 쪽**이라
> 모르고 시작하면 첫 달에 대부분을 버린다.

## 구조는 세 층이다

```
캠페인      무엇을 얻으려 하는가 (목표)
 └ 광고 세트  누구에게 · 얼마에 · 무엇으로 최적화하는가   ← 돈이 갈리는 층
    └ 광고     실제로 보이는 이미지·영상·글
```

**돈이 갈리는 건 가운데 층이다.** 아래 머신 러닝 단계 이야기가 전부 여기서 일어난다.

## ★ 머신 러닝 단계 — 여기서 대부분의 돈이 샌다

메타 광고는 켜자마자 잘 돌지 않는다. **머신 러닝 단계** 를 거친다.
시스템이 "누구에게 보여줘야 하는지" 를 배우는 기간이다.

공식 문구는 이렇다.

> 광고 세트를 안정적으로 게재할 수 있게 되면 즉시 머신 러닝 단계를 종료합니다.
> 이는 일반적으로 광고 세트가 **마지막으로 대폭 수정되고 한 주가 지난 후
> 약 50건의 결과**가 발생하면 이루어집니다.

**두 가지를 정확히 봐야 한다.**

```
'7일 안에' 가 아니다   →  '마지막 대폭 수정 후 한 주가 지난 뒤'
'이벤트' 가 아니다      →  '결과(results)'
```

그리고 이 단계에서 어떻게 되는지도 공식 문구에 있다.

> 머신 러닝 단계에서는 광고 세트의 성과가 안정적이지 못하며 **일반적으로 CPA가
> 높아집니다.**

### ★ Shops 광고는 기준이 다르다

제품을 파는 사장님이 반드시 봐야 할 문장이다.

> Shops 광고의 경우 **웹사이트를 통한 최소 17건의 구매, Meta를 통한 5건의 구매**가
> 발생해야 머신 러닝 단계가 완료됩니다.

**50건이 아니라 17건 + 5건이다.** 훨씬 낮다.
제품 판매를 하는 가게라면 이쪽이 현실적일 수 있다
(연동은 `메타-제품-판매-연동.md`).

### 그래도 대부분의 동네 가게에는 벅차다

동네 가게 기준으로 계산해 보자.

```
주 50건 구매가 나오는 가게   →  머신 러닝 단계를 벗어난다
주 10건 구매가 나오는 가게   →  영영 머신 러닝 단계 안에 머문다 → 계속 비싸다
```

**대부분의 동네 가게는 주 50 구매를 못 만든다.**

### 세는 단위는 '광고 세트' 다

**광고 하나가 아니라 광고 세트 하나가 50건을 채워야 한다.**
한 세트 안에 광고를 5개 넣어도 **50건 풀을 나눠 쓰는 게 아니라 함께 채운다.**

```
광고 세트 1개, 광고 5개   →  다섯 개가 같이 50건을 채운다  ⭕
광고 세트 3개, 광고 5개   →  세 세트가 각각 50건씩, 총 150건이 필요하다  ❌
```

### 화면에서 확인하는 법

50건에 이르지 못하면 광고 세트가 **'제한된 머신 러닝'** 상태가 된다.
광고 관리자 화면에 그렇게 표시된다.

**이 표시를 보면 성과가 안 나오는 게 아니라 아직 배우는 중인 것이다.**
그런데 그 상태로 계속 두면 비싼 채로 굳는다.

### 그래서 어떻게 하나

```
1  더 자주 일어나는 이벤트로 최적화한다
   구매(주 10건) 대신 → 랜딩 조회 · 문의 · 전화처럼 흔한 것
2  광고 세트를 쪼개지 않는다
   3개로 나누면 각각 50건을 채워야 한다. 하나로 몰아야 채워진다
3  자주 건드리지 않는다
   아래 '재시작을 부르는 것' 목록을 보고, 그 항목은 손대지 않는다
```

## 무료와 유료는 이렇게 갈린다

| | 무료 | 유료 |
|---|---|---|
| **언제 나오나** | 반응이 좋으면 (통제 못 함) | 켜는 동안 (통제 가능) |
| **끄면** | 남는다. 쌓인다 | 즉시 사라진다 |
| **필요한 것** | 시간과 꾸준함 | 돈과 데이터(이벤트 50건) |
| **잘 맞는 때** | 알릴 게 쌓여 있을 때 | 팔 게 확실하고 재고가 돌 때 |

`../../개념-가게키우기/길게-짧게-어디에-쓸까.md` 의 장기·단기 이야기 그대로다.
**둘 중 하나를 고르는 문제가 아니라 비중의 문제다.**

## 돈 쓰기 전 점검

```
□ 프로페셔널 계정이고 프로필이 정비돼 있나
   → 광고로 사람을 보내도 프로필이 비어 있으면 그냥 나간다
□ 무료 게시물 중 반응이 좋았던 게 있나
   → 그걸 광고로 미는 게 새로 만드는 것보다 낫다
□ 주 50건이 나올 만한 이벤트가 무엇인가
   → 이걸 먼저 정해야 최적화 목표를 정할 수 있다
□ 전환을 어디서 잡을 것인가
   → 한국은 인스타 안에서 결제가 안 된다(공식 확인).
     구매는 우리 쇼핑몰에서 일어나므로 추적을 거기 붙여야 이벤트가 잡힌다.
     이게 안 되어 있으면 머신 러닝 단계를 영영 못 벗어난다.
□ 얼마까지 잃어도 되는가
   → 첫 달은 배우는 값이라고 보는 게 맞다
```

## 대행사에 맡길 때

네이버 쪽에서 확인한 것과 같은 원칙이 적용된다
(`../네이버/네이버-광고는-이렇게-과금된다.md`).

```
□ 광고 계정은 사장님 명의여야 한다
□ 과금 내역을 직접 볼 수 있어야 한다
□ '월정액 보장' 은 의심한다 — 메타 광고는 경매 기반이다
□ '무조건 상위노출·1페이지 보장' 은 성립하지 않는다
```

한국인터넷광고재단이 **중소상공인 인터넷광고 계약 피해 주의보**를 내고 있다.
네이버든 메타든 같은 수법이 돈다.

## 아직 확인 못 한 것

**정직하게 적어 둔다. 이 항목들은 집행 전에 직접 확인해야 한다.**

```
· 한국의 메타 광고 최소 예산·과금 방식 공식 문구를 못 확보했다
· 쇼핑 검수 기간이 자료마다 다르다 (1~3일 vs 최대 4주). 둘 다 2차 자료다
· 머신 러닝 단계 50건 기준은 공식 페이지 위치를 찾았으나 전문을 못 봤다
  facebook.com/business/help/411605549765586 (학습 단계)
  facebook.com/business/help/316478108955072 (중요한 수정과 학습 단계) ← 우선순위 높음
  두 번째가 '무엇을 바꾸면 머신 러닝 단계가 재시작되는가' 를 담고 있다
· (해결됨) 인스타 결제 기능은 공식 문서에서 "현재 미국에서만" 으로 확인됐다
  → 한국은 광고로 보내도 결제는 우리 쇼핑몰에서 일어난다.
    그래서 전환 추적을 우리 쇼핑몰 쪽에 붙여야 머신 러닝 단계 이벤트가 잡힌다.
· ADVoost 등 최근 광고 방식 변화를 확인 못 했다
  (네이버 2025 통합보고서에 '광고 집행 방식의 전환 – ADVoost' 라는 표현이 있으나
   이건 네이버 쪽 이야기다. 메타의 최근 변화는 별도로 확인해야 한다)
```
