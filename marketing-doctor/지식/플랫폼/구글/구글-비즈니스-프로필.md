> ⚠️ **B등급이다.** support.google.com 이 차단돼 **원문을 못 열었다.**
> **큰따옴표를 쓰지 않고 "~로 전해진다"** 로만 적는다.
> 네이버 플레이스 쪽(`../네이버/네이버-플레이스-순위.md`)은 **A등급**이다. 다르다.

## 동네 가게에 구글이 필요한가

**한국에서는 네이버가 먼저다.** 국내 검색 이용을 보면 그렇다
(`../../현황/사람들은-지금-어디서-찾나.md`).

그래도 구글 비즈니스 프로필을 해두는 이유는 셋이다.

```
1  외국인 손님        한국어 검색을 안 한다. 구글 지도를 쓴다
2  안드로이드 지도     구글 지도가 기본으로 깔려 있다
3  무료다             시간만 들면 된다
```

**네이버 플레이스를 먼저 채우고, 그다음 여기를 채우는 순서다.**
**같은 재료를 두 번 쓰는 것**이라 품이 크게 늘지 않는다.

## 지켜야 할 것 — 전해지는 내용

```
· 정보는 정직하고 솔직해야 하며, 손님이 우리 가게를 이해하는 데
  관련 있고 쓸모 있는 내용에 집중해야 한다
· ★ 한 사업체당 프로필은 하나여야 한다
     여럿이면 지도·검색에서 정보가 어떻게 보이는지에 문제가 생긴다
· 업체와 무관하거나 명확한 연관이 없는 콘텐츠는 허용되지 않는다
· ★ 업체 설명에 링크는 어떤 형태도 허용되지 않는다
```

**'프로필 하나' 와 '설명에 링크 금지' 두 가지가 실수하기 쉽다.**

옛날에 만들어둔 프로필이 있는데 새로 또 만드는 경우가 흔하다.
**새로 만들기 전에 이미 있는지부터 확인한다.**

## 제한 콘텐츠

주류 · 도박 · 담배 · 총기 · 건강 및 의료기기 · 규제 의약품 ·
성인 서비스 · 금융 서비스 등이 포함된다고 전해진다.

> ⚠️ **목록이 이게 전부인지 확인하지 못했다.** 우리 업종이 걸리는지는
> 사장님이 원문에서 직접 확인하셔야 한다.

## 어기면 어떻게 되나

```
콘텐츠 표시 제한  →  순위 억제  →  프로필 정지
```

**정지되면 검색과 지도에서 목록이 내려간다**고 전해진다.
네이버 플레이스가 **"어뷰징 행위에 대한 페널티 부여 및 제재 조치"** 라고 밝힌 것과
같은 구조다(`../네이버/네이버-플레이스-순위.md`, A등급).

## 네이버 플레이스와 나란히 놓으면

| | 네이버 플레이스 (A등급) | 구글 비즈니스 프로필 (B등급) |
|---|---|---|
| 정보 채우기 | "정확하고 풍부하게" — 항목 10개 명시 | 정직·관련성·유용성 |
| 사진 | 시술사진 기준 공개 · AI 이미지 기준 명시 | 사진·게시물 정책 별도 문서 (미확인) |
| 링크 | 제한 규정 미확인 | **업체 설명에 링크 금지** |
| 중복 | 규정 미확인 | **한 사업체당 프로필 하나** |
| 제재 | 페널티·제재 조치 | 표시 제한 · 순위 억제 · 정지 |

**두 플랫폼의 방향이 같다** — 정확하고 충실한 정보, 조작 금지, 어기면 제재.
**다만 네이버 쪽이 지금 훨씬 자세히 확보돼 있다.**

## 아직 모르는 것

**정직하게 적어 둔다. 여기는 비어 있다.**

```
· 로컬 검색 순위 요소의 공식 문구 — 관련성·거리·인지도로 알려져 있으나
  구글 문서 원문을 확보하지 못했다. 이 창고는 그 세 단어를 쓰지 않는다
· 사진·동영상 정책과 게시물 정책 본문
· 리뷰 정책 (네이버는 리뷰가 검색어 재료라는 걸 확인했는데, 구글은 모른다)
· 정지 후 복구 절차와 걸리는 기간
· 한국에 따로 적용되는 조건
```

## 주의

- **B등급이다.** support.google.com 이 차단됐다. **원문 대조를 못 했다.**
- **큰따옴표를 쓰지 않았다.** 인용할 자격이 없다.
- **순위 요소를 쓰지 않았다.** '관련성·거리·인지도' 는 널리 알려져 있지만
  **공식 문구를 확보하지 못했다.** 확보하기 전에는 쓰지 않는다.
- **A로 올리려면** `support.google.com/business/answer/3038177` 과
  `.../7400114` 를 열어 붙여 주시면 된다.
