> ⚠️ **B등급이다.** google.com 계열이 이 환경에서 전부 차단돼 **원문을 못 열었다.**
> 그래서 **큰따옴표를 쓰지 않고 "~로 전해진다"** 로만 적는다.
> 같은 폴더의 네이버·메타 파일 상당수는 A등급이다 — **등급이 다르다.**

## 구글은 기준을 세 덩어리로 공개해 뒀다

「검색 필수 요건(Search Essentials)」이 이렇게 나뉜다고 전해진다.

| | 뜻 |
|---|---|
| **기술 요건** | 구글이 페이지를 검색에 보여주려면 최소한 필요한 것 |
| **스팸 정책** | **순위가 내려가거나 아예 빠지게** 만드는 행위 |
| **핵심 권장사항** | 도움이 되는·신뢰할 수 있는·사람을 위한 콘텐츠 |

**네이버와 구조가 같다.** 올려주는 쪽과 걸러내는 쪽이 따로 있다
(`../네이버/네이버-검색로직.md`).

## ★ 2024년에 새로 생긴 것 셋 — 여기가 지금 제일 중요하다

### 대량 콘텐츠 남용 (scaled content abuse)

> 검색 순위를 조작할 목적으로 **이용자에게 도움이 되지 않는 페이지를 대량 생성**하는 것.
> 가치가 거의 없는 **비독창적 콘텐츠를 대량으로** 만드는 데 초점이 맞춰진 관행이며,
> **만드는 방식과 무관하게 적용**된다고 전해진다.
> (영어 원문은 no matter how it's created 로 전해진다. **원문 대조는 못 했다.**)

**★ 이 마지막 구절이 핵심이다.**

```
AI로 만들었느냐   →  기준이 아니다
무엇을 만들었느냐  →  이게 기준이다
```

**세 플랫폼이 같은 말을 하고 있다.**

| | 문장 |
|---|---|
| **네이버 블로그** (A등급) | "**특정 기술의 활용 여부만으로는 판단하지 않습니다**" |
| **네이버 웹** (A등급) | "**AI 도구를 활용하는 경우, 단순 생성·요약에 그치지 말고 운영자의 경험과 관점을 더해 고유한 콘텐츠로 완성해 주세요.**" (`../../홈페이지/홈페이지-무슨-글을-올리나.md`) |
| **네이버 블로그** (A등급) | 걸리는 건 "**동일·유사한 템플릿**을 활용하여 콘텐츠를 **무의미하게 대량으로 발행**하는 경우" |
| **구글** (B등급) | **만드는 방식과 무관하게** 적용된다고 전해진다 — 문제는 **대량·비독창** |

> 이 세 줄을 나란히 놓으면 결론이 하나로 모인다.
> **AI를 쓰는 게 문제가 아니라, 남과 똑같은 것을 많이 뿌리는 게 문제다.**

### 만료 도메인 남용

만료된 도메인을 사서 **과거 평판을 이용해** 저품질 콘텐츠를 올리는 것.

### 사이트 평판 남용 (기생 SEO)

남의 신뢰도 높은 사이트에 얹혀 순위를 얻는 방식.
**2024-05-05 부터 적용**된다고 전해진다.

> ⚠️ 셋 다 **동네 가게가 스스로 할 일은 아니다.**
> 다만 **대행사가 우리 이름으로 이런 걸 하면 우리가 맞는다.**

## 그 밖에 스팸으로 다뤄지는 것

```
클로킹        사람과 검색로봇에게 다른 내용을 보여주는 것
도어웨이 남용   비슷한 검색어마다 페이지를 만들어 중간 페이지로 보내는 것
해킹된 콘텐츠 · 숨긴 텍스트 · 키워드 스터핑
```

**대부분 웹사이트 운영자용이다.** 블로그만 하시는 사장님은 대개 무관하다 —
이건 네이버 스팸사례 때와 같다(`../네이버/네이버가-검색에서-빼는-글.md`).

**사장님이 실제로 걸릴 수 있는 건 둘뿐이다.**

```
키워드 스터핑    같은 말을 억지로 반복하는 것
대량 비독창 콘텐츠  남의 글과 비슷한 걸 많이 올리는 것
```

## 네이버와 나란히 놓으면

| 구글 | 네이버 |
|---|---|
| 대량 콘텐츠 남용 | "무의미하게 대량 발행" · **유사 문서 분석 로직** |
| 키워드 스터핑 | "동일 키워드를 의도적으로 반복" |
| 도어웨이 | "실제 명칭 대신 검색량이 많은 키워드로 치환" |
| — | "실제 체험 없이 작성된 **비체험 원고**" ← 네이버에만 있다 |

**네이버가 한 칸 더 엄격하다.** '체험 없이 쓴 글' 을 명시적으로 든 건 네이버뿐이다.

## 주의

- **B등급이다.** developers.google.com 이 차단됐다. **원문 대조를 못 했다.**
  각 항목의 원문 정의와 **전체 목록을 확보하지 못했다.**
- **큰따옴표를 쓰지 않았다.** 인용할 자격이 없기 때문이다.
- **기술 요건 세부**(상태 코드·robots·색인 가능 형식)는 이 창고에 없다.
- **A로 올리려면** 아래를 열어 붙여 주시면 된다.
  - `developers.google.com/search/docs/essentials/spam-policies`
  - `developers.google.com/search/blog/2024/03/core-update-spam-policies`
- **구글은 정책이 자주 바뀐다. 반년마다 다시 본다.**
