## 제목(title) — 메인과 개별 페이지가 다르다

> 사이트 메인 페이지의 title 태그는, 사이트의 성격을 잘 표현할 수 있는 브랜드명으로 기입해야 합니다. 사이트의 개설 목적에 맞는 브랜드 키워드를 활용하는 것이 좋으며 상호명, 서비스명, 제품명 등의 고유명사를 사용하는 것을 권장합니다. 또한, 검색 노출만을 위하여 제목을 자주 변경하는 경우, 제목이 과도하게 길어서 사용자가 쉽게 사이트를 파악하지 못하는 경우 등은 검색 노출에 불이익을 받을 수 있습니다.

> 개별 페이지의 title 태그는, 페이지의 콘텐츠 주제를 명확하게 설명할 수 있는 문구를 기입해야 합니다. 별도의 글자 수 제한은 없지만 검색 결과에서 표현이 가능한 수준으로 제목의 길이를 제한하여 작성해 주시길 권장합니다. 과도한 길이의 제목 등은 검색 사용자의 사용성을 저해할 수 있습니다. 2회 이상 반복적인 키워드, 스팸성 키워드, 콘텐츠와 연관이 없는 키워드나 홍보 문구 등이 나열되어 있는 경우 등은 검색 노출에 불이익을 받을 수 있으니 유의하세요.

```
메인 페이지    브랜드명 · 상호명 · 서비스명 · 제품명 같은 고유명사
개별 페이지    그 페이지가 무슨 내용인지 설명하는 문구
```

★ **메인에 "○○동 맛집 | 배달 | 예약 | 회식" 처럼 키워드를 붙이는 게 정확히 반대다.**
가이드는 메인을 **브랜드명**으로 쓰라고 적었다(우리가 붙인 것).

### 글자 수 제한은 없다 — 다만

가이드는 **별도의 글자 수 제한은 없다**고 적으면서, 검색 결과에서 표현이 가능한 수준으로
길이를 제한하라고 권장한다. **길이 자체보다 "쓰지 말라" 고 열거한 쪽이 구체적이다.**

```
검색 노출만을 위하여 제목을 자주 변경        불이익
제목이 과도하게 길어 사이트 파악이 어려움     불이익
2회 이상 반복적인 키워드                    불이익
스팸성 키워드                              불이익
콘텐츠와 연관이 없는 키워드 · 홍보 문구 나열   불이익
```

> 사이트 내의 모든 페이지를 동일한 제목으로 넣지 마세요. 페이지 콘텐츠에 맞는 고유한 제목을 기입해야 검색 사용자가 여러분의 콘텐츠를 찾을 가능성이 높아집니다.

★ 빌더로 만든 사이트가 **모든 페이지 제목이 '○○ 홈페이지' 하나**인 경우가 흔하다.
이 문장에 정면으로 걸린다(우리가 붙인 것).

### ★ 내가 쓴 제목이 그대로 나오지 않는다

> 검색 노출에 사용되는 제목은 검색엔진이 이 태그 및 아래 오픈그래프 태그 등에 지정해주신 내용을 포함해 해당 페이지와 앵커 등 다양한 정보중 가장 적절한 것을 자동 추출하여 결정합니다.

**제목 태그는 후보 중 하나다.** 오픈그래프 태그, 페이지 본문, 앵커까지 보고 네이버가 고른다.
"제목만 잘 쓰면 된다" 가 아니라는 뜻이다(우리가 붙인 것).

## 설명(description) — 한두 문장

> 페이지의 description 태그는 페이지의 콘텐츠에 대한 간략한 설명으로 1-2개의 문장으로 구성된 짧은 단락을 사용할 수 있습니다. 단, 2회 이상 반복적인 키워드, 스팸성 키워드, 사이트와 연관이 없는 키워드가 있는 경우 검색 노출에 불이익을 받을 수 있습니다. 또한, 검색 노출만을 위하여 사이트 메인 페이지의 description 태그 내용을 자주 변경하거나 과도하게 길어서 사용자가 쉽게 사이트를 파악하지 못하는 경우도 불이익 대상에 포함될 수 있습니다.

> 간혹 페이지 내의 전체 내용을 복사해서 붙여넣거나, 제목과 동일한 경우, 사이트 내 다른 페이지들의 태그가 모두 동일한 경우, 단순히 키워드만 나열하는 경우 등이 있습니다. 이런 경우 검색 노출에 불이익을 받을 수 있으니 콘텐츠에 맞는 필요한 문구만을 간추려서 넣어주세요.

```
본문 전체를 복사해서 붙여넣기      불이익
제목과 똑같이 쓰기                불이익
사이트 내 모든 페이지가 같은 설명   불이익
키워드만 나열                    불이익
검색 노출만을 위해 메인 설명을 자주 변경 · 과도하게 긴 설명   불이익
```

> 검색 결과에 실제 표시되는 설명문과 스니펫은 검색엔진이 유저의 검색 키워드 및 의도 분석 결과를 바탕으로, 위의 태그들을 포함해 본문 내 텍스트 등 각종 정보중 가장 적합한 것을 자동 추출해 구성됩니다.

**설명문도 자동 추출이다.** 적어 둔 설명이 곧 검색 결과 문구가 되는 게 아니다.

## 오픈그래프 — 소셜용인데 네이버도 본다

> 오픈 그래프 태그는 사이트가 소셜 미디어로 공유될 때 우선적으로 활용되는 정보입니다. 그러나 네이버 검색 로봇도 해당 정보의 내용을 동시에 활용하여 페이지 분석 및 노출에 사용하는 경우가 있으므로, 가급적 같이 기입하시는 것을 권장합니다. 특히, 오픈 그래프에는 사이트의 제목, 설명과 더불어서 대표하는 이미지도 포함할 수 있습니다. 전체 포멧의 자세한 내용은 http://ogp.me를 참고하세요.

★ **"카톡·인스타 공유용" 으로만 알려진 태그인데, 네이버 검색로봇도 쓴다고 적혀 있다.**
그래서 `og:title` · `og:description` 을 대충 넣으면 검색 쪽에도 영향이 갈 수 있다.

### 대표 이미지(og:image) 기준 네 가지

> 오픈 그래프 이미지 (og:image)는 네이버 검색 결과 내에서 사이트나 페이지를 대표하는 이미지 섬네일로 활용될 수 있습니다. 입력한 이미지가 잘 활용될 수 있도록 아래와 같은 사항들을 체크해주시길 권장드립니다.

```
크기      150x150 보다 커야 한다
파일 용량  5,000 byte 이상이어야 한다
비율      가로:세로가 3:1 을 넘지 않아야 한다
고유성    문서를 대표하는 고유 이미지여야 한다
```

> 각 문서를 대표할 수 있는 고유 이미지인지 확인해주세요. 서로 다른 페이지에 중복하여 출현하는 이미지 또는 사이트 전체에 반복되는 로고 등의 이미지, 홍보 배너성 이미지의 경우 개별 페이지를 대표하는 이미지로 볼 수 없거나 검색 결과에 노출시 유저를 혼란스럽게 할 수 있어 검색엔진이 사용하지 않는 경우가 있습니다.

★ **모든 페이지에 로고를 og:image 로 넣어 두면 안 쓰일 수 있다.** 배너도 마찬가지다.

## 사장님이 확인할 것 (우리가 만든 점검표)

```
□ 메인 제목이 가게 이름(브랜드)인가 — 키워드 나열이 아니고
□ 페이지마다 제목이 다른가
□ 같은 단어가 제목에 두 번 이상 들어가지 않았나
□ 설명이 한두 문장인가 — 본문 복사·제목 복사가 아니고
□ 페이지마다 설명이 다른가
□ og:image 가 로고 하나로 다 채워져 있지 않나
□ og:image 가 150x150 보다 크고 3:1 을 안 넘나
```

## 주의

- **A등급.** 다만 「HTML 마크업 가이드」의 **다른 절**(선호 URL · 로봇 메타 태그)은 아직 못 봤다.
- 붙여 주신 내용에 **첫 소제목(「페이지 제목」) 줄이 빠져 있다.** 본문은 그 절의 첫 문장부터다.
- **가로세로 픽셀·용량 숫자는 네이버가 적은 그대로다.** 우리가 반올림하거나 바꾸지 않았다.
