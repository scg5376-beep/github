## ★ 노출에는 돈이 들지 않는다 — 문서 첫 줄이다  **A등급**

> 누가 뭐라고 하든 검색결과에 페이지가 표시되게 하는 데에는 비용이 들지 않습니다. 페이지가 최소 기술 요구사항을 충족하기만 하면 Google 검색의 색인 생성 대상이 됩니다.

**"누가 뭐라고 하든" 이라는 말까지 붙어 있다.** 구글 상위노출을 돈 받고 보장한다는 제안은
이 한 줄로 정리된다(우리가 붙인 것).

## 색인의 최소 조건 셋  **A등급**

| 요건 | 원문 | 사장님 홈페이지에서 흔히 깨지는 곳 (우리가 붙인 것) |
|---|---|---|
| **Googlebot 차단 안 됨** | 아래 인용 | 빌더의 "검색엔진 노출" 스위치가 꺼져 있음 |
| **페이지가 작동함** | HTTP 200 | 도메인 연결 실수 · 만료된 SSL |
| **색인 생성 가능한 콘텐츠** | 지원 형식 + 스팸 정책 위반 아님 | 글자가 전부 이미지 안에만 있음 |

> 페이지가 이러한 요구사항을 충족한다고 해서 페이지의 색인이 생성되는 것은 아닙니다. 색인이 생성된다는 보장은 없습니다.

★ **네이버가 "검색 등록 절차는 존재하지 않습니다" 라고 한 것과 같은 자리다.**
두 곳 다 **보장을 하지 않는다**고 스스로 밝힌다(`홈페이지-네이버에-보이게-하려면.md`).

> Google은 일반 사용자가 액세스할 수 있으며 크롤러 Googlebot이 페이지를 크롤링하지 못하도록 차단하지 않는 웹상의 페이지만 색인을 생성합니다. 페이지를 비공개로 만드는 경우(예: 로그인해야 볼 수 있는 경우) Googlebot은 페이지를 크롤링하지 않습니다. 마찬가지로 여러 메커니즘 중 하나를 사용하여 Google의 색인 생성을 차단할 경우 페이지의 색인이 생성되지 않습니다.

**로그인해야 보이는 페이지는 크롤링되지 않는다.** 회원 전용으로 막아 둔 소개 페이지가 흔한 실수다.

> Google은 HTTP 200 (success) 상태 코드로 게재되는 페이지만 색인을 생성합니다. 클라이언트 및 서버 오류 페이지의 색인은 생성되지 않았습니다. URL 검사 도구를 사용하여 특정 페이지의 HTTP 상태 코드를 확인할 수 있습니다.

## ★ robots.txt 로 막아도 주소는 남는다  **A등급**

> robots.txt 파일로 Googlebot을 차단하면 크롤링은 차단되지만, 페이지의 URL이 검색결과에 계속 표시될 수 있습니다. Google에서 페이지의 색인을 생성하지 않도록 하려면 noindex를 사용하여 Google이 URL을 크롤링하도록 허용합니다.

**흔한 오해가 정면으로 부정된 자리다.** "검색에서 빼려면 robots.txt 로 막으면 된다" 는
틀렸다. 막으면 **내용을 못 읽을 뿐 주소는 계속 뜰 수 있다.**

```
검색에서 빼고 싶다   →  noindex 를 넣고, 크롤링은 허용한다
robots.txt 로 차단   →  크롤링만 막힌다. URL 은 남을 수 있다
```

> robots.txt에 의해 차단된 페이지는 Google 검색결과에 표시될 가능성이 작습니다. Google에서 액세스할 수 없지만 검색결과에 표시하고 싶은 페이지 목록을 보려면 Search Console의 페이지 색인 생성 보고서 및 크롤링 통계 보고서를 모두 사용하세요. 보고서마다 URL에 관한 정보가 다를 수 있으므로 두 보고서를 모두 살펴보는 것이 좋습니다.

**두 보고서를 다 보라고 명시한다** — 보고서마다 URL 정보가 다를 수 있기 때문이다.

## 서치 콘솔 — 구글 쪽 웹마스터도구## 서치 콘솔 — 구글 쪽 웹마스터도구

- **소유권 확인 방법 다섯**: HTML 파일 업로드 · HTML 메타 태그 · DNS 레코드 · Google Analytics ·
  Google Tag Manager. 빌더를 쓰면 대개 메타 태그를 붙여 넣는 칸이 있다(우리가 붙인 것).
- **URL 검사** 에서 색인 생성을 요청할 수 있다. 요청 횟수에 **일일 한도**가 있지만 구글은
  정확한 수를 공개하지 않는다. 2차 자료의 10~12건은 **이용자 보고**일 뿐이다.

## 사이트맵은 작은 가게엔 필요 없을 수 있다

약 **500페이지 이하**의 작은 사이트이고 홈에서 링크를 따라 **모든 페이지에 닿는다면**
사이트맵이 필요 없을 것이라고 문서가 안내한다고 전해진다. 가게 홈페이지는 보통 열 페이지다.
**메뉴에서 안 닿는 페이지가 없는지**가 사이트맵보다 먼저다.

모바일 우선 색인이 완료돼 **모든 사이트가 Googlebot Smartphone 으로 수집·색인**된다고
전해진다. 데스크톱에서만 보이는 내용은 없는 것이 된다. 네이버도 진단 리포트에서 모바일을 보지만
공식 문구를 확보하지 못했다.
