## 구글이 페이지를 색인하는 최소 조건 셋

검색 기술 요건 문서에 따르면 색인 자격의 최소 요건은 셋이라고 전해진다.

| 요건 | 뜻 | 사장님 홈페이지에서 흔히 깨지는 곳 (우리가 붙인 것) |
|---|---|---|
| **Googlebot 이 차단되지 않음** | 공개된 페이지이고 로봇을 막지 않는다 | 빌더의 "검색엔진 노출" 스위치가 꺼져 있음 · robots.txt 가 전체 차단 |
| **페이지가 작동함** | HTTP 200 응답 | 도메인 연결 실수 · 만료된 SSL |
| **색인 가능한 콘텐츠** | 지원 파일 형식의 글자 · 스팸 정책 위반 아님 | 글자가 전부 이미지 안에만 있음 |

★ 요건을 다 채워도 **색인은 보장되지 않는다**고 문서가 못 박는다고 전해진다.
네이버가 검색 등록 절차가 없다고 한 것과 같은 자리다(`홈페이지-네이버에-보이게-하려면.md`).

## 서치 콘솔 — 구글 쪽 웹마스터도구

- **소유권 확인 방법 다섯**: HTML 파일 업로드 · HTML 메타 태그 · DNS 레코드 · Google Analytics ·
  Google Tag Manager. 빌더를 쓰면 대개 메타 태그를 붙여 넣는 칸이 있다(우리가 붙인 것).
- **URL 검사** 에서 색인 생성을 요청할 수 있다. 요청 횟수에 **일일 한도**가 있지만 구글은
  정확한 수를 공개하지 않는다. 2차 자료의 10~12건은 **이용자 보고**일 뿐이다.

## 사이트맵은 작은 가게엔 필요 없을 수 있다

약 **500페이지 이하**의 작은 사이트이고 홈에서 링크를 따라 **모든 페이지에 닿는다면**
사이트맵이 필요 없을 것이라고 문서가 안내한다고 전해진다. 가게 홈페이지는 보통 열 페이지다.
**메뉴에서 안 닿는 페이지가 없는지**가 사이트맵보다 먼저다.

## 2024-07-05 부터 모바일이 기준이다

모바일 우선 색인이 완료돼 **모든 사이트가 Googlebot Smartphone 으로 수집·색인**된다고
전해진다. 데스크톱에서만 보이는 내용은 없는 것이 된다. 네이버도 진단 리포트에서 모바일을 보지만
공식 문구를 확보하지 못했다.

## 시작 가이드에서 건질 것

- 검색결과의 **제목 링크는 title 요소와 페이지 제목들**로 만들어진다. 눈에 띄는 건 제목 링크와
  스니펫이라고 전해진다. 네이버가 title 을 브랜드명으로 쓰라는 것과 겹친다.
- **메타 키워드 태그는 순위에 쓰지 않는다**(2009 발표). 아직도 "키워드 태그 최적화" 를 파는
  곳이 있다.
