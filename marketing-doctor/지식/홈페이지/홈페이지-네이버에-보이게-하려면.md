> 블로그 글이 아니라 **내 사이트(홈페이지·쇼핑몰)** 를 네이버 웹 검색에 올리는 이야기다.

## 첫 문장부터 대행사와 다르다 — 등록 절차는 없다

네이버 FAQ(사이트 등록 및 소유확인)는 네이버 웹 검색이 **로봇이 자동 수집한 사이트 정보**를
반영하므로 **검색 등록 절차는 존재하지 않는다**고 안내한다. 검색엔진 최적화 가이드를 보고 로봇이
사이트를 잘 수집하게 하라는 것이다.

```
"네이버 사이트 등록 대행 ○○만 원"   →  등록이란 게 없다. 소유확인 대행이거나 그 이하다
"등록하면 노출 보장"                →  노출은 수집·색인 결과다. 보장할 주체가 없다
```

## 서치어드바이저(웹마스터도구)는 무엇을 해 주나

내 사이트의 **검색 수집·색인 반영 현황**을 보여주고, 검색에 친화적인 사이트로 관리하는 데 필요한
**진단 리포트**를 주는 도구라고 안내한다. 올려 주는 도구가 아니라 **살펴보는 도구**다.

## 순서 (가이드 페이지 순서를 우리가 정리)

| 단계 | 무엇을 | 가이드가 말하는 것 (전해진다) |
|---|---|---|
| 1 | **소유확인** | 수집·삭제 요청이 검색 결과에 영향을 주므로 내 사이트임을 증명한다. HTML 메타 태그 또는 HTML 파일 업로드. 아이디당 100개. **http/https 를 정확히** 고른다 |
| 2 | **robots.txt** | 로봇의 수집을 허용·제한하는 국제 권고안. IETF 가 2022-09 표준 문서 발행. **루트 디렉터리**에 둔다 |
| 3 | **주소 정리** | 여러 hostname 을 쓴다고 노출 가능성이 높아지지 않는다. 같은 내용은 **중복 판정**. 대표 URL 은 canonical 로 |
| 4 | **제목** | 메인 페이지 title 은 사이트 성격을 표현하는 **브랜드명**(상호명·서비스명 등)으로 |
| 5 | **RSS·사이트맵 제출** | 로봇이 콘텐츠 피드로 간주해 **주기적으로 재방문** |
| 6 | **수집요청** | 로봇이 아직 못 본 주요 페이지를 직접 요청. **사이트별 제한**이 있다. 갱신은 IndexNow 로도 알릴 수 있다 |
| 7 | **진단하기** | 검색 친화적인지 진단하고 문제점을 알려 준다. 노출이 안 되면 **먼저 여기서** 본다 |

**우리가 붙인 것** — 사장님이 직접 하는 건 1·5·6·7 이다. 2·3·4 는 빌더가 대개 해 두고,
직접 구축했다면 만든 사람에게 확인시킨다.

## 안 보일 때 — 네이버가 먼저 보라는 것

- **site: 검색**에 사이트가 안 나오면, 로봇이 아직 수집하지 못했거나 여러 이유로
  **수집·색인이 불가능한 문서**일 가능성이 있다고 안내한다.
- **자바스크립트 redirect** 는 로봇이 이해하기 어려우니 자제하라고 한다. 리뉴얼 뒤 사라지는
  사이트의 흔한 원인이다(우리가 붙인 것).
- Angular·React·Vue 같은 프레임워크로 만든 사이트는 **자바스크립트 검색 최적화** 페이지가
  따로 있다. AI 로 만든 사이트가 대개 여기에 해당한다(→ `홈페이지-AI로-만들면.md`).

## 빼 달라고 해도 안 뺀다

네이버는 **법률 위반·저작권 위반 같은 정책위반의 경우에만** 검색 결과에서 삭제할 수 있고,
사이트가 정상 접속되면 임의로 삭제할 수 없다고 안내한다. 반대로 말하면 **경쟁사가 신고해서
내 사이트를 내릴 수도 없다.**

## 콘텐츠 기준은 블로그와 같은 뿌리다

가이드에 **콘텐츠 작성시 권장 사항**과 **웹 콘텐츠 스팸사례** 페이지가 있다. 스팸사례는
블로그 쪽 A등급 원문(`../플랫폼/네이버/네이버가-검색에서-빼는-글.md`)과 같은 문서로 보이지만
**URL 이 달라 동일성을 확인하지 못했다.** 그래서 여기서는 그 인용문을 가져오지 않는다.
