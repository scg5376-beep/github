> 보안은 두 층이다 — **법이 시키는 것**(손님 정보를 받는 순간)과 **브라우저가 강제하는 것**(HTTPS).

## 1층 · 손님 정보를 받는 순간 법이 붙는다

문의 폼·회원가입·주문 — 이름·전화번호 하나라도 받으면 **개인정보처리자**다.

| 조문 (전해진다) | 무엇 | 소규모 가게에 걸리는 부분 |
|---|---|---|
| 개인정보보호법 **제29조** | 안전조치 의무 | 아래 고시가 구체 기준 |
| **제30조** | 개인정보 **처리방침** 수립·공개 | 홈페이지에 처리방침 페이지가 있어야 한다. 위원회 작성지침 개정본 2024-04-30 |
| **제34조** · 시행령 제39조 | 유출 통지·신고 | 알게 된 때부터 **72시간 이내** 정보주체에게 통지 |
| 안전성 확보조치 기준 고시 (**제2026-9호, 시행 2026-07-01**) | 제4조 내부 관리계획 | **1만 명 미만** 정보주체를 처리하는 **소상공인·개인·단체는 생략 가능** (제4조 제1항 단서) |
| 같은 고시 **제7조** | 암호화 | 전송 시 고유식별정보·**비밀번호** 암호화, 저장 시 비밀번호 **일방향** 암호화 |

★ **2026-03-10 개정(법률 제21445호)** 이 있다. 대규모 유출이 반복돼 반복·중대 침해 제재를
강화했다는 것이 개정 이유다. 2차 자료는 과징금 상한 전체 매출액 **3% → 10%**, **대표자 총괄책임**
(2026-09-11 시행) 을 든다 — **조문은 못 봤다.** 이 파일을 쓰는 날 기준 아흐레 뒤다.

**우리가 붙인 것** — 사장님 홈페이지에서 제일 흔한 위반은 셋이다. 처리방침 페이지가 없음 ·
비밀번호를 그대로 저장 · 문의 폼이 HTTP. 셋 다 위 표에 조문이 있다.

## 2층 · HTTPS 는 선택이 아니게 됐다

| 언제 | 누가 | 무엇 (전해진다) |
|---|---|---|
| **2018-07** | Chrome 68 | HTTP 사이트 주소창에 **Not secure** 표시 |
| **2026-10** | Chrome 154 | **항상 보안 연결 사용**이 기본. 공개 사이트에 HTTPS 가 없으면 첫 접속 전에 사용자에게 **허락을 묻는다** |

이 파일을 쓰는 시점에서 **한 달 뒤**다. HTTP 홈페이지는 손님이 경고창을 넘어야 들어온다.

- 인증서는 Let's Encrypt 가 무료로 준다. 90일짜리인 이유는 **자동 갱신을 강하게 권하되 수동도
  가능한 길이**라서라고 전해진다. **45일로 줄어든다** — 2026-05 옵트인 → 2027-02 기본 64일 →
  2028-02 기본 45일. **수동으로 갱신하는 사이트는 앞으로 반드시 끊긴다.** 빌더를 쓰면 빌더가 한다.
- 고시 제7조의 전송 암호화와 같은 자리다. **HTTPS 가 법 준수이기도 하다.**
