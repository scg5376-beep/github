# 채널별 플랫폼 공식 문서 — 남은 것 (서치-소넷 조사 2026-09-11, 설계자 정리)

확보해 `원문/` 에 넣은 것: Threads 5건(MT-03) · 유튜브 6건(YT-01~03) · Blogger 3건(GB-01·02) · 아임웹 1건(BD-01). 레지스트리 `레지스트리/플랫폼/`.
쿠팡 입점·로켓그로스 페이지는 마케팅 문구라 원문으로 넣지 않았다(수수료 문서 EC-03 만 A).

## 못 찾은 것 전체 목록

1. Threads 게시물 노출·추천 방식을 단독으로 설명하는 공식 문서 — 못 찾음
2. Threads 비즈니스 이용 안내 전용 문서(광고 아닌 일반 비즈니스 계정 운영) — 못 찾음
3. Instagram 릴스 "추천 가이드라인(Recommendation Guidelines)" 정식 help.instagram.com 페이지 — 못 찾음
4. 워터마크 있는 영상 노출 불이익에 대한 Meta/Instagram 공식 문서 — 못 찾음 (서드파티 추정 글만 존재, 발행 불가)
5. 릴스 길이·형식 기준 공식 문서(help.instagram.com) — 못 찾음
6. YouTube 검색 시스템 작동 방식 한국어(hl=ko) 정확 URL — 못 찾음(영문판만 확인)
7. 네이버 카페 검색 노출 기준 공식 문서 — 못 찾음
8. 네이버 카페 운영 정책·이용약관(광고·홍보 글 규정) — 못 찾음
9. 네이버 카페 게시글 통합검색 노출 조건 — 못 찾음
10. 네이버 카페 공식 블로그 공지 — 못 찾음
11. 티스토리 검색 노출·사이트맵·RSS 공식 공지(notice.tistory.com) — 못 찾음
12. 티스토리 애드센스 연동 공식 도움말 URL — 못 찾음
13. 티스토리 운영 정책(스팸·광고성 글) 공식 문서 URL — 못 찾음

---

확인됨 : 인스타그램(Threads 계정 생성·커뮤니티 가이드라인·광고 도입), 유튜브(커뮤니티 가이드·추천 시스템·쇼츠 길이/수익화·파트너 프로그램), 구글 블로거(시작·도메인·콘텐츠 정책), 쿠팡(입점·로켓그로스), 아임웹·카페24(도메인·결제·시작 절차) — 각 URL은 검색 결과에 실제로 노출된 것만 기재.
미확인 : 위 "못 찾은 것 전체 목록" 13건. 특히 릴스 워터마크 불이익은 서드파티 추정 글만 있어 공식 근거 없음 — 본문에 사실처럼 쓰면 안 됨.
운영자확인필요 : 네이버 카페 관련 문서 전체(help.naver.com 이 이 환경 검색에서 거의 안 잡힘) — 운영자가 브라우저로 help.naver.com 접속해 URL을 직접 캡처해서 넘겨주면 표 채울 수 있음. 티스토리 notice.tistory.com 공지 URL도 동일하게 운영자 확인 필요.

## 운영자가 열어 주시면 A 가 되는 것
- **네이버 카페 고객센터 → 「카페 검색」 「공개설정과 검색설정 안내」 「비즈센터」** — help.naver.com/service/5622 안의 항목인데 화면이 스크립트로 열려 헤들리스로 주소를 못 잡았다. 브라우저에서 항목을 열고 주소를 복사해 주시면 된다.
- **티스토리 notice.tistory.com** 검색 노출·애드센스 공지.
- **카페24 도움말** — 보안 대기 화면에 막힘.
