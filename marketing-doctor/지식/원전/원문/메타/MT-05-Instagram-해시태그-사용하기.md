- 핵심: 「하나의 게시물에 최대 5개의 태그를 사용할 수 있습니다. 5개를 초과하면 댓글이 게시되지 않습니다.」 (예전 30개에서 바뀐 것으로 보이나 변경일은 문서에 없음 → 미확인)

다른 질문이 있습니다
게시물의 캡션이나 댓글에 해시태그를 추가할 수 있습니다. 계정을 전체 공개로 설정하고 게시물에 해시태그를 추가하면 게시물이 해당 해시태그 페이지에 표시됩니다.
사진이나 동영상에 해시태그 추가하기
사진 또는 동영상을 찍거나 업로드합니다.
사진에 필터를 추가하도록 선택하거나 동영상을 다듬고 다음을 클릭합니다.
캡션 입력...을 클릭하고 # 기호와 텍스트 또는 이모티콘을 차례로 입력합니다(예: #꽃).
공유를 클릭합니다.
이미 업로드한 게시물에 해시태그를 추가하려면 캡션을 수정하거나 사진의 댓글에 해시태그를 포함합니다.
게시물에 해시태그를 추가한 후 해당 해시태그를 클릭하면 사람들이 동일한 해시태그를 사용하여 업로드한 모든 사진과 동영상을 볼 수 있는 페이지가 표시됩니다.
유의 사항
프로필을 비공개로 설정한 사람이 게시물에 태그를 다는 경우 해당 게시물은 해시태그 페이지에 전체 공개되지 않습니다.
해시태그에 숫자를 사용할 수 있지만 공백과 $ 또는 % 등의 특수 문자는 사용할 수 없습니다.
자신의 게시물에만 태그를 달 수 있으며, 다른 사람의 사진/동영상에는 태그를 달 수 없습니다.
하나의 게시물에 최대 5개의 태그를 사용할 수 있습니다. 하나의 사진/동영상에 포함된 태그 수가 5개를 초과하면 댓글이 게시되지 않습니다.
