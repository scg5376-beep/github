# 디스플레이 광고 알아보기

토스 디스플레이 광고는 토스 앱에서 상품·앱·서비스·혜택을 살펴보는 유저에게 광고를 보여주고, 캠페인 목표에 맞는 행동으로 연결해요.


## 토스 디스플레이 광고의 특징

* **탐색 흐름에 맞춰 광고를 보여줘요.** 쇼핑·앱·서비스·혜택처럼 유저가 관심을 갖고 살펴보는 지면에 광고가 노출돼요.
* **관심을 보인 유저를 다시 만나요.** 브릿지 페이지를 쓰는 방식에서는 유저가 본 상품·앱·서비스가 홈의 최근 본 영역에 다시 노출될 수 있어요. 재노출 자체에는 과금되지 않아요.
* **목표에 맞춰 자동으로 최적화해요.** 오토 타겟팅으로 반응할 가능성이 높은 유저를 찾고, 캠페인 목표에 맞는 입찰 방식으로 성과를 최적화해요.

## 토스 네이티브 광고 알아보기 <a href="#native-a-ds" id="native-a-ds"></a>

토스 디스플레이 광고의 일부 캠페인 목표와 등록 방식은 **토스 네이티브 광고**로 운영돼요. 네이티브 광고는 유저의 탐색 흐름 안에서 자연스럽게 노출되고, 광고를 누르면 브릿지 페이지에서 자세한 정보를 확인한 뒤 광고주 랜딩이나 전환 동선으로 이어져요.

다음 캠페인 목표와 등록 방식이 토스 네이티브 광고에 해당해요.

* [구매 유도하기 > 카탈로그 연동](/guide/a-d/purchase.md#catalog-flow)
* [앱 설치 유도하기](/guide/a-d/app-install.md#app-install-overview)
* [잠재고객 모으기 > 토스 양식 사용](/guide/a-d/lead-generation.md#toss-form-flow)
* [잠재고객 모으기 > 외부 url 사용](/guide/a-d/lead-generation.md)

### 네이티브 광고가 유저와 만나는 흐름

브릿지 페이지를 쓰는 방식은 아래 흐름으로 운영돼요.

1. 유저가 쇼핑, 앱, 서비스·혜택 탐색 지면에서 광고를 발견해요.
2. 광고를 클릭하면 브릿지 페이지에서 상품·앱·서비스 정보를 확인해요.
3. 유저가 배너 또는 소개 화면(브릿지 페이지)의 CTA를 클릭하면 광고주 랜딩 또는 전환 동선으로 이동해요. 광고비는 랜딩 직전 클릭을 기준으로 과금돼요.
4. 관심을 보인 유저에게는 홈의 최근 본 영역에서 광고가 다시 노출되어, 후속 탐색과 전환으로 이어질 수 있어요.

브릿지 페이지 없이 배너 소재를 직접 등록하는 방식은 광고를 클릭한 유저를 설정한 랜딩 URL로 바로 연결하고, 배너 클릭을 기준으로 과금돼요. 어떤 목표와 방식이 브릿지 페이지를 쓰는지는 아래 표에서 확인할 수 있어요.

## 캠페인 목표 고르기

캠페인을 만들 때는 가장 먼저 캠페인 목표를 선택해요. 목표에 따라 광고가 노출되는 탐색 맥락과 과금 기준, 준비할 정보가 달라져요.

쇼핑 탐색 맥락에서 상품을 노출하고 구매 동선으로 연결하고 싶다면 구매 유도하기를 선택해요. 상품을 직접 등록하거나 카탈로그를 연동해 광고를 만들어요.

[구매 유도하기](/guide/a-d/purchase.md)

앱 탐색 맥락에서 앱 정보를 소개하고 설치, 재실행, 게임 플레이를 유도하고 싶다면 앱 설치 유도하기를 선택해요.

[앱 설치 유도하기](/guide/a-d/app-install.md)

서비스·혜택 탐색 맥락에서 관심을 유도하고 상담 신청·가입·리드 수집으로 연결하고 싶다면 잠재고객 모으기를 선택해요.

[잠재고객 모으기](/guide/a-d/lead-generation.md)

중간 화면 없이 광고를 클릭한 유저를 하나의 랜딩 URL로 바로 연결해 방문을 늘리고 싶다면 방문 유도하기를 선택해요.

[방문 유도하기](/guide/a-d/website-visit.md)

## 목표와 등록 방식 한눈에 비교하기 <a href="#goal-method-comparison" id="goal-method-comparison"></a>

구매 유도하기와 잠재고객 모으기는 캠페인을 만들 때 등록 방식도 함께 선택해요. 같은 목표라도 어떤 방식을 고르느냐에 따라 과금 기준부터 타겟팅, 준비물까지 달라지니, 아래 표에서 차이를 먼저 확인해 주세요.

| 목표 (등록 방식)              | 과금 기준                                | 입찰 방식                    | 타겟팅   | 필수 준비물                  |
| ----------------------- | ------------------------------------ | ------------------------ | ----- | ----------------------- |
| **구매 유도하기** (직접 등록)     | 광고 배너 클릭 시 (CPC)                     | 자동 입찰(전환 최대)·직접 입찰(CPC)  | 오토·직접 | 전환 및 추적 연동              |
| **구매 유도하기** (카탈로그 연동)   | 브릿지 페이지에서 광고주 랜딩으로 이동하는 클릭 시         | 목표 광고 수익률(tROAS)         | 오토    | 전환 및 추적 연동, 상품 카탈로그     |
| **앱 설치 유도하기**           | 브릿지 페이지에서 광고주 랜딩으로 이동하는 클릭 시         | 목표 전환당 비용(tCPA)          | 오토    | 앱 MAT 연동, 앱 정보 수집·활용 동의 |
| **잠재고객 모으기** (토스 양식 사용) | 광고 배너 또는 브릿지 페이지 내 CTA 버튼 클릭 시 (CPC) | 목표 전환당 비용(tCPA)          | 오토    | 없음                      |
| **잠재고객 모으기** (URL로 사용)  | 광고 배너 또는 브릿지 페이지 내 CTA 버튼 클릭 시 (CPC) | 목표 전환당 비용(tCPA)          | 오토·직접 | 전환 및 추적 연동              |
| **방문 유도하기**             | 광고 배너 클릭 시 (CPC)                     | 자동 입찰(클릭 최대화)·직접 입찰(CPC) | 오토·직접 | 없음 (전환 및 추적 연동은 선택)     |

세부 노출 지면과 과금 조건은 운영 상황에 따라 달라질 수 있으니, 집행 전에 각 목표 문서에서 최신 조건을 확인해 주세요.

## 캠페인 구조 이해하기 <a href="#campaign-structure" id="campaign-structure"></a>

어떤 목표를 선택하더라도 디스플레이 광고는 캠페인, 광고세트, 소재의 세 단계로 만들어요.

| 단계   | 설정 내용                                           |
| ---- | ----------------------------------------------- |
| 캠페인  | 광고 목표, 집행 기간, 총예산                               |
| 광고세트 | 일 예산, 입찰 방식, 타겟, 노출 일정                          |
| 소재   | 목표에 따라 카탈로그 상품, 앱 정보, 고객 수집 양식, 문구·이미지·영상 등을 설정 |

하나의 캠페인 아래에 여러 광고세트를, 하나의 광고세트 아래에 여러 소재를 만들 수 있어요. 목표별 문서에서는 이 구조에 따라 광고를 만드는 순서를 안내해요.
