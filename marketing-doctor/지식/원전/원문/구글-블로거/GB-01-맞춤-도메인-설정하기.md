맞춤 도메인 설정하기

중요: 맞춤 도메인에 CAA 레코드를 사용하는 경우 letsencrypt.org용 레코드를 추가해야 합니다. 추가하지 않으면 Blogger에서 SSL 인증서를 만들거나 갱신하지 않습니다.

블로그의 웹사이트 주소를 맞춤설정하려면 도메인을 구입하세요. 관리자는 Blogger를 통해 등록된 도메인을 관리할 수 있습니다.

블로그에서 도메인 설정하기

도메인 공급업체에서 도메인을 구매하면 Blogger에서 도메인을 설정하고 도메인 설정을 관리할 수 있습니다.

 중요: 'blogspot.com' 주소가 맞춤 도메인으로 리디렉션되기까지 최대 24시간이 걸릴 수 있습니다.

Blogger에서 도메인 설정하기
Blogger에 로그인합니다.
왼쪽 상단에서 블로그를 선택합니다.
왼쪽 메뉴에서 설정을 클릭합니다.
'게시' 아래에서 맞춤 도메인을 클릭합니다.
구매한 도메인의 URL을 입력합니다.
저장을 클릭합니다.
CNAME 2개가 포함된 오류가 표시됩니다.
블로그 CNAME: 이름에 'blog.' 또는 'www.' 같은 하위 도메인 이름을 입력합니다. 도착 URL에 'ghs.google.com'을 입력합니다.
보안 CNAME: '이름: XXX, 도착 URL: XXX'. 이는 사용자별로 다르며 내 블로그와 Google 계정에만 해당됩니다.
도메인 공급업체 설정 설정하기
도메인 제공업체의 웹사이트로 이동합니다.
제어판에서 DNS(도메인 이름 시스템)를 찾습니다.
'이름, 라벨 또는 호스트' 아래에 위 5단계에서 입력한 하위 도메인을 입력합니다.
'도착, 타겟 또는 연결 대상' 아래에 'ghs.google.com'을 입력합니다.
내 블로그 및 Google 계정과 관련된 두 번째 CNAME의 세부정보를 입력합니다.
DNS 설정이 활성화되려면 1시간 이상 기다려야 합니다.
Blogger에서 도메인 설정을 반복합니다.
하위 도메인이 없는 URL을 블로그 URL로 리디렉션하기

독자를 'mydomain.com'에서 'www.mydomain.com'으로 리디렉션하려면 다음 안내에 따라 네이키드 도메인 리디렉션을 설정합니다.

도메인 제공업체의 웹사이트로 이동합니다.
DNS 설정을 엽니다.
Google IP를 가리키는 다음 4개의 A 레코드를 추가합니다. 'mydomain.com'의 A 레코드가 이미 있는 경우 기존 A 레코드를 삭제해야 합니다.

맞춤 도메인 설정 관련 문제 해결하기

문제가 발생한 경우 다음 단계를 따르세요.

도메인을 설정할 때 2개의 CNAME을 입력하지 않아도 됩니다.
'이름, 라벨 또는 호스트' CNAME이 올바른지 확인합니다.
맞춤 도메인이 작동하지 않으면 단계를 다시 시도하기 전에 먼저 기다려 보세요. 문제가 있으면 도메인 제공업체에 문의하세요.
