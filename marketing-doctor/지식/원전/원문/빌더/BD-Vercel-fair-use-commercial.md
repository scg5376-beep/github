# Vercel Docs 「Fair use guidelines」 — Commercial usage
# https://vercel.com/docs/limits/fair-use-guidelines
# 받은 날 2026-09-17 · curl · 본문 발췌(Commercial usage 절)

Commercial usage Hobby teams are restricted to non-commercial personal use only. All commercial usage of the platform requires either a Pro or Enterprise plan. Commercial usage is defined as any Deployment that is used for the purpose of financial gain of anyone involved in any part of the production of the project, including a paid employee or consultant writing the code.
