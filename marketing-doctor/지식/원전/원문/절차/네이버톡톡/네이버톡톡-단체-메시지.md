# 네이버 톡톡파트너센터 고객센터 「단체 메시지 기능 활용 방법」
- 출처: https://help.naver.com/service/11830/contents/20135
- 확인: 2026-09-20 (헤들리스)
- 등급: A 공식 도움말

단체 메시지는 톡톡 친구에게 스마트 스토어의 이벤트나 소식을 전달하는 기능입니다.
단체 메시지 발송 방법
1. 톡톡 파트너 센터 > 내 계정 > 계정 관리 > 마케팅 관리 > 단체 메시지로 이동합니다.
톡톡 파트너 센터 바로 가기
※ 단체 메시지는 PC에서 만 발송할 수 있습니다.
2. 메시지에 첨부할 이미지, 내용, 혜택 등을 기재합니다.
3. 전송하기 버튼을 클릭하면 전송이 완료됩니다.
단체 메시지 세부 기능 살펴보기
1. 이미지: 단체 메시지 내용 상단에 이미지를 삽입합니다.
1) 이미지 사이즈 기준
- 이미지의 너비는 최소 150픽셀 이상 되어야 합니다.
- 가로와 세로의 비율이  1:2 이상 차이가 나지 않아야 합니다.
즉, 정사각형, 가로가 더 긴 직사각형은 가능, 세로가 긴 직사각형(비율이 1:2 이상)은 불가합니다.
좌우 여백 없이 보기 좋은 꽉 찬 이미지로 보이기 위해 변경된 부분이니, 업로드할 때 이미지가 가이드에 맞는지 체크 바랍니다.
예시)
- 가로 사이즈가 150픽셀 이하라면, 업로드가 불가합니다.
- 가로가 150픽셀이라면, 세로는 300픽셀을 넘어갈 수 없습니다. (1:2 비율)
※ 단, 가로와 세로의 비율이 꼭 1:2여야 하는 것은 아닙니다. (1:1이나 2:1은 가능하지만 1:3은 어렵습니다)
2. 링크/혜택 : 메시지를 받는 톡톡 친구에게 쿠폰을 발송하거나 사이트 링크를 전송합니다.
1) 링크를 여러 개 첨부할 수 있습니다.
하나의 링크만 첨부 가능했던 전과 달리, 최대 4개의 링크를 텍스트 하단에 첨부할 수 있습니다.
이용 방식은 동일합니다.
마케팅관리 단체 메시지 메뉴에 들어갑니다.
① 링크/혜택 영역에서 첨부를 선택합니다.
② 첨부 설정 버튼을 누르면 오른쪽 설정 메뉴가 등장합니다.
③ 링크 추가 버튼을 추가하면 내용을 입력할 수 있습니다.
※ 엑스 버튼을 눌러 추가하신 링크 영역을 삭제할 수 있습니다.
※ 추가한 영역에 대해서는 모든 내용이 입력되어야 합니다.
※ 각 링크의 '확인'버튼을 눌러 주소가 잘 되었는지 확인이 되어야 하단 첨부하기 적용이 가능합니다.
2) 혜택은 스마트 스토어 판매자 센터에서 발급한 쿠폰과 오프라인, 외부 사이트의 설정으로 첨부할 수 있습니다.
링크/혜택 첨부 방법 자세히 확인하기
3. 저장된 메시지 불러오기 : 이전에 전송했던 메시지 내용이나, 임시 저장 내용을 불러올 수 있습니다.
1) 본문 내용은 20줄까지 작성 가능
광고성 정보 메시지는 주요한 정보가 던져져야 합니다.
고객은 네이버 앱으로 푸시를 받고 모바일에서 메시지를 읽기 때문에, 한 번에 들어올 수 있는 핵심 문구가 중요합니다.
너무 긴 텍스트로 가독성이 떨어지는 문제를 줄이기 위해 텍스트 줄 수를 최대 20줄까지만 제한합니다.
4. 타깃: 성별, 연령, 이전 메시지 수신 여부를 설정하여 원하는 대상자에게 발송할 수 있습니다.
단체 메시지 전송량 기준
단체 메시지는 과도한 광고성 메시지 발송으로 겪는 불편함을 줄이기 위해 제한된 전송량 내에서만 발송할 수 있습니다.
▲ 단체 메시지 전송량
톡톡 친구가 100명이라면 100명에게 전송이 가능합니다.
전송량의 경우 내가 모은 톡톡 친구 수만큼 주어지는 값으로 1,000명의 친구가 있다면 1,000명에게 메시지 발송이 가능합니다.
단체 메시지는 월 1회만 발송이 가능하며, 전송 량은 매월 1일 친구 수만큼 자동 충전됩니다.
새롭게 추가된 톡톡 친구가 있다면 매주 월요일에 전주에 추가된 친구 수만큼 전송 량이 충전됩니다.
새롭게 추가된 톡톡 친구에 대한 전송량 충전 기준은 아래의 예시를 참고하세요.
예시)
1월 1일에 친구를 100명 보유했다면 = 전송 가능 메시지 수 100건
1주 차에 친구 10명이 증가했다면, 차주 월요일 10건 추가 = 110건 발송 가능
2주 차에 친구 10명이 증가했다면, 차주 월요일 10건 추가 = 120건 발송 가능
3주 차에 친구 20명이 증가했다면, 차주 월요일 20건 추가 = 140건 발송 가능
4주 차에 전체에게 단체 메시지를 발송했다면, 140건 차감 = 0건 발송 가능
2월 1일 기준, 보유한 친구 수는 140명이기 때문에 = 단체 메시지 140건 충전
※ 단체 메시지 발송 유의 사항
1. 단체 메시지 발송 전 아래의 유의 사항을 참고하세요.
단체 메시지 작성 유의 사항 바로가기
2. 단체 메시지 하단에 프로필 전화번호가 자동으로 추가됩니다. 관련 참고 사항
3. 톡톡 친구 1명에 메시지 발송 건 1건이 차감됩니다.
4. 새롭게 추가된 친구는 매주 월요일에 추가된 친구 수만큼 전송량이 충전됩니다.
