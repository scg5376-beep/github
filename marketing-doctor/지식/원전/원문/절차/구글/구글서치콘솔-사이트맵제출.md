사이트맵 보고서를 사용하여 사이트맵 관리하기

사이트맵 보고서를 사용하여 속성의 새로운 사이트맵에 관해 Google에 알리고, 사이트맵 제출 기록을 확인하고, Google에서 제출된 사이트맵을 파싱할 때 어떤 문제가 발견되었는지 알아보세요.

사이트맵 보고서 열기

 

사이트맵이란 무엇인가요? 이 보고서가 꼭 필요한가요?

사이트맵은 사이트에 있는 파일로, 내 사이트에서 Google이 알아야 하는 페이지에 관한 정보를 담고 있습니다.

Squarespace 또는 Wix 등의 웹 호스팅 서비스를 사용하면 이러한 서비스에서 사이트맵을 관리할 수도 있으며 이 경우 직접 사이트맵을 만들거나 이 보고서를 사용하지 않아도 됩니다. 호스팅 업체를 검색하여 사이트맵에 관한 정보를 알아보세요.
사이트의 규모가 작고(작다는 것은 사이트에 있는 페이지가 500개 이하임을 의미함) 홈페이지에서 한 개 이상의 링크로 사이트의 모든 페이지를 방문할 수 있다면 사이트맵이나 이 보고서를 사용하지 않아도 됩니다. 이 경우 홈페이지의 색인 생성을 요청하세요. 다만, 앞서 언급한 웹 호스팅 서비스를 사용하는 경우에는 아무 작업도 하지 않아도 됩니다.

사이트맵 크롤링 일정

사이트맵이 제출되는 즉시 Google에서 크롤링합니다. 요청에 성공하면 Google은 사이트 크롤링 일정과 무관한 속도로 계속 사이트맵을 다시 크롤링합니다.

사이트맵을 가져오거나 파싱하는 데 실패하면 Google에서 며칠 동안 계속 사이트맵을 가져오고 처리하려고 시도합니다. 그러나 시도가 계속 실패하면 Google에서 URL 크롤링을 중지합니다. 일반적으로 사이트맵을 가져오고 읽을 수 있는 한 사이트맵 내의 개별 URL에 영향을 미치는 문제가 Google이 계속 사이트맵을 읽지 못하게 만들지는 않습니다.

보고서 읽기
최상위 사이트맵 보고서 페이지에서 이 보고서 또는 API를 사용하여 제출된 모든 사이트맵에 대한 Google의 요청 상태를 확인할 수 있습니다. 보고서에는 각 사이트맵의 마지막 요청 상태가 표시됩니다. 각 사이트맵에는 마지막 요청 상태를 보여주는 다음 값 중 하나가 표시됩니다.
성공: 사이트맵을 가져와서 아무런 오류 없이 읽었습니다.
가져올 수 없음: Google이 사이트맵을 가져올 수 없습니다.
사이트맵에 X개의 오류가 있음: 사이트맵을 가져와서 부분적으로 읽을 수 있지만 오류가 발생했습니다.
특정 사이트맵을 클릭하여 사이트맵에 관한 정보 및 요청을 보여주는 세부정보 페이지를 확인합니다.
세부정보 페이지에 사이트맵을 읽을 수 없음이라고 표시되면 세부정보 페이지에 표시된 대로 이러한 이유 중 하나로 인해 가져오기가 실패한 것입니다. 오류 아래의 섹션을 펼쳐 자세한 내용을 확인하세요. 문제를 해결한 후 사이트맵을 보고서에 다시 제출해 주세요. 사이트맵을 가져오는 데 실패하면 Google이 몇 번 더 시도하다가 결국 사이트맵 읽기를 중지합니다.
세부정보 페이지에 사이트맵을 읽을 수 있지만 오류가 있음이라고 표시되는 경우 사이트맵의 세부정보 페이지에 오류 목록이 표시됩니다. 오류 아래의 섹션을 펼쳐 오류에 관해 자세히 알아보세요. 여기에서 이러한 오류와 해결 방법 자세히 알아보기

중요:

이 보고서에는 이 보고서 또는 API를 통해 제출한 사이트맵만 표시됩니다. robots.txt 참조 또는 기타 검색 방법을 통해 발견된 사이트맵은 표시되지 않습니다. 하지만 Google에서 다른 방법을 통해 이미 사이트맵을 발견했더라도 이 보고서를 이용하여 사이트맵을 제출하면 성공률 및 오류율을 추적할 수 있습니다.
사이트맵 보고서에는 현재 속성의 사이트맵만 표시합니다. 표시될 것으로 예상되는 사이트맵이 표시되지 않으면 http와 https 또는 www와 www이 아닌 속성을 혼동하지 않았는지 확인합니다.
Google에서 여러 번 시도한 후에도 사이트맵을 가져올 수 없으면 사이트맵 읽기를 중지합니다. 오류를 수정하고 사이트맵을 다시 제출해야 합니다.
Google이 사이트맵을 읽을 수 있다면 그 정보를 기억합니다. 나중에 사이트맵 읽기에 실패하거나 성공해도 Google이 이전 읽기의 정보를 '삭제'하지는 않습니다. 하지만 주어진 URL에 관한 새로운 정보가 해당 URL에 관한 이전 정보를 덮어씁니다.
사이트맵을 통해 이미지, 동영상, 뉴스 URL을 제출할 수 있습니다. 하지만 사이트맵 보고서에서는 현재 이러한 유형의 URL에 관한 데이터가 표시되지 않습니다.
보고서에는 제출된 요청이 최대 1,000개 표시될 수 있습니다. 추가로 제출할 수도 있지만 여기에는 1,000개까지만 표시됩니다(제출 순으로 표시되지 않음). 현재 Search Console에서 추가 요청을 볼 수 있는 방법은 없습니다.

 

각 사이트맵에 다음 정보가 표시됩니다.

사이트맵 URL
사이트맵을 제출할 때 명시된 URL입니다. 리디렉션을 통해 이동하지 않습니다. 이 보고서 또는 API를 사용하여 제출된 사이트맵만 여기에 표시됩니다.
유형
사이트맵의 유형입니다. 가능한 값은 다음과 같습니다.
사이트맵: XML 또는 텍스트 형식의 사이트맵입니다.
사이트맵 색인: 여러 사이트맵의 한 사이트맵입니다.
RSS: RSS 피드 양식의 사이트맵입니다.
Atom: Atom 피드 양식의 사이트맵입니다.
알 수 없음: 제출한 파일이 알려진 사이트맵 유형이 아니거나 사이트맵이 아직 처리되지 않았습니다.
제출됨
이 보고서를 사용하여 사이트맵을 Google에 마지막으로 제출한 날짜입니다.
마지막으로 읽은 날짜
Google에서 사이트맵을 마지막으로 가져온 시간입니다. Google에서 사이트맵을 가져올 수 있는 경우에만 표시됩니다.
상태
마지막으로 크롤링했을 때의 상태입니다. 가능한 값은 다음과 같습니다.
성공: 사이트맵이 오류 없이 로드 및 처리되었습니다. 모든 URL이 크롤링 대기 상태로 전환됩니다.
오류 발생: 사이트맵을 가져올 수 있지만 오류가 하나 이상 있습니다. 사이트맵에서 오류 없이 파싱할 수 있는 URL은 모두 크롤링 대기열에 추가됩니다. 표에 있는 사이트맵을 클릭하여 자세한 내용과 함께 오류 목록을 확인하세요. 아래에서 파싱 오류 설명 전문을 확인하세요.
가져올 수 없음: 어떤 이유로든 사이트맵을 가져올 수 없습니다. 가져오기 오류 문제의 해결 방법을 참고하세요.
발견된 페이지
사이트맵에서 파싱된 페이지 URL의 수입니다. 사이트맵 색인의 경우에는 모든 하위 사이트맵에 있는 모든 URL의 수를 나타냅니다. 중복 URL은 한 번만 계산됩니다. 사이트맵에서 발견된 페이지 URL이 Google에 의해 크롤링되거나 색인 생성되었다는 보장은 없습니다. 사이트맵별로 페이지 색인 생성 보고서를 필터링하여 이 사이트맵의 색인이 생성된 페이지 URL 수를 확인할 수 있습니다.
발견한 동영상
사이트맵에서 파싱된 동영상 URL의 수입니다. 이러한 URL이 Google에 의해 크롤링되거나 색인 생성될 것이라고 보장되지는 않습니다. 사이트맵별로 동영상 페이지 색인 생성 보고서를 필터링하면 색인이 생성된 동영상이 있는 이 사이트맵의 페이지 URL 수를 확인할 수 있습니다. Search Console은 사이트맵에 제공된 동영상 URL과 다른 동영상 URL의 색인이 생성되었는지 여부를 표시합니다. 여기에 나열된 사이트맵은 Google이 크롤링할 때 색인이 생성된 페이지 중 동영상이 포함된 페이지가 포함된 경우 동영상 페이지 색인 생성 보고서에 연결됩니다.
 색인 생성 범위 보기
클릭하면 이 사이트맵에 있는 모든 URL의 색인 범위를 보여 주는 보고서가 열립니다. 사이트맵 색인의 경우에는 이미 크롤링된 하위 사이트맵에 있는 모든 URL이 포함됩니다.

 

사이트맵이 표시되지 않음

사이트맵이 보고서에 표시되지 않는 몇 가지 이유는 다음과 같습니다.

다른 속성에 있음: 하나의 속성에 연결된 사이트맵은 다른 속성에 표시되지 않습니다. 따라서 사이트 http://example.com과 관련하여 제출한 사이트맵은 http://m.example.com이나 https://example.com의 사이트맵 보고서에는 표시되지 않습니다. 이 문제를 해결하려면 사이트의 모든 버전을 추가했는지 확인하세요.
이 보고서 또는 API를 사용하여 사이트맵을 제출하지 않았음: 이 보고서 또는 Search Console API를 사용하여 제출한 사이트맵만 표시되며, 다른 방법을 사용하여 찾거나 제출한 사이트맵은 Google에서 찾아서 사용할 수 있더라도 보고서에는 표시되지 않습니다.
