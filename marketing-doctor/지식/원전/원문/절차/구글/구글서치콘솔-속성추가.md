Search Console에 웹사이트 또는 플랫폼 속성 추가하기

속성은 Search Console에서 검사하거나 관리할 수 있는 개별 애셋을 가리키는 Search Console의 용어입니다. 속성은 검사하거나 관리할 수 있는 개별 애셋을 가리키는 Search Console의 용어입니다.

웹사이트 속성은 지정된 도메인 또는 URL 접두사를 공유하는 모든 페이지를 포함하는 웹사이트입니다. 
플랫폼 속성은 Instagram, TikTok, X, YouTube와 같은 지원되는 플랫폼에서의 인지도입니다.

 여러 속성을 관리하고 Search Console의 속성 선택기를 사용하여 확인하거나 관리할 속성을 선택할 수 있습니다.

웹사이트 또는 플랫폼 속성을 계정에 추가하려면 먼저 사이트 (또는 사이트의 적절한 섹션), 계정 또는 채널의 소유자임을 증명해야 Search Console 계정에 추가할 수 있습니다. 추적하는 항목에 따라 다음과 같은 속성을 만들 수 있습니다.

전체 웹사이트 도메인 (예: example.com)
웹사이트의 특정 하위 경로 (예: example.com/clothing/)
플랫폼 속성 (예: instagram.com/username)

소유권을 증명할 수 없는 경우 다른 속성 소유자에게 속성 액세스 권한 부여를 요청할 수 있습니다.

Search Console 계정에 최대 1,000개의 속성을 추가할 수 있습니다.

플랫폼 속성

Search Console은 Google 검색에서 플랫폼 계정 또는 채널(예: Instagram, TikTok, X, YouTube)의 실적을 추적하려는 크리에이터를 위한 플랫폼 속성을 지원합니다. 플랫폼 속성에 대해 자세히 알아보세요.

인증: 기존 웹사이트 속성을 통한 자동 연결 또는 직접 플랫폼 로그인

예: instagram.com/username

이 기능은 점진적으로 출시되고 있으므로 아직 일부 사용자에게 제공되지 않을 수 있습니다.
새 속성 추가하기

다른 사용자가 나에게 속성에 대한 권한을 부여했다면 Search Console을 열고 속성 선택기를 사용하여 속성을 선택하기만 하면 됩니다. 권한이 없는 경우 아래에 설명된 대로 Search Console 계정에 새 속성을 추가해야 합니다.

속성을 추가해도 Google 검색에서 웹사이트 또는 플랫폼 속성에 영향을 미치지는 않으며, Google에서의 사이트 실적을 추적할 수 있게 될 뿐입니다. 작업을 한 번에 완료하지 않거나 설정 문제가 있더라도 웹사이트는 손상되지 않습니다.

새 속성을 추가하려면 다음 단계를 따르세요.

Search Console 페이지에서 속성 선택기 드롭다운을 열거나 여기를 클릭합니다.
드롭다운에서 + 속성 추가를 선택합니다.
추가할 속성 유형을 선택합니다.
웹사이트 속성
플랫폼 속성 (Instagram, TikTok, X, YouTube)
Google에서 호스팅하는 속성(Sites, Blogger, Workspace)

4. 인증 방법을 선택하라는 메시지가 표시됩니다. 인증 방법을 선택하면 해당 방법에 필요한 인증 단계가 표시됩니다. 즉시 인증하거나 설정을 저장하고 나중에 프로세스를 다시 시작할 수 있습니다.

즉시 인증하려면 팝업창을 닫지 않고 설명된 인증 단계를 따른 다음 팝업창에서 인증을 클릭합니다. 이 단계를 진행하는 데 시간이 걸린다면 언제든지 설정을 저장하고 나중에 절차를 다시 시작할 수 있습니다(다음에 설명됨).
일시중지하고 나중에 절차를 재개하려면 나중에 인증을 클릭하여 현재 상태를 저장하고 팝업을 닫고 편할 때 사이트를 인증할 수 있습니다. 필수 인증 단계를 실행한 후 탐색 메뉴의 속성 선택기에서 저장된(미인증) 속성을 선택하고 인증을 선택하여 인증을 완료합니다.

5. 며칠 후 데이터가 속성에 표시되기 시작합니다. 속성이 인증되지 않았어도 누군가 Search Console 계정에 속성을 추가하면 속성 데이터 수집이 바로 시작됩니다. 인증된 소유자가 있는지에 관계없이 어떤 사용자든 계정에 해당 속성을 갖고 있는 이상 데이터 수집이 계속됩니다. 인증 후 며칠이 지나도 속성에 데이터가 없으면 사이트가 Google 검색에 노출되지 않았거나 URL을 잘못 지정했기 때문일 수 있습니다 예를 들어, URL 접두사 속성에 https가 아닌 http를 지정했을 수 있습니다.

속성 URL에서 라틴어 이외 문자 지원
Search Console은 사이트 URL로 IDNA(Internationalizing Domain Names in Applications)를 지원합니다. 평소와 같이 도메인 이름을 입력하면 Search Console에 올바르게 표시됩니다. 예를 들어 http://bücher.example.com/ 입력란에 http://bücher.example.com/을 입력하면 정확하게 표시됩니다.
삭제된 속성 다시 추가하기

속성에 인증된 소유자가 있는 경우 인증하지 않고 삭제된 속성을 다시 추가할 수 있습니다.

속성을 다시 추가할 때는 위의 1~3단계에 설명된 것처럼 속성을 추가하기만 하면 자동으로 재인증됩니다.
