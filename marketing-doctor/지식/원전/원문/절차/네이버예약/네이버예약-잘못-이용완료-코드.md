# 네이버 예약주문 사업자 고객센터 「아직 사용 전인데 잘못 완료(사용처리)한 경우」
- 출처: https://help.naver.com/service/11712/contents/18654
- 확인: 2026-09-20 (헤들리스)
- 등급: A 공식 도움말

사용하지 않은 예약 건을 이용자(예약자)가 실수로 이용완료를 누른 경우 업체 운영에 맞게 이용자에게 사용 가능 또는 사용 불가를 안내하면 됩니다.아울러, 이용완료를 확정으로 변경할 수 없습니다.사업자 재량(업체 재량)으로 이용자가 예약을 사용할 수 있다면 해당 예약 건을 별도 관리하여 이용자 방문 시 사용하도록 안내하면 됩니다.위와 같은 상황을 예방하기 위해 업체 직원만 알고 있는 이용완료 코드를 설정할 수 있습니다.이용완료 코드 설정 시 이용완료를 눌렀을 때 이용완료 코드를 입력하는 칸이 노출됩니다.올바른 이용완료 코드를 입력하지 않으면 이용완료 되지 않습니다.이용완료 코드 설정 방법1. 스마트플레이스에 접속합니다.2. 예약/주문을 누릅니다.3. 예약 서비스명(업체명, 공연명)을 누릅니다.4. 예약(예약·주문)을 누릅니다.5. 설정을 누릅니다.6. 운영설정을 누릅니다.7. 모바일티켓 내 이용완료 버튼에서 이용완료 코드를 사용으로 변경합니다.8. 1~4자리의 숫자 코드를 입력합니다.
