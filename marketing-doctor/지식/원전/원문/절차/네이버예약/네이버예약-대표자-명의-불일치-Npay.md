# 네이버 예약주문 사업자 고객센터 「대표자 명의 불일치로 Npay 이용불가 시 해소 요청」
- 출처: https://help.naver.com/service/11712/contents/18602
- 확인: 2026-09-20 (헤들리스)
- 등급: A 공식 도움말

예약/주문 서비스 관리자 아이디 명의와 사업자등록증 내 대표자 명의(공동사업자 명의)가 일치하지 않으면 "네이버 ID의 이름과 대표자명이 일치하지 않아 가입할 수 없습니다." 로 노출되고, Npay가 이용불가로 확인될 수 있습니다.이 경우 실명인증된 대표자 명의의 네이버 아이디로 예약/주문 서비스를 위임한 뒤 Npay를 다시 가입해야 합니다.이용불가 상태에서는 다시 Npay를 가입할 수 없기 때문에 고객센터에서 Npay 가입 신청을 철회해야 합니다.현재 네이버 예약/주문 서비스의 관리자 아이디로 로그인 후 아래 링크를 눌러 문의 바랍니다.Npay 가입 심사 철회 문의하기그 후, Npay 가입 철회가 완료되었다고 답변 받았다면 아래 링크를 참고하여, 대표자 명의의 네이버 아이디로 예약/주문 서비스를 위임한 뒤 다시 Npay 가입을 신청하면 됩니다.예약/주문 서비스 관리자 권한 위임 방법 바로가기※ 참고해 주세요!- 이미 대표자 명의의 네이버 아이디로 위임했다면 대표자의 아이디로 로그인한 뒤 문의해야 합니다.
