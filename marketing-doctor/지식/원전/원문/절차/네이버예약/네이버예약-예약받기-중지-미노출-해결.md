# 네이버 예약주문 사업자 고객센터 「예약/주문받기 중지(미노출) 해결 방법」
- 출처: https://help.naver.com/service/11712/contents/23176
- 확인: 2026-09-20 (헤들리스)
- 등급: A 공식 도움말

예약받기(또는 주문받기 또는 예약/주문받기)가 갑자기 중지(미 노출) 되거나, 예약 가능한 시간이 마감(비활성화) 되었다면 아래 사유일 수 있습니다.
예약
1. 검수 보류로 미노출
검수 보류 시 미노출 되오니 보류 사유 해소 후 재 검수를 신청하세요.
검수 보류 사유 확인 방법
2. 6개월 내에 예약 가능한 상품/일정이 없어 미노출
6개월 내에 예약 가능한 상품이 없다면 예약 상품 및 서비스가 자동 미노출(중지)됩니다.
이 경우, 예약할 수 있도록 상품의 재고를 설정하면 자동 노출됩니다. (이때 재고만 수정해야 하며 다른 정보도 함께 수정 시 자동 노출 기능이 작동하지 않습니다. 직접 노출로 변경하세요.)
3. Npay 비정상으로 미노출
당장 Npay를 사용하지 않아도 된다면 [예약 > 예약상품]에서 상품을 노출로 변경한 뒤, [예약 > 설정 > 운영설정]에서 예약받기를 시작으로 변경합니다.
Npay 관련 상세 문의는 1599-1598(가맹점)로 접수 바랍니다.
4. 회차형 일 단위 재고를 초과한 예약 수량으로 미노출
회차형은 일 단위 재고(모든 회차 재고 총합) 대비 실제 예약 완료된 수량이 더 많고, 더 이상 예약 가능한 일정이 없다면(단일 일정으로 예약받는 중) 해당 예약 상품이 자동으로 미노출 됩니다. 이때, 예약 상품이 1개라면 상품 미노출 후 예약 서비스 미노출까지 진행 되는 점 참고 바랍니다.
(예시) 0월 00일 하루만 공연하며, 하루에 1회차/2회차 공연이 있을 때 1회 기존 재고 10개, 2회차 기존 재고 10개인 상태일 때
: 1회차 10개 예약 완료/2회차 5개 예약 완료, 총 15개 예약 완료
> 업체에서 1회차 재고를 1개로 수정
> 1회차 1개/2회차 10개로 총 11개의 일 단위 재고 발생
> 이때 이미 예약된 수량은 1, 2회차 총합 15개. 일 단위 총 재고 11개 보다 4개가 많이 예약된 상태라 2회차에 5개의 재고가 남았음에도 자동 미노출 (미노출 전까지 예약은 가능)
예약 상품 미노출 사유는 직접 확인할 수 있습니다.
예약 상품 노출/ 미노출 이력 확인 방법
5. 뷰티형/병의원형 시술 소요 시간 대응 불가로 시간대 마감(비활성화)
뷰티형/병의원형은 시술메뉴별 시술 소요 시간을 설정할 수 있습니다.
이때 설정한 시술 소요 시간만큼 예약 가능한 시간이 대응되지 않는 시간대가 있다면 자동으로 마감(비활성화)됩니다.
시술 소요 시간으로 인해 예약이 없는 시간대가 마감(비활성화) 되기를 원치 않는다면, 시술메뉴별 설정한 시술 소요 시간을 삭제하세요.
1) 시술메뉴 수정 경로(PC만 가능, 모바일 불가)
① 스마트플레이스 접속
② 예약/주문 선택
③ 운영하는 서비스 선택
④ 예약 선택
⑤ 시술메뉴 선택 후 등록한 시술메뉴를 눌러 수정합니다.
주문
1. 검수 보류
검수 보류 시 미노출 되오니 보류 사유 해소 후 재 검수를 신청하세요.
검수 보류 사유 확인 방법
2. 메뉴 미노출
[예약·주문 > 메뉴]에 등록한 모든 메뉴를 미노출 하면 주문할 수 있는 메뉴가 없어 주문 상품 자동 비활성 후 주문버튼이 미노출 됩니다.
메뉴를 노출로 변경한 뒤 [주문 > 주문상품]에서 상품별 시작하기를 눌러 활성하세요.
3. Npay 비정상
예약/주문 서비스에 가입(가맹)한 Npay가 비정상이라면 주문 사용이 불가하여 주문 상품 자동 비활성 후 주문 버튼이 미노출됩니다.
Npay 관련 상세 문의는 1599-1598(가맹점)로 접수 바랍니다.
예약/주문 가능 여부에 따른 자동 노출/미노출 탐지 시간 안내
1. 예약 서비스
1시간 내 탐지하여 자동 노출/자동 미노출 진행
2. 예약 서비스에 구성한 예약 상품
하루 1회 새벽 시간에 탐지하여 자동 노출/자동 미노출 진행
※ 참고해 주세요!
- 예약/주문 서비스가 미노출 되어도 기존 예약자 정보나 예약 알림에 영향은 없습니다.
