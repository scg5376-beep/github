# 네이버 예약주문 사업자 고객센터 「[그 외] N예약 혜택 노출/수정/삭제」
- 출처: https://help.naver.com/service/11712/contents/18630
- 확인: 2026-09-20 (헤들리스 fetch_text.mjs, ?osType=COMMONOS)
- 등급: A 공식 도움말

네이버 플레이스 업체 상세 정보에 N예약 혜택 문구를 노출할 수 있습니다.

예약혜택 문구 설정 방법
1. 스마트플레이스에 접속합니다.
2. 예약/주문을 누릅니다.
3. 예약 서비스명(업체명, 공연명)을 누릅니다.
4. 예약(예약·주문)을 누릅니다.
5. 기본정보(운영자는 업체정보)를 누릅니다.
6. 예약 시 혜택이 있다면 알려주세요.를 수정한 뒤 저장합니다.

삭제가 필요하다면 등록한 내용을 지우고 저장하면 됩니다.

예약혜택에 입력한 내용이 N예약혜택에 자동 노출되며 입력 후 플레이스 정보에 반영되기까지 최대 3시간 소요됩니다.

다만, 입력한 내용이 예약혜택 기준에 맞지 않을 경우 검수가 보류되거나 입력한 혜택이 삭제될 수 있습니다.

이 경우 해당 내용을 이메일로 안내합니다.

혜택 등록 가능 내용
네이버 예약 시 이용자에게 업체의 혜택을 줄 수 있는 내용

- 공연 예시) 네이버 예매 시, 브로마이드 제공
- 공방 예시) 4인 이상 동일 클래스 수업 시, 25% 할인
- 시설물 예시) 네이버 예약 시, 최대 48%할인 + Npay포인트 적립

혜택 등록 불가 내용
- 허위, 과장, 비방 등의 부적절한 문구 확인될 경우 불가
- 현금 결제 시 할인 등
- 혜택으로 볼 수 없는 내용 (정성을 다해 모시겠습니다, 조기 마감될 수 있습니다 등)
- 유효하지 않은 혜택 (종료된 이벤트 등)

※ 참고해 주세요!
- 플레이스가 아닌 지도 업체 정보라면 PC에서는 예약혜택이 노출되지 않습니다.
- 병의원 업종은 예약혜택을 등록할 수 없습니다.
- 예약혜택은 이용자(예약자)와의 약속이니 꼭 이행 바랍니다.
- 특수 문자 중 입력을 허용하지 않는 것도 있으니 작성 시 입력칸에 안내 문구가 노출된다면 수정하세요.
