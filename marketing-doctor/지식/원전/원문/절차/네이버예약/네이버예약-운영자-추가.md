# 네이버 예약주문 사업자 고객센터 「예약/주문 관리자가 여러 명일 경우(운영자 추가)」
- 출처: https://help.naver.com/service/11712/bookmark/7595
- 확인: 2026-09-20 (운영자가 브라우저에서 주소를 복사해 줌 → 헤들리스 fetch_text.mjs)
- 등급: A 공식 도움말

예약을 함께 관리할 운영자 ID를 등록할 수 있습니다. 

추가된 운영자 ID가 톡톡에 가입되어 있다면 톡톡 상담이 가능하도록 권한을 부여할 수 있습니다.

운영자 ID는 예약 서비스 별로 60명까지 등록 가능합니다. (관리자 권한은 1개의 네이버 ID에만 부여)

참고로, 1개의 네이버 ID가 받을 수 있는 운영자 권한의 수는 제한이 없습니다. (여러 예약 서비스의 운영자 권한을 받을 수 있습니다.)

운영자 ID 등록 방법

1. 스마트플레이스에 관리자(주인) ID로 접속합니다.

2. 오른쪽 위 초록색 닉네임/성함/ID 또는 메뉴(≡)를 누릅니다.

3. 권한관리​를 누릅니다.

4. 예약·주문 운영자 관리에서 운영자 추가(또는 운영자 X명)를 누릅니다.

5. 운영자로 추가할 네이버 ID 입력에 운영자 ID 입력 후 동의 및 추가를 누릅니다. (만약 미가입 ID 안내가 노출된다면 운영자 아이디로 로그인 후 스마트플레이스 > 예약/주문에 접속하여 약관 동의만으로 가입 가능)

6. 운영자에게 권한 부여 동의에 대한 네이버 알림이 전송됩니다. (알림이 오지 않는다면 아래 주의사항 3번 확인)

7. 운영자가 수신한 네이버 알림에서 반드시 동의하기를 눌러야 운영자로 추가됩니다. ★중요★

권한관리 화면

​

추가한 운영자 ID 삭제 방법

1. 권한관리​에 접속한 뒤 운영자 00명을 누릅니다.

2. 운영자 ID 오른쪽의 X​을 누릅니다.

3. 권한삭제 안내 팝업의 삭제를 누르면 즉시 삭제됩니다.

​

주의사항

권한 추가 시 아래 주의 사항을 꼭 확인 바랍니다.

1. 사업자님의 내부 직원에게만 권한을 부여할 수 있습니다. 

이를 위반하여 내부 직원 외에게 권한을 부여할 경우, 개인정보 보호법상 동의 없는 개인정보 제3자 제공에 해당하여 5년 이하의 징역 또는 5천만 원 이하의 벌금형에 처할 수 있습니다.

2. 내부 직원이 권한 관리에 소홀하거나 관련 법령상의 개인정보 보호 의무를 준수하지 않아 네이버 회원에게 피해가 발생하거나 발생할 가능성이 있을 경우 관리 권한은 회수될 수 있습니다.

이 경우에도 개인정보 보호법 위반으로 처벌될 수 있습니다.

3. 운영자 ID 추가(동의 및 추가) 후 알림이 수신되지 않는다면 운영자 ID의 네이버 알림 설정을 확인하세요.

1) 네이버 알림 설정하는 방법

① 네이버 홈페이지에 접속합니다.

② 권한 받을 ID로 로그인합니다.

③ 알림(종 모양)을 누릅니다. (또는 네이버 알림 검색 후 접속)

④ 톱니바퀴를 누른 뒤 알림설정을 누릅니다.

⑤ 서비스별 설정에서 네이버예약을 누릅니다.

⑥ 푸시 알림과 예약&주문 진행 및 이용안내를 ON으로 설정합니다.

※ 참고해 주세요!

- 운영자가 열람할 수 있는 정보(고객 휴대폰 번호 등)를 제한할 수 없습니다.

- 관리자(주인)만 운영자를 추가/삭제할 수 있으며, 운영자가 다른 운영자를 추가/삭제할 수 없습니다.

- 운영자를 추가해야 한다면 관리자(주인) ID로 로그인하세요. 

· 운영자 ID로 로그인 시 권한관리 메뉴는 노출되지 않습니다.

- 운영자는 서비스 삭제, 플레이스 노출, Npay 가입, 톡톡 연동이 불가합니다.

- 삭제된 운영자 ID는 복구 불가합니다.
