# 네이버 블로그 고객센터 「유입 분석 안내」

선택한 기간 동안 내 블로그에 방문한 전체 유입 수 중 경로별 유입 비중을 유입 분석 리포트에서 제공합니다.네이버의 서비스는 각 서비스 단위로, 외부 사이트는 사이트 단위로 구분합니다.예시로 네이버 검색과 다음 검색은 네이버 검색_PC, 네이버 이미지검색_모바일, 다음 통합검색_모바일, 다음 사이트검색_PC 등으로 세분화합니다.그보다 하위 등급은 검색어 목록으로 제공하여 검색어를 클릭할 시 검색 결과 페이지를 살펴볼 수 있습니다.※ 참고해 주세요!1. 매월 1일은 월 단위로 통계 데이터를 집계하므로 업데이트까지 시간이 소요될 수 있습니다.2. 통계 데이터 업데이트가 완료되기 전에는 모든 지표가 0으로 노출될 수 있습니다.통계 업데이트 주기 안내 바로가기
