# 스마트스토어 고객센터 FAQ 「[반품 관리] 반품 주문건 페널티 부과 기준」
- 출처: https://help.sell.smartstore.naver.com/faq/content.help?faqId=3890
- 확인: 2026-09-20 (curl, ss_faq.py)
- 등급: A 공식 도움말

반품 수거완료 + 3영업일 이내 주문건 내 '환불 보류 미설정' 상태 또는 반품완료(반품 거부)처리가 진행되지 않은 경우 판매관리 페널티가 부과됩니다. 
반품환불 처리지연 페널티 상세내용 보러 가기》

반품 수거완료 후 기한 내 완료처리가 어려울 경우 [판매관리 > 반품관리] 메뉴에서 '환불보류 설정'을 진행해 주세요.

! 주의. 
 · 환불 처리 또는 환불 보류가 설정되지 않은 주문 건은 아래 기준에 따라 자동으로 환불 완료 처리됩니다. (환불금 차감, 추가 결제 주문 건 포함)
 · 자동환불 처리일 기준: 수거완료일 + 5영업일 + 2일(영업일 무관) 경과 시 환불 처리
