# 스마트스토어 고객센터 FAQ 「[반품 관리] 구매자가 반품배송비를 결제하지 않는 경우 환불 보류설정 방법」
- 출처: https://help.sell.smartstore.naver.com/faq/content.help?faqId=3858
- 확인: 2026-09-20 (curl, ss_faq.py)
- 등급: A 공식 도움말

이러한 경우 자동으로 구매자에게 환불되지 않도록 '환불 보류'를 꼭 설정해 주세요.

반품배송비 보류 설정방법

1. [판매관리 > 반품관리] 메뉴에서 해당 주문건 클릭 후 '환불보류 설정' 버튼을 눌러주세요.
2. 팝업창 하단의 '보류사유 선택'을 '반품배송비 청구'로 선택 해주세요.
3. 사유 입력 후 하단의 '환불 보류설정' 클릭 해주시면 됩니다.

※ 참고. 
· 반품배송비 이외에 추가 비용 청구가 필요한 경우에는 보류사유 '기타반품비용 청구'로 청구할 수 있습니다.
· 보류설정 시 본상품+추가구성상품 같이 체크되어있을 경우 '기타반품비용' 설정은 불가능합니다.

반품배송비 결제 방식은 구매자만 직접 설정하거나 변경할 수 있습니다. 

구매자가 반품 배송비를 직접송금/상품에 동봉으로 설정한 경우, 
연락이 되지 않는다는 이유로 반품배송비 결제 방식을 환불금 차감 방식으로 변경해드릴 수는 없으니,
다시 한 번 [판매관리 > 반품관리] 메뉴에서 구매자/수취인 연락처를 확인해 보시기 바랍니다.

※ 참고.
· 구매자는 주문 시 '구매자연락처 / 수취인연락처1 / 수취인연락처2'를 기재할 수 있으며, [판매관리 > 반품관리] 메뉴에서 주문건 목록 스크롤바를 우측으로 이동하여 확인 가능합니다.  
· 구매자가 정확한 연락처를 기재하지 않은 경우 스마트스토어센터 고객센터에서도 추가 구매자 연락처를 확인할 수 없는 점 양해 부탁 드립니다.  

! 주의.
· 반품환불처리, 반품거부처리, 환불보류 설정은 반품수거완료 후 3영업일 이내 진행해 주셔야 페널티가 부여되지 않습니다. 
· 만약 반품상품 미입고, 반품배송비 미입금 등의 사유로 환불이 어려운 경우에는 해당 기간 내에 보류설정이 필요합니다.
· 구매자가 직접 반품 접수 시수거정보 입력 단계에서 정보를 입력하지 않고 [닫기]를 선택한 경우에는 Npay를 통한 반품배송비 결제가 불가능합니다. 
이 경우 판매자가 먼저 반품/교환 수거정보를 등록 또는 '수거완료'처리 했을 시 구매자가 배송비를 결제할 수 있습니다.
· 이미 보류설정이 되어 있더라도, 보류해제 후 재 설정을 진행해 주셔야 페널티가 부여되지 않습니다.
