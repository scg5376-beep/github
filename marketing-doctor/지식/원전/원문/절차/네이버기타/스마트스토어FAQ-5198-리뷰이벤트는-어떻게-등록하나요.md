# 스마트스토어 고객센터 FAQ 「리뷰이벤트는 어떻게 등록하나요?」
- 출처: https://help.sell.smartstore.naver.com/faq/content.help?faqId=5198
- 확인: 2026-09-19 (curl, ss_faq.py)
- 등급: A 공식 도움말

리뷰이벤트는 [문의/리뷰관리 > 리뷰 관리 > 리뷰이벤트 관리] 메뉴에서 '리뷰 이벤트 등록' 버튼을 선택하여 등록하고, 관리할 수 있습니다.

리뷰이벤트 등록을 위해서는 최초 1회 사전 동의가 필요하며,'필수입력 사항' 입력 후 저장해주세요.
등록하신 이벤트는 운영하시는 스마트스토어/쇼핑윈도 전체에 적용됩니다.
리뷰이벤트 관리 메뉴얼 바로 가기》 

리뷰이벤트 등록
리뷰이벤트 등록
1) 이벤트 제목 : 최대 15자 이내로 입력
2) 이벤트 적용 대상: 스토어전체/일부 카테고리/일부 상품 대상으로 설정 가능
3) 이벤트 기간 : 이벤트 시작일은 이벤트 등록일 + 1일부터 선택 가능하며 이벤트 종료일은 이벤트 시작일 + 31일까지 선택 가능
4) 발표일 : 이벤트 종료일 + 3일부터 +10일까지 선택 가능하며 이벤트 종료 후 발표일 전일까지 베스트리뷰를 모두 선정/확정 필요
5) 선정 리뷰 수 : 리뷰이벤트를 통하여 베스트리뷰로 선정할 리뷰 수를 입력(최대 100개), 응모 현황에 따라 실제 베스트 리뷰는 더 많거나 적게 선정 가능
6) 포인트 혜택(판매자 부담) : 베스트리뷰로 선정된 리뷰 작성자 개별에게 당첨자발표와 함께 자동 적립되며 베스트리뷰 당 최소 10원 ~ 최대 20,000원까지 설정 가능
                  충전금과 네이버지원포인트 모두 사용 가능하며, 네이버지원포인트가 충전금보다 우선 차감되어 혜택이 지급
7) 이벤트 내용 : 어떤 리뷰를 받고 싶으신 지 최대 30자 이내로 입력
8) 이벤트 배너 스타일 : 기본형/강조형 중 선택

등록/ 선정관련 자세한 내용은 아래의 도움말을 참고해 주세요.
▶ 리뷰이벤트는 등록/선정 시 참고 사항 도움말 바로가기
