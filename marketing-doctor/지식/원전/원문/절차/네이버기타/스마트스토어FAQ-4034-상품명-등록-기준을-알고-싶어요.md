# 스마트스토어 고객센터 FAQ 「상품명 등록 기준을 알고 싶어요」
- 출처: https://help.sell.smartstore.naver.com/faq/content.help?faqId=4034
- 확인: 2026-09-20 (curl, ss_faq.py)
- 등급: A 공식 도움말

상품명에는 해당 상품의 브랜드, 모델명 등을 포함할 수 있습니다. (특수문자 : \*?"<> 사용불가)

상품명은 중복된 단어, 상품과 관련 없는 키워드, 할인 정보 등을 제외하고 간결하게 작성해 주세요.

잘못된 상품명을 입력 시 검색에서 불이익을 받게 되며 판매 상품과 직접 관련이 없는 
상품명, 유명 상품 유사문구, 스팸성 키워드, 이모지(윈도우 이모지 등) 입력 시 관리자에 의해 판매 금지될 수 있습니다.
또한, 유명상품 유사문구를 무단으로 사용하여(예시 : ~스타일, ~풍, ~st 등) 기재하는 경우 별도 고지 없이 제재될 수 있습니다.

제재 예시) 
상표명 : 네이버
등록한 상품명 : 네2버, 네@버, 네이버스타일, 네이버st, 네이버풍 등의 단어 입력 시 제재 대상

상품명을 검색최적화 가이드에 잘 맞게 입력하면 검색 노출에 도움이 될 수 있습니다. 검색최적화 가이드를 참고해 주세요.
