1.  1:1 채팅
1-1. 관리자 추가인증

개인정보 보호를 위해 1:1 채팅 메뉴에 접근하려면 관리자 추가인증이 필요합니다. 관리자 추가인증은 카카오톡 또는 SMS를 통해 가능합니다. 
관리자 추가인증 기능 사용을 원하지 않을 경우, [내 계정 정보 > 관리자 추가인증 설정] 페이지에서 OFF 상태로 설정을 변경해 주세요. 

관리자 추가인증 정보
관리자 추가 인증에 활용되는 정보는 카카오비즈니스 통합회원에 등록된 회원정보를 기반으로 합니다. 
원활한 인증을 위해서는 https://business.kakao.com/my-info 에 등록된 전화번호와 이메일 주소를 최신화 해주세요.   

관리자 추가인증 기능 사용을 원하지 않을 경우
[채널 > 설정] 페이지에서 OFF상태로 설정을 변경해 주세요. 

1-2. 채팅설정

채팅 설정 페이지에서 채팅기능 ON/OFF 및 채팅가능 시간 등을 설정할 수 있습니다. 
1:1 채팅은 카카오톡 사용자가 먼저 시작할 수 있으며, 채팅기능을 사용하지 않을 경우 채팅방에 메시지 입력창이 노출되지 않습니다. 

➊ 채팅가능 요일, 시간
시작시간보다 종료시간을 빠르게 설정할 경우, 다음날 새벽 시간대까지 채팅이 가능합니다. 
(채팅가능 시간은 한국시간 기준)  
채팅가능 시간은 요일별로 시간 설정이 가능합니다.

➋ 채팅불가능 안내 메시지 
채팅 불가능 시간대에 말을 건 사용자에게 전송되는 메시지입니다. 
직접 입력 선택 시에는 메시지에 채팅 가능 요일과 시간에 대한 정보를 포함해 주세요. 

➌ 채팅 안내 메시지 
친구가 아닌 사용자가 채널 채팅방 최초 접속 시, 자동으로 1회 전송되는 메시지입니다. 
자동 전송을 원치 않을 경우 ON/OFF 버튼을 통해 설정을 변경할 수 있습니다. 
친구가 아닌 사용자에게 전송되므로 광고성 내용이 포함되면 과태료가 부과될 수 있으니 주의해주세요.

➍ 사진 묶어 보내기 
사진 전송 시 최대 30장까지 하나의 말풍선으로 보낼 수 있습니다. (각 이미지 크기 최대 20MB 제한) 
해당 옵션 변경 시 대화중인 채팅방에 실시간으로 반영되지 않으므로, 채팅방을 새로 열거나 새로고침해주세요.

1-3. 채팅알림

채팅 상태를 ON으로 변경한 후 사용자가 채팅 메시지를 전송할 경우,
상단 채팅알림 영역과 1:1 채팅 메뉴 우측에 읽지 않은 채팅 메시지의 합계가 노출됩니다. 

1-4. 채팅 PC 알림

내 계정 정보 페이지에서 PC 알림을 설정하면, 크롬브라우저에서 제공하는 웹 푸시 알림을 통해 채팅 메시지를 빠르게 확인할 수 있습니다. 

설정 
크롬 브라우저 알림이 차단 상태일 경우, PC알림을 'ON'으로 설정해도 채팅 알림 메시지를 받을 수 없습니다.
알림을 받으시려면 브라우저의 주소창에서 '자물쇠' 아이콘을 클릭한 후, '알림' 항목에서 '이 사이트에서 항상 허용'을 선택하세요. 
2개 이상의 컴퓨터를 사용하실 경우, 컴퓨터별로 크롬 브라우저 알림을 허용해야 합니다. 
PC 알림은 크롬 버전 52 이상부터 지원합니다. 

1-5. 채팅 목록

채팅방 나가기를 통해서 더 이상 확인할 필요가 없는 채팅목록을 삭제할 수 있으며, 친구차단을 통해 어뷰징 사용자를 관리할 수 있습니다. 

➊ 채팅방 나가기
'채팅방 나가기'를 할 경우 채팅방이 삭제되며, 관리자앱에서도 해당 채팅방이 사라집니다. 
단, 사용자가 다시 채팅요청을 할 경우 채팅방은 복구됩니다.
차단상태에서 '채팅방 나가기'를 할 경우, 차단해제가 불가능하니 주의해주세요. 

➋ 친구차단 및 해제
[친구차단]을 한 사용자가 말을 걸 경우, '{프로필명}에 의해 차단된 사용자로 1:1 채팅을 할 수 없습니다.'라는 내용의 메시지가 전송됩니다. 
차단 이후 홈 게시물에 남긴 댓글은 다른 사용자들에게 노출되지 않습니다. 
차단한 친구는 '차단친구 목록' 탭에서 확인할 수 있으며, 차단 전까지의 채팅내용 확인 및 차단해제가 가능합니다. 

1-6. 채팅 목록 관리

친구그룹 추가, 중요표시, 읽음, 담당자 지정, 상담완료 기능을 이용하여 채팅목록을 편리하게 관리해 보세요. 

➊ 친구그룹에 추가
특정 채팅목록을 선택한 후 친구그룹을 생성할 수 있습니다.
생성한 친구그룹에게 '메시지 작성 페이지'에서 그룹메시지를 전송할 수 있습니다. 

➋ 중요표시 
빠른 답변이 필요하거나 중요한 고객과의 채팅방에는 '중요표시'를 해보세요. 
중요표시를 한 채팅방은 '중요채팅 목록'에서 따로 모아볼 수 있습니다. 중요표시된 채팅방을 '차단'할 경우 중요표시가 해제됩니다. 

➌ 읽음 
뱃지 카운트를 한번에 없애고 싶다면 채팅방 선택 후 '읽음' 버튼을 클릭해 주세요. 

➍ 담당자 지정 
프로필의 관리자가 여러명일 경우, 채팅방의 담당자를 지정하여 채팅방을 손쉽게 분류하고 관리해 보세요. 
채팅 메시지 전송은 담당 여부와 상관없이 모든 관리자가 할 수 있습니다. 
채팅목록에서 특정 채팅방을 선택한 후 '담당자 지정' 버튼을 클릭하면 담당 관리자를 선택할 수 있으며, '담당자'별로 채팅목록을 분류할 수 있습니다. 

➎ 상담 완료하기
고객과의 상담이 끝났다면 '상담 완료하기' 버튼을 클릭해 보세요. 
채팅목록에서 '완료된 상담'을 모아서 확인할 수 있습니다. 상담이 완료된 후 채널 관리자 또는 친구가 채팅 메시지를 보낼 경우 다시 '상담 진행중' 상태로 변경됩니다. 

1-7. 채팅 목록 필터링

채팅목록을 조건별로 분류하여 확인해 보세요. 
상담 진행 상태, 채팅방 라벨, 채팅 담당자, 기간을 기준으로 분류할 수 있습니다. 

➊ 상담 진행 상태
'진행 중 상담'을 클릭하면 상담 진행 상태별로 채팅목록을 분류할 수 있습니다.

읽지 않은 상담 : 읽지 않은 메시지가 있는 채팅방

답변하지 않은 상담 : 메시지는 모두 읽었으나 관리자가 아직 답변을 하지 않은 채팅방

답변한 상담 : 관리자가 답변을 한 채팅방

완료된 상담 : 상담 완료 처리된 채팅방

상담완료 기능이 신설되기 전에 시작된 채팅방은, 메시지를 읽었어도 실제 답변 여부와 상관 없이 모두 ‘답변하지 않은 상담' 상태로 표시됩니다. 상담이 끝난 경우 채팅방에서 ‘상담완료' 처리를 하시면 채팅방의 상태가 ‘완료된 상담'으로 변경됩니다.

➋ 채팅방 라벨, 채팅 담당자, 채팅 기간

채팅방 라벨 : 채팅방 라벨 관리 페이지에서 생성한 채팅방 라벨 기준으로 분류합니다. 

채팅방 라벨기능은 PC에서만 지원됩니다.

채팅 담당자 : 채팅 담당자(특정 관리자)를 기준으로 분류합니다. 

기간 : 마지막으로 대화를 나눈 시점을 기준으로 분류합니다. 

 

1-8. 채팅하기

채팅목록을 클릭하면 채팅방이 노출되며 친구에게 채팅 메시지(텍스트, 이미지, 동영상, 파일)를 전송할 수 있습니다.
우측 상단 더보기 버튼 클릭 시, 채팅방 이름 수정과 메모입력을 할 수 있습니다. 

➊ 보낸 관리자 이름 표시
여러명의 관리자가 동일한 사용자와 채팅하는 경우, 관리자들끼리 구분을 위해 관리자 이름을 표시해주고 있습니다. 
이름은 사용자에게 절대 노출되지 않으며 관리자들만 볼 수 있습니다. 

➋ 설명 미디어 수신 (PC에서만 가능)
톡에서 보낸 설명 포함 이미지/동영상을 수신할 수 있습니다.
설명 아이콘이 노출되는 미디어를 클릭하여, 상세뷰에서 최대 50자의 설명을 확인할 수 있습니다.

➌ 자주 쓰는 답변 선택 (PC에서만 가능)
'1:1 채팅 > 자주 쓰는 답변' 페이지에서 자주 쓰는 답변을 등록하여 빠르고 편리하게 채팅/상담을 진행해 보세요. 
채팅방 하단 '자주 쓰는 답변' 버튼을 클릭하면 사전에 등록한 자주 쓰는 답변을 불러올 수 있습니다. 

➍ 쿠폰 보내기 (PC에서만 가능) 
'쿠폰 작성' 페이지에서 생성한 쿠폰을 카카오톡 사용자에게 보낼 수 있습니다.
친구상태인 사용자에게만 쿠폰 전송이 가능합니다. 친구가 아닐 경우에는 먼저 채널 추가를 요청해 보세요.

➎ 채널추가 요청
채널 친구가 아닌 대화상대방에게 채널추가 요청을 할 수 있습니다.

채팅 시 꼭 주의해주세요.

접속한 관리자가 여러명일 경우 채팅 내용이 동일한 내용으로 업데이트 됩니다. 

2018년 3월 1일부터 1:1 대화 내용은 소비자의 권익 보호와 분쟁처리를 위해 카카오톡 서버에 3년간 보관됩니다. 

3년이 지난 메시지는 서버에서 완전히 삭제되어 확인이 어려울 수 있습니다. 

1-9. 채팅방 관리

채팅방 관리 화면에서 상담완료 처리, 채팅방 이름 수정, 채팅방 라벨 등록, 메모입력을 할 수 있습니다. 

➊ 채널추가 요청 메시지 발송
1:1 채팅방에서 친구에게 채널추가 요청 메시지를 발송할 수 있습니다. 
(단, 이미 채널을 추가한 고객에게는 해당 메시지를 보낼 수 없습니다.)

➋ 상담 완료하기 
고객과의 상담이 끝났다면 '상담 완료하기' 버튼을 클릭해 보세요. 
채팅목록에서 '완료된 상담'을 모아서 확인할 수 있습니다. 
상담이 완료된 후 채널 관리자 또는 친구가 채팅 메시지를 보낼 경우 다시 '상담 진행중' 상태로 변경됩니다. 

➌ 채팅방 이름 수정/메모 입력
채팅 상대를 구별하기 쉽도록 채팅 이름을 수정해 보세요.
채팅 내역이 삭제되기 전에 중요한 내용은 메모기능을 이용하여 저장해 두세요.  

➍ 채팅방 라벨 등록 (PC에서만 가능)
채팅방 라벨을 적용하면 채팅목록에서 '채팅방 라벨'별로 채팅방을 분류할 수 있습니다. 

1-10. 고객 정보 조회 기능 사용하기

카카오톡 비즈플러그인을 활용하면 1:1 채팅 과정에서 고객의 개인정보를 쉽고 빠르게 제공받을 수 있습니다. 
고객의 개인정보를 1회성으로 제공받고 상담에 활용해보세요. (개인정보는 상담완료 또는 이용자의 개인정보 제3자 제공 동의 완료일로부터 3일 후 파기됩니다.) 

고객 정보 조회 기능은 카카오톡 비즈플러그인에서 '개인정보이용 플러그인'을 등록하시면 사용할 수 있습니다. 
카카오톡 비즈플러그인에서 등록이 완료되었다면 채널 관리자센터에서는 별도의 설정 없이 고객 정보 조회 기능을 사용할 수 있습니다.  

➊ 고객 정보 조회
비즈플러그인(https://business.kakao.com/info/talkbizplugin) 에서
‘개인정보이용 플러그인’ 을 등록하면 고객정보조회 기능을 사용할 수 있습니다.

'개인정보이용 플러그인' 사용 환경 셋팅하기

준비물 : 비즈니스채널, 비즈앱

1단계 [카카오비즈니스 > 비즈니스 설정 > 채널-앱 연결]
- 개인정보이용 플러그인을 사용하실 비즈니스 채널을 비즈앱과 연결해주세요.
- 해당 비즈앱과 연결된 개인정보이용 플러그인을 채널에서 사용할 수 있습니다. 

2단계 [카카오비즈니스 > 서비스/도구 > 비즈도구 > 비즈플러그인]
- 플러그인을 등록해주세요.

- 비즈앱 선택 : 1단계에서 연결한 채널-앱 선택

- 플러그인 목적 선택 : '개인정보이용' 플러그인 선택

- 상세내용 입력 : 플러그인 정보 및 개인정보 수집 항목 설정

개인정보이용 플러그인 등록 완료!
- 등록된 개인정보이용 플러그인의 상태를 확인해주세요.
- 플러그인 상태가 '사용가능'인 경우 채널 관리자센터에서도 별도 설정 없이 바로 사용 가능합니다.


1-11. 자주 쓰는 답변 관리

자주 쓰는 답변을 등록하여 빠르고 편리하게 채팅/상담을 진행해    보세요. 
채팅방에서 사전에 등록한 자주 쓰는 답변을 불러올 수   있습니다.

1-12. 채팅방 라벨 관리

채팅방 라벨(예: VIP, 단골, 재구매고객)을 등록하여 채팅방을 라벨별로 분류하여 관리해보세요. 
라벨 적용은 개별 채팅방에서 할 수 있습니다. 

1-13. 채널추가 요청 메시지

채널 친구가 아닌 대화상대방에게 전송할 채널추가 요청 메시지를 작성해 보세요.
등록된 메시지는 1:1 채팅방을 통해 직접 발송 가능합니다.

➊ 메시지 꾸미기
채널추가 요청 메시지에 이미지를 첨부할 수 있습니다. 
이미지는 800px X 400px 사이즈를 권장하며, 최대 10MB / jpg, png 형식의 이미지 파일만 업로드할 수 있습니다.

➋ 내용 (광고)
최대 100자까지 입력 가능합니다. 
단, 필수 노출 문구*는 수정 불가합니다. 
(* '채널명' 채널을 추가하시면 광고와 마케팅 메시지를 카카오톡으로 받아 볼 수 있습니다.)

➌ 쿠폰 첨부
채널추가 혜택을 강조하기 좋은 기능입니다. 

‘자동첨부’의 경우, 메시지 발송시점에 쿠폰 상태가 ‘사용가능’ 상태이며, 노출설정이 ‘노출’로 설정된 응모기간 이내의 쿠폰이 모두 첨부됩니다.

조건을 만족하는 쿠폰이 없는 경우, 메시지 전송 시 쿠폰 강조 버튼은 자동으로 미노출됩니다.

‘개별첨부’의 경우 채널 관리자센터 내 등록되어 있는 쿠폰을 최대 5개까지 첨부할 수 있습니다.
