# 사용자 혜택

우리채널 알리기는 사용자가 채널을 추가할 때 **혜택**을 받도록 설계된 광고입니다. \
혜택이 명확할수록 친구 추가 전환이 높아지기 때문에, 어떤 혜택이 제공되는지 이해하고 활용하는 것이 중요해요.

혜택은 두 가지로 구성됩니다.

### 1. 쇼핑포인트 100원 (카카오 지원)

우리채널 알리기로 채널을 추가한 사용자에게 **카카오가 쇼핑포인트 100원을 지원**합니다.

* 광고주 추가 부담 없이 모든 우리채널 알리기 광고에 공통으로 적용돼요.
* 광고주가 별도 혜택을 준비하기 어려운 경우에도, 사용자에게 기본 혜택을 보장할 수 있어요.
* 쇼핑포인트는 '채널당 1회만 지급'이 돼요.

> 💡 광고주 관점에서는, 쿠폰이 없어도 **쇼핑포인트 100원만으로 광고를 시작**할 수 있어요. 진입 장벽이 낮은 것이 장점입니다.

{% hint style="warning" %}
1\. 지급 조건아래 두 가지 조건을 모두 충족하신 경우 리워드가 지급됩니다.

* 광고 클릭 후 24시간 이내에 광고주의 카카오톡 채널을 친구추가
* 친구추가 완료 시점부터 24시간이 경과한 시점에 해당 채널과 친구 관계 유지

\
2\. 지급 한도

* 동일 채널당 최초 1회에 한해 지급됩니다. 채널 차단 후 다시 친구추가하시더라도 추가 지급되지 않습니다.
* 1일(00:00\~24:00) 최대 5건까지 지급됩니다.

\
3\. 유효기간

* 유효기간은 리워드 지급일로부터 90일이며, 경과 시 자동 소멸됩니다.
* 소멸된 리워드는 재지급·환급되지 않습니다.

\
4\. 환불·소멸 관련 준용 규정본 유의사항에서 정하지 않은 환불·소멸 관련 사항은 다음 약관에 따릅니다.

* 「[카카오쇼핑 이용약관](https://buy.kakao.com/shopping-front/user/term-detail/PAY?channel=STORE)」
* 「[카카오 전자금융거래 이용약관](https://billing-web.kakao.com/kbill/terms/finance)」&#x20;

\
5\. 리워드 정산은 친구 관계가 성립된 지 24시간이 지난 시점부터 최대 1시간 내에 처리됩니다.\
만약 친구추가 후 25시간이 지났음에도 포인트가 들어오지 않았다면 [쉬운광고 고객센터](https://cs.devel.kakao.com/requests?service=289)를 통해 문의할 수 있습니다.<br>

6\. 유의사항 변경 시 안내본 유의사항이 변경되는 경우 [카카오 서비스 변경 공지사항](https://www.kakao.com/notices?searchWord=\&lang=ko)에 사전 게재됩니다.
{% endhint %}

### 2. 채널 쿠폰 탑재 (광고주 선택)

광고주가 채널 쿠폰을 함께 탑재하면, 쇼핑포인트에 더해 **추가 혜택**을 제공할 수 있습니다. 쿠폰은 채널 추가 전환에 가장 효과가 큰 혜택입니다.

#### 쿠폰 혜택 유형

| 유형     | 표시 예시     |
| ------ | --------- |
| 할인 금액  | 1,000원 할인 |
| 할인율    | 10% 할인    |
| 무료증정   | 음료 무료 증정  |
| 업그레이드  | 사이즈 업그레이드 |
| 배송비 할인 | 배송비 할인    |

* 쿠폰은 채널에서 발행한 쿠폰을 연결할 수 있어요.

### 3. 혜택 지급 흐름

사용자가 광고를 통해 채널을 추가하면 아래 순서로 혜택이 제공됩니다.

* 광고 클릭 → 채널 추가 완료 → 베네핏 알림 센터를 통해 포인트 적립 예정 알림 메시지 수신 → 친구 추가를 24시간 이상 유지할 경우, 포인트 적립 완료 메시지 수신 → 포인트 지급 완료
* 쇼핑포인트 혜택 관련 사항은 "베네핏 알림 센터" 채널을 통해서 안내 드립니다.
* 쿠폰이 함께 탑재된 광고의 경우, 광고 대상 채널로 쿠폰 메시지가 발송됩니다.&#x20;
