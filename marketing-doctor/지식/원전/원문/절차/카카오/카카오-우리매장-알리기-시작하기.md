# 시작하기

'우리 매장 알리기' 집행 조건을 확인하고 빠르게 시작해 보세요!

**'우리 매장 알리기'**&#xB294; 오프라인 매장을 운영하고, \
카카오맵 매장관리에서 매장주 인증을 완료한 경우에만 원활하게 광고를 집행할 수 있습니다.


## 1. 내 매장 인증하기

* **카카오맵 매장관리** 서비스에서 매장주 인증을 완료하였다면 바로 **우리 매장 알리기** 광고를 시작할 수 있습니다.
* 만약 매장관리에 가입되어 있지 않거나 매장주 인증이 되어 있지 않은 경우, **'내 매장 등록하기'** 버튼을 클릭하여 매장 등록 및 인증 이후 우리 매장 알리기 광고를 시작해 주세요.

## 2. 광고계정 만들기

**Step.1 쉬운 광고 플랫폼 로그인하기**

* 카카오비즈니스 통합회원 계정으로 로그인 가능합니다. ([카카오비즈니스 통합 가입 안내 바로가기](/main/business-start/kakaobusiness-signup.md))
* 매장관리 서비스와 동일한 카카오계정으로 로그인해 주세요.

**Step.2 광고할 매장 선택하기**

* 로그인 이후 내 카카오 계정에 연결된 매장의 목록을 확인할 수 있습니다.
  * 매장관리에서 내가 **대표자 또는 운영자**인 매장 목록이 표시됩니다.


* '광고 시작하기' 버튼을 선택하면 광고계정이 자동으로 생성됩니다.


## 3. 광고 만들기

* 내 매장으로 광고계정을 생성한 후에는 클릭 한번으로 광고 설정부터 광고 소재까지 자동으로 생성할 수 있습니다.


## 4. 결제 수단 등록하기

* 광고를 노출하기 위해서는 캐시 충전 또는 자동결제카드 등록이 필요합니다. ([결제 관리 (비즈월렛)](/main/ad/ezad/payment.md))
