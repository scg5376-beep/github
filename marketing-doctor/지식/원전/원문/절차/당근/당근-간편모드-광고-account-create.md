# 간편모드 광고 계정 생성

당근비즈니스에서 광고를 집행하려면 광고계정이 필요해요.

간편모드는 광고 경험이 없어도 누구나 쉽고 빠르게 광고를 시작할 수 있는 방식이에요.

모바일 앱과 PC 웹 두 가지 방법으로 광고계정을 만들 수 있어요.

{% stepper %}
{% step %}

### Step 1. 약관 동의하기

#### 무엇을 설정하는 단계인가요?

광고계정을 처음 만들 때 약관 동의가 필요해요. 진입 경로에 따라 약관 항목이 조금 다를 수 있어요.

#### 주요 설정 항목

**진입 경로**

* **모바일**: 나의 당근 → \[광고] 탭 진입 시 약관 동의 팝업이 표시돼요.
* **PC**: [https://business.daangn.com](https://business.daangn.com/) 접속 후 약관 동의 팝업이 표시돼요.

**약관 항목**

| 구분 | 항목                                                      |
| -- | ------------------------------------------------------- |
| 필수 | 통합 이용 약관 / 개인정보 수집 이용 동의 / 개인정보처리 관련 고지사항 / 당근비즈니스 이용약관 |
| 선택 | 마케팅 수신 동의 (푸시, 채팅, 이메일)                                 |

> 필수 항목에 동의해야 다음 단계로 진행할 수 있어요.
> {% endstep %}

{% step %}

### Step 2. 광고 모드 선택하기

#### 무엇을 설정하는 단계인가요?

광고를 운영할 방식을 선택하는 단계예요. 간편모드와 전문가모드 중 하나를 선택해요.

#### 주요 설정 항목

**간편모드**

* 광고 경험이 없어도 누구나 쉽게 만들 수 있어요.
* 당근 홈 피드 및 다양한 지면, 검색 결과에 광고를 노출할 수 있어요.
* 좋은 성과를 위한 광고 조건을 자동으로 추천해드려요.
* 요약 보고서로 성과를 확인할 수 있어요.

**전문가모드**

* 전문 마케터 또는 대행사에게 추천해요.
* 전문가모드 광고 계정 생성은 아래 페이지를 참고해 주세요.

[광고 계정 생성](/business.daangn/ads-pro/account/create.md)

### Step 3. 광고계정 이름 설정하기

#### 무엇을 설정하는 단계인가요?

광고계정의 이름을 입력하면 광고계정 생성이 완료돼요.

#### 주요 설정 항목

**광고계정 이름**

* 광고계정을 구분할 수 있는 이름을 자유롭게 입력해요.
* 이름 입력 후 \[광고계정 만들기] 버튼을 누르면 생성이 완료돼요.

**새 광고계정 생성 전 확인사항**

* 기존 광고계정의 광고캐시는 새 광고계정에서 사용할 수 없어요.
* 기존 광고계정을 함께 운영 중인 운영자가 있어도, 운영자를 다시 초대해야 해요.
* 기존 광고계정에 등록된 심사 서류는 재사용할 수 없어, 심사 서류를 다시 제출해야 해요.
  {% endstep %}

{% step %}

### Step 4. 세금계산서 정보 입력하기

#### 무엇을 설정하는 단계인가요?

광고계정 생성 후 광고비에 대한 세금계산서 발급을 위해 정보를 입력하는 단계예요. 광고를 집행하기 위해서는 광고 계정에 개인 또는 사업자 정보를 반드시 입력해야 해요.

정보를 입력하지 않으면 광고비 충전을 할 수 없기 때문에, 광고를 집행할 수 없어요.

#### 주요 설정 항목

**발급 유형 선택**

| 유형        | 대상         | 발급 방식              |
| --------- | ---------- | ------------------ |
| 사업자로 발급받기 | 법인 / 개인사업자 | 해당 사업자번호로 세금계산서 발급 |
| 개인으로 발급받기 | 사업자가 아닌 개인 | 개인에게 세금계산서 발급      |

**유형 선택 시 참고사항**

* 간이과세자, 면세사업자, 고유번호증을 가진 비영리단체도 **사업자**를 선택해요.
* 사업자등록증이 있다면 **사업자**, 없다면 **개인**을 선택해요.
* 세금계산서는 광고계정 단위로 발급되므로, 사업자별로 세금계산서를 따로 받으려면 광고계정을 별도로 만들어야 해요.
* 개인 선택 시, 당근 가입 휴대폰 명의자와 다른 사람 정보도 입력할 수 있어요. 단, 해당 분의 휴대폰 본인인증이 추가로 필요해요.
* **사업자와 개인 간 전환은 불가능해요.** 잘못 선택한 경우 일부 항목만 수정할 수 있어요.
  {% endstep %}

### 광고계정은 몇 개까지 생성할 수 있나요?

| 구분                       | 최대 수량 |
| ------------------------ | ----- |
| (간편모드) 광고계정 소유           | 5개    |
| (전문가모드) 광고계정 소유          | 500개  |
| (간편모드, 전문가모드 공통) 광고계정 운영 | 500개  |

새로 만든 광고계정에서는 기존 계정의 캐시를 함께 사용할 수 없어요.

### 운영 시 참고 사항

* 광고계정은 모바일(나의 당근 → 광고)과 PC(business.daangn.com) 모두에서 만들 수 있어요.
* 새 광고계정을 만들면 기존 광고계정의 캐시, 운영자, 심사 서류를 이어받을 수 없어요.
* 세금계산서 발급 유형(사업자/개인)은 한 번 설정하면 전환이 불가능하므로 신중하게 선택해 주세요.
