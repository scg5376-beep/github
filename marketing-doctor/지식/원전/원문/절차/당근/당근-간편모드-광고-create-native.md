# 디스플레이광고 만들기

디스플레이광고는 동네 이웃이 가장 많이 보는 당근 홈 피드 및 다양한 지면에 광고를 노출하는 상품이에요. 설정한 지역의 홈 피드 중고거래 게시글 사이 및 다양한 화면에 광고가 자연스럽게 노출돼요. 원하는 동네와 타겟을 설정하고, 이웃이 광고를 클릭했을 때만 비용이 차감되는 방식이에요.

### 광고할 내용 선택하기



#### 무엇을 설정하는 화면인가요?

광고를 클릭했을 때 고객에게 보여줄 내용(랜딩페이지)를 선택하는 화면이에요.

#### 랜딩페이지 유형

비즈프로필 광고인지, 웹사이트 광고인지에 따라 선택할 수 있는 랜딩페이지가 달라요.

유형랜딩페이지비즈프로필비즈프로필 홈 / 소식 / 스토리 / 상품(비즈프로필에 등록된 상품) 중 선택웹사이트웹사이트 URL 직접 입력

{% endstep %}

{% step %}

### 광고 사진과 제목 작성하기



#### 무엇을 설정하는 화면인가요?

어떤 사진과 제목으로 광고할지 작성해요. 사진과 제목이 광고 클릭률에 직접적인 영향을 미쳐요.

#### 주요 설정 항목

**광고 사진**

* 상품/서비스를 대표하는 사진을 등록해요.
* 중고거래 게시글 사이에 노출되므로, 자연스러운 사진일수록 반응이 좋아요.

{% hint style="info" %}
**광고 사진 고르는 팁**

* 직접 찍은 자연스러운 사진이 효과적이에요.
* 글자가 삽입된 이미지보다 상품/서비스가 생생하게 담긴 사진의 반응이 좋아요.
  {% endhint %}

**광고 제목**

* 상품/서비스를 설명하는 대표 문구를 작성해요.
* 어떤 제목으로 광고할지 고민된다면 제목 추천 기능을 이용해보세요.

{% hint style="info" %}
**광고 제목 작성 팁**

* 혜택을 제목에 직접 강조하면 클릭률이 높아져요. (예: 최소 월 1만원에 자전거 가져가세요 +무제한 세차)
* 누구나 이해할 수 있는 쉬운 문구를 사용해 주세요. (예: "제로웨이스트 & 리필스테이션"보다 "세제를 필요한 만큼만 구매할 수 있는 곳")
  {% endhint %}

**행동 유도 버튼**  `웹사이트`

* URL로 등록한 랜딩페이지 내용과 관련된 버튼을 4가지 중 선택할 수 있어요.
  * 바로가기: 웹사이트 메인 화면, 본문으로 이동될 때
  * 문의하기: 문의 화면으로 이동될 때
  * 구매하기: 바로 구매할 수 있는 상품 화면으로 이동될 때
  * 신청하기: 이벤트, 신청 화면 등으로 이동될 때

{% endstep %}

### 광고 사진/제목 추가하기



#### 무엇을 설정하는 화면인가요?

사진과 제목을 여러 개 추가할 수 있어요. 다양한 사진과 제목으로 광고를 만들면 더 좋은 성과를 거둘 수 있어요. 사진이나 제목을 다르게 하여 성과를 테스트해볼 수도 있어요.&#x20;

어떤 사진과 제목으로 할지 고민되는 경우에는 **AI 추천 기능**을 이용해보세요.&#x20;

광고 내용은 한번에 최대 10개까지 추가할 수 있어요.

**직접 추가하기**

* '다른 사진/제목 추가하기' 버튼을 눌러 추가할 수 있어요.

**AI 추천받기**

* 하단 '추천받기' 버튼을 눌러 추천받을 수 있어요.
* 클릭 한 번으로 AI가 내 업체에 딱 맞는 맞춤형 광고 내용을 3개까지 만들어줘요.
* AI가 추천한 내용은 일부 문구가 부정확할 수 있으니 적용 전 꼭 검토해주세요.

{% endstep %}

### 광고 그룹 설정 선택하기



#### 무엇을 설정하는 화면인가요?

광고 그룹의 설정을 입력하는 화면이에요. 어떤 광고 그룹에 광고를 만들지 정하고, 지역∙예산∙일정 등 광고 설정을 수정할 수 있어요.

* 설정한 타겟 수와 하루예산을 기반으로 하루 최대 노출 예상 인원을 확인할 수 있어요.
* 광고가 진행되는 동안 앱 이용자 수에 따라 실제 노출수는 달라질 수 있어요.

#### **광고 그룹**

기본적으로 새 광고 그룹을 만들어요. 기존에 운영중인 광고 그룹이 있다면, 그룹을 변경해서 기존 그룹의 설정 그대로 광고만 추가할 수도 있어요.

#### **지역**

광고를 노출할 지역을 설정해요. 동네 인증한 지역과 관계없이 원하는 지역을 자유롭게 선택해 광고할 수 있어요.

지역은 '지역으로 검색'과 '그려서 선택' 두 가지 방식으로 정할 수 있어요.

| 설정 방법   | 설명                                                            |
| ------- | ------------------------------------------------------------- |
| 지역으로 검색 | 시/구/동을 검색해 광고할 동네를 직접 골라요. '전국에 광고하기'를 켜면 전국을 대상으로 광고할 수 있어요. |
| 그려서 선택  | 지도에서 직접 광고할 지역을 정해요. 걸어서·차량·그리기 중 원하는 방법을 골라요.                |

그려서 선택에서는 이렇게 지역을 정할 수 있어요.

* 걸어서: 가게를 중심으로 걸어서 갈 수 있는 거리만큼 지역을 설정해요.
* 차량: 가게를 중심으로 차로 갈 수 있는 거리만큼 지역을 설정해요.
* 그리기: 지도 위에 원하는 영역을 직접 그려서 설정해요.

지역을 추가하거나 지울 때마다 예상 타겟 수가 바로 표시돼요.

{% hint style="info" %}
**타겟 수가 최소 3만 명 이상 되도록 설정해 주세요.**&#x20;

광고 노출 대상이 너무 적으면 광고가 노출되지 않을 수 있어요. 지역은 최소 3만 명 이상이 되도록 넓게 선택하는 것을 권장해요.
{% endhint %}

#### **예산**

하루에 광고 비용을 최대 얼마까지 사용할지 직접 설정할 수 있어요.

* 최소 5,000원부터 설정할 수 있으며, 적어도 **10,000원 이상** 설정하는 것을 권장해요.
* 예산을 많이 설정할수록 광고가 더 많이 노출되고, 더 많은 반응을 얻을 수 있어요.
* 설정한 예산이 바로 지출되지 않아요. 이웃이 광고를 보고 클릭했을 때만 비용이 지출돼요.

#### **일정**

어느 기간 동안 광고할지 광고 시작일과 종료일을 정할 수 있어요.

* 광고 기간은 최소 **2일 이상** 진행하는 것을 권장해요.
* 광고 노출이 최적화되기 위해 최소 2일 이상이 필요해요.
* 원하는 광고 효과를 얻었다면 예산을 모두 사용하지 않아도 언제든지 광고를 중단할 수 있어요.

{% hint style="info" %}
광고 상세 일정을 설정하면 원하는 요일·시간대에만 광고를 노출할 수 있어요.
{% endhint %}

#### 성별 및 연령

광고를 노출할 성별 및 연령대를 선택할 수 있어요. 특정 성별/연령 고객만 이용하는 업체라면 해당 조건을 선택해요.

* 예) 여성 전용 헬스장, 20\~30대 여성 대상 속눈썹 가게

{% hint style="info" %}
**주요 고객층이 명확하지 않다면 전체 선택을 권장해요.**

* 특정 성별/연령이 주 고객층이더라도 전체 선택이 유리할 수 있어요. 타겟 외 고객도 관심에 따라 반응할 수 있기 때문이에요.
  {% endhint %}

### 광고 생성 완료



광고 그룹의 설정까지 끝마치고 '이대로 만들기'를 누르면 광고 생성이 완료돼요. 이후 설정한 예산과 기간에 따라 필요한 예산을 확인할 수 있어요.

필요한 예산을 확인한 후 광고캐시가 부족하다면 충전해주세요.
{% endstep %}
