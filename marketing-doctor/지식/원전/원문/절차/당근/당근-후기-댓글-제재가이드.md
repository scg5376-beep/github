# 당근 고객센터 「동네업체 후기 및 댓글 제재 가이드」
- 출처: https://cs.kr.karrotmarket.com/wv/faqs/11747
- 확인: 2026-09-20 (헤들리스)
- 등급: A 공식 운영정책

고객센터 / 홈동네업체 후기 및 댓글 제재 가이드 당근은 비즈프로필 이용자 모두에게 양질의 서비스를 제공하기 위해 노력하고 있어요.
이용자는 후기 및 댓글 이용 정책을 준수해야 하며, 이를 준수하지 않은 작성글은 미노출 처리 될 수 있어요. 서비스 이용에 제한 받지 않도록 작성하는 후기 및 댓글이 이용 정책의 금지 행위에 해당하지 않는지 꼭 확인해 주세요.
비즈프로필 및 소식에 작성된 후기와 댓글은 유저 신고 시 게시글 즉시 삭제 또는 계정이 제재될 수 있어요.
아래 항목을 참고하여, 주의하여 이용 부탁드려요.
[후기] 유저신고 시 제재 항목사유판단근거제재 항목욕설, 혐오 표현 같은 부적절한 내용이 포함되어 있어요.
- 신고 인입 시 운영담당자 검토후기 즉시 미노출, 최대 영구 후기 작성 제한음란성 글이나 사진이 포함되어 있어요.
- 신고 인입 시 운영담당자 검토후기 즉시 미노출, 최대 영구 후기 작성 제한개인정보가 노출되었어요.
- 신고 인입 시 운영담당자 검토후기 즉시 미노출, 최대 영구 후기 작성 제한업체와 관련이 없는 내용이에요.
- 신고 인입 시 운영담당자 검토후기 즉시 미노출, 최대 영구 후기 작성 제한부적절한 방식으로 후기를 작성해요.
- 이용여부와 상관없이 후기 어뷰징 행위 확인 후기 즉시 미노출, 최대 영구 후기 작성 제한[댓글] 유저신고 시 제재 항목사유판단근거제재 항목욕설, 혐오 표현 같은 부적절한 내용이 포함되어 있어요.
- 신고 인입 시 운영담당자 검토댓글 즉시 미노출음란성 글이나 사진이 포함되어 있어요.
- 신고 인입 시 운영담당자 검토댓글 즉시 미노출개인정보가 노출되었어요.
- 신고 인입 시 운영담당자 검토댓글 즉시 미노출업체와 관련이 없는 내용이에요.
- 신고 인입 시 운영담당자 검토댓글 즉시 미노출
