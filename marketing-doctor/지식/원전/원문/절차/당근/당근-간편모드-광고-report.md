# 간편모드 광고 성과 보는 방법

## 간편모드 광고 성과 보는 방법

### 1. 소개



간편모드 광고 성과는 **광고 그룹 단위**와 **개별 광고 단위** 두 가지로 확인할 수 있어요.

**광고 그룹 성과**\
광고 그룹에 속한 광고들의 성과를 합쳐서 보여줘요. 보는 위치에 따라 확인할 수 있는 지표가 달라요.

| 보는 위치 | 확인할 수 있는 지표                                 |
| ----- | ------------------------------------------- |
| 광고 목록 | 노출수 / 클릭수 / 반응수 / 총 지출                      |
| 그룹 상세 | 노출수 / 클릭수 / 클릭률 / 반응수 / 반응률 / 반응당 지출 / 총 지출 |

광고 목록에서는 그룹의 성과를 한눈에 훑어보고, 그룹 상세에서는 클릭률·반응률·반응당 지출까지 함께 확인할 수 있어요.

**광고 성과**\
그룹 상세의 광고 목록에서 개별 광고의 노출수, 클릭수, 클릭률, 반응수, 지출을 확인할 수 있어요.

> 앱 \[나의 당근] → \[광고] → 확인할 광고 그룹 또는 광고 선택\
> 그룹 상세로 이동하려면 광고 그룹의 \[그룹 상세]를 눌러 주세요.

### 2. 주요 성과 지표

**노출수** 당근 앱에서 내 광고가 보여진 총 횟수예요. 설정한 예산·지역·타겟에 따라 달라져요.

**클릭수** 이웃이 내 광고를 발견하고 눌러본 총 횟수예요. 클릭 수가 많을수록 가게 방문이나 상품 구매로 이어질 가능성이 높아요.

**클릭률** 노출 수 대비 클릭 수의 비율이에요. 클릭률이 높다는 건 광고 제목·대표 사진·소개 문구가 이웃의 관심을 잘 끌고 있다는 의미예요.

**지출** 광고에 사용된 광고캐시 금액이에요. 이웃이 광고를 클릭할 때만 비용이 발생하는 CPC(클릭당 비용) 방식이에요. 광고가 아무리 많이 노출되어도 클릭이 없으면 비용은 부과되지 않아요. 내가 직접 내 광고를 클릭해도 과금되지 않아요.

**어뷰징 클릭 보호** 일정 시간 내에 동일한 이웃이 여러 번 클릭해도 1회만 과금돼요. 광고 기간에 따라 한 명에게 노출되는 최대 횟수도 자동으로 제한돼요.

**반응수** 광고를 보고 들어온 이웃이 비즈프로필에서 한 활동의 횟수예요. 단골 등록, 관심 누르기, 댓글, 후기, 전화·채팅 문의, 쿠폰 사용, 포장주문 같은 활동이 모두 들어가요.

반응은 광고를 눌러 도착한 페이지에서 일어난 활동만 세지 않아요. 광고를 보고 들어온 이웃이 그 비즈프로필 안에서 한 다른 활동까지 함께 집계해요. 광고 랜딩 페이지가 A 소식이더라도 이웃이 같은 비즈프로필의 B 소식에 댓글을 달거나 관심을 누르면 성과에 나와요.

**반응률** 클릭 수 대비 반응 수의 비율이에요. 광고를 누른 이웃이 실제 활동까지 이어졌는지 볼 수 있어요.

**반응당 지출** 반응 1건이 일어나는 데 쓴 광고캐시 금액이에요.

반응률과 반응당 지출은 그룹 상세의 광고 그룹 성과에서 확인할 수 있어요.

비즈프로필 광고에서는 아래 지표도 함께 확인할 수 있어요.

* **포장주문 수** 광고를 보고 들어온 이웃이 포장주문을 완료한 횟수예요.
* **쿠폰 사용 수** 광고를 보고 들어온 이웃이 받은 쿠폰을 실제로 사용한 횟수예요.

### 3. 성과 조회 기간 설정

성과 조회 기간은 기본값이 최근 7일로 설정되어 있어요. 더 긴 기간의 성과를 확인하고 싶다면 조회 기간을 직접 변경할 수 있어요.

| 옵션     | 설명                     |
| ------ | ---------------------- |
| 오늘     | 오늘 하루 성과               |
| 어제     | 어제 하루 성과               |
| 최근 7일  | 기본값                    |
| 최근 30일 | 최근 30일 성과              |
| 전체     | 최근 13개월 이내             |
| 직접 선택  | 원하는 기간 직접 설정 (13개월 이내) |

광고 성과 데이터는 최근 13개월 이내의 데이터만 조회할 수 있어요. 13개월이 지난 데이터는 자동으로 제외되기 때문에, 시간이 지날수록 전체 성과 수치가 줄어 보일 수 있어요. 실제 성과가 감소한 것이 아니에요.

13개월을 초과한 데이터가 필요하다면 광고 상세 화면의 [문의하기](/business.daangn/ads-lite/support.md)를 통해 요청해 주세요. 요청 시 아래 정보를 함께 작성해 주세요.

* 광고계정 이름 또는 광고주 ID
* 광고 제목 또는 소재 ID
* 필요한 지표 종류 (예: 노출 수, 클릭 수 등)
* 성과 요청 기간
* 성과 파일을 받을 이메일 주소

이미 이메일로 받은 성과 데이터는 동일 기간에 대해 재발송하지 않으니 잘 보관해 주세요.

### 4. 광고 필터



광고 그룹 목록에서 필터를 활용하면 원하는 광고만 모아서 확인할 수 있어요.

**광고 상품 필터** 전체 / 디스플레이광고 / 검색광고

**광고 그룹 상태 필터** 전체 / 광고중 / 하루예산 초과 / 기간종료 / 시작전 / 광고꺼짐 / 운영불가

현재 광고 중인 그룹만 보고 싶다면 **광고중** 필터를 사용하면 돼요.

### 5. 내 광고가 보이지 않을 때

광고는 설정한 지역·성별·연령에 해당하는 이웃에게 노출돼요. 아래 상황에서는 광고가 일시적으로 보이지 않을 수 있어요.

* **일일예산이 모두 소진된 경우** : 다음 날 자동으로 다시 시작돼요.
* **한 명의 이웃에게 최대 노출 횟수를 채운 경우** : 동일 이웃에게는 더 이상 노출되지 않아요.

***

### 디스플레이광고 성과

디스플레이광고는 예산이 많을수록 노출 기회가 늘어나요. 예산을 낮게 설정하면 노출 횟수가 적어 광고를 직접 볼 확률도 낮아질 수 있어요. 당근은 동일한 이웃에게 같은 광고가 반복 노출되지 않도록 자동으로 조절하고 있어요.

#### AI 광고 성과 진단

간편모드 디스플레이광고에서는 AI 성과 진단 기능을 시범적으로 제공해요. 최근 7일간의 성과 데이터를 분석해 광고 효율을 진단하고, 개선을 위한 맞춤 제안도 받을 수 있어요. 제안이 마음에 들면 광고에 바로 적용할 수도 있어요.

이용 시 아래 내용을 참고해 주세요.

* 비즈프로필 소재의 디스플레이광고에서만 사용할 수 있어요.
* 소재별로 하루 1회 진단할 수 있으며, 다음 날 오전 8시에 새 진단을 받을 수 있어요.
* 최근 7일간 데이터가 충분하지 않으면 기능을 사용할 수 없어요.
* 진단 보고서는 생성 후 7일이 지나면 만료되며, 만료된 보고서는 다시 확인할 수 없어요.
* 맞춤 제안이 항상 효율 개선을 보장하는 것은 아니에요.

***

### 검색광고 성과

검색광고는 클릭당 비용, 품질, 키워드 연관성 등을 종합한 순위에 따라 노출돼요. 광고 소재와 비즈프로필, 키워드 간 연관성이 높을수록 노출에 유리해요. 설정한 클릭당 비용이 낮거나 당근에서 검색량이 많지 않은 키워드라면 광고가 노출되지 않을 수 있어요.

노출이 원활하지 않다면 아래 원인을 확인해 보세요.

| 원인                    | 해결 방법                                                 |
| --------------------- | ----------------------------------------------------- |
| 클릭당 비용이 낮은 경우         | 클릭당 비용을 높여 경쟁력을 높여보세요                                 |
| 비즈프로필과 소재 연관성이 낮은 경우  | 사업체마다 맞는 비즈프로필을 각각 만들어 운영해 주세요                        |
| 소재에 핵심 키워드가 없는 경우     | 노출하고 싶은 키워드를 광고 제목·소개 문구·비즈프로필에 포함해 주세요               |
| 동일한 광고를 2개 이상 운영하는 경우 | 동일한 비즈프로필로 동일한 내용의 광고를 2개 이상 생성한 경우, 그중 1개의 광고만 노출돼요. |

#### 무효 클릭 대응

무효 클릭은 광고비 소진이나 성과 조작을 목적으로 발생하는 비정상적인 클릭이에요. 당근은 다양한 자동화 로직으로 무효 클릭을 탐지하고 과금되지 않도록 처리하고 있어요.

무효 클릭이 의심된다면 고객센터로 아래 정보를 포함해 문의해 주세요.

* 광고 제목
* 클릭 일시
* 키워드

단, 클릭한 사용자의 개인정보(ID, IP 등)는 제공이 어려운 점 참고해 주세요.
