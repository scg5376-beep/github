# 충전 / 쿠폰

### 1. 소개

광고캐시는 당근 광고를 집행할 때 사용하는 잔액이에요. 필요할 때마다 직접 충전하거나, 자동충전을 설정해 편리하게 관리할 수 있어요.

> 당근머니와 광고캐시는 별개예요. 당근머니를 충전해도 광고캐시는 자동으로 충전되지 않아요.

### 2. 광고캐시 잔액 확인

광고캐시 잔액과 사용 내역은 아래 경로에서 확인할 수 있어요.

* **앱** : \[나의 당근] → \[광고] → 상단 광고캐시 잔액 확인 → 잔액 클릭 시 사용 내역 확인
* **PC** : \[광고] → \[광고캐시] → \[광고캐시 내역]

잔액이 부족하면 광고 노출이 줄어들 수 있어요. 운영 중인 광고 수가 많다면 그만큼 캐시를 넉넉히 충전해 주세요. 남은 캐시는 그대로 보관되며, 다른 광고 예산으로 사용하거나 환불을 요청할 수 있어요.

### 3. 광고캐시 충전 방법

#### 충전 경로

* **앱** : \[나의 당근] → \[광고] → 상단 \[캐시 충전]
* **PC** : \[광고] → \[광고캐시 관리] → \[광고캐시 내역] → \[캐시 충전]

#### 결제 수단

| 결제 수단       | 특징                                   |
| ----------- | ------------------------------------ |
| 간편카드        | 본인 명의 신용·체크카드 등록 후 사용. 일부 카드사 미지원    |
| 일반카드        | 무기명 법인카드 및 타인 명의 카드 사용 가능. 모든 카드사 지원 |
| 계좌이체 (가상계좌) | 입금 은행 선택 시 가상계좌 발급. 유효기간 72시간        |
| 당근머니        | 앱에서만 사용 가능. 당근페이 연결 계좌에서 충전          |

* 계좌이체 결제 시
  * 가상계좌 유효기간(72시간)이 지났다면 충전을 다시 진행해 새 계좌를 발급받아 주세요.
* PC에서 일반카드 결제 시&#x20;
  * 결제창에서 결제하려는 카드사가 확인되지 않는 경우 BC카드를 선택해서 결제해 주세요. (ex. IBK기업은행, BNK부산은행, BNK경남은행, iM뱅크(구 대구은행) 등)

#### 간편카드 등록 방법

* **앱** : \[나의 당근] → \[광고] → \[캐시 충전] → 결제수단 \[간편카드] → \[+카드 등록]
* **PC** : \[광고캐시] → \[광고캐시 관리] → \[충전하기] → 결제수단 \[간편카드] → \[+카드 등록]

본인 명의의 신용·체크카드만 등록할 수 있어요. 무기명 법인카드 및 타인 명의 카드는 등록할 수 없어요.

**등록 및 사용 가능한 카드사** 국민, BC, 신한, 현대, 농협, 삼성, 하나, 롯데, 카카오뱅크, 전북은행, 다날, 페이코, 아이엠뱅크

**지원 준비 중인 카드사** 토스뱅크, 씨티카드(Non-BC)

#### 법인카드 충전

* 결제수단을 **일반카드**로 선택하면 무기명 법인카드로도 결제할 수 있어요.
* 간편카드 또는 자동충전으로는 기명식 법인카드만 사용할 수 있어요.

#### 간편카드 삭제·변경 방법

* **앱** — \[나의 당근] → \[당근페이] → 우측 상단 설정(⚙️) → \[카드 관리] → 삭제할 카드 \[⋮] → \[삭제하기]
* **PC** — \[광고캐시] → \[광고캐시 관리] → \[충전하기] → 결제수단 \[간편카드] → \[카드 삭제]

### 4. 자동충전

자동충전을 설정하면 설정한 조건에 따라 캐시가 자동으로 충전돼요. 결제 수단은 카드만 선택할 수 있어요.

#### 자동충전 종류

| 종류    | 충전 조건                            |
| ----- | -------------------------------- |
| 잔액 기준 | 유상 캐시 잔액이 설정한 기준 금액보다 적을 때 자동 충전 |
| 날짜 기준 | 설정한 날짜 오전 8시에 자동 충전              |

#### 자동충전 설정 경로

* **앱** : \[나의 당근] → \[광고] → 상단 \[캐시 자동충전] → 기준 선택 → 금액·결제수단 선택 → \[자동충전하기]

#### 자동충전 해지 경로

* **앱** : \[나의 당근] → \[광고] → \[자동충전 관리] → \[해지]
* **PC** : \[광고] → \[광고캐시] → \[광고캐시 내역] → \[자동충전 관리] → \[해지]

해지 후 언제든 다시 신청할 수 있어요.

**자동충전 유의사항**

* 180일 동안 광고를 이용하지 않으면 자동충전이 자동 해지돼요.
* 캐시 점검 시간에는 충전 완료까지 최대 30분이 걸릴 수 있어요.
* 결제 실패 시 다음날 오전 8시에 재시도하며, 최대 3회 재시도 후에도 실패하면 자동충전이 해지돼요.

### 5. 광고캐시 쿠폰 등록

쿠폰 코드가 있다면 아래 경로에서 등록할 수 있어요.

* **앱** : \[나의 당근] → \[광고] → 상단 \[≡] → \[광고캐시 쿠폰 등록] → 쿠폰 코드 입력

**캐시 종류별 유의사항**

* 무상 캐시는 현금 환불이 불가하며, 광고비로 소진하거나 만료 처리만 가능해요.
* 유상 캐시·무상 캐시 모두 다른 광고계정으로 이관할 수 없어요.
* 잘못된 계정에 충전했다면 환불 신청 후 원하는 계정에서 다시 충전해 주세요.

**🎁 이벤트 안내** 간편카드를 처음 등록하고 충전하면 적립캐시 5,000원이 적립돼요.

### 7. 자주 묻는 질문

**캐시를 충전했는데 잔액이 없어요.**

충전 후 시스템 반영까지 최대 30분이 걸릴 수 있어요. 특히 은행 점검 시간이나 오후 5시 환불 처리 시간대에는 더 지연될 수 있어요. 광고계정을 여러 개 운영 중이라면 다른 계정에 충전한 것은 아닌지 확인해 주세요.

> 앱 \[나의 당근] → \[광고] → 좌측 상단 계정 이름 → \[광고계정 선택]에서 계정 확인

당근알바 글쓰기 등록권을 결제한 경우, 캐시 내역에서 '당근알바 글 등록'으로 사용된 내역이 있는지도 확인해 주세요.
