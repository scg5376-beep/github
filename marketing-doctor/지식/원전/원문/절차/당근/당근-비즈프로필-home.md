# 비즈프로필 홈

비즈프로필 정보를 꼼꼼히 채운 가게일수록, 동네 이웃들이 비즈프로필을 눌러볼 거예요. 우리 가게 정보를 쉽고 편하게 알리고, 더 강력한 홍보 효과를 누려 보세요.

### Step 1. 가게 소개 정보 확인하기

#### 무엇을 설정하는 단계인가요?

비즈프로필 생성 시 등록한 소개글과 위치가 홈 화면에 노출돼요. 고객이 가게를 처음 접하는 정보이므로 꼼꼼하게 작성하는 것이 중요해요.

#### 주요 설정 항목

**위치**

* 생성 시 등록한 주소가 비즈프로필 홈에 표시돼요.
* 주소를 정확히 입력하면 고객이 가게를 방문하기 더 쉬워요.

**공지**

* 이벤트, 휴무 안내 등 고객에게 전달하고 싶은 내용을 공지로 작성할 수 있어요.

**소개**

* 비즈프로필 생성 시 등록한 소개글이 홈 상단에 노출돼요.
* 소개 문구는 비즈프로필에서 가장 먼저 보이는 정보이므로 꼼꼼하게 작성해 주세요.

***

### Step 2. 사진 등록하기

#### 무엇을 설정하는 단계인가요?

가게 분위기와 서비스를 시각적으로 전달하는 사진을 등록하는 단계예요.

#### 주요 설정 항목

**사진**

* 한 번에 최대 20장까지 등록할 수 있어요.
* 등록한 사진은 비즈프로필 홈상단과 \[사진] 탭에 노출돼요.
* 나중에 추가하거나 변경할 수 있어요.

***

### Step 3. 업체 정보 관리하기

#### 무엇을 설정하는 단계인가요?

고객이 가게를 이용하기 전 확인하는 핵심 정보를 관리하는 단계예요.

#### 주요 설정 항목

**업체 정보 항목**

| 항목       | 내용                                                            |
| -------- | ------------------------------------------------------------- |
| 영업시간     | <p>가게 운영 시간을 설정해요<br>평상시와 다르게 운영하는 날짜가 있다면 '임시 영업일'에 설정해요</p> |
| 부가정보     | 서비스·결제 수단·시설 정보를 표시해요                                         |
| 전화번호     | 고객이 언제든 궁금한 점을 문의할 수 있어요                                      |
| 홈페이지 URL | 외부 링크를 연결할 수 있어요                                              |
| 제공 서비스   | 일부 업종에 한해 제공돼요                                                |
| 단골 혜택    | 단골 맺기를 유도하는 혜택 문구를 설정해요.                                      |

### Step 4. 쿠폰·가격·콘텐츠 활용하기

#### 무엇을 설정하는 단계인가요?

비즈프로필 홈에 노출되는 쿠폰, 가격, 소식, 스토리를 통해 고객의 방문을 유도하는 단계예요.

#### 주요 설정 항목

**쿠폰**

* 등록한 쿠폰 중 최대 2개까지 비즈프로필 홈에 표시돼요.
* 쿠폰 관리 페이지에서 쿠폰을 생성·수정·삭제할 수 있어요.

### \[참고] 기본 정보

* 비즈프로필 우측 메뉴 > \[정보 관리] > \[기본 정보] 에서 이름/주소/업종을 설정/수정할 수 있어요.&#x20;
* 기본 정보의 변경은 다음과 같이 진행돼요.&#x20;
  * 이름, 주소
    * 사업자 정보 등록을 하지 않은 비즈프로필 : 30일에 1회 가능해요&#x20;
    * 사업자 정보 등록이 완료된 비즈프로필 : 변경 요청건에 대한 검수를 통해 반영돼요 이름, 주소
    * 사업자 정보 등록을 하지 않은 비즈프로필 : 30일에 1회 가능해요&#x20;
    * 사업자 정보 등록이 완료된 비즈프로필 : 변경 요청건에 대한 검수를 통해 반영돼요&#x20;
  * 업종&#x20;
    * 사업자 정보 등록 여부와 상관없이 변경 요청 사항에 대해 검수를 통해 반영돼요.&#x20;

### \[참고] 통계 알림 설정

비즈프로필 통계 알림은 당근 앱의 알림 설정에서 켜고 끌 수 있어요.

> 당근 앱 → \[나의 당근] → \[설정] → \[알림 설정] → \[최근 받은 알림] → 통계 알림

* 비즈프로필 관리자 홈에서는 통계 알림을 설정할 수 없어요.
* \[최근 받은 알림]에는 실제로 받아본 알림만 보여요. 통계 알림을 받은 적이 없다면 목록에 나타나지 않으니, 알림을 한 번 받은 뒤에 설정해 주세요.

### 운영 시 참고 사항

* 소개글과 공지는 고객이 가장 먼저 보는 정보예요. 최신 상태로 유지해 주세요.
* 쿠폰은 최대 2개까지만 홈에 노출되므로, 핵심 혜택 위주로 등록하는 것을 권장해요.
