# 네이버 클립 고객센터 「클립 게시물 제작 방법」
- 출처: https://help.naver.com/service/30048/contents/24423
- 확인: 2026-09-20 (헤들리스)
- 등급: A 공식 도움말

게시물 제작은 모바일 앱(네이버앱·클립 크리에이터 앱)에서만 제공됩니다.
진입 경로 (모바일 앱)
- 네이버앱 클립탭 상단 +(만들기) 버튼 또는 내 프로필 하단 만들기 버튼
- 클립 크리에이터 앱 하단 +(만들기) 버튼
게시물 제작 방법
1. 에디터 하단의 게시물 버튼을 눌러 게시물 에디터를 선택하고, 업로드할 사진/영상을 골라 주세요.
클립 게시물은 최대 10개의 사진/영상을 업로드할 수 있으니 참고하시기 바랍니다.
2. 비율, 음원, 필터, 조정, 얼굴블러 기능으로 사진과 영상을 원하는 대로 편집할 수 있습니다.
첨부한 미디어를 바탕으로 AI가 어울리는 음원을 추천해 드리며, 음원 기능을 통해 원하는 음원을 직접 추가할 수도 있습니다.
가리고 싶은 얼굴이 있다면 '얼굴블러' 메뉴를 이용해 보세요. 사진의 경우 자동/수동으로 블러를 설정할 수 있습니다.
※ 음원 추가 시 첨부된 영상의 원본 소리는 자동으로 음소거되고, 선택한 음원만 재생됩니다. (참고 공지글)
3. 정보 태그 단계에서 다양한 태그를 추가해 유용한 정보를 덧붙이면 더 풍부한 클립을 만들 수 있습니다.
4. 편집을 완료하면 기본 정보를 입력하고 클립 게시물을 등록해 주세요.
클립 게시물 기본 정보 안내
클립 기본 정보는 클립을 업로드하거나, 이미 등록한 클립의 정보를 수정할 때 확인할 수 있습니다.
1. 본문
게시물 본문은 최대 3,000자까지 입력 가능합니다.
해시태그는 최대 5개까지 입력 가능하며, 해시태그(#)와 언더스코어(_)를 제외한 특수문자, 이모지는 해시태그에 포함되지 않습니다.
첨부한 미디어와 정보 태그를 바탕으로 AI가 어울리는 해시태그를 추천해 드립니다.
※ AI가 생성한 해시태그에는 정확하지 않은 표현이 포함될 수 있으며, 직접 수정하여 사용이 가능합니다.
※ 클립의 노출과 추천은 해시태그 개수와 상관없이 콘텐츠 자체를 기준으로 이루어집니다.
링크 기능은 지원하지 않습니다.
2. 음원 설정
게시물에 추가된 음원을 확인하거나 수정, 삭제할 수 있습니다.
편집 화면에서 음원을 추가하지 않은 경우에도 새로운 음원을 추가할 수 있습니다.
단, 저작권 등의 사유로 음원 재생이 제한된 경우, 뷰어에서 음원이 재생되지 않을 수 있습니다.
3. 공개 여부
전체 공개/비공개 중에서 선택할 수 있습니다.
비공개 선택 시, 해당 클립은 설정 및 활동 > 비공개 클립 페이지에 발행됩니다.
4. AI 활용 설정
AI를 활용한 콘텐츠인 경우, AI 활용을 ON으로 설정한 후 등록해 주세요.
5. 광고・협찬 설정
광고나 협찬이 포함된 콘텐츠의 경우 광고・협찬 설정이 필요합니다.
클립 에디터 혹은 클립 크리에이터 PC 웹에서 '광고・협찬 설정' 항목을 ON으로 설정해 주세요.
6. 재생 국가
내 클립이 재생될 국가를 설정할 수 있습니다.
기본값인 ‘전 국가’ 선택 시 모든 국가에서 재생되며, 추가 설정을 통해 ‘대한민국만 재생’ 또는 '특정 국가의 재생을 제한'할 수 있습니다.
※ 네이버앱에서 클립을 생성할 경우, Android 사용자는 앱 실행 시 최초 1회 에디터 다운로드가 필요합니다.
※ 다운로드 참고 사항
- 약 100MB 이하 데이터를 다운로드합니다.
- 데이터 사용료가 부과될 수 있으므로 가급적 WIFI 환경에서 다운로드해 주세요.
- 원활한 다운로드를 위해 앱 실행을 유지해 주세요.
- 에디터 다운로드 완료 시 앱을 재시작해야 합니다.
