# 네이버 클립 고객센터 「인증태그 이용 방법」
- 출처: https://help.naver.com/service/30048/contents/25159
- 확인: 2026-09-20 (헤들리스)
- 등급: A 공식 도움말

인증태그는 실제 방문/구매 인증이 완료된 장소/상품/공연·전시·축제에 대한 정보태그를 의미합니다.
장소 태그 / 쇼핑 태그 / 공연·전시·축제 태그에 한해 제공되며, 네이버 MY플레이스/네이버 플러스 스토어/Npay 서비스 내 인증 내역(예약/주문/카드 결제 등)이 확인되어야 인증이 생성됩니다.
장소 방문 인증 태그
- 장소 방문 인증 태그는 방문일 기준 최근 1년 내 내역만 노출됩니다.
- 일부 영수증∙결제내역의 경우, 정책에 따라 클립 에디터에 '방문 인증' 표기가 노출되지 않을 수 있습니다.
- 방문 인증 내역의 신뢰도 유지를 위해, 하나의 콘텐츠(플레이스 리뷰 또는 클립)에는 방문 인증 태그를 1개만 사용할 수 있습니다.
- 방문 인증과 관람 인증은 중복하여 사용할 수 없습니다.
쇼핑 구매 인증 태그
- 쇼핑 구매 인증 태그는주문일 기준 최근 1년 내 내역만 노출됩니다.
- 구매확정 처리된 건에 한해서만 '구매인증' 표기가 노출됩니다.
공연·전시·축제 태그 관람 인증 태그
- 공연·전시·축제 관람 인증 태그는 방문일 기준 최근 1년 내 내역만 노출됩니다.
- 관람 인증 내역의 신뢰도 유지를 위해, 하나의 콘텐츠(플레이스 리뷰 또는 클립)에는 관람 인증 태그를 1개만 사용할 수 있습니다.
- 방문 인증과 관람 인증은 중복하여 사용할 수 없습니다.
인증태그 이용 방법
1. 클립 프로필에서 장소∙쇼핑∙공연·전시·축제 인증태그 추가하기
클립 에디터에서 '정보태그' 단계로 진입하면 다양한 정보태그를 첨부할 수 있습니다.
이때 장소∙쇼핑∙공연·전시·축제 태그 중 본인이 실제로 방문∙구매∙관람하여 결제가 인증된 내역은 '방문인증'∙'구매인증'∙'관람인증' 표기가 노출됩니다.
인증 표기가 있는 태그를 첨부하여 클립을 업로드하고, 직접 경험한 후기와 감상을 공유해 보세요.
※ 클립 크리에이터 PC 버전에서도 동영상 업로드 시, 숏폼/롱폼 클립 모두 인증태그를 부착할 수 있습니다.
2. MY플레이스에서 장소∙공연·전시·축제 인증태그 추가하기
먼저 클립 프로필에 MY플레이스를 연결해 주세요.
클립 연결 방법 알아보기
- 클립 동영상 만들기 : MY플레이스에서 클립 만들기 버튼을 선택해 미디어를 고르고, '정보태그' 단계에서 인증 표기가 있는 태그를 첨부할 수 있습니다.
- 클립 게시물 만들기 : MY플레이스에서 영수증∙결제내역을 기반으로 미디어를 포함한 방문 인증 리뷰를 작성하면, 해당 리뷰가 클립 프로필의 게시물 형태로 노출되며 작성한 장소∙공연·전시·축제가 '인증 태그'로 변환되어 자동으로 추가됩니다.
단, 영수증∙결제내역 인증 없이 사진/영상, 장소검색만으로 작성된 리뷰는 '인증 태그'가 아닌 '일반 태그'로 노출됩니다.
1개의 인증 내역 기준, 클립 프로필 또는 클립 프로필과 연결된 MY플레이스에서 작성한 콘텐츠에 한해 인증 콘텐츠로 인정됩니다.
