# 네이버 광고주센터 도움말 「스마트스토어 광고란?」
- 출처: https://ads.naver.com/help/faq/950
- 최종 수정일: 2026-03-30
- 확인: 2026-09-20 (curl, ads_faq.py)
- 등급: A 공식 도움말

스마트스토어 광고는 AI가 내 스토어의 모든 상품을 분석하여, 구매 전환으로 이어지기 좋은 상품과 노출되는 지면에 딱 어울리는 상품을 자동으로 선별하여 네이버 서비스 곳곳에 내 상품을 자동으로 노출해 줍니다. 
​
스마트스토어 광고는 판매자분들이 복잡한 설정 없이 센터내에서 간편하게 광고를 시작하실 수 있습니다. 
​
광고 설정이 너무 어려우셨다면, 복잡한 설정이나 광고 소재 제작, 상품 선별 없이 AI가 모두 자동으로 알아서 해주는 스마트스토어 광고를 시작해 보세요.
