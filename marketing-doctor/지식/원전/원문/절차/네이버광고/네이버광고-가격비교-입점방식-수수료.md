쇼핑검색광고 상품을 이용하기 위해서는 네이버 가격비교에 입점(회원가입 및 상품등록)이 되어있어야 하며 네이버 가격비교 입점 방식은 크게 CPC Package 입점, CPS Package 입점, 스마트스토어 입점으로 나뉘어집니다.  
일반적으로 운영중이신 자체 쇼핑몰 사이트를 보유하신 경우, CPC Package 입점 방식을 선택하여 입점이 가능하며, 운영중인 쇼핑몰이 없는 경우, 스마트스토어 입점 방식을 선택하여 스마트스토어로 사이트는 만들면서 네이버 가격비교에 동시에 입점이 가능합니다. 기존에 운영중이신 스마트스토어 사이트가 있는 경우에도 스마트스토어에 가입된 정보로 네이버 가격비교에 입점 가능합니다. 
CPC Package 입점 방식 
CPC Package 입점이란 가장 일반적인 방식으로 별도의 쇼핑몰 사이트를 운영하시는 경우 입점하는 방식입니다. 온라인으로 입점 신청 후 운영하고 있는 쇼핑몰의 상품을 네이버 가격비교에 등록하여 상품에 대한 정보를 노출시킬 수 있습니다. 
상품을 클릭하여 운영하시는 쇼핑몰 페이지로 이동될 때마다 일정 금액(클릭당 단가)이 부과되며 클릭당 비용은 상품이 등록된 카테고리별 및 상품 가격에 따라 책정된 수수료율로 차등 계산됩니다. 
CPC Package 입점과 관련한 보다 자세한 내용은 아래 페이지에서 확인할 수 있습니다. 

CPC Package 입점 안내 

CPS Package 입점 방식
CPS Package 입점이란 제휴 담당자를 통해 입점 조건을 검토/협의 한 후 운영하고 있는 쇼핑몰의 상품을 네이버 가격비교에 등록하여 상품에 대한 정보를 노출시키는 방식입니다. 
매월 고정비와 네이버 가격비교를 통한 매출액의 일정 비율로 판매수수료가 부과됩니다.
CPS Package 입점과 관련한 보다 자세한 내용은 아래 페이지에서 확인할 수 있습니다. 

CPS Package 입점 안내 

스마트스토어 입점 방식
현재 스마트스토어를 운영중이거나 스마트스토어로 쇼핑몰을 운영 계획하시는 경우, 스마트스토어 판매자 가입을 통해 네이버 가격비교에 입점이 가능하며 보다 간편하게 네이버 가격비교 입점 및 상품 정보 노출이 가능합니다. 
스마트스토어로 네이버 가격비교에 입점하는 경우, 네이버 가격비교를 통한 상품 판매 시에만 2% 매출연동수수료가 발생되며 별도로 네이버 가격비교에서 부과되는 비용은 없습니다. (단, 네이버페이 수수료 별도)
