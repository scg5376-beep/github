# 스마트플레이스 사업주 고객센터 「유사 검색어 업체 노출 방법」

- 확인: 2026-09-19 (헤들리스 fetch_text.mjs, ?osType=COMMONOS + 15초 대기)
- 등급: A 공식 도움말

업체명과 유사하지 않은 검색어 추가 요청은 처리되지 않습니다.

지도 검색 영역에 노출되는 업체 정보는 업체명, 대표키워드, 업종, 주소에 포함된 단어를 조합하여 자동 노출됩니다.

유사 검색어로 업체 노출을 원한다면 아래와 같이 업체 정보를 보완해 주세요.

1. 대표키워드 수정 방법

특정 검색어로 검색 결과에 반영되고자 한다면 스마트플레이스 수정 페이지에서 대표키워드를 수정하세요.

- 수정 경로 (PC버전에서 제공): 스마트플레이스 > 내 업체 > 정보수정 버튼 > 기본정보 > 대표키워드​

2. 영문 업체명 수정 방법

한글 업체명인 경우, 영어로 검색했을 때 노출되지 않는다면 스마트플레이스 수정페이지에서 영문 업체명을 입력하세요. 

- 수정 경로: 스마트플레이스 > 내 업체 > 정보수정 버튼 > 기본정보 > 업체명 > 영문 업체명

3. 유의어 추가 요청

아래와 같은 유의어 보강이 필요한 업체명인 경우, 유의어 추가 요청을 통해 지도 검색 결과에 노출될 수 있습니다.

* 유의어 예시

1. 발음상 유의어(네이버/내이버)

2. 한글/영문 병용 표기(NHN엔터테인먼트/엔에이치엔엔터테인먼트)

유의어는 스마트플레이스 수정페이지에서 직접 입력이 어려우므로 아래 링크를 눌러 문의 바랍니다.

문의 접수 바로 가기
