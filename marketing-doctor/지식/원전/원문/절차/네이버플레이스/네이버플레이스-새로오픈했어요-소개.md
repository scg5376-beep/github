# 스마트플레이스 사업주 고객센터 「새로 오픈했어요 소개」
- 출처: https://help.naver.com/service/30026/contents/20510
- 확인: 2026-09-19 (헤들리스 fetch_text.mjs, ?osType=COMMONOS + 15초 대기)
- 등급: A 공식 도움말

새로오픈했어요는 네이버에서 검색한 지역(읍/면/동)에 개업한 지 90일이 넘지 않은 신규 업체를 소개하는 서비스입니다. 

1. 새로오픈했어요 노출 대상 업종

- 음식점, 미용실, 네일샵, 숙박 업종

숙박 업종은 아래 하위 업종에 따라 일부만 제공합니다.

- 노출 대상: 게스트하우스, 캠핑장, 전통숙소(한옥스테이), 민박, 여관, 펜션 업종

- 미노출 대상: 모텔, 호텔, 레지던스 업종

새로오픈했어요 노출 대상이 아닌 경우는 스마트플레이스 페이지에 신청란이 없습니다.

2. 새로오픈했어요 검색 결과 화면 예시

1) 미용실, 네일샵, 숙박 업종

플레이스 영역 아래에 새로오픈했어요 영역을 별도 제공합니다.

2) 음식점 업종

음식점 업종의 경우 별도 영역이 아닌 플레이스 > 키워드 필터를 통해 제공합니다. 

만약 해당 지역에 최근 개업한 음식점, 미용실, 네일샵, 숙박 업종들이 여러 개일 경우, 해당 업종의 업체들이 각 검색어에 따라 랜덤으로 변경되어 노출됩니다.
