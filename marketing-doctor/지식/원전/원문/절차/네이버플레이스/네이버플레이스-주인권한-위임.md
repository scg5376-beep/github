# 스마트플레이스 사업주 고객센터 「플레이스 주인 권한 위임 방법」
- 출처: https://help.naver.com/service/30026/contents/20522
- 확인: 2026-09-19 (헤들리스 fetch_text.mjs, ?osType=COMMONOS + 15초 대기)
- 등급: A 공식 도움말

스마트플레이스 등록 후, 정보의 관리 담당자가 변경된 경우, 변경된 담당자가 데이터 정보를 관리하도록 주인 권한을 위임할 수 있습니다.

주인 권한 위임 방법

1. 스마트플레이스 페이지에 접속합니다.

2. 내 업체 버튼을 클릭합니다.

3. 업체명 클릭하여 상세페이지에 접속합니다.

4. 업체 홈 오른쪽 더보기(⋯)를 클릭 후 주인 권한 위임을 클릭합니다.

신청 시, 위임받는 분의 네이버 ID를 입력하세요.

신청 후 일주일의 유예 기간이 주어지며 유예 기간 안에 위임받는 분이 수락해야 하고, 기간 동안 수락되지 않으면 주인 권한 위임이 취소됩니다.

위임 취소는 상대방이 수락하기 전 내 업체 페이지에서 할 수 있습니다.

주인 권한 위임이 완료되면 완료 안내 메일이 발송됩니다.

주인 권한 위임에 대한 수락/거절은 위임받는 분의 네이버 아이디로 로그인 후 등록 내역에서 주인 권한 위임 수락/거절을 클릭하세요.

이전 관리자에게 주인 권한 위임을 받을 수 없는 상황이면 아래 도움말을 참고해 주인 변경을 신청하세요.
