# 스마트플레이스 사업주 고객센터 「스마트플레이스 앱 알림 기능 안내」

알림 기능은 스마트플레이스, 예약 서비스, MY플레이스 서비스의 주요 내용을 바로 확인하고 관리할 수 있습니다.알림 설정은 홈 화면 아래쪽 알림 아이콘 클릭 후 설정 페이지에서 할 수 있습니다.​1. 스마트플레이스업체 정보 상태 변경, 새소식, 정보 수정 제안, 스마트콜 부재 등​2. 네이버 예약신청, 접수된 예약/주문 건들 과 변경 사항(확정, 취소, 리뷰 작성 등)​3. MY플레이스리뷰어가 작성한 영수증 리뷰 등록​※ 상위 메뉴 탭에서 안읽음을 체크하면 읽지 않은 알림만 확인할 수 있습니다.※ 플레이스와 예약/주문 개별 탭이 제공되며 서비스별 알림만 확인할 수 있습니다.​
