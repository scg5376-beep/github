# 스마트플레이스 사업주 고객센터 「방문자 리뷰 키워드 설정 방법」
- 출처: https://help.naver.com/service/30026/contents/20504
- 확인: 2026-09-19 (헤들리스 fetch_text.mjs, ?osType=COMMONOS + 15초 대기)
- 등급: A 공식 도움말

업체의 강점을 더 잘 드러낼 수 있는 키워드를 사업주(주인권한 보유 필수)가 직접 선택할 수 있습니다.

- 키워드 설정 방법: 스마트플레이스 > 내 업체 > 리뷰 > 키워드 설정

각 업종별로 적합한 키워드 문구를 선택형으로 제공하며, 일부 업종에는 키워드를 선택할 수 없습니다.

또한, 필수로 선택해야 하는 키워드는 필수 아이콘이 있으며 선택 해제를 할 수 없습니다.

설정 완료된 키워드는 리뷰어가 리뷰를 작성하는 페이지에 바로 노출됩니다.

※ 참고해 주세요!

- 키워드는 사업주가 원하는 문구를 직접 입력할 수 없습니다. 

- 업종별로 키워드 문구 및 개수가 다를 수 있습니다.

- 선택 해제한 키워드도 리뷰 작성 페이지에서 사용자가 모두 확인할 수 있습니다.

- '키워드 설정' 페이지에서 직접 선택하신 키워드는 리뷰 작성 시, 선택지로 가장 먼저 순서로 노출됩니다.
