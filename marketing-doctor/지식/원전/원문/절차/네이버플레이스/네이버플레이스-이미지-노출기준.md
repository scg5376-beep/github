# 스마트플레이스 사업주 고객센터 「업체 플레이스 이미지 노출 기준 안내」

1. 업체 이미지 노출 기준

업주가 스마트플레이스 페이지에서 직접 등록하고 관리하는 이미지가 우선 노출됩니다.

블로그 등 서비스에 업로드된 이미지 중 업체와 관련된 이미지를 자동 수집하여 추가로 노출하고 있습니다.

만약, 검색 결과에 등록된 식당의 업주인 경우 아래의 정보 수정 방법을 확인하여 직접 이미지를 추가하거나 삭제할 수 있습니다.

업체 정보 수정 방법 바로 가기

또한, 자동 수집된 이미지는 수정 및 삭제가 불가합니다.

2. 업체 상세 페이지 등록한 이미지 노출 기준

업체 이미지 노출 기준은 아래와 같습니다.

1) 업체 이미지 1개 등록 →  등록 이미지 1개 + 거리뷰 이미지 노출

2) 업체 이미지 2개 이상 등록 → 등록 이미지 2개 + 새소식 영상 또는 리뷰 수집 이미지 함께 노출

데이터 수집 결과에 따라, 검색 결과에 노출되는 이미지는 업체 정보 내 위에 노출되는 이미지와 다를 수 있습니다.
