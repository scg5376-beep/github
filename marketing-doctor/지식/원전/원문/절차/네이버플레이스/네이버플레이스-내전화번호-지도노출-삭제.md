# 스마트플레이스 사업주 고객센터 「내 전화번호가 지도에 노출되는 경우」

본인이 사용 중인 전화번호(휴대폰/가정집/내업체)로 등록된 업체 정보가 있다면 ARS 인증으로 직접 삭제할 수 있습니다.​잘못 걸려오는 전화로 불편을 겪고 있다면 아래 방법으로 진행하세요. ​업체 삭제 방법(ARS 인증)1. 스마트플레이스 > 업체 찾기 페이지 이동2. 조회 방법 중 전화번호로 조회하기를 선택하여 업체 조회3. 본인이 사용 중인 전화번호의 업체를 확인한 뒤 삭제 요청 버튼을 누르시면 ARS가 수신됩니다. ​
​ARS 인증이 완료되면 업체 정보는 자동 삭제되며 검색 결과에 제외되기까지는 최대 1일 이내의 업데이트가 소요됩니다. ​[영상으로 더 알아보기]
