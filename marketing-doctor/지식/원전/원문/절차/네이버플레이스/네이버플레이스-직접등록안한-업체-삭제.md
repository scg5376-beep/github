# 스마트플레이스 사업주 고객센터 「직접 등록하지 않은 내 업체 정보 삭제 방법」

업체 삭제 방법 (ARS 인증)

내 업체 또는 현재 사용 중인 전화번호가 이미 등록되어 직접 삭제가 어려운 경우에는 업체의 전화번호 ARS 인증 후 삭제 가능합니다. 

ARS 인증은 스마트플레이스 > 업체 찾기에서 업체 정보를 입력한 뒤 직접 이용할 수 있습니다. 

1. 조회 방법 세 가지 중 1개를 선택하여 조회하기를 버튼을 클릭

2. 업체 정보를 확인한 뒤 오른쪽 아래 '삭제 요청' 버튼을 누르면 ARS가 수신됩니다.

※ ARS 인증이 완료되면 업체 정보는 자동 삭제되며 검색 결과에 제외되기까지는 최대 1일 이내의 업데이트가 소요됩니다. 

휴/폐업 상태라 ARS 인증으로 업체 삭제가 어려운 경우

이미 휴/폐업 상태라 ARS 인증이 어려운 상황이라면 [정보수정제안 > 폐업] 항목을 눌러 제보해 주세요.

1) 정보 수정 제안하기 페이지 접속

2) 업체 정보 검색 후 폐업 항목 선택

3) 폐업임이 확인되는 사진 정보와 함께 접수

※ 참고해 주세요!

- 폐업/가격표사진/전화번호/영업시간/위치이전 항목에 대해서만 제보 가능합니다.

- 위 제보 항목 외에는 업주 요청 또는 자동 수집에 의해 노출되므로 제보받지 않습니다.

- 업종 또는 브랜드가 변경된 경우 정책상 수정이 불가하므로 폐업 제보하세요.

제보하신 내용은 해당 업체 정보의 정확성 여부를 판단하여 수정합니다.

검토 후 실제 검색 결과에 반영되기까지는 시일이 다소 소요될 수 있으며, 업데이트 결과에 대해서는 개별 안내를 하지 않습니다.
