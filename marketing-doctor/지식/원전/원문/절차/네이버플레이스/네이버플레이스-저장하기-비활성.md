# 스마트플레이스 사업주 고객센터 「저장하기 버튼이 비활성화된 경우」
- 출처: https://help.naver.com/service/30026/contents/20385
- 확인: 2026-09-19 (헤들리스 fetch_text.mjs, ?osType=COMMONOS + 15초 대기)
- 등급: A 공식 도움말

업체명, 상세 설명, 찾아오는 길 항목에 입력된 정보를 다시 한번 확인하세요.

한글, 영문, 한자, 일본어, 숫자, 특수문자(-_():&![],.%+~@*^'/?²℃※><)만 입력 가능합니다.

이 외 입력 제한된 특수문자나 이모티콘이 있다면 아래 예시 이미지처럼 빨간색 안내 문구가 표시되고 저장하기 버튼이 비활성화됩니다.

입력이 제한되는 특수문자 또는 이모티콘을 삭제하시면 저장하기 버튼이 활성화됩니다.

​Q1. 문장에 어떤 문자가 문제인지 알 수 없어요.

A. 보이지 않는 특수문자가 섞여 있는 경우입니다. 전체 내용을 삭제한 뒤, 하나씩 다시 입력해 보세요.

Q2. 과거에 입력 허용되던 특수문자가 지금은 안 돼요. 왜 그런가요?

A. 입력 기준이 변경되었기 때문입니다. 현재 기준에 맞게 내용을 다시 수정해 주세요.

Q3. 업체명에도 제한이 있나요?

A. 네, 업체명 및 찾아오는 길 항목에도 같은 입력 제한이 적용됩니다. 특수문자가 들어간 상호명이라도 허용 문자 외에는 사용할 수 없습니다.
