# 스마트플레이스 사업주 고객센터 「플레이스 전화번호 수정 방법」
- 출처: https://help.naver.com/service/30026/contents/20388
- 확인: 2026-09-20 (헤들리스)
- 등급: A 공식 도움말

플레이스 페이지에 표기되는 전화번호는 사업주(주인 권한)가 직접 수정할 수 있습니다.
- 수정 경로: 스마트플레이스 > 내 업체 > 업체 정보 > 기본정보 > 전화번호 항목
스마트플레이스에서는 한 업체마다 하나의 전화번호만 등록 가능하며, 다른 업체에 동일 번호가 이미 등록된 경우 중복으로 입력할 수 없습니다.
고객의 전화 연결 혼선을 방지하고, 검색 사용자에게 정확한 업체 정보를 제공하기 위해 스마트플레이스는 전화번호 중복 입력을 제한하고 있습니다.
여러 업체를 운영 중이신 경우라면, 각 업체마다 연락 가능한 고유 전화번호를 입력해 주셔야 합니다.
대표 전화번호 관련 문의 유형
Q1. 업체 대표 전화번호 수정이 필요합니다.
A. 대표 전화번호는 업체를 관리할 수 있는 주인 권한이 있다면 스마트플레이스 페이지 통해 직접 수정할 수 있습니다.
아래 방법을 확인하고 이용해 주세요.
업체 수정 방법 도움말 바로가기
Q2. 내 업체의 전화번호 수정을 위해 주인 권한이 필요합니다.
A. 주인 권한은 스마트플레이스 페이지를 통해 직접 신청/변경할 수 있습니다.
아래 방법을 확인하고 이용해 주세요.
주인 변경/신청 방법 도움말 바로가기
Q3. "중복된 전화번호입니다."라는 메시지가 나옵니다. 어떻게 해야 하나요?
A. 해당 번호가 이미 다른 업체에 등록되어 있다는 뜻입니다.
[스마트플레이스 > 업체 찾기 > 전화번호로 조회] 를 통해 현재 등록된 업체를 확인해 주세요.
삭제가 필요한 업체라면 '삭제 요청' 버튼을 눌러 ARS 인증 절차를 진행합니다.
플레이스에 등록된 내번호 삭제 방법 도움말 바로가기
ARS 인증 진행 성공 시, 해당 업체 정보가 바로 삭제되며, 삭제 완료 후 내 업체 정보 수정 페이지로 돌아가 다시 전화번호를 입력하시면 됩니다.
(!) 여러 업체를 관리 중이지만 업체별로 입력할 개별 전화번호가 없는 경우
예를 들어 A, B 업체 모두 하나의 전화번호로 동일하게 노출이 필요하다면, 아래 링크로 문의바랍니다.
