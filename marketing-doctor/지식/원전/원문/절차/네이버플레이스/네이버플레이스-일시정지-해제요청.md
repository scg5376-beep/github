# 스마트플레이스 사업주 고객센터 「업체 일시정지 해제 요청 방법」
- 출처: https://help.naver.com/service/30026/contents/20456
- 확인: 2026-09-19 (헤들리스 fetch_text.mjs, ?osType=COMMONOS + 15초 대기)
- 등급: A 공식 도움말

네이버에서는 보다 정확한 검색 결과를 제공하기 위해 등록된 업체 정보(업체명, 전화번호, 주소)를 대상으로 정기적인 모니터링을 진행하고 있습니다. 

해당 과정에서 스마트플레이스 반영 기준에 부합하지 않는 정보가 확인되면 검색 노출을 일시정지하고 있으며 일시정지된 다음 날부터 검색 결과에서 제외됩니다. 

대표적인 일시정지 예시

- 스마트플레이스 등록 기준에 부합하지 않은 경우

- 모니터링 or 제3자 신고 시 ARS 전화가 부재중, 결번, 폐업으로 확인되는 경우

일시정지 사유는 등록된 정보에 따라 다를 수 있으며 자세한 사유는 아래 방법으로 확인할 수 있습니다.

일시정지 사유 확인 방법 

1. 스마트플레이스 > 내 업체 > 해제 요청 > 일시정지 사유 확인하기 클릭

2. 네이버 회원정보의 기본 이메일 주소로 발송된 안내 메일을 통해 확인 가능

일시정지 사유를 명확히 파악하신 후에는 정지된 사유를 보강 또는 서류를 첨부하여 일시정지 해제 신청을 접수하세요.

일시정지 해제 신청 방법

1. 스마트플레이스 > 내 업체 > 해제 요청

2. 일시정지 해제 신청하기 > 신청 사유를 작성한 후 입증 서류를 첨부하고 신청하기 클릭

일시 정지 사유에 해당하는 내용을 보강하지 않고 신청하면 해제가 어렵습니다.

일시정지 해제 심사 기간은 영업일 기준으로 5일이 소요되며, 결과는 네이버 회원정보의 기본 이메일 주소로 안내됩니다. 

업체 일시정지 시점으로부터 30일 내에 업체 정상 운영이 확인되지 않으면, 스마트플레이스에 등록된 업체 정보는 자동으로 삭제됩니다.
