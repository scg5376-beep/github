# 스마트플레이스 사업주 고객센터 「리뷰 통계 안내」
- 출처: https://help.naver.com/service/30026/contents/20530
- 확인: 2026-09-19 (헤들리스 fetch_text.mjs, ?osType=COMMONOS + 15초 대기)
- 등급: A 공식 도움말

리뷰 통계는 네이버 이용자가 작성한 예약/주문 리뷰, 영수증 리뷰 데이터를 제공합니다.​1. 리뷰 지표플레이스에 작성된 주제별 리뷰 수, 리뷰어 수 정보를 제공합니다.
​2. 내용 분석플레이스에 작성된 예약/주문, 영수증 리뷰의 내용을 분석한 정보를 제공합니다.​이 정보는 음식점, 숙박, 헤어샵, 레저, 공연 업종에 한해서만 제공하며, 이 외 업종은 내용 분석 데이터를 제공하지 않습니다.
​3. 성별/연령별 비율리뷰를 작성한 고객의 성별/연령별 비율을 제공합니다.
​※ 리뷰 통계 데이터는 최근 1년 데이터만 조회 가능합니다.
