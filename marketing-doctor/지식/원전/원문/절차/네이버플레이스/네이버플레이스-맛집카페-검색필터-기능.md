# 스마트플레이스 사업주 고객센터 「맛집/카페 검색 결과 필터 기능 소개」
- 출처: https://help.naver.com/service/30026/contents/20417
- 확인: 2026-09-19 (헤들리스 fetch_text.mjs, ?osType=COMMONOS + 15초 대기)
- 등급: A 공식 도움말

유

1. 키워드 필터

키워드 필터에서는 기존에 있던 탐색 도구와 함께, 새로운 탐색 도구를 한데 모아 검색어마다 알맞은 도구를 제공합니다.

키워드 종류별 상세 내용은 아래를 참고하세요.

- 많이찾는: 검색어와의 연관성, 사용자 클릭 등의 인기도가 점수화되어 정렬

- 요즘뜨는: 많이찾는 정렬 기준을 기본으로 정보의 최신성이 강조되어 정렬

- 리뷰많은: 블로그리뷰 및 방문자리뷰 수가 합산되어 정렬

- 새로오픈: 검색한 지역에 개업한지 90일이 넘지 않은 신규 업체 노출 정렬

- 이 외 키워드: 사용자 리뷰, 검색어와의 연관성, 사용자 클릭 등의 인기도가 점수화되어 정렬

2. 인기메뉴

네이버에서 지역별로 맛집/카페의 인기메뉴를 확인하고 검색할 수 있습니다. 

인기 메뉴는 메뉴명+맛집(카페)로 검색하거나, 지역명+맛집(카페)로 검색하면 특정 지역의 인기 메뉴를 사용자의 니즈 또는 반응에 따라 자동으로 선별되어 노출합니다.

인기메뉴 데이터가 없을 경우 음식 종류로 노출됩니다. 

※ 참고해 주세요!

단, 지역별로 인기메뉴 데이터가 부족할 경우, 음식 종류로 노출될 수 있으며, 매장별 상황에 따라 메뉴 판매 여부가 달라질 수 있으므로 정확한 판매 여부는 방문 전 매장으로 확인 바랍니다.
