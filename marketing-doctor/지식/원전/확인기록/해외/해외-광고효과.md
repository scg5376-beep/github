## AD-01 · 어떤 가게가 광고로 이득을 보나

**확인한것**

```
Yelp 과 함께한 무작위 배정 현장실험. Marketing Science 42(3), 2023.
  식당 18,294곳 중 7,209곳을 무작위로 뽑아 표준 광고 패키지를 3개월 무료 제공

결과
  구매 의도 지표 여러 가지가 평균 7~19% 증가
  리뷰 수 5% 증가

효과가 큰 쪽
  독립 매장 · 평점 높은 곳 · 리뷰 많은 곳 · 실험 전 자연 유입이 많던 곳
```

**왜 이게 중요한가**

```
창고에 이미 있는 RV-01(리뷰가 매출을 움직인다)과 결론이 겹친다.

  RV-01   관측 자료 · 회귀 불연속   리뷰 별점이 매출을 움직인다 — 독립 매장에서만
  AD-01   무작위 배정 실험          광고 효과가 크다 — 독립 매장에서 더

방법이 다르고 재는 대상도 다른데 '독립 매장' 이라는 방향이 같다.
저자 한 명(Michael Luca)이 겹치는 건 짚어 둔다 — 완전히 독립된 두 팀은 아니다.
```

**반증시도**

```
③ 조건 — 반대 결과가 나온 실험을 일부러 찾았고, 찾았다. → AD-02

그리고 이 논문 자체의 한계를 셋 찾았다.

(가) 무엇을 쟀나?  '구매 의도 지표' 다. 매출이 아니다.
     길찾기·전화·웹사이트 방문·리뷰 같은 행동이다.
     → "광고하면 매출이 7~19% 오른다" 는 이 자료로 말할 수 없다.

(나) 광고비를 냈나?  안 냈다. 무료로 줬다.
     그러니 이건 '광고의 효과' 이지 '광고비의 값어치' 가 아니다.
     사장님이 진짜 알고 싶은 건 후자인데, 이 연구는 거기 답하지 않는다.

(다) 누가 같이 했나?  Yelp 이다. 광고를 파는 회사다.
     저자는 대학 연구자이고 학술지 심사를 거쳤지만, 협력 관계는 밝히고 쓴다.
```

**주의**

```
원문 미확인. nber.org · dash.harvard.edu · ssrn · pubsonline · dl.acm · insead
전부 이 환경에서 차단됐다. 확보한 것은 색인 페이지 넷의 초록이고, 넷이 같은 문장이다.
미국 Yelp 의 식당이다. 한국 네이버가 아니다.
```

## AD-02 · 같은 설계인데 결론이 반대로 나왔다

**확인한것**

```
eBay 의 대규모 현장실험. Econometrica 83(1), 2015. 경제학 최상위 학술지다.

브랜드 키워드 광고    단기 효과가 측정되지 않았다
비브랜드 키워드 광고  신규·저빈도 이용자는 반응했다
                      그런데 광고비 대부분을 쓰게 만드는 고빈도 이용자는 반응 없음
                      → 평균 수익률이 음수

★ 실험으로 구한 수익률이 통상적인 비실험 추정치의 일부에 불과했다
```

**두 실험이 왜 갈렸나**

```
정면으로 모순되지는 않는다. 처지가 다르다.

  eBay    이미 다 아는 큰 브랜드. 'eBay' 를 검색한 사람은 광고가 없어도 온다
          → 광고가 원래 올 사람을 다시 산 셈이 된다
  Yelp 식당  나를 모르는 사람이 '근처 파스타' 로 찾는다
          → 광고가 없으면 안 보인다

여기서 나오는 한 줄이 창고를 관통한다.
  광고는 '나를 이미 찾는 사람' 에게는 값어치가 없다.
  값어치는 '나를 모르는 사람' 에게 닿을 때 생긴다.

⚠️ 이 해석은 우리가 두 논문을 붙여 만든 것이다.
   어느 논문도 이 문장을 쓰지 않았다. 그렇게 밝히고 쓴다.
```

**주의**

```
원문 미확인. 관련 도메인 전부 차단.
2015년이다. 검색광고 지면과 알고리즘이 그 뒤로 많이 바뀌었다.
eBay 는 동네 가게와 처지가 정반대다. 그대로 옮기면 안 된다.
```
