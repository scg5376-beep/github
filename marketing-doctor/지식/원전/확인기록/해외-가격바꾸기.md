## SK-01 · 원가가 올랐을 때 셋 중 무엇을 하나  **A등급**

**확인한것 (전문 확인)**

```
MSI 워킹페이퍼 24-107, PDF 38쪽 전문을 열었다. 보관본은 ../원문/ 에 둘로 나눠 뒀다.
원가 상승에 대한 세 가지 대응을 같은 사람에게 물었다 (초콜릿, N=200)
  가격을 올린다   공정 85%     불공정 15%
  양을 줄인다     공정 57.5%   불공정 42.5%
  질을 낮춘다     공정 16.5%   불공정 83.5%

제품을 바꿔도 순서가 한 번도 안 뒤집혔다.
  스트리밍(N=201)        38.8% / 51.7% / 72.6%   ← 불공정 응답
  올리브 스프레드(N=200) 12%   / 36%   / 65.5%
  네 카테고리(N=502)     ~15%  / ~44%  / ~81%
  보습크림(N=1,001)      14.8% / 49.1% / 82.3%
왜 그런가 (실험 5)
  가격 인상은 눈에 보인다 → 덜 속인다고 느낀다
  양 줄이기·질 낮추기는 알아채기 어렵다는 점에서 똑같이 나빴다
  질 낮추기가 더 나쁜 진짜 이유는 "제품 자체가 달라졌다" 는 느낌이다
```

**반증시도**

```
③ 조건 — 세 갈래로 흔들었다.

(가) 한계 절이 있나?  없다. 사전등록 여섯 실험인데 저자가 밝힌 한계가 없다.
     그래서 내가 찾아 적는다.

(나) 잰 것이 무엇인가?  '공정하다고 말하는가' 이지 '그래서 안 사는가' 가 아니다.
     실험 4·5에서 구매 의향도 같은 방향이었지만 실제 매출을 잰 건 아니다.
     → "질을 낮추면 손님이 부당하다고 느낀다" 까지만 쓴다.

(다) 누구에게 물었나?  Prolific 응답자, 대체로 영미권. 한국 표본이 아니다.
     가상 시나리오이고 이름 없는 '제조사' 다. 얼굴 아는 단골 가게가 아니다.

(라) 반대 방향 자료를 찾았나?  못 찾았다. 순서가 뒤집힌 연구를 못 찾았다는
     것까지가 기록이다.
```

**주의**

```
A등급이지만 판본에 주의한다. 확보한 것은 MSI 워킹페이퍼(2024-02) 판본이다.
학술지 게재본(JCR, doi 10.1093/jcr/ucag019)은 academic.oup.com 차단으로 못 열었다.
게재 과정에서 수치가 조정됐을 수 있다. 인용할 때 판본을 밝힌다.
```

## FP-01 · 이중 자격 — 왜 올리느냐가 전부다

**확인한것**

```
Kahneman·Knetsch·Thaler 1986, American Economic Review.
캐나다(토론토·밴쿠버) 전화 설문.

눈삽 문항
  "철물점이 눈삽을 $15 에 팔다가 큰 눈이 온 다음 날 $20 으로 올렸다"
  응답자 107명 중 82% 가 불공정하다고 답했다.

이중 자격
  손님에게는 기준 가격이, 가게에는 기준 이익이 있다.
  기준 이익을 지키려는 인상은 공정, 수요를 이용한 인상은 불공정.
```

**반증시도**

```
③ 조건 — 두 갈래로 흔들었다.

(가) 말과 행동이 같은가?  아니다. 이건 전화 설문이고 가상 상황에 대한 '말' 이다.
     현실에서는 항공사·호텔·차량호출·공연 티켓이 수요에 따라 값을 올리고도
     장사를 계속한다. ATM 수수료 연구에서는 공정성 인식이 행동 의도와
     유의미하게 연결되지 않았다는 보고도 있다(원문 미확인).
     → '불공정하다고 느낀다' 와 '그래서 안 온다' 는 다른 이야기다.
       다만 동네 가게는 대체할 곳이 많아 항공사와 처지가 다르다.
       이 차이는 내 판단이지 연구가 말한 게 아니다.

(나) 재현됐나?  방향은 재현됐다. Tarrahi·Eisend·Dost 2016 메타분석(FP-04).
     다만 그쪽도 초록을 못 봐서 효과 크기를 모른다.
(다) 문화가 다르면?  다르다. → FP-05
```

**주의**

```
원문 미확인. 1986년 캐나다 표본이다. 82% 라는 숫자를 지금 한국에 그대로 옮기지 않는다.
쓸 수 있는 건 '왜 올리느냐가 공정성 판단을 가른다' 는 방향이다.
```

## FP-02 · 손님은 우리 원가를 모른다

**확인한것**

```
Bolton·Warlop·Alba 2003, Journal of Consumer Research.

손님은 파는 값이 '공정한 값' 보다 훨씬 높다고 믿는 쪽으로 기운다.
  · 가게가 무는 비용의 전 범위를 계산에 안 넣는다
  · 가격 차이를 대부분 '이익' 으로 돌린다
  · 물가 상승분의 영향도 과소평가한다
반대로 그 요소들을 눈에 보이게 해주면 공정하다는 판단이 올라간다.
```

**왜 이게 중요한가**

```
FP-01 만 읽으면 "원가 올랐다고 말하면 된다" 로 끝난다. 그런데 안 된다.
손님은 그 말을 곧이 안 듣는다. 원가를 원래 과소평가하고 있기 때문이다.
  FP-01  이유를 말해야 한다
  FP-02  말만으로는 부족하다. 보이게 해야 한다
```

**주의**

```
원문 미확인(academic.oup.com 차단). 초록과 이차 요약으로만 확인했다.
"얼마나" 과소평가하는지 숫자를 모른다. 숫자는 인용하지 않는다.
```

## FP-03 · 어떤 비용이 올랐다고 말하느냐  **C등급**

**확인한것**

```
Bolton & Alba 2006. 가격 변화와 결이 맞는(alignable) 비용일수록 공정하게 느껴진다.
  생산 원가(재료비)  → 결이 맞는다  → 더 받아들여진다
  일반 관리비(간접비) → 결이 덜 맞는다 → 덜 받아들여진다
```

**주의**

```
⚠️ C등급이다. SK-01 원문이 요약한 것만 봤다. 원 논문은 초록도 확인하지 못했다.
표본·설계·효과 크기를 하나도 모른다.
쓸 때는 "SK-01 이 인용한 바에 따르면" 으로 밝힌다. 단독 인용하지 않는다.
```

## FP-04 · 메타분석  **C등급**

```
⚠️ 서지 정보와 "이중 자격을 재현했다" 는 요약만 확보했다.
포함 논문 수·효과 크기·조절변수를 모른다. 숫자는 절대 인용하지 않는다.
쓸 수 있는 건 "메타분석에서도 같은 방향이 나왔다" 는 사실 하나뿐이다.
```

## FP-05 · 문화가 다르면 기준도 다르다

**확인한것**

```
Chen·Bolton·Ng·Lee·Wang 2018, Journal of Consumer Research 45(1).

비대칭 가격(원가 오르면 올리고, 내려도 그대로 두기)에 대해
  집단주의 문화  덜 공정하다고 본다. 실제로도 비대칭 가격이 덜 흔하다
  개인주의 문화  거래 규범과 맞아 덜 거슬린다

이유: 집단주의 문화의 손님은 가게에 '선의(benevolence)' 를 기대한다.
해법: 가게가 그 결정을 선의로 설명하면 문화 차이가 줄어든다.
```

**반증시도**

```
③ 조건 — "그럼 한국은?" 을 확인하려 했다.

한국이 표본에 들어갔는지 확인하지 못했다.
저자 중 한 명(Dongwon Lee)이 한국계로 보이지만 그건 근거가 아니다.

→ "한국은 집단주의니까 이렇다" 로 단정하지 않는다.
  쓸 수 있는 건 "문화에 따라 다르다는 게 확인됐고,
  한국은 대체로 집단주의로 분류돼 왔다" 까지다.
  이 연결은 우리가 붙인 것이라고 밝히고 쓴다.
```

**주의**

```
원문 미확인. 표본 국가 목록이 특히 궁금하다. 사장님이 열어 주시면 A로 올린다.
```
