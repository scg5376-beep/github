## RV-01 · Reviews, Reputation, and Revenue (Luca)

**확인한것**

```
결과 세 가지
  ① 별점 1개 오르면 매출 5~9% 증가
  ② 이 효과는 독립 매장에서만 나타난다.
     체인 소속 매장은 평점이 매출에 영향을 주지 않는다.
  ③ Yelp 보급이 늘수록 체인 매장의 시장 점유율이 떨어졌다.
```

**반증시도**

```
③ 조건 — 반증을 찾아봤고, 결과를 여기 적는다.

찾은 한계 (연구 자체가 밝히거나 후속 논의에서 지적된 것)
  · 회귀 불연속은 '국소' 효과다. 경계선 근처 매장에만 해당한다.
    내적 타당도는 높지만 외적 타당도는 낮을 수 있다.
  · 미국 음식점 데이터다. 다른 업종·나라로 옮기는 건 그럴듯할 뿐 검증 안 됐다.
  · Yelp 보급률이 낮던 초기 데이터다. 포화된 지금은 크기가 다를 수 있다.
  · Yelp 의 검색 랭킹 효과를 분리하지 않았다. 순위 효과가 섞였을 수 있다.

결과를 뒤집는 연구는 못 찾았다. 오히려 독립 재현이 있었다 → RV-02.
```

**주의**

```
원문(HBS working paper PDF) 미확인 — hbs.edu 접근 차단.
SSRN·HBS·Harvard Magazine·RePEc 네 곳이 같은 수치를 말한다.
'별점 1개 = 매출 5~9%' 를 한국 매장에 그대로 옮기지 않는다.
옮길 수 있는 건 숫자가 아니라 방향이다 (개념 파일에 적어뒀다).
```

## RV-02 · Learning from the Crowd (Anderson & Magruder)

**확인한것**

```
별 0.5개가 더 붙으면 그 식당이 매진되는 빈도가 19%p 늘었다 (49% 증가).
그리고 대체 정보가 부족할수록 효과가 컸다.
```

**주의**

```
원문 미확인. 학술지 초록과 2차 요약으로 확인했다.
RV-01 과 도시·자료·방법이 다른데 같은 방향이 나왔다는 게 이 항목의 값어치다.
'19%p' 는 매출이 아니라 예약 매진 빈도다. 매출 증가율로 옮겨 쓰면 안 된다.
```

## RP-01·02 · 리뷰에 답글 달기

**확인한것**

```
2017  Proserpio & Zervas   답글 시작 → 평점 +0.12별, 리뷰 수 +12%
                           부정 리뷰가 줄어들되 길어진다
2025  Jin 외               정중할수록 효과가 깎인다.
                           설득하려는 시도로 읽히기 때문이다.
```

**반증시도**

```
③ 조건 — 효과의 방향은 여럿이 확인하지만 조건과 위험이 함께 나온다.

· 정중함 역효과 (RP-02). '고객님의 소중한 의견 감사드립니다' 식 과잉 정중이
  오히려 효과를 깎을 수 있다.
· 악순환 위험. 답글이 후속 게시물의 양과 부정성을 둘 다 늘려
  불만이 커지는 '악순환' 을 만들 수 있다는 연구가 있다.
  → '어떤 리뷰에 어떤 방식으로' 답하느냐가 관건이라는 것이 공통 결론이다.
· 다른 연구는 답글이 리뷰 '양' 에는 유의한 영향을 주지만
  '평점' 에는 뚜렷하지 않았다고 보고한다 (맥락에 따라 다르다).
· 답글을 받고 리뷰를 수정한 사용자는 평균 1별 상향했다는 보고도 있다.

· 역인과 — 평점이 떨어진 뒤에 답글을 시작하는 경향이 있다.
  RP-01 저자들이 이를 다뤘다고 보고되나 원문으로 확인하지 못했다.

⚠️ RP-02 는 학술지명을 확보하지 못했다. 인용 전에 서지를 확인해야 한다.
```

**주의**

```
원문 미확인 (학술지 접근 차단). 호텔·여행 업종 데이터다.
'0.12별' 은 작아 보이지만 RV-01 기준으로 매출 약 0.6~1.1% 에 해당한다
(별 1개 = 5~9%). 다만 그 환산은 내가 한 계산이지 연구 결과가 아니다.
```

## LR-01·02 · 문의에 얼마나 빨리 답하나

**확인한것**

```
[LR-01 HBR 2011] 미국 2,241개 기업에 시험 문의를 넣어 감사
  1시간 내 응답 37% / 1~24시간 16% / 24시간 초과 24% / 아예 응답 안 함 23%
  응답한 곳의 평균 응답 시간 42시간
  1시간 내 접촉 → 리드 검증 확률 약 7배
  24시간 이상 기다린 곳 대비 60배 이상

[LR-02 MIT·InsideSales 2007] 6개 회사 · 리드 15,000+ · 통화 시도 100,000+
  "5분 안에 연락하면 접촉 100배 · 검증 21배" 의 실제 출처
```

**반증시도**

```
③ 조건 — 출처가 잘못 붙은 사례를 잡았다. RH-01 과 같은 구조다.

업계에 도는 문장   "하버드 연구에 따르면 5분 안에 답하면 100배"
실제               100배·21배는 2007년 MIT/InsideSales 연구 숫자다.
                  HBR(2011) 은 다른 연구이고 다른 숫자(7배·60배)를 냈다.
                  HBR 이 더 유명한 이름이라 수치가 그쪽에 붙어 떠돈 것으로 보인다.

→ '하버드 연구에 따르면 5분 안에 100배' 라고 쓰면 틀린다.

LR-02 의 한계
  6개 회사 데이터다. 표본이 좁다.
  2004~2007년 자료다. 20년 가까이 됐고 연락 수단이 완전히 달라졌다
  (그때는 전화 중심, 지금은 DM·카톡·댓글).
  B2B 영업 리드 맥락이다. 동네 가게 문의와 성격이 다르다.
```

**주의**

```
둘 다 원문 미확인. 미국 B2B 데이터다.
'100배' 를 동네 가게에 옮기지 않는다. 옮길 수 있는 건 방향이다 —
빨리 답할수록 낫고, 아예 안 답하는 곳이 생각보다 많다.
```
