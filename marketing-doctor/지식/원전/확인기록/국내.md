## KR-01 · 2024년 기준 소상공인실태조사

**확인한것**

```
소상공인 기업체 613만개 · 종사자 961만명 · 창업비용 8,300만원(600만원 감소)
디지털·스마트 기술 활용 비율 27.2% (전년 대비 +9.2%p)
활용 분야 — 온라인 판로 49.0% / 매장관리 34.4% /
            경영관리 소프트웨어 19.6% / 스마트 주문·결제 15.2%
창업자 연령 — 40대 +22.9% · 30대 +15.8%
```

**근거강도**

```

숫자 불일치 없음. 원문 보도자료만 못 열었다.
```

**못한것**

```

```

## KR-02 · 2026 인터넷 이용자 조사 (NPR)

**확인한것**

```

숏폼 매일 시청 82.5% / 하루 3회 이상 60.5%
  숏폼 보다 제품 정보 검색 62.6% / 보고 바로 구매 24.7%
크리에이터 콘텐츠 시청 경험 63.5% (20대 78.5% 로 최고)

20대 생성형 AI 이용 95.9%
10대 유튜브 시청 비중 50.8% vs TV 채널 21.4%

30대는 제품 구매 시 텍스트 채널에서 정보 탐색 (숫자 없는 정성 서술)
```

**주의**

```

```

## KR-04 · AI 검색 트렌드 리포트 2026

**확인한것**

```
[상반기] 검색 서비스 이용률
  네이버   81.6%   (여전히 1위, 다만 하락 추세)
  유튜브   72.3%   (하락 추세)
  ChatGPT  54.5%   (과반 돌파)
  Gemini   28.9%   (전년 대비 3배 가까이 급증)
지식 습득 목적 검색 +5.9%p — 검색 목적 중 1위

[하반기] 2026-07-02 조사
  만족도    Gemini 77.3% > ChatGPT 70.6%
  유료 의향  Gemini 42.1% > ChatGPT 39.4%
  검색 이용자 절반 이상이 ChatGPT·Gemini 이용

[행태 변화]
  AI 가 원하는 답을 못 주면 포털로 돌아가지 않는다.
  질문을 고치거나 다른 AI 를 교차로 쓴다.
```

**주의**

```
리포트 원문 미확인 — 블로그 요약과 언론 보도로만 확인했다.
상반기 표본 서술(2025년 3월·12월 각 1,000명)은 언론 요약 기준이라
원문으로 재확인이 필요하다.
'검색 서비스 이용률' 이 경험률인지 최근 이용률인지 정의를 못 봤다.
정의를 모른 채 다른 조사와 직접 비교하지 않는다.
```

## KR-05 · 기업생멸행정통계

**확인한것**

```
신생기업  92만 2천개 (전년 대비 -3.5%, 4년 연속 감소)
소멸기업  79만 1천개 (전년 대비 +5.3%, 4년 만에 증가)

생존율
  1년  64.4%  (2022년 신생기업 기준, 전년 대비 -0.5%p)
  5년  36.4%  (2018년 신생기업 기준, 전년 대비 +1.6%p)

산업별 5년 생존율 상위
  전기·가스·증기 79.1% / 보건·사회복지 62.9% / 수도·하수·폐기 55.1%
```

**주의**

```

'신생기업' 은 전 산업의 영리기업이다. 소상공인만 뽑은 수치가 아니다.
```

## ⚠️ 생존율 숫자가 출처마다 다르다

```
국가데이터처 기업생멸행정통계   1년 64.4% / 5년 36.4%
다른 보도에서 본 수치           1년 77.0% / 3년 52.3% / 5년 40.2%
또 다른 보도                   창업 5년 생존율 39.6% (생활업종)
                              개인사업자 평균 생존기간 2.8년

두 번째·세 번째 수치는 출처를 특정하지 못했다. 국세청 생활업종 통계이거나
개인사업자만 뽑은 것으로 보이지만 **확인 못 했다.**

→ 국가데이터처 수치만 쓴다. 나머지는 출처가 확인될 때까지 인용하지 않는다.
→ 업종별 1년 생존율(미용실 91.6% 등)도 같은 이유로 보류한다.
```
