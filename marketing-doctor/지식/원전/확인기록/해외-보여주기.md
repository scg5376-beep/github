## PH-01 · 전문가 사진으로 바꾸면 얼마나 달라지나

**확인한것**

```
에어비앤비 숙소 7,423곳 · 16개월 · 사진 51만 장 이상.
전문 사진사가 찍은 사진으로 바꾼 뒤 점유율 +8.98%, 연 약 $2,521.

가장 쓸모 있는 숫자는 이것이다.
  효과의 58.83% 가 '전문가가 찍었다는 표시' 가 아니라 사진 품질 자체에서 왔다.
  → 배지를 사는 게 아니라 사진을 좋게 만드는 게 절반 이상이다.
```

**반증시도**

```
③ 조건 — 세 갈래로 흔들어 봤다.

(가) 무작위 배정인가?  아니다.
     사진사를 부를지는 사장이 스스로 정했다. 부지런한 사장이 부른다.
     그 사장은 사진 말고도 잘한다. 그러면 효과가 부풀려진다.
     저자들도 처치군·대조군의 사전 특성이 다르다고 인정하고
     성향점수매칭·민감도 분석으로 보완했다고 밝힌다. 그래도 실험은 아니다.

(나) 숫자가 서로 맞는가?  안 맞는다.
     +8.98%(점유율) 와 +17.51%(수요) 가 같이 돌아다닌다.
     평균 점유율 21.057% × 17.51% ≈ 3.7%p 라 8.98% 와 맞지 않는다.
     판본(ICIS 2016 / 워킹페이퍼 / 학술지본)이 여럿이라 그런 것으로 보인다.
     ⚠️ 추정이다. 원문을 못 열었다. → 불일치.md 에 적었다.

(다) 같은 팀이 나중에 뒤집지 않았나?  단서를 달았다. → PH-03
```

**주의**

```
원문 미확인(pubsonline·SSRN·cmu.edu 모두 이 환경에서 차단).
숙박업 데이터다. 음식점·미용실에 그대로 옮기면 안 된다.
'사진 바꾸면 매출 9% 오른다' 로 인용하지 않는다. 방향만 쓴다.
```

## PH-02 · 좋은 사진의 정체는 색이었다

**확인한것**

```
사진을 12가지 특성으로 분해했다. 구도 · 색 · 피사체와 배경의 관계.
수요에 가장 크게 작용한 것은 색(color).
```

**주의**

```
Management Science(동료심사)에 실렸다. PH-01 보다 근거가 단단한 쪽이다.
다만 이것도 에어비앤비 숙소 사진 이야기다.
'색이 제일 중요하다' 를 모든 업종의 법칙으로 옮기지 않는다.
원문 미확인.
```

## PH-03 · 같은 팀이 스스로 단서를 달았다

**확인한것**

```
맨해튼 숙소 958곳 · 1년.
좋은 사진은 지금 손님을 끌지만, 실물이 기대에 못 미치면
나쁜 리뷰 또는 무리뷰로 이어져 나중 수요를 깎는다.
```

**왜 이게 중요한가**

```
PH-01 을 쓴 저자진(Zhang·Singh·Srinivasan)이 그대로 들어 있다.
남이 반박한 게 아니라 자기들이 조건을 붙인 것이다.
남들이 인용할 때는 대개 PH-01 의 +9% 만 옮긴다.
우리는 PH-03 까지 같이 쓴다. 그게 다른 점이다.
```

**주의**

```
SSRN 워킹페이퍼다. 2026-08 기준 동료심사 학술지 게재를 확인하지 못했다.
'저품질 사진이 낫다' 로 읽으면 틀린다. 원제가 물음표로 끝난다.
말하는 것은 '사진 품질을 실물 수준에 맞춰라' 다.
원문 미확인.
```

## PH-04 · 음식 사진을 너무 많이 보면 물린다

**확인한것**

```
음식 사진을 반복 평가하면 실제로 먹지 않았는데도
비슷한 맛의 음식에 대한 즐거움이 떨어진다(감각특정적 포만).
Journal of Consumer Psychology 2014, 실험 2건.
```

**반증시도**

```
③ 조건 — 반대 방향 연구가 많아서 경계를 찾아봤다.

효과가 나타난 조건이 좁다.
  · 같은 음식 사진을 30번 넘게 반복해서 본 경우
  · 사진 속 '음식' 에 주의를 기울인 경우 (배경을 보면 효과 없음)
  · '먹는 장면' 을 떠올리게 하는 자극이었던 경우

반대 방향도 있다.
  사진이 식욕을 돋운다는 연구('visual hunger') 계열이 따로 있다.
  생리 지표(인슐린·그렐린) 쪽은 연구마다 결론이 갈려 결론이 안 났다.

→ '음식 사진을 줄여라' 로 쓰면 안 된다.
  쓸 수 있는 건 '같은 메뉴 같은 각도 사진을 끝없이 반복하는 건 득이 없다' 까지다.
```

**주의**

```
원문 미확인. 실험실 연구다. 가게 매출을 잰 게 아니다.
표본 크기를 확인하지 못했다. 사장님이 원문을 열어 주시면 승급한다.
```

## 안 쓰기로 한 수치

```
① "사진 있는 업체는 길찾기 요청 42% · 웹사이트 클릭 35% 더 받는다"
   인용한 곳이 전부 SEO 대행사 블로그다. 하나같이 '구글 자체 데이터' 라고만 하고
   원 문서·연도·표본을 대지 않는다. 구글 공식 문서에서 확인 실패.
   → 이 창고에서는 쓰지 않는다. 사장님이 구글 공식 페이지를 찾아 주시면 다시 본다.

② "전문 사진 쓰면 예약 2.5배 · 호스트 월 평균 $1,025"
   에어비앤비 자체 홍보 수치다. 방법론·비교 대상 비공개.
   PH-01 의 학술 수치와 자릿수가 다르다. → 쓰지 않는다.
```
