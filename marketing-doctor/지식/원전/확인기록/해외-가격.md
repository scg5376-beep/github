## PR-01·02·03 · 9로 끝나는 가격

**확인한것**

```
2003  Anderson & Simester   현장실험 3건. 9로 끝내면 수요가 늘었다.
                            신상품에서 효과가 더 강했다.
2005  Thomas & Morwitz      실험 5건. 단, 맨 왼쪽 자리가 바뀔 때만이다.
                            $2.99 vs $3.00 은 효과 있고, 앞자리가 같으면 없다.
2020  Fraccaro & Macé       명품·고급 영역에서는 역효과일 수 있다.
                            저품질·기만으로 인식되는 경향.

작동 원리로 제시된 설명 두 가지
  level effect  사람이 가격을 왼쪽부터 읽고 끝자리를 흘려버린다
  image effect  9로 끝나면 '싼 물건' 이라는 신호로 읽는다
  → 둘째 설명이 명품에서 역효과가 나는 이유를 함께 설명한다.
```

**반증시도**

```
③ 조건 — 반증을 찾았고, 조건이 좁혀졌다.

한 2023년 메타분석은 9로 끝나는 가격이 품질 이미지를 해치지는 않는다고
보고했다고 한다(전반적으로 효과 없음). 그런데 암묵적 측정을 쓴 실험에서는
저품질 연상이 강하게 나왔다 — 설문으로 물으면 안 잡히는 반응이다.

⚠️ 이 2023년 메타분석은 **저자·학술지를 확보하지 못했다.**
   서지가 없으므로 글에 인용하지 않는다. 조사중 항목으로 남긴다.

소매업체들이 99 대신 95 로 끝내는 관행도 이미지 우려와 연결돼 논의된다.
```

**주의**

```
세 편 다 원문 미확인 (학술지 접근 차단).
미국·유럽 소매 데이터다. 한국 원 단위(9,900원 문화)에서 검증된 자료는 못 찾았다.
'9를 붙이면 더 팔린다' 로 단순화하면 PR-02 와 PR-03 을 둘 다 빠뜨린다.
```

## FR-01 · 공짜는 다른 종류의 가격이다

**확인한것**

```
허쉬 1센트 vs 린트 14센트   → 다수가 린트(비싸고 좋은 것)
허쉬 0센트 vs 린트 13센트   → 다수가 허쉬로 갈아탐

가격차는 13센트로 똑같다. 바뀐 건 한쪽이 '공짜' 가 된 것뿐이다.
```

**반증시도**

```
③ 조건 — 경계 조건이 여러 개 확인됐다. 효과가 늘 나타나는 게 아니다.

· 실험이 싸고 덜 중요한 물건에 한정돼 있다.
  큰 금액·중요한 결정에서도 통하는지는 열려 있는 질문이다.
· 제안이 주로 실용적(utilitarian) 성격이면 효과가 사라진다.
· 개인정보처럼 중요한 비금전적 비용에는 적용되지 않는다.
· 초콜릿에서는 재현됐으나 고가 단일 제품 맥락에서는 증거가 약했다.
· 가격 비율 정보를 함께 주면 고가 복합제품 맥락에서 효과가 사라졌다.

→ '공짜는 늘 강하다' 가 아니다. 싸고 가벼운 결정에서 강하다.
```

**주의**

```
원문 미확인. 미국 실험이고 초콜릿 단가 수준이다.
'공짜로 바꾸면 더 팔린다' 로 옮기면 위 경계 조건을 전부 빠뜨린다.
```

## AN-01 · 앵커링

**확인한것**

```
먼저 본 숫자가 뒤의 판단을 끌어당긴다.
Klein et al.(2014) 의 대규모 사전등록 다중 실험실 재현에서 방향이 확인됐다.
심리학에서 재현이 잘 되는 편에 드는 현상이다.
```

**반증시도**

```
③ 조건 — 방향은 살아남았지만 크기와 조건이 크게 깎였다.

· 효과 크기를 재평가한 연구가 있다. 표본이 작았던 초기 연구들이 과장했다는 것
  (Li 2025, Economic Inquiry). 방향은 견고하되 특정 수치는 믿지 말라는 뜻이다.
· 익숙한 물건에서는 효과가 약하다. 낯선 물건에서 강하다.
· 무관한 환경 앵커(우연히 눈에 띈 숫자)는 증거가 약하고 무효 결과도 있다.
· ★ 소비재 가격 앵커는 '가상의 결정' 일 때만 유지된다는 연구가 있다.
  실제로 돈을 쓰는 상황에서는 나타나지 않았다는 것이다.

→ '비싼 걸 먼저 보여주면 다음 게 싸 보인다' 를 가격 전략의 기둥으로 삼으면 안 된다.
```

**주의**

```
원문 미확인. 특정 수치를 인용하지 않는다 — 크기가 과장됐다는 게 요점이다.
'가상 결정에서만' 이라는 연구는 특히 중요하다. 실제 매장은 실제 돈이 오간다.
```

## LA-01·02 · 손실 회피

**확인한것**

```
1979  Kahneman & Tversky   손실이 이득보다 크게 느껴진다. 교과서 계수 약 2.25
2018  Gal & Rucker         "손실 회피가 크게 과잉일반화됐다"
                           현장 계수는 2.0~2.5 가 아니라 1.0~1.5 에 가까운 경우가 많다
                           강한 형태도 약한 형태도 지지되지 않는다
이후   재반박               "Bringing (Contingent) Loss Aversion Down to Earth" (JCP)
```

**반증시도**

```
③ 조건 — 반박과 재반박을 둘 다 확인했다.

Gal & Rucker 는 손실 회피로 잘못 귀속돼 온 현상도 지적한다 —
  처분 효과 (반사 효과나 평균회귀 믿음으로 설명될 수 있다)
  매몰비용 효과 (손실을 인정하지 않으려는 것이지, 손실이 더 크게 느껴지는 게 아니다)

그런데 이 반박에 대한 재반박이 같은 학술지에 실렸다. 끝난 논쟁이 아니다.

→ '2배' 라는 숫자는 쓰지 않는다.
→ '손실 프레이밍이 무용하다' 도 쓰지 않는다.
→ '널리 인용되는 2배는 근거가 약하다' 까지가 지금 말할 수 있는 선이다.
```

**주의**

```
원문 미확인 (학술지 접근 차단).
마케팅 강의에서 '손실 회피는 2배' 라고 단정하는 걸 자주 본다.
그 숫자를 근거로 겁주는 문구를 만들지 않는다.
```
