## SI-01 · 검색은 세 갈래다 (검색 의도)

**확인한것**

```
정보형 39~48%  ·  거래형 22~36%  ·  이동형 20~24.5%
2002년 AltaVista 질의 로그 기준.
```

**주의**

```
⚠️ 2002년 데이터다. 비율을 그대로 인용하면 안 된다.
   지금도 쓸 수 있는 건 '세 갈래 구분' 이라는 틀뿐이다.
   최신 자료는 SI-02 에 있다 — 다만 그쪽도 자료끼리 크게 어긋난다.
원문 미확인.
```

## SI-02 · 검색 의도 분포 최신 조사

**반증시도**

```
③ 조건 — 최신 자료를 찾았더니 자료끼리 극단적으로 어긋났다.

거래형 비율
  Broder 2002    22 ~ 36%
  Semrush 2026   전년 대비 +19% 성장 (절대 비율은 미확보)
  Datos 2025     0.82%          ← 40배 차이

원인 추정 — 분류 체계가 다르다.
  Broder 는 3분류(정보/거래/이동)
  최신 조사는 4~6분류. '상업형(commercial investigation)' 을 따로 떼면
  '살까 말까 알아보는' 질의가 거래형에서 빠져나간다.
  그러면 '지금 사겠다' 만 남아 거래형이 급감한다.
⚠️ 이건 추정이다. 세 곳 다 분류 기준을 공개하지 않았다.

→ 어느 비율도 단정하지 않는다. '조사마다 크게 다르다' 는 사실 자체를 쓴다.

성격 한계
  셋 다 상업 조사기관이다. 동료심사가 없고 방법론이 공개되지 않는다.
  데이터 규모(184억 건, 5천만 프롬프트)는 크지만 규모가 정확성을 보장하지 않는다.
```

**주의**

```
원문 미확인. "연구에 따르면" 이 아니라 "OO 사의 분석에서" 로 쓴다.
ChatGPT 의 '생성형 37.5%' 는 특히 조심한다 — 새 분류라 비교 대상이 없다.
```

## RD-01 · 사람은 웹에서 훑는다

**확인한것**

```
평균 20~28% 만 읽는다. 232명 아이트래킹으로 처음 보고(2006), 20년간 일관.

훑는 방식 네 가지
  F 패턴        소제목이 없을 때. 왼쪽만 훑고 나간다
  케이크층 패턴  소제목이 있을 때. 소제목만 따라가다 관심 있는 데서 멈춘다
  점박이 패턴    찾는 낱말만 튀어 다닌다
  몰입 패턴      처음부터 끝까지 읽는다 (드물다)
```

**반증시도**

```
③ 조건 — 성격상의 한계가 더 크다.

⚠️ 이건 상업 UX 연구기관의 자체 연구다. 동료심사 논문이 아니다.
   반박 논문을 찾는 방식으로는 검증이 잘 안 된다.
   대신 20년간 반복 확인됐다는 점, 그리고 실무에서 널리 재현된다는 점이 근거다.

'20~28%' 라는 수치는 페이지·과제에 따라 달라진다. 고정된 값으로 쓰지 않는다.
한국어 문서에서의 아이트래킹 자료는 못 찾았다. 문자 체계가 다르면
훑는 방식도 다를 수 있다.
```

**주의**

```
원문 미확인. 학술 논문이 아니라는 점을 밝히고 인용한다.
"연구에 따르면" 이 아니라 "UX 연구기관 NN/g 의 아이트래킹 실험에서" 로 쓴다.
```

## VR-01 · 무엇이 퍼지나

**확인한것**

```
뉴욕타임스 3개월치 기사 + '가장 많이 이메일로 공유된' 목록.

퍼짐을 이끄는 건 감정의 좋고 나쁨이 아니라 '각성(arousal)' 수준이다.
  높은 각성  경외 · 분노 · 불안   → 잘 퍼진다
  낮은 각성  슬픔                → 덜 퍼진다
긍정이 부정보다 잘 퍼지되, 각성 수준이 그만큼 중요하다.
```

**반증시도**

```
③ 조건 — 재현 실패와 일반화 한계가 둘 다 나왔다.

· 독일 언론(Spiegel Online) 재현 연구에서 **일부 효과가 재현되지 않았다.**
  감정 차원별 결과가 채널마다 불규칙했다.
· ★ 측정한 '퍼짐' 이 이메일 공유다. 소수에게 보내는 행위(narrowcasting)이고
  트위터 같은 널리 뿌리는 행위(broadcasting)와 다르다.
  → 채널이 다르면 결과가 다를 수 있다는 것이 명시적으로 지적된다.
· 표본 대표성 문제 — 인구·문화 집단 전반으로의 일반화에 우려가 제기된다.

→ '각성이 높으면 퍼진다' 를 법칙처럼 쓰지 않는다.
  다만 '슬픈 얘기는 잘 안 퍼진다' 쪽은 여러 곳에서 방향이 일치한다.
```

**주의**

```
원문 미확인. 2012년 미국 뉴스 기사 데이터다.
'이메일 공유' 를 잰 것이라 인스타 공유·DM 전송과 같다고 볼 수 없다.
분노·불안도 잘 퍼지지만 가게 브랜드에는 독이다 — 개념 파일에 그 균형을 적었다.
```
