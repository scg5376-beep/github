## NV-04 · 네이버 광고 공식 도움말

**확인한것**

```
네이버 검색 API 가 돌려준 공식 페이지 발췌문. 그대로 옮긴다.

[파워링크 순위 · faq/189]
"이용자의 검색어와 사이트 콘텐츠의 연관성이 가장 높은 광고를 우선하여 광고를
 선정됨에 따라, 검색어와 사이트 콘텐츠의 연관성, 입찰가(자동입찰), 소재 품질
 등의 종합적인 결과를 바탕으로 광고 순위가 결정됩니…"

[쇼핑검색광고 순위 · faq/253]
"쇼핑검색광고는 소재 입찰가와 품질지수를 고려하여 노출순위를 산정합니다.
 품질지수는 키워드별 이용자들의 관심사 등을 비롯하여 상품 정보간의 연관도 및
 해당 상품의 이용자 반응을 종합하여 계산됩니다."

[플레이스광고 과금 · faq/400]
"플레이스광고는 클릭당 과금이 되는 상품(CPC)입니다. 개별 플레이스 업체
 페이지로 이동하는 클릭 및 광고 노출 요소 중 '전화', '예약', '저장하기',
 '길찾기' 아이콘, '방문자 리뷰', '플레이스 플러스(beta)' 등) 클릭에 대…"

[브랜드검색 · faq/1006]
"광고 집행 전 계약을 통해 일정 금액을 선 지불하고 계약 기간 동안 노출수나
 클릭수에 제한 없이 광고가 노출되는 정액제 상품입니다. 광고비는 상품 유형,
 광고 가능한 키워드의 기간 조회 수(최근 30일 …"

[최소 노출 입찰가 · faq/1341]
"과거 4주간 검색을 통해 노출된 광고 중에서 최하위에 노출되었던 광고의 입찰가
 중 가장 큰 값이 최소 노출 입찰가입니다."

[노출 영역 · faq/1012]
"파워링크 광고는 네이버 통합검색의 '파워링크' 영역 외에도 제휴를 맺고 있는
 파트너 사이트 등 다양한 영역에 광고가 노출됩니다. 광고가 노출되는 영역을
 '매체'라고 하며, 매체별 노출 여부는 직접 설정할 수 있습니…"

[사칭 피해 · faq/87 · help/report]
"네이버 광고는 광고주의 예산에 맞춰 광고비를 설정할 수 있습니다. 광고비는
 실시간으로 공정한 입찰과정을 통해 결정되며, 광고가 클릭되는 경우에만
 광고비가 과금됩니다."
"사례 1) 월정액제로 결제 유도 및 과도…"
```

**반증시도**

```
③ 조건 — 대행사 설명과 공식 문구를 대조했다.

대행사 블로그들은 '입찰가 × 품질지수 = 순위지수' 라는 공식을 파워링크에
적용해 설명한다. 그런데 공식 파워링크 문서에는 '품질지수' 라는 말이 없다.
쓰는 말은 '연관성 · 입찰가(자동입찰) · 소재 품질' 이다.
'품질지수' 는 쇼핑검색광고 문서에만 나온다.

→ 상품마다 순위 산정 방식이 다르다. 뭉뚱그린 설명을 그대로 옮기면 안 된다.
→ '자동입찰' 이라는 표현이 파워링크 문서에 있는 것도 짚어둘 만하다.

대행사 블로그에서 '파워링크 품질지수 서비스가 2026년 7월 종료' 라는 말을
봤으나 공식 확인을 못 했다. 쓰지 않는다.

★ 2026-09-01 — faq/189 전문을 확보해 위 추론이 맞았음을 확인했다.
  원문에 '품질지수' 라는 말이 아예 없다. 쓰는 말은
  "검색어와 사이트 콘텐츠의 연관성, 입찰가(자동입찰), 소재 품질 등" 이다.
  → 발췌만으로 세운 추론이 원문으로 확인된 첫 사례다. 이 방식이 통한다는 증거다.

★ faq/400 전문에서 발췌 때 못 봤던 것 둘이 나왔다.
  ① "길찾기 출발 아이콘, 공유하기 아이콘 클릭에 대해서는 과금하지 않습니다."
     — 과금 목록만 보고 있었으면 놓쳤을 예외다.
  ② PC 지도검색에서는 마커 클릭 자체가 과금인데, 모바일은 요약카드를 눌러야 과금이다.
     같은 광고인데 기기에 따라 과금 시점이 다르다.
  → "등)" 으로 끊긴 뒤에 실제로 중요한 내용이 있었다. 발췌를 믿으면 안 된다는 사례다.

★ 그리고 발췌 때는 아예 몰랐던 것이 나왔다.
  "순위가 높은 10개의 광고가 파워링크 영역에 노출됩니다."
  "검색 사용자가 많이 찾지 않는 일부 키워드의 광고는
   파워링크 영역에 최대 3개까지만 노출될 수도 있습니다."
  → 동네 키워드는 자리가 3개일 수 있다. 발췌에는 이 문장이 없었다.
```

**주의**

```
faq/189 · faq/400 전문 확인(2026-09-01). 나머지 광고 문서는 여전히 발췌만 봤다.
특히 '광고가 클릭되는 경우에만 과금' 과 '월정액제로 결제 유도' 는
다른 페이지의 발췌라 전문을 못 봤다. 인용할 때 그렇게 밝힌다.
플레이스광고의 '순위' 를 무엇으로 정하는지는 아직 어느 문서에서도 못 찾았다.
광고 상품과 과금 방식은 자주 바뀐다. 반년마다 다시 본다.
```

## NV-05 · 플레이스 순위와 사진 (스마트플레이스 공식)

**확인한것**

```
① 순위 요소 — 두 문서(고객센터 23472 · 스마트플레이스 운영원칙)에 같은 문장.

"네이버 플레이스 검색 결과 순위는 이용자의 다양한 니즈를 고려하여,
 검색 질의에 대한 업체 유사도, 검색질의에 대한 카테고리와 업체의 인기도,
 거리, 정보의 충실성 등을 감안하여 결정합니다."

  유사도 · 인기도 · 거리 · 정보의 충실성       ← 네이버가 직접 쓴 말
  ★ 문장이 '등' 으로 끝난다. 이게 전부가 아니다.

② 시술 사진 (미용실 20426)

"스마트플레이스에서 시술 사진을 등록하면 업체 정보뿐 아니라, 네이버 검색
 결과에도 함께 노출됩니다. 따라서 검색 결과 품질을 위해 수시로 시술 사진
 모니터링을 진행하고 있습니다. 모자이크, 합성사진, 뒷머리만 …"

③ 어뷰징 — "각종 프로그램과 기술적인 도구들로 트래픽을 과도하게 유발"
```

**반증시도**

```
③ 조건 — 대행사 글이 말하는 '랭킹 5요소' 와 대조했다.

대행사·SEO 블로그들은 흔히 "네이버가 공식으로 밝힌 랭킹 5요소" 라며
유사도·인기도·거리·정보의 충실성 + '검색 품질' 을 든다.
그런데 내가 확보한 공식 문장에는 넷뿐이고 '등' 으로 끝난다.
다섯 번째를 네이버가 명시했는지 확인하지 못했다.

→ 우리는 넷만 쓰고, '등' 이 붙어 있다는 사실을 같이 적는다.
→ '5요소' 라고 단정하지 않는다.

'저품질 블로그' 때와 같은 구조다 (NV-03). 업계가 만든 말이
공식 용어처럼 굳어지는 일이 네이버 쪽에서 반복된다.
```

**주의**

```
전문 미확인 (naver.com 접근 차단). 스니펫이 "…" 로 끊긴 뒤는 모른다.
특히 시술사진 금지 목록의 나머지를 모른다 — '뒷머리만' 뒤에 더 있다.
23473(순위 높이는 방법)은 첫 문단 말고 확보하지 못했다.
플랫폼 자료다. 반년마다 다시 본다.

승급 부탁: 23472 · 23473 · 20426 세 쪽을 열어 붙여 주시면 A 로 올린다.
```
