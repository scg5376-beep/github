## ★ 전문으로 새로 알게 된 것 (2026-09-02)

```
1. 문서 첫 줄이 "누가 뭐라고 하든 검색결과에 페이지가 표시되게 하는 데에는 비용이 들지
   않습니다" 다. 구글 상위노출 보장 상품을 정면으로 부정하는 자리다
2. ★ robots.txt 로 Googlebot 을 차단하면 크롤링은 막히지만 URL 은 검색결과에 계속 표시될
   수 있다. 색인을 막으려면 noindex 를 쓰고 크롤링은 허용해야 한다.
   웹검색 요약만 볼 때는 이 관계를 몰랐다 — 흔한 오해가 원문으로 정리됐다
3. 비공개(로그인해야 보이는) 페이지는 크롤링되지 않는다
4. Search Console 의 페이지 색인 생성 보고서와 크롤링 통계 보고서를 둘 다 보라고 한다.
   보고서마다 URL 정보가 다를 수 있다고 명시했다

Web Vitals (GS-07)
5. 기준값 숫자는 웹검색 요약과 같았다 — LCP 2.5초 · INP 200ms · CLS 0.1 · 75번째 백분위
6. 새로 안 것 — 모바일과 데스크톱을 기기별로 구분해서 본다. 셋 다 통과해야 통과다
7. ★ 수명 주기(실험용 → 대기 중 → 안정)가 문서에 명시돼 있다. 안정 측정항목은 1년에 한 번
   이상 바뀌지 않지만 "반드시 영구적인 것은 아니다" 라고 못 박았다. 2024년 INP 가 FID 를
   대체한 것이 그 예다 → 이 창고의 속도 파일은 반년마다 다시 봐야 한다는 근거다
8. Lighthouse 는 사용자 입력이 없어 INP 를 측정할 수 없다. TBT 가 프록시다
9. TBT 는 필드에서 측정할 수 없어 Core Web Vitals 에 들어가지 않는다
10. ★ 한국어판은 기계 번역이다. 페이지 자체에 "AI 번역에는 오류가 있을 수 있습니다" 라고
    적혀 있고, 실제로 Core Web Vitals 가 "핵심 성능 보고서" 로 옮겨진 곳이 여럿 있다.
    → 번역본을 원문으로 다룰 때는 그 사실을 반드시 함께 적는다
```
