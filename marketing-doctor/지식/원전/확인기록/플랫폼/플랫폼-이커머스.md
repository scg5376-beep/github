# 확인 기록 · 이커머스 (스마트스토어 · 쿠팡 · 온라인쇼핑 통계)

> **EC-01(스마트스토어 수수료)과 EC-03(쿠팡 수수료 표)이 A 다.** 2026-09-02 사장님이 「[정산관리] 수수료의 종류」 전문을
> 열어 붙여 주셨다. 보관본 `../../원문/네이버-커머스/`.
> **나머지(EC-02 랭킹 · EC-04 통계)는 원문 미확인이다.** mods.go.kr 차단.
> 레지스트리 `../../레지스트리/플랫폼/플랫폼-이커머스.yaml` · 형제 `플랫폼-네이버-사이트.md`

```
EC-01  ★ 「수수료의 종류」 전문 확보 (A) — 과금 기준 표, Npay 등급표 두 시기,
       판매수수료 네 종, 국세청 등급 산정, 계산 예시. 가입·전환 FAQ 는 아직 발췌만
EC-03  ★ 카테고리별 판매 수수료 표 전문 확보 (A) — 대분류 15개 기본 수수료,

EC-04  국가데이터처 — 2026-06 24조 6,067억 · 모바일 76.9% (통계청이 국가데이터처로 바뀜)
```

## ★ 전문으로 새로 알게 된 것 (2026-09-02)

```
1. 두 수수료가 붙는 자리가 다르다 — Npay 는 배송비(초기·반품/교환)에도 붙고,
   네이버쇼핑 판매수수료는 상품금액에만 붙는다. 발췌만 볼 때는 몰랐다
2. Npay 수수료 = 결제수수료 + 주문관리수수료(0.99%, VAT포함)
3. 2025-10-01 결제건부터 영세·중소 요율이 내려갔다. 일반은 인하 대상이 아니다.
   ★ 요율에 적용 시작일이 붙어 있다 — 날짜 없이 옮기면 틀린 숫자가 된다
4. 등급은 국세청 신고 총매출 기준이고 자사몰·Npay 가맹점 매출도 포함된다.
   입점일 당일은 무조건 '일반' 으로 노출된다
5. 판매수수료는 주문건이 생기면 넷 중 하나가 무조건 발생한다
6. ★ 판매자가 직접 광고·홍보로 유입한 고객이 사면 판매자 마케팅 수수료가 적용돼
   낮게 과금된다. 문서 예시로 3%(300원) 가 1%(100원) 이 된다.
   손님을 직접 데려오는 일이 수수료에서도 숫자로 돌아온다는 공식 근거다
7. 신규 창업자가 '일반' 으로 시작했다가 영세·중소에 해당하면 이전 반기 카드 수수료를
   소급 환급한다 (매년 3월·9월)
```

## ★ 쿠팡 표에서 확인한 것 (2026-09-02)

```
1. 쿠팡이 스스로 밝힌 셋 — 할인된 가격에 부과 / 포털 연동 비용 추가 없음 /
   결제수수료 이중 부과 없음. "타 오픈마켓 대비 최저" 는 쿠팡 주장이라 검증하지 않았다
2. 대분류 기본 수수료가 7.8~10.8% 로 갈린다. 소분류 최저 4%(순금·골드바·돌반지),
   최고 10.9%(면·라면). 같은 대분류 안에서도 다르다
3. ★ 상품 등록 후 카테고리를 변경할 수 없다. 부적절하면 쿠팡이 고칠 수 있고 그때는
   바뀐 카테고리 수수료율이 적용된다. 분류 책임은 판매자에게 있다
4. 표에 VAT 포함 여부가 없다 — 네이버 표(VAT 포함 명시)와 나란히 놓을 때 주의
```

## 못한 것 · 주의

```
· EC-02 네이버쇼핑 랭킹 세 축 → C. 원 문서 URL 못 찾음. 단독 인용 금지
· 스마트스토어·쿠팡 수수료는 이제 원문이 있다. 2차 자료가 말하던 쿠팡 범위(5.5~10.8%)는
  실제와 달랐다 — 표의 최저는 4%, 최고는 10.9% 다
· 건별 정산내역(정산기준일·정산예정일)은 화면 캡처로만 봤다. 글자를 옮길 수 없어 인용하지 않았다 —
  텍스트로 다시 받아야 인용할 수 있다
· 정산 주기 · 반품 정책 · 광고(쇼핑검색광고) 는 이번에 손대지 않았다
```
