# 확인 기록 · 네이버 서치어드바이저 (사이트 노출)

> ⚠️ **전 항목 원문 미확인.** searchadvisor.naver.com · help.naver.com 차단. 네이버 자체 색인
> 발췌로만 봤다. 블로그 문서(NV-01·03)는 A 인데 **이 묶음은 B 다. 등급을 섞지 않는다.**
> 레지스트리 `../../레지스트리/플랫폼/플랫폼-네이버-사이트.yaml` · 형제 `플랫폼-네이버.md` · `플랫폼-이커머스.md`

## 확인한 것

```
NS-01  가이드 22개 페이지의 URL 과 첫 문단 발췌.
       핵심: 검색 등록 절차는 존재하지 않는다 → 로봇이 수집 → 웹마스터도구는 진단·요청 도구
       robots.txt(IETF 2022-09) · canonical · JS redirect 자제 · title 은 브랜드명 ·
       RSS·사이트맵은 콘텐츠 피드 · 수집요청은 사이트별 제한 · IndexNow 지원 ·
       검색 제외는 정책위반만
NS-02  소유확인은 수집·삭제 요청이 검색 결과에 영향을 주기 때문. 아이디당 100개. 프로토콜 정확히
```

## 못한 것 · 주의

```
· 어느 페이지도 전문을 못 봤다. 발췌는 첫 1~2문장이다
· 수집요청 상한 횟수 · 콘텐츠 권장 원칙 전체 목록 · 사이트 최적화 리포트 항목 → 없음
· content-abusing 페이지가 NV-03 원문(원문/네이버/)과 같은 문서인지 확인 못 함. 같아 보여도
  URL 이 다르므로 이 묶음에서는 NV-03 의 A 등급 인용문을 가져다 쓰지 않는다
```

## 반증 시도

```
찾아본 것   "네이버에 사이트를 등록하면 노출된다" 는 주장 → 공식 발췌가 정면으로 부정
            (등록 절차 없음 · 노출 보장 없음). 대행사 "사이트 등록 서비스" 는 소유확인 대행일 뿐
```
