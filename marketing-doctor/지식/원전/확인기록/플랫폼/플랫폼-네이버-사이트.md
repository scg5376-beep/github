# 확인 기록 · 네이버 서치어드바이저 (사이트 노출)

> **NS-01 의 핵심 페이지 넷이 A 다.** 2026-09-02 사장님이 「검색엔진 최적화의 목적」·
> 「사이트 등록 및 소유확인」·「콘텐츠 작성시 권장 사항」·「HTML 마크업 가이드(콘텐츠 마크업)」
> 전문을 열어 붙여 주셨다. 보관본 `../../원문/네이버-사이트/`.
> **같은 가이드의 나머지 장과 NS-02 는 여전히 발췌만 봤다** — searchadvisor.naver.com ·
> help.naver.com 이 이 환경에서 차단돼 있다. **A 인 페이지만 큰따옴표를 쓴다.**

## ★ 전문으로 새로 알게 된 것 (2026-09-02)

```
1. 사이트 등록이 호스트 단위만 된다 — …/myid 형태는 안 된다. 발췌만 볼 때는 몰랐다
2. 소유 확인이 안 되는 다섯 경우가 명시돼 있다 (방화벽·JS redirect·frame·파일 손상·IE11 미만)
3. 검색로봇 이름이 Yeti 이고, IP 기반 차단을 하지 말라고 네이버가 직접 적었다
4. 동일 콘텐츠로 여러 사이트를 만들면 검색 노출에 불이익이라고 명시했다.
   블로그 쪽 유사 문서 로직과 같은 방향이다
5. 반영은 검색로봇 방문 뒤 최대 1주일 이내
6. noindex 라도 공공기관·교육기관 등 공공재 성격 사이트와 선호도 높은 사이트는
   내부 정책에 따라 반영될 수 있다는 예외가 있다
7. 콘텐츠 전체가 자바스크립트로 로딩되는 구조가 미반영 원인으로 명시돼 있다
8. ★ 웹마스터도구에 등록하지 않아도 검색 결과에 반영된다. 등록·소유확인은 노출 조건이 아니라
   수집·색인·노출을 리포트로 보기 위한 것이다. 발췌만 볼 때는 "소유확인이 1단계" 로만 적었다
9. 소유확인 메타태그가 body 태그 안이나 frame 안에 있으면 검증에서 제외된다.
   브라우저단 리다이렉션(자바스크립트·meta refresh·cookie)도 검증 불가 — HTTP 301·302 로 하라
10. 소유확인은 자바스크립트를 실행하지 않으므로 view-source: 로 마크업을 확인하라고 안내한다
11. ★ 네이버가 웹 사이트 문서에서 AI 를 직접 언급한다 — 단순 생성·요약에 그치지 말고
    운영자의 경험과 관점을 더하라. 블로그 쪽 A등급 문장과 같은 자리이고, 이제 웹 쪽에도
    A등급 근거가 생겼다. 구글 쪽은 여전히 B 다 — 세 줄을 나란히 쓸 때 등급을 표시한다
12. "전체 콘텐츠의 절반 이상이 핵심 주제" — 네이버 문서에서 숫자가 나온 드문 자리다
13. 제목·설명문에 인기 검색어를 넣으면 품질 평가 불이익, 같은 단어 반복은 어뷰징 의심이라고
    명시했다. 대행사 관행을 정면으로 겨냥한 문장이다
14. 방치되어 스팸 콘텐츠가 생성되면 불이익이라고 적었다. 만들어 놓고 두는 홈페이지의 자리다
```

## ★ 마크업 가이드에서 새로 알게 된 것 (2026-09-02)

```
15. ★ title 태그는 후보 중 하나다 — 검색에 쓰이는 제목은 title·오픈그래프·페이지·앵커 등
    여러 정보 중 검색엔진이 가장 적절한 것을 자동 추출해 결정한다고 적혀 있다.
    설명문·스니펫도 같은 방식이다. "제목만 잘 쓰면 된다" 가 아니다
16. 제목 글자 수는 별도 제한이 없다고 명시했다. 대신 "검색 결과에서 표현이 가능한 수준" 이라는
    말로 권장한다. 떠도는 "제목 ○○자" 숫자는 이 문서에 없다
17. 메인 title 은 브랜드명(상호명·서비스명·제품명 같은 고유명사), 개별 페이지 title 은
    콘텐츠 주제를 설명하는 문구로 나눠 적으라고 한다. 메인에 키워드를 붙이는 관행과 반대다
18. ★ 오픈그래프를 네이버 검색로봇도 활용한다고 적혀 있다. 소셜 공유용으로만 아는 태그인데
    검색 쪽에도 쓰인다 — 그래서 권장한다
19. og:image 기준이 숫자로 나온다 — 150x150 초과 · 5,000 byte 이상 · 가로세로 3:1 이내 ·
    문서를 대표하는 고유 이미지. 사이트 전체에 반복되는 로고나 배너성 이미지는
    안 쓰는 경우가 있다고 밝혔다
20. description 불이익 항목이 구체적이다 — 본문 전체 복사 / 제목과 동일 / 모든 페이지 동일 /
    키워드만 나열 / 메인 설명을 자주 변경 / 과도하게 긺
```

## 못한 것 · 주의

```
· 하위 가이드(robots.txt 설정하기 · RSS 및 사이트맵 제출 · 검색로봇 확인 방법 ·
  자바스크립트 검색 최적화)는 링크만 있고 본문을 못 봤다
· HTML 마크업 가이드는 **콘텐츠 마크업 절만** 받았다. 같은 가이드의 선호 URL·로봇 메타 태그
  (markup-structure)는 아직 못 봤다. 붙여 주신 내용에 첫 소제목(「페이지 제목」) 줄이 없어
  본문 첫 문장부터 보관했다 — 그 사실도 보관본 머리에 적어 뒀다
· brand_check 가 원문 인용문을 주소로 잘못 잡았다 — "간략한 설명으로 1-2개의 문장" 과
  "가로세로 3:1". 인용문은 고칠 수 없으므로 검사기 쪽을 넓혔다(조사 '으로' 제외 · '가로세').
  넓힌 뒤 진짜 도로명("중앙대로 123")을 일부러 넣어 여전히 잡는 것을 확인하고 지웠다
· NS-02(고객센터 쪽 소유확인 소개·등록 가능 사이트)는 발췌뿐이다
· 웹 검색 미노출 FAQ · 웹 검색 제외 FAQ · 서브링크 FAQ 본문을 못 봤다
· 수집요청 상한 횟수 · 콘텐츠 권장 원칙 전체 목록 · 사이트 최적화 리포트 항목 → 없음
· content-abusing 페이지가 NV-03 원문(원문/네이버/)과 같은 문서인지 확인 못 함. 같아 보여도
  URL 이 다르므로 이 묶음에서는 NV-03 의 A 등급 인용문을 가져다 쓰지 않는다
```
