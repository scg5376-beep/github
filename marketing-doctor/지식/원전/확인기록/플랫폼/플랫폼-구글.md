## GG-01 · Creating Helpful, Reliable, People-First Content

**확인한것**

```
E-E-A-T = Experience(경험) · Expertise(전문성) ·
Authoritativeness(권위) · Trustworthiness(신뢰).
"people-first content" 를 만들라, "search engine-first content"
(검색엔진 노출만 노린 글) 를 만들지 말라는 것이 문서의 중심 주장.
```

**못한것**

```
전문 열람 (developers.google.com 접근 차단). 자기점검 질문 전체 목록 미확보.
```

## GG-02 · 검색 필수 요건과 스팸 정책  **B등급**

**확인한것**

```
검색 필수 요건이 세 부분 — 기술 요건 · 스팸 정책 · 핵심 권장사항 — 이라고 전해진다.
2024년 3월에 스팸 정책 셋이 추가됐다고 전해진다.
  확장된 콘텐츠 악용 · 만료된 도메인 악용 · 사이트 인지도 정책
```

**왜 이게 중요한가**

```
확장된 콘텐츠 악용 정의에 "생성 방법에 관계없이" 라는 공식 문구가 있다 (2026-09-02 확인).
그 전에는 영어를 우리가 옮겨 큰따옴표 없이 썼다.
→ 네이버가 "특정 기술의 활용 여부만으로는 판단하지 않습니다" 라고 한 것과 같다.
  네이버 쪽은 A등급 원문이고 구글 쪽은 B다. 등급을 섞어 인용하지 않는다.
```

**주의**

```
원문 미확인. 각 항목의 원문 정의와 전체 목록을 확보하지 못했다.
기술 요건 세부는 아예 손대지 않았다.
```

## GG-03 · 비즈니스 프로필 정책  **B등급**

**확인한것**

```
· 정보는 정직·관련성·유용성 중심
· 한 사업체당 프로필 하나
· 업체 설명에 링크 금지
· 제한 콘텐츠 — 주류·도박·담배·총기·건강 및 의료기기·규제 의약품·성인·금융 등
· 위반 시 표시 제한 · 순위 억제 · 프로필 정지
```

**안 쓰기로 한 것**

```
로컬 검색 순위 요소 '관련성 · 거리 · 인지도'.
널리 알려진 세 단어지만 구글 공식 문구를 확보하지 못했다.
지식 파일에 쓰지 않았고, 왜 안 썼는지도 그 파일에 적어 뒀다.
```

**주의**

```
원문 미확인. 제한 콘텐츠 목록이 전부인지 모른다.
사진·게시물 정책, 리뷰 정책, 정지 후 복구 절차는 확보하지 못했다.
```

## ★ 2026-09-02 · 스팸 정책 전문으로 바로잡은 것

```
1. 항목 이름이 공식 명칭과 달랐다 — 2차 자료가 영어를 각자 옮긴 것을 받아 적은 탓이다
   대량 콘텐츠 남용 → 확장된 콘텐츠 악용 / 만료 도메인 남용 → 만료된 도메인 악용
   사이트 평판 남용·기생 SEO → 사이트 인지도 정책 / 키워드 스터핑 → 유인 키워드 반복
   도어웨이 남용 → 도어웨이 악용
2. ★ 사이트 인지도 악용의 "2024-05-05 부터 적용" — 스팸 정책 페이지에 없어서 한 번 뺐는데,
   같은 날 받은 공식 블로그에 있었다. 되살렸다.
   교훈: 한 문서에 없다고 사실이 아닌 게 아니다. 짝이 되는 문서를 같이 봐야 한다
3. 스팸 정의에 "생성형 AI 대답을 조작하려고 시도하는 것" 이 들어간다 — 몰랐다
4. 링크는 rel="nofollow" 또는 rel="sponsored" 를 붙이면 사고팔아도 위반이 아니다
5. 숨기기·표시 UI 중 위반이 아닌 것 넷이 명시돼 있다 (아코디언·탭 / 슬라이드쇼 /
   상호작용 도움말 / 스크린 리더 전용 텍스트)
6. 사용자 생성 스팸은 사이트 소유자가 모르는 경우가 많다고 문서가 적었다
7. 유인 키워드 반복 예시에 "웹페이지의 순위와 관련된 도시와 지역을 나열하는 텍스트 블록" 이
   있다. 지역명을 늘어놓는 국내 관행이 정확히 이 예시다
```
