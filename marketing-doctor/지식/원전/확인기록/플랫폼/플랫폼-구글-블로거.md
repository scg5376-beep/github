# 확인 기록 · 구글 Blogger

> 레지스트리는 `../../레지스트리/플랫폼/플랫폼-구글-블로거.yaml`. 전문 보관은 `원문/`.
> 확인 방법: 이 환경의 WebFetch 는 막혀 있어, 설계자가 **이 PC 의 Edge 를 헤들리스로 띄워 화면 텍스트를 받았다**(2026-09-11).
> 화면에 보이는 본문은 전부 받았고, 접힌 FAQ 항목(클릭해야 열리는 것)은 못 받았다.

## GB-01 · 시작·도메인
**확인한것** 블로그 만들기 7단계. 맞춤 도메인: CNAME 2개(ghs.google.com + 계정별 보안 CNAME), 네이키드 도메인은 A 레코드 4개, DNS 반영 1시간 이상, blogspot → 맞춤 도메인 리디렉션 최대 24시간, CAA 레코드 쓰면 letsencrypt.org 추가 필요.
## GB-02 · 콘텐츠 정책
**확인한것** 스팸 정의("원치 않는 홍보성 또는 상업적 콘텐츠, 자동 프로그램으로 생성된 원치 않는 콘텐츠…"), 규제 상품(주류·도박·의약품·담배·무기·건강/의료 기기) 판매·광고 금지, 성인용 표시 의무.
**못한것** 검색 노출·애드센스 연동 문서는 못 찾음(서치-소넷 조사).
