# 확인 기록 · 토스 광고 (toss ads)

> **이 묶음에 A 가 없다.** 토스가 직접 낸 문서를 한 장도 못 봤다.
> 확보한 것은 **토스 광고를 파는 대행사가 만든 판매 소개서 두 건**(2024.03 · 2024.04)이다.
> 보관본 `../../원문/토스/` · 레지스트리 `../../레지스트리/플랫폼/플랫폼-토스.yaml`
> 형제 `플랫폼-메타구글.md` (광고 정책은 저쪽이 A 다)

## 무엇을 확보했나

```
TS-01  머니 알림 소개서 2024.03  7장 전부 — 상품 설명 · 참여 구조 · 업종 매칭 5칸 ·
                                운영 정책 6줄 · 단가표 2줄
TS-02  배너 소개서 2024.04     12장 전부 — 배너 4종 · 지면 7곳 · 상품별 표 3개 ·
                                썸네일 배너 시간대별 단가표 2개(주중·주말)
```

둘 다 PDF 가 **전부 이미지**였다. 글자를 못 뽑아서 140dpi 그림으로 만들어 눈으로 읽어
옮겼다. **자동 대조를 못 했다** — 이 창고에서 처음 있는 방식이라 적어 둔다.
표 숫자는 특히 오독 위험이 있다.


**2025년 3분기 판 소개서가 있다는 것까지 확인했는데 못 받았다.** 우리가 가진 건
2024년 봄 판이다. 그 사이에 상품 이름이 바뀐 흔적이 이미 문서 안에 있다 —
「썸네일 배너 (*구 프리미엄 보드)」. **이 묶음은 지금도 낡아 가는 중이다.**

## ★ 두 문서를 붙여 보니 알게 된 것 (우리가 붙인 것이다)

```
1. 과금 축이 상품마다 다르다 — 배너는 CPC, 썸네일 배너는 CPT, 머니알림은 CPP.
   "토스 광고 단가" 라는 하나의 숫자는 없다
2. 진입 문턱이 상품마다 백 배 넘게 벌어진다 —
   배너는 클릭 200원부터 입찰, 썸네일 배너는 시간대 한 칸이 천만 원 단위,
   머니알림은 최소 발송 3만 명이라 시작이 백만 원 단위
3. 두 문서가 똑같이 적은 문장이 둘 있다 — "집행일 기준 영업일 D-1 까지 신청" 과
   "※ 상기 단가는 추후 변경될 수 있습니다"
4. 예상 CTR 이 지면마다 다섯 배 벌어진다(리스트 0.6% → 풀페이지 3%).
   화면을 많이 차지할수록 높다. 대신 그 지면은 더 비싸다
```

★ 2·3·4 는 **문서에 그렇게 쓰여 있는 게 아니라 우리가 두 문서를 나란히 놓고 붙인
해석**이다. 인용할 때 문서가 한 말처럼 옮기면 안 된다.

## 못 한 것 · 모르는 것

```
· 토스 공식 단가를 모른다. 우리가 본 건 대행사 소개서의 2024년 표다
· 오픈율 30% · CTA 클릭률 90% 의 근거를 모른다. 표본도 기간도 안 적혀 있다
· 지금(2026) 상품 구성이 어떤지 모른다. 이름부터 이미 한 번 바뀌었다
· 셀프서브로 최소 얼마부터 되는지 모른다 (TS-03 은 검색 요약뿐이라 C 다)
· ★ 오프라인 매장이 토스로 무엇을 할 수 있는지가 가장 안 잡힌다 (TS-05)
· 실패 사례를 못 찾았다. 찾아봤고 못 찾았다
```
