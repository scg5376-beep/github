## CH-01·02·03 · 선택지가 많으면 안 팔리는가

**확인한것**

```
논쟁이 세 판으로 이어졌다. 한 편만 인용하면 어느 쪽이든 틀린다.

2000  Iyengar & Lepper   잼 6종 30% vs 24종 3%. 10배 차이
2010  Scheibehenne 외    메타분석 50개 실험 N=5,036 → 평균 효과 거의 0
                         + 출판 편향 확인
2015  Chernev 외         메타분석 99개 관측 N=7,202 → 조절변수 4개를
                         고려하면 효과는 견고하다
```

**반증시도**

```
③ 조건 — 이 항목은 반증을 '찾은' 사례다.

CH-01 만 인용하는 마케팅 글이 매우 많다. 그런데 10년 뒤 메타분석에서
평균 효과가 0으로 나왔고, 직접 재현 실패 사례도 있다.

CH-02 가 짚은 출판 편향이 특히 중요하다 —
성공한 실험은 논문이 되고 실패한 실험은 서랍에 남는다.
그래서 '논문이 여러 편 있다' 가 '효과가 있다' 를 뜻하지 않는다.

다시 CH-03 이 조절변수를 넣어 재분석하니 효과가 살아났다.
현재 학계 상태는 '조건부로 존재한다' 로 정리된다.

세 편 다 원문 미확인 (학술지·chernev.com 접근 차단).
```

**주의**

```
'잼 실험' 만 근거로 "선택지를 줄이세요" 라고 쓰면 안 된다.
2010년에 사실상 반박됐고 2015년에 조건부로 복원된 주장이다.
조건을 빼고 옮기면 15년 뒤진 글이 된다.
```

## SP-01 · 남들이 많이 산다는 표시 (사회적 증거)

**확인한것**

```
중국의 실제 식당에서 한 무작위 현장실험. 설문이 아니다.
메뉴판에 '지난주 많이 나간 5개' 를 표시했더니
  · 그 메뉴 수요가 13~20% 증가
  · 효과는 '가끔 오는 손님' 에게 더 강했다
  · 손님의 식사 만족도도 같이 올라갔다
```

**반증시도**

```
③ 조건 — 반대 결과를 찾았다.

소프트웨어 다운로드에서는 사회적 증거의 효과가 나타나지 않았다는 연구가 있다
("Social Proof is in the Pudding: The (Non)-Impact of Social Proof on
 Software Downloads", arXiv). 서지가 불완전해 원전에 올리지 않았다.

→ 사회적 증거는 '늘 통한다' 가 아니라 맥락을 탄다.
   SP-01 이 통한 조건은 '처음 온 손님' 과 '뭘 고를지 모르는 상황' 이다.
   이건 CH-03 의 선호 불확실성 조절변수와 같은 이야기다.
```

**주의**

```
원문 미확인 (aeaweb 접근 차단). 중국 식당 데이터다.
'13~20%' 는 그 실험의 숫자다. 우리 가게에서 같은 크기로 나온다는 보장은 없다.
```
