## RH-01 · Zero Defections (Reichheld & Sasser)

**확인한것**

```
원문의 실제 문장
  "이탈률을 5% 줄였더니 어느 한 은행의 지점망에서 이익이 85% 늘었다"
   (reducing the defection rate just 5% generates 85% more profits
    in one bank's branch system)

즉 원문은 '한 은행의 사례' 다. 모든 업종에 통하는 법칙이 아니다.
개별 사례로 보고된 다른 수치 — 소프트웨어 회사 35%, 광고 대행사 95%
(고객 순현재가치 기준)
```

**반증시도**

```
③ 조건 — 널리 퍼진 인용문이 원문과 맞는지 대조했다.

업계에 도는 문장    "유지율 5% 올리면 이익이 25~95% 늘어난다"
원문에 있는 것      한 은행 사례의 85%. 25~95% 라는 범위 문장은 없다.

25~95% 는 서로 다른 업종의 개별 사례들을 모아 만든 범위로 보인다.
Bain 의 짧은 브리프에는 25% 만 있고 95% 는 없으며, 그마저 금융업 한정이다.

→ 이 통계는 '개별 사례 몇 개' 가 '보편 법칙' 으로 둔갑한 경우다.
   출처를 밝히지 않고 인용하면 안 된다.

반대 진영도 확인했다 — Ehrenberg-Bass (EB-01).
  로열티 프로그램 논문 30편 이상. 대부분 실제 충성도에 미미한 효과.
  가입자는 이미 충성 고객이었다는 선택 편향.
  Double Jeopardy 법칙 — 유지율은 침투율의 '결과' 지 독립 변수가 아니다.
  라이트 바이어(가끔 사는 사람)가 수가 많아 총합 효과가 크다.
```

**주의**

```
원문 미확인 (hbr.org 접근 차단). 서지는 네 곳이 일치한다.
HBR 68(5), 1990년 9-10월호, 105-111쪽.

이 항목은 '숫자를 인용하지 말라' 가 아니라
'원문이 뭐라고 했는지 확인하고 인용하라' 는 사례로 쓴다.
```

## EB-02 · 가용성과 범주 진입점

**확인한것**

```
정신적 가용성  살 상황에서 떠오를 확률 (인지도가 아니다)
물리적 가용성  사려 할 때 쉽게 살 수 있는가
범주 진입점    그 범주를 떠올리게 되는 상황·계기. 손님이 정한다.

Ehrenberg-Bass 는 30개국 이상의 소비자 행동 패널 자료를 근거로 든다.
```

**반증시도**

```
③ 조건 — 완료. 틀 자체를 뒤집는 연구는 못 찾았고, 대신 한계 다섯 개를 찾았다.

1  '원형성 법칙' 의 증거가 부족하다
   범주의 상위 속성 중 절반 정도만 '원형적' CEP 로 나온다.
   명백해 보이는 필요(예: 배터리 주행거리, 충전 시간)가 CEP 에서 빠지기도 한다.
   → 우리가 '당연히 이게 CEP겠지' 하고 짐작한 게 실제로는 아닐 수 있다.

2  ★ 한 CEP 를 독점하려는 것이 전략적 실수로 지적된다
   소비자는 하나의 CEP 에 브랜드 하나만 연결하지 않는다.
   '이 상황은 우리 것' 으로 만들려는 목표 자체가 틀렸다.

3  CEP 를 브랜드 가치와 혼동하는 문제가 흔하다

4  CEP 목록을 '완전한 목록' 으로 착각하는 문제
   다 적었다고 생각하는 순간 틀린다. 손님이 정하는 것이라 계속 바뀐다.

5  정신적 가용성이 CEP 로만 환원되지 않는다는 지적이 있다
   (Marketing Week — "정신적 가용성에는 CEP 말고도 더 있다")

그리고 실무 간극 — 대부분의 조직이 CEP 를 정기적으로 측정하지 않는다.
이론과 실무 사이가 벌어져 있다.

⚠️ '정신적 가용성 2배 → 점유율 30~50% 증가' 라는 수치를 봤는데
   출처가 대행사 블로그다. 원 연구를 못 찾아 쓰지 않기로 했다.
   이 수치를 다른 데서 보더라도 서지를 확인하기 전엔 인용하지 않는다.

⚠️ 이 한계들 상당수가 업계 매체·컨설팅 자료 출처다.
   Ehrenberg-Bass 자신도 '전략적 함정' 이라는 글로 일부를 다룬다.
   학술 반박 논문은 아니다.
```

**주의**

```
원문 미확인. 대형 소비재 브랜드 연구가 바탕이라 동네 가게 적용은
검증된 게 아니다 (RH-01 확인기록의 같은 한계).
```

## EB-03 · 차별화보다 독특함

**확인한것**

```
'다르다고 인식되지 않은' 브랜드들도 그만큼 성공했다.
→ 인식된 차별화는 성공의 필요조건이 아니다.

대신 독특함(distinctiveness)을 중심에 놓자는 제안.
  차별화  남과 다른 '의미' 를 준다      → 베껴진다
  독특함  우리 것이라고 '알아보게' 한다  → 상표로 보호된다
```

**반증시도**

```
③ 조건 — 반대 진영이 뚜렷하게 존재한다.

차별화(포지셔닝) 전통은 마케팅 주류였고 지금도 그렇다.
Romaniuk 본인이 '차별화를 옹호하는 논문 16편을 읽었지만 생각이 안 바뀌었다'
는 글을 쓸 만큼 논쟁이 계속되고 있다.

→ '차별화는 필요 없다' 가 아니라 '차별화가 성공의 필요조건은 아니었다' 로
   좁혀 읽어야 한다. 두 진영이 다 살아 있는 논쟁이라고 밝히고 쓴다.

⚠️ '독특한 자산이 광고 인지를 평균 34% 높였다' 는 수치는 대행사 블로그가
   출처다. 원 연구 확인 전에는 쓰지 않는다.
```

**주의**

```
원문 미확인 (marketingscience.info PDF 접근 차단).
2007년 논문이다. 대형 소비재 브랜드 기준.
```
