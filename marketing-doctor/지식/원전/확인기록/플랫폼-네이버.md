## NV-01 · 네이버 블로그 검색 로직 (C-Rank · D.I.A.)

**확인한것**

```
네이버 검색 API 가 돌려준 위 공식 페이지의 발췌문 두 건.
D.I.A. — "네이버의 데이터를 기반으로 키워드별로 사용자들이 선호하는 문서에
대한 점수를 랭킹에 반영한 모델. 문서 자체의 경험과 정보성을 분석해 랭킹에
반영하는 D.I.A. 는 출처의 신뢰도를 (검색결과 랭킹에 반영하는 C-Rank 를 보완)"
C-Rank — "검색 랭킹의 정확도를 높이기 위해 사용되는 기술로 개별 문서보다는
해당 문서 출처의 신뢰도를 평가하는 알고리즘. 네이버 검색 결과는 C-Rank 를
토대로 블로그의 관심사 집중도(Context)..."
```

**주의**

```
C-Rank 의 구성 요소(집중도·품질·이용 패턴 / 주제별 신뢰도·인기도)는
NV-03 원문에서 확인됐다. 그 부분만 A 로 다룬다.
D.I.A. 의 7가지 요소는 여전히 2차 자료 기준 — B.
```

**못한것**

```
전문 열람 (help.naver.com 접근 차단). 7가지 반영 요소 목록은 여전히 2차 자료 기준.
```

## NV-03 · 네이버 공식 안내 문서군 (블로그 검색 제한·노출·저품질)

**확인한것**

```
네이버 검색 API 가 돌려준 위 공식 페이지들의 발췌문. 아래는 그대로 옮긴 것.

전문 확보분은 지식/원전/원문/ 에 원문 그대로 보관. 핵심 문장만 아래.

[저품질]
  "저품질 블로그, 최적화 블로그, 블로그 지수 등은 네이버에서 만든 개념이 아닙니다"
  "C-Rank는 ... 집중도, 품질, 이용 패턴 등을 파악하고
   주제별 출처의 신뢰도와 인기도를 계산해 개선해나가고 있습니다"
  "알고리즘 역시 매일 업데이트되므로 어떤 출처도 지속적으로 상위에
   노출되기 어렵습니다"

[제한 기준] "'상위 고정 노출'이라는 개념은 존재하지 않으며"
  미노출 사유에 "실제 체험 없이 작성된 비체험 원고 게시물" 과
  "뉴스와 중복되는 기사성 게시물 또는 단순 홍보성 게시물" 이 명시됨.
  순위 하락 사유로 대가성 표기 누락 · 과도한 대가성 후기 반복
  (후자는 "정상적으로 작성된 게시물까지 함께" 불이익).

[스팸사례] "AI나 자동화 프로그램을 활용하는 경우도 포함될 수 있으나,
  특정 기술의 활용 여부만으로는 판단하지 않습니다"
  「키워드 반복·남용」에 "실제 명칭 대신 검색량이 많은 키워드로 치환하여
  작성하는 경우" 가 포함됨.
  「사용자 혼동 및 피해 유발」에 "잘못된 전화번호·주소·신청 링크,
  합성 또는 생성 이미지·동영상" 이 포함됨.

[게시글 노출] "네이버는 제한 대상 내용을 담고 있는 블로그, 게시물이 아닌 경우
  검색 결과에 노출되지 않도록 제한하지 않습니다"
  확인 순서: 24시간 경과 → 제한 사유 → 글의 문장으로 검색 → 제보.

[수정 반영] "글 제목 및 내용 수정 시 검색 결과 반영까지 최대 1일 소요됩니다."
  ← 발췌만 확인. B.
```

```

다만 본문은 못 봤다 — blog.naver.com 도 i-boss 미러도 이 환경에서 차단.

⚠️ 조사 중 알게 된 것: 이 후속 글들은 2019~2020년 글이고

   2026년 제한 기준 문서가 아직 링크하고 있지만,
```
