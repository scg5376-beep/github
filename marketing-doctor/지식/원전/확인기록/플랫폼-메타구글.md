# 확인 기록 · 메타 · 구글

> 인스타·페이스북과 구글. **국가별 지원 범위가 자주 바뀐다 — 반년마다 확인.**
>
> 레지스트리는 `../레지스트리/플랫폼-메타구글.yaml`. 전문 보관은 `원문/`. 형제 묶음: `플랫폼-네이버.md`

## MT-01 · 메타 공식 자료

**확인한것**

```
[링크 불이익 — Mosseri 발언]
"'링크 인 바이오' 라고 쓰면 도달이 줄어든다 — 그건 사실이 아니다(That is not true).
 '링크 인 바이오' 라고 얼마든지 써도 되고, 도달에 어느 쪽으로도 영향을 주지 않는다."

[랭킹 신호 — Mosseri, 2025-01 확인 · 이후 반복]
  시청 시간 (총 시청 시간 + 재생 반복률)  ← 1순위
  도달 대비 좋아요
  도달 대비 전송(DM 공유)
Mosseri (2025-02): "긴 영상에 불이익을 주고 싶지 않다. 그래서 영상의 몇 %가
재생됐는지뿐 아니라 몇 초를 봤는지도 함께 본다."
피드 · 스토리 · 릴스 · 탐색이 각각 다른 랭킹 시스템을 쓴다.

[커머스 자격 — 전문 확보 · 원문/ 에 보관] ★A등급
  1 Facebook·Instagram 정책 준수 (위반 시 계정 비활성화 가능)
  2 비즈니스 및 도메인 대표하기
    "판매 채널로 이용하는 도메인을 축약되지 않은 단일 형태로 제공해야"
    "제공된 도메인에 연결된 매장이나 웹사이트를 대표해야"
    "도메인 소유자인지 확인하기 위해 도메인 인증 프로세스를 완료하도록 요청할 수 있습니다"
  3 지원되는 국가에 위치
    ★ "Facebook과 Instagram 결제 기능은 현재 미국에서만 사용할 수 있습니다"
  4 신뢰도 입증
    "진정성 있고 확고한 입지 등을 통해 신뢰도를 입증해야"
    "팔로워층을 충분하게 유지하는 것도 하나의 방법일 수 있습니다"
  5 정확한 정보 제공
    "오해의 소지가 있는 가격 및 구매 가능 정보가 포함되지 않아야"
    "환불 및 반품 정책은 명확히 안내되어야"
  커머스 채널 = Marketplace · Facebook Shop · Instagram Shop 포함, 이에 국한 안 됨

[제품 태그]
  게시물 · 릴스 · 스토리에 최대 20개 제품을 태그할 수 있다
```

**반증시도**

```
③ 조건 — 통설과 공식을 대조했다.

'링크를 걸면 도달이 깎인다' 는 업계 통설을 Mosseri 가 직접 부정했다.
네이버가 '저품질' 을 부정한 것과 같은 구조다.

다만 도달이 실제로 떨어지는 현상 자체는 관찰된다. 설명은 이렇게 갈린다 —
불이익을 준 게 아니라, "링크 인 바이오" 만 적힌 글에는 반응할 거리가 없어서
상호작용이 안 나오고 그래서 도달이 낮다는 것. 벌이 아니라 결과다.

⚠️ 아래는 2차 자료에서만 봤고 공식 확인을 못 했다. 사장님이 직접 확인해야 한다.
  · 한국에서 쇼핑 태그 신청은 인스타 앱 > 설정 > 비즈니스 > 쇼핑 > 계정 검토 요청,
    평균 1~3일 승인
  · 자사 도메인 쇼핑몰이 필수이고 네이버 스마트스토어는 불가
    → 원문 확인 결과: 공식 문서에 '스마트스토어 불가' 라는 말은 없다.
      다만 도메인 요건 세 가지가 스마트스토어와 충돌한다 —
      ① 축약되지 않은 단일 형태의 도메인  ② 그 도메인을 대표해야 함
      ③ 도메인 소유자 확인(도메인 인증)
      smartstore.naver.com/가게 는 네이버 도메인의 하위 경로이고
      소유자가 사장님이 아니다. '불가' 로 단정하진 않되 이 충돌을 설명한다.
  · (해결됨) 50건 — 「머신 러닝 단계」 전문 확보. ★A
    공식 문구: "일반적으로 광고 세트가 마지막으로 대폭 수정되고 한 주가 지난 후
    약 50건의 '결과' 가 발생하면" 종료된다.
    ⚠️ 내가 '7일 안에 50건' 으로 썼는데 원문은 '마지막 대폭 수정 후 한 주가 지난 뒤' 다.
       그리고 세는 단위는 '최적화 이벤트' 가 아니라 '결과(results)' 다.
    ★ Shops 광고는 기준이 다르다 —
      "웹사이트를 통한 최소 17건의 구매, Meta를 통한 5건의 구매"
    ★ '제한된 머신 러닝' 이 공식 한국어 상태명이다. 게재 열에 표시된다.
      머신 러닝 중일 때는 게재 열에 '머신 러닝' 이 표시된다.
    ★ 균형 — 메타는 "머신 러닝 단계를 완전히 건너뛰지는 마세요. 새로운 크리에이티브
      및 마케팅 전략 테스트는 시간이 갈수록 높은 성과를 달성하는 데 반드시
      필요합니다" 라고도 말한다. '절대 바꾸지 마라' 가 아니다.
    → 「영향이 큰 변경 및 머신 러닝 단계」는 전문 확보 완료 (원문/ 에 보관). ★A
      다만 '50건' 이라는 숫자는 그 문서에 없다. 별도 문서(머신 러닝 단계,
      facebook.com/help/112167992830700)에 있을 것으로 보이나 아직 못 봤다.
    → 확보한 문서가 밝힌 것: 재시작을 부르는 '영향이 큰 변경' 목록.
      무조건 재시작 — 타게팅 모든 변경 / 크리에이티브 모든 변경 /
        최적화 이벤트 모든 변경 / 세트에 새 광고 추가 /
        7일 이상 일시 중지 후 재개 / 입찰 전략 변경
      규모에 따라 — 지출 한도 · 입찰가/비용목표/ROAS 목표 · 예산 금액
        ($100→$101 은 재시작 안 될 가능성 높음, $100→$1,000 은 재시작될 수 있음)
      어드밴티지+ 예산 — 예산 분배는 재시작 아님. 한 세트의 변경이 다른 세트를
        재시작시키지 않음. 세트 추가도 마찬가지. 다만 캠페인 입찰 전략 전환과
        캠페인 예산 조정은 여러 세트를 재시작시킬 수 있음.
    ⚠️ 용어 — 공식 한국어는 '머신 러닝 단계' 다. '학습기' 로 쓰지 않는다.
    → 2차 자료가 일치하는 추가 사실: 카운트는 광고 '세트' 단위다.
      한 세트 안 광고 5개가 50건 풀을 공유한다.
      결과가 부족하면 '제한된 머신 러닝' 상태가 된다 (공식 한국어).
  · 쇼핑 신청 절차 (2차 자료 일치)
    프로페셔널 계정 전환 → 커머스 관리자에서 숍 만들기 → 카탈로그 연결
    → 도메인 인증 → 검수 제출. 메타는 검수에 최대 4주가 걸릴 수 있다고 안내.
    ⚠️ 앞서 기록한 '1~3일 승인' 과 '최대 4주' 가 어긋난다. 둘 다 2차 자료다.
      어느 쪽도 단정하지 않는다.
```

## GG-01 · Creating Helpful, Reliable, People-First Content

**확인한것**

```
E-E-A-T = Experience(경험) · Expertise(전문성) ·
Authoritativeness(권위) · Trustworthiness(신뢰).
"people-first content" 를 만들라, "search engine-first content"
(검색엔진 노출만 노린 글) 를 만들지 말라는 것이 문서의 중심 주장.
```

**못한것**

```
전문 열람 (developers.google.com 접근 차단). 자기점검 질문 전체 목록 미확보.
```

## MT-02 · 광고 기준과 검토 정책  **B등급**

**확인한것**

```
⚠️ 원문 미확인. 메타 도메인이 전부 차단됐다.
   transparency.meta.com · facebook.com · developers.facebook.com — 직접 시도해 확인.
   그래서 큰따옴표를 쓰지 않고 "~로 전해진다" 로만 적었다.

검토 절차
  게재 전 자동 검토, 보통 24시간 이내 (더 걸릴 수 있음), 상태는 '검토 중'
  ★ 검토 대상에 이미지·동영상·텍스트·타겟팅뿐 아니라
    랜딩 페이지·웹사이트 같은 '도착 페이지' 가 포함된다
  시작된 뒤에도 재검토되며 언제든 거부될 수 있다
  광고 기준·커뮤니티 규정을 안 지키면 광고 계정 자체를 제한할 수 있다

구조 (세 층)
  금지 콘텐츠 / 제한 콘텐츠 / 특별 광고 카테고리(신용·고용·주택·사회이슈)
```

**반증시도**

```
③ 조건 — 두 갈래로 확인했다.

(가) 여러 곳이 같은 말을 하나?  검토 절차 서술은 일치한다.
     특히 '도착 페이지도 검토 대상' 은 여러 2차 자료가 같은 문장으로 전한다.
     메타 자체 페이지(facebook.com/business/ads/review-policy-guidelines)를
     인용한 것으로 보인다. 다만 원문 대조는 못 했다.

(나) 카테고리 세부 목록은?  자료마다 다르다.
     대행사 블로그가 각자 정리한 목록이라 서로 어긋난다.
     → 이 창고는 그 목록을 옮기지 않기로 했다. 구조까지만 쓴다.
```

**주의**

```
같은 폴더의 MT-01 은 A등급이다. MT-02 와 등급이 다르다.
한 파일에서 둘을 같이 인용할 때 등급을 섞어 쓰지 않는다.
한국에 따로 걸리는 조건이 있는지 확인하지 못했다.
```
