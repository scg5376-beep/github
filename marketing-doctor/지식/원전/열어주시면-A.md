# 우선순위

> **원문 미확인이 많다. 다 부탁드리지 않는다.**
> 유료 학술지는 사장님도 못 여신다. **무료로 열리는 것만** 골라 뒀다.
> 하는 법은 하나 — **링크를 열고, 본문을 통째로 복사해서, 대화창에 붙여넣기.**

### 1순위 · 네이버 공식 (한국어 · 무료 · 바로 열림)

이 블로그의 주제 자체다. **열 건을 2026-09-01 에 다 받았다 — 남은 것이 없다.**

### 1순위-b · 메타 광고 정책 (무료 · 바로 열림)

광고는 **돈이 먼저 나가고, 최악의 경우 계정이 막힌다.** 집행 전에 필요하다. 두 건은 받았다.

```
□ MT-02  카테고리별 세부 규정  금지·제한 콘텐츠 각 항목 페이지
                             transparency.meta.com/ko-kr/policies/ad-standards/
                             안에서 항목을 눌러 들어가면 나온다
□ MT-02  비즈니스 자산 광고 제한 facebook.com/business/help/975570072950669
```

### 1순위-c · 구글 (무료 · 바로 열림) — **지금 창고에서 가장 약한 곳**

다섯 건을 받아 A 가 됐다. **비즈니스 프로필 둘만 남았다.**

```

□ GG-03  금지·제한 콘텐츠   support.google.com/business/answer/7400114
```

### 2순위 · 국내 공공 조사 원문 (무료)

### 3순위 · 무료로 공개된 논문 PDF

**유료 학술지 판본 말고, 저자·기관이 무료로 올려둔 것만 골랐다.**

```

□ AD-02  nber.org/papers/w20171        eBay 광고 실험
□ FR-01  web.mit.edu/ariely/www/MIT/Papers/zero.pdf     공짜의 값
□ VR-01  jonahberger.com → Papers      무엇이 퍼지나
□ SI-01  sigir.org/files/forum/F2002/broder.pdf         검색 의도 3분류
```

### 부탁드리지 않는 것

유료 학술지(oup · sciencedirect · wiley · informs · springer)에만 있는 것은
**목록에 넣지 않았다.** 사장님이 여실 수 없고, 억지로 2차 자료로 때우면
이 창고의 값어치가 없어진다. **그것들은 B 로 두고 B 라고 밝히고 쓴다.**
