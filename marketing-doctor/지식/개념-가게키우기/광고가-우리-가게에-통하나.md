> **이 창고에서 설계가 가장 강한 자료다.** 둘 다 **무작위 배정 현장실험**이다.
> "광고했더니 매출이 올랐다" 는 관측 자료와 다르다 —
> 광고를 할지 말지를 **가게가 고른 게 아니라 뽑기로 정했다.**

## 왜 이 구분이 중요한가

```
관측 자료   광고한 가게가 잘된다  →  광고 덕인가? 원래 잘하는 가게가 광고도 하는 건가?
무작위 실험  뽑기로 광고를 준다    →  두 무리의 차이는 광고뿐이다
```

`../개념-손님/사진이-매출을-바꾸나.md` 의 에어비앤비 연구가 앞의 문제를 안고 있다.
**여기 둘은 그 문제가 없다.**

## 실험 하나 — 식당 18,294곳

Yelp(미국의 가게 리뷰 플랫폼)과 함께 한 실험이다.

> 식당 **18,294곳** 중 **7,209곳을 무작위로 뽑아** 광고 패키지를 **3개월 무료**로 줬다.
> 나머지는 대조군이다.

```
구매 의도 지표 여러 가지   평균 7~19% 증가
리뷰 수                    5% 증가
```

**★ 진짜 값어치 있는 건 여기다 — 효과가 가게마다 달랐다.**

| 더 크게 이득 본 곳 |
|---|
| **독립 매장** (체인 아님) |
| 평점이 높은 곳 |
| 리뷰가 많은 곳 |
| 실험 전부터 자연 유입이 많던 곳 |

### 창고 안의 다른 자료와 겹친다

`../개념-손님/리뷰가-매출을-움직인다.md` 의 결론이 **독립 매장에서만** 이었다.
방법이 전혀 다른 두 연구가 **같은 방향**을 가리킨다.

```
리뷰 연구   관측 자료 · 회귀 불연속   별점이 매출을 움직인다 — 독립 매장에서만
광고 실험   무작위 배정              광고 효과가 크다 — 독립 매장에서 더
```

> ⚠️ 다만 **저자 한 명이 겹친다**(Michael Luca). 완전히 독립된 두 팀은 아니다.

## ★ 그런데 이 실험이 말하지 않는 것 셋

여기를 빼고 옮기면 **틀린 글**이 된다.

```
① 잰 것은 '구매 의도' 다. 매출이 아니다
   길찾기·전화·웹사이트 방문·리뷰 같은 행동을 셌다. 실제 매출은 안 봤다
   → "광고하면 매출 7~19% 오른다" 는 이 자료로 말할 수 없다

② 광고를 무료로 줬다
   그러니 이건 '광고의 효과' 이지 '광고비의 값어치' 가 아니다
   → 사장님이 진짜 알고 싶은 건 후자인데, 이 연구는 거기 답하지 않는다

③ 미국 Yelp 의 식당이다
   → 한국 네이버가 아니다
```

## 실험 둘 — 같은 설계인데 결론이 반대다

**일부러 반대 결과를 찾았고, 있었다.** eBay 에서 한 실험이다(경제학 최상위 학술지).

```
브랜드 키워드 광고     단기 효과가 측정되지 않았다
비브랜드 키워드 광고   신규·저빈도 이용자는 반응했다
                       그런데 광고비 대부분을 쓰게 만드는 단골은 반응이 없었다
                       → 평균 수익률이 음수
```

> **실험으로 구한 수익률이 통상적인 비실험 추정치의 일부에 불과했다.**
> 광고 플랫폼이 보여주는 성과 숫자는 대개 부풀려져 있다는 뜻이다.

### 두 실험이 왜 갈렸나

정면 모순이 아니다. **처지가 다르다.**

```
eBay        이미 다 아는 브랜드. 'eBay' 를 검색한 사람은 광고 없어도 온다
            → 원래 올 사람을 돈 주고 다시 산 셈

동네 식당    나를 모르는 사람이 '근처 파스타' 로 찾는다
            → 광고가 없으면 아예 안 보인다
```

여기서 한 줄이 나온다.

> **광고는 '나를 이미 찾는 사람' 에게는 값어치가 없다.**
> **값어치는 '나를 모르는 사람' 에게 닿을 때 생긴다.**

`브랜드는-어떻게-크는가.md` 의 침투율과 같은 이야기다 —
**성장은 새 손님에게서 온다.**

> ⚠️ 이 해석은 **우리가 두 논문을 붙여 만든 것**이다.
> 어느 논문도 이 문장을 쓰지 않았다. 그렇게 밝히고 쓴다.

## 사장님이 가져갈 것

```
1. 가게 이름으로 검색한 사람에게 광고를 붙이는 건 값어치가 낮다
   그 사람은 광고가 없어도 온다 (eBay 실험)

2. 값어치는 '업종+지역' 처럼 나를 모르는 사람이 치는 말에서 나온다

3. 광고 전에 평점과 리뷰부터다
   평점 높고 리뷰 많은 곳에서 광고 효과가 더 컸다.
   빈 가게에 사람을 데려오면 그냥 나간다

4. 플랫폼이 보여주는 성과 숫자는 부풀려져 있다고 보는 게 맞다
   실험으로 다시 재면 그 일부밖에 안 남았다
```
