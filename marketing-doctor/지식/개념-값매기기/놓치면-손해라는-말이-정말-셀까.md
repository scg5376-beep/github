> 마케팅 강의에서 **"손실 회피는 2배"** 라고 단정하는 걸 자주 본다.
> **그 숫자는 근거가 약하다.** 그리고 이건 사장님 글의 말투를 정하는 문제라 중요하다.

## 원래 주장

Kahneman 과 Tversky 가 1979년에 제시한 **손실 회피**다.

> 같은 크기라면 **손실이 이득보다 크게 느껴진다.**

교과서에서 인용되는 계수는 **약 2.25** — 손실이 이득의 두 배 남짓이라는 것이다.

여기서 마케팅 문구가 나왔다.

```
"이만큼 아끼실 수 있습니다"    ← 이득 프레이밍
"이만큼 손해 보고 계십니다"    ← 손실 프레이밍 (두 배 세다고들 한다)
```

## 그런데 2018년에 정면으로 반박됐다

Gal 과 Rucker 가 소비자심리학회지에 낸 논문 제목이 이렇다 —
**"손실 회피의 상실: 그것은 그 이득보다 크게 다가올까?"**

결론은 이렇다.

> **손실 회피가 크게 과잉일반화됐다.**
> 현재 증거는 **손실이 전반적으로 이득보다 더 영향력 있다는 것을 뒷받침하지 않는다.**

그리고 숫자도 다르다.

```
교과서       2.0 ~ 2.5
현장 연구    1.0 ~ 1.5 에 가까운 경우가 많다
```

**1.0 이면 차이가 없다는 뜻이다.**

### 잘못 갖다 붙인 사례도 지적한다

| 현상 | 손실 회피 때문이 아닐 수 있다 |
|---|---|
| 손해 본 주식을 못 파는 것 | 평균으로 돌아올 거라는 믿음일 수 있다 |
| 이미 쓴 돈이 아까워 계속하는 것 | 손실을 **인정하기 싫은 것**이지, 손실이 더 크게 느껴지는 게 아니다 |

## 끝난 논쟁이 아니다

이 반박에 대한 **재반박도 같은 학술지에 실렸다.**
`선택지가-많으면-안-팔리나.md` 와 같은 구조다 — 주장 → 반박 → 재반박.

**그래서 이렇게 쓴다.**

```
⭕ 널리 인용되는 '2배' 는 근거가 약하다는 반박이 있습니다
❌ 손실 회피는 2배입니다
❌ 손실 회피는 없습니다
```

## 사장님이 가져갈 것

**"놓치면 손해"에 기대서 전략을 짜지 않는다.**

그리고 이건 숫자 문제만이 아니다. **겁주는 문구는 신뢰를 깎는다.**

```
❌ "지금 안 하시면 경쟁 업체에 다 뺏깁니다"
❌ "이대로 두면 저품질 걸립니다"        ← 애초에 근거도 없다
⭕ "이렇게 하시면 이런 게 달라집니다"
```

두 번째 줄은 네이버가 직접 부정한 개념이다
(`../플랫폼/네이버/네이버가-직접-부정한-것.md`).
**근거 없는 공포를 파는 게 이 바닥의 기본값인데, 우리는 그 반대로 간다.**

`../../콘텐츠/전달규칙.md` 의 "겁주지 않는다" 가 이 자료에 근거를 두고 있다.

## 그럼 손실 얘기를 아예 하지 말라는 건가

아니다. **사실을 사실대로 말하는 것과 겁주는 것은 다르다.**

```
⭕ "옛 번호가 남은 글이 있으면 손님이 헛걸음합니다"   사실이다
❌ "지금 안 고치면 큰일 납니다"                    근거 없는 공포다
```

앞쪽은 **일어나는 일을 알려주는 것**이고, 뒤쪽은 **일어날지 모르는 일로 겁주는 것**이다.
