> 사장님이 **할인을 할까 사은품을 줄까** 정할 때 쓰는 자료다.
> 결론은 **둘이 같은 종류가 아니다**, 그런데 **함정도 같이 있다.**

## 실험

초콜릿 두 개를 놓고 고르게 했다.

```
허쉬 키세스  1센트   vs   린트 트러플 14센트
   →  다수가 린트를 골랐다. 비싸도 더 좋은 걸 골랐다.
```

이제 **둘 다 1센트씩** 내렸다. 가격 차이는 13센트로 그대로다.

```
허쉬 키세스  0센트   vs   린트 트러플 13센트
   →  다수가 허쉬로 갈아탔다.
```

**바뀐 건 한쪽이 공짜가 된 것뿐이다.** 그런데 선택이 뒤집혔다.

## 뜻

> **0으로 내리는 것은 '1원 싸진 것' 이 아니라 다른 종류의 사건이다.**

같은 크기로 깎아도, 0에 닿는 순간의 힘이 훨씬 세다.
배송비 무료가 왜 그렇게 강한지가 여기서 설명된다.

실무로 옮기면 이렇다.

```
1,000원 할인      가격표의 숫자가 조금 바뀐다
사은품 무료 증정   '공짜' 라는 다른 사건이 된다
```

**같은 1,000원을 쓴다면 뒤쪽이 더 셀 수 있다.**

## 함정 — 좋은 걸 안 사게 된다

실험을 다시 보자. 허쉬가 공짜가 되니 사람들이 **린트를 안 샀다.**
린트는 더 비싸고 더 좋은 것, 즉 **마진이 큰 쪽**이다.

> **공짜 미끼가 좋은 상품의 판매를 잠식한다.**

```
❌ 공짜 사은품을 걸었더니 손님이 늘었다 — 그런데 다들 싼 것만 샀다
⭕ 공짜는 '안 오던 사람을 오게 하는 데' 쓰고,
   와서 고를 때는 좋은 쪽이 눈에 들어오게 한다
```

## 늘 통하지는 않는다 — 경계가 여럿이다

**반증을 찾았고, 조건이 꽤 좁았다.**

| 이럴 때는 약하거나 없다 | |
|---|---|
| 금액이 크고 중요한 결정 | 실험은 초콜릿 단가였다. 큰 결정은 검증 안 됨 |
| 실용 목적이 뚜렷할 때 | 필요해서 사는 걸 공짜로 흔들지 못한다 |
| 개인정보 같은 값을 요구할 때 | "무료지만 정보 주세요" 는 안 통한다 |
| 가격 비율을 같이 보여줄 때 | 비교가 되면 효과가 사라졌다 |

동네 가게로 옮기면 이렇게 갈린다.

```
⭕ 커피 한 잔 · 작은 사은품 · 배송비 · 기본 점검
   가볍고 싼 것 → 공짜의 힘이 잘 작동한다

❌ 안경 · 시술 · 수리처럼 금액이 크고 필요해서 하는 것
   여기서 통한다는 증거가 없다. 공짜 미끼로 큰 결정을 흔들려 하지 않는다
```

## 주의

- **B등급 · 실증.** 원문 미확인. 미국 실험이고 초콜릿 단가 수준이다.
- **"공짜로 바꾸면 더 팔린다" 로 줄이면 안 된다.** 위 경계 조건을 다 빠뜨린다.
- 함정(좋은 상품 잠식)은 실험 결과에 그대로 들어 있다. **같이 말해야 정직하다.**
- 대가성 사은품을 블로그 후기와 엮을 때는 별개 규칙이 있다 —
  대가성 표기 누락은 네이버 순위 하락 사유다
