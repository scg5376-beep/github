# 작업 환경

> **A 등급이 왜 사람 몫인지**의 근거가 되는 사실이다.
> 등급 규칙 자체는 `출처등급.md` 에 있다. 여기엔 환경 사실만 둔다.

## 막힌 곳 (2026-09-01 확인)

AI 작업 환경의 네트워크 정책이 아래 접근을 막는다. **직접 확인한 것만 적는다.**

공식 문서가 **어디 있는지까지는** 찾을 수 있다. 열어서 전문을 확인하는
마지막 한 걸음이 안 된다.

## 뚫리는 곳 — 확인된 것

```
⭕ thearf-org-unified-admin.s3.amazonaws.com
   마케팅사이언스연구소(MSI) 워킹페이퍼 아카이브. PDF 전문이 열린다.
   URL 꼴: .../MSI_Report_24-107.pdf · .../MSI/2026/MSI_Report_26-113.pdf
   → SK-01 을 이 경로로 확보해 이 창고의 첫 실증 A 등급이 나왔다

⭕ PlayMCP 의 네이버 검색
   naver.com 이 막혀 있어도 네이버 자체 색인의 발췌문은 받을 수 있다.
   본문이 "…" 로 끊긴다. 공식 문서가 어디 있는지 찾는 데는 쓸 수 있다.
```

**새 조사를 시작할 때 이 순서로 본다.**

```
1. MSI 워킹페이퍼 아카이브에 그 주제가 있나          → 있으면 전문 확보 (A 가능)
2. 없으면 색인 페이지 여러 곳에서 초록을 대조         → B
3. 초록이 서로 같은 문장인지 반드시 확인             → 한 곳만 보고 쓰지 않는다
4. 반대 결과가 나온 연구를 일부러 찾는다             → ③반증 시도
```

## 찾으려다 못 찾은 것 (2026-09-01)

**네이버 검색 공식블로그의 「최적화·저품질 개념이 어떻게 시작되었나」 편.**
C-Rank 글(2016-07-29)이 "지난 포스트" 라고 부르는 바로 앞 글이다.
지금 창고에서 값어치가 가장 클 자리인데 **URL 을 특정하지 못했다.**

```
해본 것
  · 네이버 웹문서·블로그 검색 4회 (제목 조합 · 시리즈명 · 본문 문구)
  · 웹 검색 2회
  · 그 글을 인용한 2차 자료(mongri.net · interad.com) 를 열어 원 링크를 뽑으려 함
    → 두 도메인 다 이 환경에서 차단

알아낸 것
  · C-Rank 글이 2016-07-29 인 것은 독립 출처(i-boss)에서 확인
  · 한 블로거가 저품질 문장의 출처를 "네이버 검색 공식 블로그 (2016. 7. …)" 로
    적었다 → 앞 글도 2016년 7월일 가능성이 높다. 다만 추정이다

사장님께 부탁드리는 방법
  C-Rank 글을 연 상태에서 그 블로그의 '운영 정책' 카테고리로 들어가
  C-Rank 글 바로 앞 글을 찾으면 된다
```

**추측 URL 을 만들어 적지 않는다.** 못 찾았다는 사실을 그대로 둔다.

⚠️ **막힌 목록은 낡는다.** 정책이 바뀔 수 있으니, 중요한 자료는
"전에 막혔다" 고 넘기지 말고 한 번 더 시도해 본다.

## 그래서 이렇게 나눈다

| 하는 일 | 누가 |
|---|---|
| 공식 문서·논문이 어디 있는지 찾기 | AI |
| 2차 자료 대조해 B 까지 올리기 | AI |
| 반증 찾아보고 기록하기 | AI |
| **그 링크를 열어서 전문 확인하기** | **사장님** |
| A·S 로 승급 표시 | 확인한 사람 |

이 방식이 통한다는 건 **NV-03 이 증명했다.** 링크를 찾아두면 사장님이
열어서 붙여주시고, 그걸로 A 가 됐다.

## 열어 주시면 A 가 되는 것 — 우선순위

> **44건이 원문 미확인이다. 다 부탁드리지 않는다.**
> 유료 학술지는 사장님도 못 여신다. **무료로 열리는 것만** 골라 뒀다.
> 하는 법은 하나 — **링크를 열고, 본문을 통째로 복사해서, 대화창에 붙여넣기.**

### 1순위 · 네이버 공식 (한국어 · 무료 · 바로 열림)

이 블로그의 주제 자체다. **품이 가장 적고 값어치가 가장 크다.**

```
✅ NV-05  플레이스 순위 알고리즘      2026-09-01 확보 → A
✅ NV-05  플레이스 SEO·어뷰징 운영원칙  2026-09-01 확보 → A
                                    23473 내용과 어뷰징 판정 기준이 여기 다 있었다
✅ NV-05  플레이스 AI 브리핑 노출 안내  2026-09-01 확보 → A
✅ NV-05  미용실 시술사진 등록 기준    2026-09-01 확보 → A
✅ NV-01  C-RANK 소개                2026-09-01 확보 → A
✅ NV-01  D.I.A. 소개                2026-09-01 확보 → A

✅ NV-01  블로그 검색 소개            2026-09-01 확보 → A
✅ NV-01  공식블로그 C-Rank 상세       2026-09-01 확보 → A (2016년 글, 연도 필수)
✅ NV-04  파워링크 노출 순위          2026-09-01 확보 → A
✅ NV-04  플레이스광고 과금 영역       2026-09-01 확보 → A
```

### 2순위 · 국내 공공 조사 원문 (무료)

숫자에 **연도·기관·표본**을 붙이려면 보도자료 원문이 필요하다.

```
□ KR-01  소상공인실태조사 보도자료    mss.go.kr → 알림·뉴스 → 보도자료
□ KR-05  기업생멸행정통계            kostat.go.kr → 보도자료
```

### 3순위 · 무료로 공개된 논문 PDF

**유료 학술지 판본 말고, 저자·기관이 무료로 올려둔 것만 골랐다.**

```
□ AD-01  nber.org/papers/w30925        광고 실험 (NBER 워킹페이퍼는 무료)
□ AD-02  nber.org/papers/w20171        eBay 광고 실험
□ FR-01  web.mit.edu/ariely/www/MIT/Papers/zero.pdf     공짜의 값
□ VR-01  jonahberger.com → Papers      무엇이 퍼지나
□ SI-01  sigir.org/files/forum/F2002/broder.pdf         검색 의도 3분류
```

### 부탁드리지 않는 것

유료 학술지(oup · sciencedirect · wiley · informs · springer)에만 있는 것은
**목록에 넣지 않았다.** 사장님이 여실 수 없고, 억지로 2차 자료로 때우면
이 창고의 값어치가 없어진다. **그것들은 B 로 두고 B 라고 밝히고 쓴다.**
