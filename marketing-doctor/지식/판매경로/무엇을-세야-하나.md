> **"효율이 좋다" 는 말은 무엇을 세느냐가 정해져야 성립한다.**
> 이 파일은 자리마다 셀 수 있는 것과 **세면 안 되는 것**을 가른다.
> 자리 구분은 `손님이-지나가는-길.md`. 내용은 각 지식 파일에 있다(규칙 4).

## 먼저 · 이 창고가 정직하게 말할 수 있는 것

```
말할 수 있다   플랫폼이 무엇을 보고 무엇을 빼는지 (공식 문서 A)
               돈이 어디서 얼마나 나가는지 (수수료·과금 A)
               법이 무엇을 시키는지 (법령 A)
말할 수 없다   "이렇게 하면 매출이 몇 % 오른다"
               전환율 · 객단가 · 광고 수익률의 업종별 기준값
```

**창고에 전환율 숫자가 한 건도 없다.** 없는 채로 쓰는 게 맞다 —
있는 척하는 순간 이 창고의 값어치가 사라진다(절대 규칙 1).

## 원칙 셋

### ① 플랫폼이 보여주는 성과 숫자를 그대로 믿지 않는다

무작위 배정 실험으로 구한 광고 수익률이 통상적인 비실험 추정치보다 **훨씬 낮았다**는
연구가 있다 → `../개념-가게키우기/광고가-우리-가게에-통하나.md` (B·실증).
플랫폼 대시보드의 '전환' 은 대개 **원래 올 사람까지 포함해 센 값**이다.

### ② 한 번에 하나만 바꾼다

메타는 **소재를 바꾸면 머신 러닝 단계가 다시 시작된다**고 공식 문서에 적었다
→ `../플랫폼/메타/메타-광고-건드리면-안-되는-것.md` (**A**).
둘을 같이 바꾸면 어느 쪽이 움직였는지 영영 모른다(우리가 붙인 것).

### ③ 다투기 어려운 숫자는 하나뿐이다 — 정산액

노출·클릭·도달은 플랫폼이 정의하고 플랫폼이 센다.
**정산액은 돈이 실제로 들어온 값이다.** 스마트스토어 수수료 구조가 A 로 확보돼 있어
계산이 검증 가능하다 → `../홈페이지/홈페이지-온라인으로-팔려면.md`.

## ⚠️ 세면 헷갈리는 것 여섯

```
① 플레이스광고 클릭        '길찾기' · '저장하기' 만 눌러도 과금된다.
                          그 안의 '출발' 아이콘은 과금이 아니다.
                          → 클릭 수는 방문 의사가 아니다  (NV-04, A)
② 브랜드 키워드 광고 성과   나를 검색한 사람은 광고가 없어도 온다.
                          여기 쓴 돈의 수익률이 음수였던 실험이 있다  (AD-02, B·실증)
③ 검색 순위 추적           네이버는 고정된 점수표가 없다고 밝혔고,
                          구글은 E-E-A-T 가 순위 요소가 아니라고 적었다.
                          순위는 목표가 아니라 결과다  (NV-01·GG-01, 둘 다 A)
④ AI 답변 노출             GEO 는 아직 "된다" 고 말할 수 있는 단계가 아니다  (GE, B)
⑤ 노출 수                  파워링크는 자리가 10개, 동네 키워드는 3개다.
                          노출이 늘어도 자리가 안 늘면 의미가 다르다  (NV-04, A)
⑥ 인스타 '구매' 버튼        한국에서는 인스타 안 결제가 안 된다.
                          판매는 결국 내 쇼핑몰에서 일어난다  (MT-01, A)
```

## ★ 마케팅이 판매 데이터로 바뀌는 단 하나의 자리

스마트스토어 공식 문서는 **판매자가 직접 광고·홍보로 유입한 고객의 구매에는
판매자 마케팅 수수료가 적용되어 낮은 수수료가 과금된다**고 적었다(**A**).

```
같은 주문인데     그냥 팔리면        판매수수료 3%
                 내가 데려오면       판매수수료 1%
```

**자리 1~3 을 잘한 값어치가 자리 4 의 정산액에 그대로 찍힌다.**
그래서 이 창고에서 효율을 재는 가장 정직한 지표는
**"내가 데려온 주문의 비율"** 이다(우리가 붙인 것).
플랫폼 대시보드가 아니라 **정산 내역**에서 나온다.

## 아직 못 채운 것

```
· 스마트스토어 건별 정산내역 조회 화면 — 캡처로만 봐서 인용을 못 한다. 텍스트가 필요하다
· 네이버 애널리틱스 · 스마트스토어 통계 · 쿠팡 판매자 데이터 공식 문서 → 한 건도 없다
· 구글 서치 콘솔 · GA4 공식 문서 → 없다
· 국내 업종별 전환율·객단가 공공 조사 → 못 찾았다
· 국내 광고 효과 무작위 실험 → 못 찾았다. 창고의 광고 실증 둘은 미국 자료다
```

**이게 다 채워지기 전까지 이 창고는 "무엇을 세라" 까지만 말한다.**
"얼마가 정상이다" 는 말하지 않는다.
