## 구조
- 첫 문단이 하는 일: 시즌 특성("구매 의지가 강해지는 시기")을 근거로 이메일 채널의 적합성부터 설득
- 전개 순서: 채널 적합성 → 세 가지 소제목(할인 강조 → 기간 강조 → 시즌 분위기 강조), 각 소제목마다 원칙 설명 → 실제 브랜드 사례(헤이데이무드·윙블링·러쉬) → 예시 제목 3개
- 독자를 부르는 방식: 없음. "브랜드"를 주어로 놓고 3인칭으로 설명
- 지시문 형태: "~해 보세요"가 소제목마다 한 번씩 등장(녹여보세요, 활용해 보세요)
- 이유를 붙이는 방식: "~기 때문에"로 원칙 뒤에 근거를 붙이고, 실제 브랜드명을 사례로 제시해 신뢰도를 보강
- 문단 하나의 길이·리듬: 원칙 설명 문단(2~3문장) 뒤에 실제 사례 문단, 그 아래 예시 제목 3개를 리스트로 붙이는 3단 구성이 소제목마다 반복
- 마무리 방식: 마지막 소제목에서 감성 소구 업종에 대한 조언으로 끝나며 별도 결론 문단 없음

## 예시 문장 (3개 이내, 원문 그대로)
1. "'무료', '공짜', '100%'와 같은 자극적인 표현은 오히려 스팸으로 분류될 확률을 높일 수 있으니 주의해야 합니다."
2. "행사가 끝나기까지 며칠 남지 않았다는 긴급성을 강조하면, 지금 이메일을 열어야 하는 분명한 이유가 생기기 때문에 자연스럽게 이메일 오픈을 유도할 수 있습니다."
3. "크리스마스 할인이 3일밖에 남지 않았어요!"
