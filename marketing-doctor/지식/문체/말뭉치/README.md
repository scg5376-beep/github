# 한국어 문체 말뭉치 — 문체 카드 (2026-09-14)

목적: 사람이 실제로 쓰는 한국어(뉴스·블로그·교육자료·강의·커뮤니티) 100편 이상을 분석해 사장님 마케팅 교실의 글쓰기 규칙과 체크리스트를 만든다. 운영자 지시: "최소 1000자 이상 레퍼런스를 100개 이상 학습하고 구조 분석을 통해 규칙 및 체크리스트를 만들어야 해".

저작권: 원문 전문은 저장하지 않는다. 글을 읽고 `엔진/문체분석.py`로 통계를 뽑은 뒤, 통계 + 구조 관찰 + 짧은 예시 문장(3문장 이내, 출처 표기)만 카드로 남긴다.

파일 이름: `NNN-갈래-출처슬러그.md` (갈래 = news | blog | edu | lecture | community)

카드 형식:
```
---
id: 001
genre: blog
title: ...
source: 매체·저자
url: ...
date: 게시일(모르면 미상)
chars: 본문 글자 수(공백 제외, 통계의 chars_nospace)
fetched: 2026-09-14
---
## 통계
(문체분석.py 출력 JSON 그대로)

## 구조
- 첫 문단이 하는 일: (독자 상황 부르기 / 결론 먼저 / 질문 / 사례 …)
- 전개 순서: (문제→이유→방법→마무리 등, 소제목이 있으면 소제목 나열)
- 독자를 부르는 방식: (사장님·여러분·~하시는 분 / 없음)
- 지시문 형태: (~해 보세요 / ~하세요 / ~하면 됩니다 / 없음)
- 이유를 붙이는 방식: (-거든요 / 때문에 / 왜냐하면 / 안 붙임)
- 문단 하나의 길이·리듬 관찰
- 마무리 방식

## 예시 문장 (3개 이내, 원문 그대로)
1. "…" 
2. "…"
3. "…"
```

통계 뽑는 법(Bash): 본문을 임시 파일에 저장 → `python "C:/Users/USER/Desktop/광고관리자/marketing-doctor/엔진/문체분석.py" 임시.txt` → 임시 파일 삭제.
