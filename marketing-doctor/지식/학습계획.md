## 1차 학습이 끝났다 (2026-08-31)

계획표의 모든 항목이 ✅ 다. **③반증 시도까지 마쳤다는 뜻이다.**

이제 할 일이 바뀐다.

```
1  글을 쓴다              창고에서 꺼내 쓴다. 콘텐츠/전달규칙.md 부터 본다
2  B 를 A·S 로 올린다      새 개념을 늘리는 것보다 이게 먼저다 (INDEX.md)
3  낡은 것을 갈아끼운다     아래 재확인 주기
```

### 재확인 주기

| 무엇 | 주기 | 왜 |
|---|---|---|
| `플랫폼/` 전체 | **반년** | 실제로 크게 바뀐 적이 있다 (2023-08 메타 APAC 축소) |
| `현황/` 전체 | **1년** | 국내 조사는 해마다 3월경 나온다 |
| `개념-*/` | 필요할 때 | 잘 안 낡는다. 새 반박이 나오면 그때 |
| `실무/` | 사례가 3개 넘으면 | 그때 `개념/` 승급을 검토한다 |

### 2차 학습으로 미룬 것


## 채우는 순서 (2026-08-31)

> **INDEX.md 에는 안 적는다.** 순서는 이 파일 한 곳에만 있다 (규칙 4).

새 개념을 늘리는 것보다 **가진 것의 등급을 올리는 게 먼저**다.
B만 잔뜩 쌓이면 "출처 있는 블로그" 가 아니라 "요약 블로그" 가 된다.

```
1. KR-02·KR-03 을 S 로      이 창고의 첫 S 가 될 자리다. ②③④ 는 이미 채웠다
                            나스미디어 NPR 보고서 · 과기정통부 보도자료 원문

2. 나머지 B → A 승급         사장님이 링크를 열어 붙여 주시는 방식
                            남은 것: 플레이스 23472·23473·20426 / D.I.A. 7요소 / GG-01
                            FP-01(눈삽 원문) · FP-02 · FP-05(표본 국가 목록)

3. C등급 둘을 B 로           FP-03(Bolton & Alba 2006) · FP-04(메타분석)
                            지금은 남의 논문이 요약한 것만 봤다. 초록만 봐도 B 가 된다

4. 첫 방문에서 뭘 보고 정하나 개념-손님 묶음
5. 소상공인 광고 효과 실증    "투입 대비 산출" 은 국내 조사에 항목이 없다.
                            해외 실증에서 로컬 매장에 맞는 걸 찾는 쪽이 잘 통했다
6. 국내 실무자               유튜브 할당량이 복구되면
```

**원전 폴더 재편은 끝냈다**(2026-08-31). yaml 열한 개를 `원전/레지스트리/` 로
내려 원전/ 이 14칸에서 4칸이 됐다. 재편하면서 낡은 참조 셋도 같이 잡혔다 —
없어진 `목록.yaml`, 평면 시절의 `확인기록-*.md`, 그리고 **검수 스크립트의
확인기록 링크 검사가 옛 이름만 보고 있어 사실상 죽어 있던 것.**

**뚫리는 문이 있다는 걸 이번에 알았다.** MSI(마케팅사이언스연구소) 워킹페이퍼가
S3 에 공개돼 있어 PDF 전문을 열 수 있었다(SK-01). 학술지 본문이 막혀 있어도
**워킹페이퍼 판본을 찾으면 뚫린다.** 다음 조사부터 이 경로를 먼저 본다.

**NV-03 후속 문서는 우선순위를 낮췄다.** 위치는 찾았으나 2019~2020년 글이고
'VIEW' 를 전제로 쓰였다. VIEW 는 2024-02 폐지 — 부분적으로 낡았을 수 있다.
