# 기록 양식

> 품목 레포의 `보고/기록.md` 에 이 틀을 복사해 쓴다.
> **숫자는 `주간.csv` 에, 왜 그랬는지는 여기에.** 둘을 섞지 않는다.
> 컨트롤 타워는 이 파일을 읽기만 하고 고치지 않는다.

## 쓰는 법

주마다 한 덩어리씩 **이어 붙인다.** 지난 것을 고치지 않는다 —
나중에 "그때 무슨 생각이었나" 를 봐야 하기 때문이다.

```
── 2026-W37

바꾼 것        (딱 하나. csv 의 '바꾼것' 칸과 같은 말로 쓴다)
왜 바꿨나      (근거가 있으면 창고 파일 이름을 적는다)
무슨 일이 있었나 (명절 · 날씨 · 품절 · 배송 사고 · 리뷰 내용)
다음 주에 볼 것
```

## 지키는 것 셋

**① 한 주에 하나만 바꾼다.** 둘을 같이 바꾸면 어느 쪽이 움직였는지 영영 모른다.
메타는 광고 소재를 바꾸면 학습 단계가 다시 시작된다고 공식 문서에 적었다
(`../../지식/플랫폼/메타/메타-광고-건드리면-안-되는-것.md`, A).

**② 안 좋았던 것도 적는다.** 잘된 주만 남으면 나중에 아무것도 배울 수 없다.

**③ 여기 적지 않는 것**

```
❌ 손님 이름·전화번호·주소     집계된 수만 적는다
❌ 상호·지역
❌ "이래서 올랐다" 는 단정      12주로 인과는 말할 수 없다
```

## 시작할 때 한 번 쓰는 것

맨 위에 이 세 줄을 적어 둔다. 12주 뒤에 이걸 보고 판단한다.

```
■ 왜 이 품목인가
■ 12주 뒤에 무엇을 보면 계속할 것인가   (품목.yaml 의 판단지표와 같은 값)
■ 안 하기로 한 것 셋
```
