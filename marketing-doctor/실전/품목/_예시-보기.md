# 채워진 모습 예시

> ⚠️ **아래 숫자는 전부 지어낸 것이다.** 양식이 어떻게 생겼는지만 보여 준다.
> 이 숫자를 근거로 아무것도 판단하지 않는다. 진짜 기록은 `품목/<품목이름>.md` 에 쌓인다.

```
■ 품목카드
품목            샴푸 500ml
시작일          2026-09-08
파는 곳         ■ 스마트스토어
수수료 등급     Npay 3.003 %  /  판매수수료 3 %  (직접 유입 시 1 %)

■ 자리 0 — 다 닫고 시작했나
                ■ 통신판매업 신고  ■ 제10조 표시  ■ 처리방침 게재  ■ 청약철회 안내

■ 이 품목의 손님은 어떻게 찾나
검색 갈래       ■ 상업형   (사기 전에 비교하는 사람)
첫 자리         ■ 블로그   광고비가 없고, 상업형은 읽고 나서 사기 때문

■ 12주 뒤에 무엇으로 판단할까
주 지표         내가 데려온 주문 비율 30 % 를 넘으면 계속

■ 안 하기로 한 것
                ■ 브랜드 키워드 광고  ■ 한 주에 둘 이상 바꾸기  ■ 순위 추적으로 판단하기
```

```
── 2026-W37  (9월 8일 ~ 14일)

바꾼 것        블로그 주 3회 발행 시작

자리 1 도달     광고비 0원   노출/도달 —
자리 2 검색     발행 3편   유입 검색어 상위 3개: (아직 없음)
자리 3 방문     방문 14
자리 4 판매     주문 1건   정산액 21,300원
               그중 내가 데려온 주문 0건
자리 5 재방문   새 리뷰 0개   답글 0개

이번 주 한 줄   색인이 아직 안 됐다. 네이버는 최대 1주일이라고 적혀 있으니 다음 주에 본다
```

```
── 2026-W38  (9월 15일 ~ 21일)

바꾼 것        없음  (지난주 것만 관찰)

자리 1 도달     광고비 0원   노출/도달 —
자리 2 검색     발행 3편   유입 검색어 상위 3개: 샴푸 추천 / 두피 샴푸 / 샴푸 성분
자리 3 방문     방문 63
자리 4 판매     주문 4건   정산액 85,900원
               그중 내가 데려온 주문 2건
자리 5 재방문   새 리뷰 1개   답글 1개

이번 주 한 줄   블로그 유입이 처음 잡혔다. 검색어가 전부 상업형이라 가정이 맞았다
```

**여기까지가 2주다.** 이 상태로는 아무것도 말할 수 없다 — 그게 정상이다.
