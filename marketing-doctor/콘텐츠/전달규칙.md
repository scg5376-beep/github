# 전달 규칙

> 창고에 아무리 좋은 자료가 있어도 **안 읽히면 없는 것**이다.
> 독자는 **장사를 오래 하신 사장님**. 마케팅은 처음이고, 나이가 있으실 수 있다.
>
> 지식 자체는 `지식/`, 전달 방식은 여기. 같은 내용을 두 곳에 쓰지 않는다.

## 독자를 어떻게 보나

**모르는 게 아니라 안 배운 것이다.** 이 구분이 글의 톤을 결정한다.

30년 장사한 사장님은 손님 심리를 나보다 잘 안다.
모르는 건 **용어와 도구**지 마케팅이 아니다.

```
❌ 쉽게 풀어서 알려드릴게요        (가르치는 자세)
⭕ 이미 하고 계신 걸 이름만 붙이면 (알아보게 하는 자세)
```

단골 관리를 이미 하고 계신다. 그걸 "리텐션" 이라고 부를 뿐이다.
목 좋은 자리를 고르실 줄 안다. 그게 "물리적 가용성" 이다.

## 글의 종류는 셋뿐이다

| 종류 | 답하는 질문 | 반드시 있어야 하는 것 |
|---|---|---|
| **방법** | 어떻게 합니까 | 순서. 1 → 2 → 3 |
| **효율** | 할 만합니까 | 들인 것과 얻는 것, 둘 다 숫자 |
| **비교** | 뭐가 낫습니까 | **기준을 먼저** 밝히고 나서 비교 |

### 방법 글

**순서대로 쓴다.** 배경 설명을 앞에 길게 깔지 않는다.
사장님은 지금 그걸 하려고 들어오셨다.

이유는 각 단계 **뒤에** 한 줄로 붙인다. 앞에 몰아두면 본론까지 못 간다.

### 효율 글

**들인 것을 반드시 같이 쓴다.** 얻은 것만 쓰면 광고가 된다.

```
❌ 블로그로 문의가 늘었습니다
⭕ 주 3회 · 2개월 (한 편에 40분 ≈ 총 16시간) 들여서 이렇게 됐습니다
```

시간도 비용이다. 사장님에게는 돈보다 시간이 귀하다.

### 비교 글

**기준을 먼저 못 박는다.** 기준 없는 비교는 그냥 취향이다.

```
1  뭘 기준으로 비교하는지 밝힌다   (예: 들인 시간 대비 문의 수)
2  그 기준으로 비교한다
3  기준이 다르면 답도 달라진다고 말한다
```

**"이게 더 좋습니다" 로 끝내지 않는다.** "이런 가게엔 이게, 저런 가게엔 저게" 로 끝낸다.
가게마다 손님 나이도 상권도 다르다.

## 숫자 쓰는 법

숫자는 이 창고의 무기다. 그런데 **그냥 던지면 안 읽힌다.**

| 규칙 | 예 |
|---|---|
| 비율은 사람 수로 바꿔 준다 | 44.5% → **열에 넷 남짓** |
| 누구를 조사한 건지 붙인다 | "국민 5만명 조사에서" |
| 연도를 붙인다 | "2025년 기준" |
| 한 문단에 숫자 셋을 넘기지 않는다 | 넘으면 표로 뺀다 |

**출처는 문장 안에 자연스럽게 넣는다.** 각주로 빼면 아무도 안 본다.

## 용어

**영어 약어는 처음 한 번만 풀고, 그다음부터는 우리말로 쓴다.**

```
❌ C-Rank, D.I.A., E-E-A-T 를 계속 반복
⭕ 처음: "C-Rank(네이버가 블로그 신뢰도를 매기는 알고리즘)"
   이후: "신뢰도 점수"
```

용어를 아는 게 목적이 아니다. **내일 뭘 할지 아는 게 목적**이다.

비유는 **장사 경험에서** 가져온다. IT 비유를 쓰지 않는다.

| 개념 | 이렇게 비유한다 |
|---|---|
| 주제별 C-Rank | 한 골목에서 오래 장사한 집이 그 골목에서 알아준다 |
| 꾸준함 | 문을 자주 닫는 가게는 손님이 발길을 끊는다 |
| 키워드 정합성 | 간판은 국밥집인데 들어가니 카페인 것 |

## 형식

```
한 글에 한 가지        여러 개 넣으면 아무것도 안 남는다
문단은 3줄 이내        폰으로 보면 글자 벽이 된다
표는 3열 이하          가로로 밀리면 안 본다
소제목은 문장으로      "키워드 전략" ❌ / "키워드는 하나씩 잡습니다" ⭕
```

## 안 하는 것

- **겁주지 않는다.** "이러면 저품질 됩니다" 같은 말은 근거도 없고
  (`지식/플랫폼/네이버가-직접-부정한-것.md`) 사장님을 위축시킨다.
- **비법이라고 하지 않는다.** 공식 문서에 다 적혀 있는 것들이다.
  비법이라고 파는 순간 우리도 그쪽이 된다.
- **단정하지 않는다.** 출처 등급에 맞게 쓴다 (`지식/출처등급.md`).
- **남의 매장을 예로 들지 않는다.** 매장명이 나가면 안 된다.

## 마지막 점검

글을 다 쓰고 이것만 본다.

```
□ 사장님이 내일 할 수 있는 게 하나라도 있나
□ 숫자마다 연도와 조사 대상이 붙어 있나
□ 영어 약어를 두 번 이상 반복하지 않았나
□ "그래서 뭘 하라는 거지" 소리가 안 나오나
```
