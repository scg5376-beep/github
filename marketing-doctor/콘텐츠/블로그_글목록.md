# 블로그 글 목록 — 사장님에게 알려주는 콘텐츠

독자는 **소상공인 사장님**. 채널은 **네이버 블로그**부터.
남의 매장 사례는 쓰지 않는다. 이 블로그가 검색에 걸리는 것 자체가 증거다.

제목은 `[후킹] | [공략 키워드]` 로 쓴다. 뒤에 잡을 검색어를 정확히 박는다.

## 쓰는 순서 원칙

1. **1단계를 다 쓰고 2단계로.** 빈자리를 먼저 채운다.
2. **한 글에 공략 키워드 하나.** 표의 키워드를 제목 뒤에 그대로 박는다.
3. **1,500자 이상.** 짧으면 내용 없는 글로 본다.
4. **자주 묻는 질문 블록**을 매 글 끝에 넣는다(6번 글에서 스스로 설명한 내용을 스스로 지킨다).
5. 사례가 필요하면 **매장명·지역을 빼고 숫자만.** 업종은 남긴다.

## 아직 안 정한 것

- 블로그 이름·주소
- 발행 주기 (주 3회 실증치가 있으나 이 블로그는 별도 판단)
- 프로필에 뭐라고 쓸지 (실명 / 활동명)
