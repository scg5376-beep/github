# 홈페이지와 온라인 판매 — 사장님용

> **순서대로 따라 하시면 됩니다.**
> 네이버·구글이 직접 적은 문장은 **원문 전문**에서 옮겼습니다. 큰따옴표가 그것입니다.
> 대행사 설명과 다르면 **여기가 맞습니다.**

## ★ 먼저 — 이 스킬이 가장 자주 바로잡는 것 셋

```
"네이버 사이트 등록을 해 드립니다"
  → 네이버 문서 원문: "검색 등록 절차는 존재하지 않습니다"
     등록해도 노출이 생기지 않습니다. 리포트를 보는 값어치만 있습니다

"지점마다·행사마다 사이트를 따로 만드세요"
  → 네이버 문서 원문: 동일한 콘텐츠로 여러 사이트를 만들면 "불이익을 받을 수 있으니 유의하세요"

"메인 제목에 키워드를 넣으세요"
  → 네이버 문서 원문: 메인 title 은 "브랜드명으로 기입해야 합니다"
```

**셋 다 흔히 파는 서비스인데 공식 문서가 정면으로 부정합니다.**

## 순서

```
1단계   어디서 시작하나            references/1-어디서-시작하나.md
        └ 도메인 · 올릴 곳 셋 · AI로 만들 때 사람이 봐야 하는 것

2단계   검색에 보이게 하려면        references/2-검색에-보이게-하려면.md
        └ 소유확인 · 안 보일 때 · 제목과 설명 · 오픈그래프

3단계   무슨 글을 올리나            references/3-무슨-글을-올리나.md
        └ 네이버 콘텐츠 5원칙. 부정한 것 열 가지가 정리돼 있습니다

4단계   빠르고 안전하게            references/4-빠르고-안전하게.md
        └ 속도 지표 · HTTPS · ★ 방치하면 남이 내 사이트를 씁니다

5단계   온라인으로 팔려면          references/5-온라인으로-팔려면.md
        └ 스마트스토어 · 쿠팡 수수료 · ★ 직접 데려오면 3%가 1%
```

## ★ 이 스킬 전체에서 가장 중요한 한 줄

스마트스토어 공식 문서입니다.

> · 판매자가 직접 네이버 내부 또는 외부에서 광고 및 홍보를 통해 유입한 고객이 상품을 구매한 경우, 판매자 마케팅 수수료가 적용되어 낮은 수수료가 과금됩니다.

**같은 주문인데 판매수수료가 3%와 1%로 갈립니다.**

홈페이지를 만드는 이유가 여기 있습니다. 손님을 직접 데려오는 일이 **막연한 브랜딩이
아니라 정산액에 찍히는 숫자**로 돌아옵니다.

## 팔기 전에 반드시 닫아야 하는 것

**이 스킬은 '만들고 보이게 하는 것' 까지입니다.**
**파는 순간 법이 붙습니다** — 통신판매업 신고 · 초기화면 표시 사항 · 개인정보
처리방침 · 청약철회 안내. 그건 **product-launch 스킬의 0단계**에 A등급으로 있습니다.

```
□ 문의 폼 하나만 있어도 개인정보처리자입니다 (규모 기준이 없습니다)
□ 처리방침 페이지가 없으면 과태료 대상입니다
□ 문의 폼이 HTTP 면 전송 암호화를 안 한 것입니다
```

**셋 다 홈페이지를 만드는 동안 같이 해야 합니다.** 나중에 하면 이미 정보를 받고 있습니다.

## 등급을 섞지 마십시오

이 스킬 안에서도 근거 세기가 다릅니다.

```
A등급   네이버 최적화·소유확인·마크업·콘텐츠 원칙 · 네이버 스팸사례
        구글 Web Vitals 지표 정의·기준값 · 스마트스토어 수수료 · 쿠팡 수수료 표
B등급   도메인 제도 · 호스팅 약관 · AI 코딩 사고 사례 · HTTPS 일정 · 속도와 매출 조사
C등급   네이버쇼핑 검색 순위(적합도·인기도·신뢰도)  ← 글에 쓰지 않습니다
```

**A 는 큰따옴표로 옮겼고, B 는 "전해집니다" 로 적었습니다.** 그 구분이 이 스킬의
값어치입니다. 인용할 때 섞지 마십시오.

## 쓰지 말아야 할 숫자

```
"100ms 마다 매출 1% 를 잃는다"     2006년 강연 슬라이드가 출처입니다. 공식으로 낸 적 없습니다
"3초 넘으면 절반이 이탈한다"       2016년 조사입니다. 10년 전 네트워크입니다. 연도 없이 쓰지 마십시오
빌더 요금 · 도구 비교              반년이면 다 바뀝니다. 요금 페이지를 직접 보십시오
".kr 이 검색에 유리하다"           근거 있는 자료를 못 찾았습니다. 아무 말도 하지 않습니다
```
