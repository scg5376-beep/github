홈페이지와 온라인 판매 (homepage-shop) 스킬 — 설치하는 법
============================================================

■ 그냥 읽기만 하셔도 됩니다

  압축을 풀고 SKILL.md 를 여세요. 메모장으로도 열립니다.

  이제 시작하신다면    references/1-어디서-시작하나.md      ← 여기부터입니다
  만들었는데 안 보이면  references/2-검색에-보이게-하려면.md
  글을 올릴 때         references/3-무슨-글을-올리나.md
  느리거나 걱정될 때    references/4-빠르고-안전하게.md
  팔기 시작할 때       references/5-온라인으로-팔려면.md

  ※ 2번과 4번 끝의 점검표는 인쇄해서 쓰시는 걸 권합니다.


■ 클로드 코드(Claude Code)에 붙여서 쓰시려면

  1. 압축을 풉니다
  2. homepage-shop 폴더째로 아래 위치에 넣습니다

       레포 폴더/.claude/skills/homepage-shop/

  3. 클로드 코드를 다시 시작합니다
  4. 대화창에 /homepage-shop 이라고 치면 불러옵니다

  파실 거면 product-launch 스킬을 반드시 함께 넣으십시오.
  법적 절차(통신판매업 신고·표시 의무·처리방침)가 거기 있습니다.


■ 안에 뭐가 들었나

  SKILL.md                          먼저 읽는 곳. 자주 바로잡는 것 셋
  references/1-어디서-시작하나.md      도메인 · 올릴 곳 · AI로 만들 때
  references/2-검색에-보이게-하려면.md  소유확인 · 안 보일 때 · 제목과 설명
  references/3-무슨-글을-올리나.md      네이버 콘텐츠 5원칙
  references/4-빠르고-안전하게.md       속도 · HTTPS · 방치의 대가
  references/5-온라인으로-팔려면.md     스마트스토어 · 쿠팡 수수료


■ ★ 이 스킬을 쓸 때 지킬 것

  큰따옴표와 "전해집니다" 를 섞지 마십시오.

    큰따옴표      공식 문서 원문 전문에서 그대로 옮긴 것입니다 (A등급)
    "전해집니다"   원문을 못 열고 2차 자료를 대조한 것입니다 (B등급)

  네이버쇼핑 검색 순위 이야기는 C등급이라 글에 쓰지 않습니다.


■ 근거

  아래 원문 전문에서 옮겼습니다. 요약본이나 강의 자료가 아닙니다.

    네이버 서치어드바이저 — 검색엔진 최적화의 목적 / 사이트 등록 및 소유확인
                          HTML 마크업 가이드(콘텐츠) / 콘텐츠 작성시 권장 사항
    네이버 검색 — 웹 콘텐츠 스팸사례
    구글 — Web Vitals (한국어판) / 검색 기술 요구사항 / 스팸 정책
    스마트스토어 — [정산관리] 수수료의 종류
    쿠팡 — 카테고리별 판매 수수료 표

  ⚠️ 구글 Web Vitals 한국어판은 기계 번역입니다. 구글이 그렇게 고지했습니다.

  ⚠️ 아직 못 본 것 — 네이버 robots.txt·사이트맵·자바스크립트 최적화 가이드,
     쿠팡 FAQ 본문, 네이버쇼핑 랭킹 원 문서. 그 자리는 B·C 로 두었습니다.
