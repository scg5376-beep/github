# 검색에 보이게 하려면

> **이 파일은 A등급입니다.** 네이버 「검색엔진 최적화의 목적」 · 「사이트 등록 및
> 소유확인」 · 「HTML 마크업 가이드」 전문에서 나왔습니다. 큰따옴표는 원문 그대로입니다.
> 구글 쪽만 등급이 낮아 절을 따로 뒀습니다.
> **블로그가 아니라 내 사이트(홈페이지·쇼핑몰) 이야기입니다.**

## ★ 등록은 노출 조건이 아닙니다

> 네이버 웹 검색은 웹 수집 로봇이 자동으로 수집한 사이트 정보를 반영하여 노출하고 있습니다. 따라서 검색 등록 절차는 존재하지 않습니다.

> 네이버 웹마스터도구에 사이트를 등록하지 않아도 네이버 검색 결과에 사이트 및 웹문서들이 반영됩니다.

**대행사가 파는 "네이버 사이트 등록" 은 노출을 만들어 주지 않습니다.**
등록·소유확인의 값어치는 **수집·색인·노출을 리포트로 보는 것**에 있습니다.
*(뒤 문장은 우리가 붙인 것입니다.)*

그리고 네이버는 이렇게도 적었습니다.

> 네이버 검색은 검색엔진에 친화적인 사이트를 우대합니다.

## 등록은 호스트 단위입니다 — 여기서 많이 막힙니다

> 사이트 등록은 호스트 단위만 지원합니다.

```
http://www.mysite.com      (O)
http://blog.mysite.com     (O)
http://www.mysite.com/myid (X)
```

★ **남의 플랫폼 안의 내 페이지는 등록이 안 됩니다.** 스마트스토어 주소나 카페
게시판 주소를 넣으려다 막히는 이유가 이것입니다.

## 소유확인 — 검증에서 빠지는 자리

```
head 안에 <meta name="naver-site-verification" …>   ← 여기여야 합니다
body 안 · frame 안 · 리다이렉트되는 페이지            ← 전부 검증 제외
```

> 소유확인용 메타태그 정보가 html body 태그 내에 존재 시 검증에서 제외 처리합니다. html head 태그 내에 기입해 주세요.

> 소유확인은 자바스크립트 실행을 지원하지 않으니 마크업 확인은 최신 웹브라우저의 URL 입력란에 view-source:사이트_URL 을 입력하거나 페이지 소스보기를 활용하시기 바랍니다.

**화면에 보이는 것과 소스가 다를 수 있습니다.** 빌더가 넣어 준 태그가 실제 소스에
없으면 확인이 안 됩니다.

안 되는 원인은 다섯입니다 — 방화벽이 로봇 차단 · 메인이 자바스크립트/meta refresh
로 리다이렉트 · frame 안에 태그 · 업로드 파일 손상 · 아주 오래된 브라우저.

## 로봇 이름은 Yeti — IP 로 막지 마십시오

```
User-agent: Yeti
Allow: /
```

> 부득이하게 검색 로봇을 차단해야 하는 경우 IP 기반으로 차단하지 마세요. 검색 로봇의 IP 대역은 언제든지 변경될 수 있습니다.

**보안업체가 IP 로 봇을 막아 두면 검색에서 사라집니다.**

## ★ 여러 사이트를 만들면 불이익입니다

> 검색 노출량을 늘이기 위하여 동일한 콘텐츠로 구성된 여러 개의 사이트를 개설하는 경우가 있습니다. 이 경우 검색 노출에 불이익을 받을 수 있으니 유의하세요.

**"지점마다 사이트를 따로 만들라" 는 조언이 여기에 정면으로 걸립니다.**

## 제목과 설명 — 메인과 개별 페이지가 다릅니다

```
메인 페이지    브랜드명 · 상호명 · 서비스명 같은 고유명사
개별 페이지    그 페이지가 무슨 내용인지 설명하는 문구
```

> 사이트 메인 페이지의 title 태그는, 사이트의 성격을 잘 표현할 수 있는 브랜드명으로 기입해야 합니다.

★ **메인에 "○○동 맛집 | 배달 | 예약 | 회식" 처럼 키워드를 붙이는 게 정확히
반대입니다.**

**글자 수 제한은 없습니다.** 다만 "쓰지 말라" 고 열거한 쪽이 구체적입니다.

```
검색 노출만을 위하여 제목을 자주 변경        불이익
제목이 과도하게 길어 사이트 파악이 어려움     불이익
2회 이상 반복적인 키워드 · 스팸성 키워드      불이익
콘텐츠와 연관이 없는 키워드 · 홍보 문구 나열   불이익
```

> 사이트 내의 모든 페이지를 동일한 제목으로 넣지 마세요.

★ 빌더로 만든 사이트가 **모든 페이지 제목이 '○○ 홈페이지' 하나**인 경우가 흔합니다.

### ★ 내가 쓴 제목이 그대로 나오지 않습니다

> 검색 노출에 사용되는 제목은 검색엔진이 이 태그 및 아래 오픈그래프 태그 등에 지정해주신 내용을 포함해 해당 페이지와 앵커 등 다양한 정보중 가장 적절한 것을 자동 추출하여 결정합니다.

**제목 태그는 후보 중 하나입니다.** 설명문도 마찬가지로 자동 추출입니다.

### 설명(description)

> 페이지의 description 태그는 페이지의 콘텐츠에 대한 간략한 설명으로 1-2개의 문장으로 구성된 짧은 단락을 사용할 수 있습니다.

```
본문 전체를 복사해서 붙여넣기      불이익
제목과 똑같이 쓰기                불이익
사이트 내 모든 페이지가 같은 설명   불이익
키워드만 나열                    불이익
```

### 오픈그래프 — 소셜용인데 네이버도 봅니다

> 오픈 그래프 태그는 사이트가 소셜 미디어로 공유될 때 우선적으로 활용되는 정보입니다. 그러나 네이버 검색 로봇도 해당 정보의 내용을 동시에 활용하여 페이지 분석 및 노출에 사용하는 경우가 있으므로, 가급적 같이 기입하시는 것을 권장합니다.

대표 이미지(og:image) 기준 넷입니다 — **150x150 보다 크고 · 5,000 byte 이상이고 ·
비율이 3:1 을 넘지 않고 · 문서를 대표하는 고유 이미지**여야 합니다.

★ **모든 페이지에 로고를 og:image 로 넣어 두면 안 쓰일 수 있습니다.**

## 언제 반영되나 · 안 보일 때

> 네이버의 검색로봇이 방문한 뒤 최대 1주일 이내에 사이트의 콘텐츠가 검색에 반영됩니다.

`site:내주소` 로 확인합니다. **일주일은 기다려 보고 나서 문제를 찾습니다.**

### 메인이 안 보이면

> 메인 페이지의 meta 태그에 noindex 처리가 되어있다면 해제해주세요.

### 글이 반영이 안 되면

> 페이지 내의 모든 콘텐츠가 자바스크립트로 로딩되는 구조인지 확인하세요. 대부분의 검색엔진은 표준 HTML 마크업을 사용하여 콘텐츠를 제공하는 것을 권장합니다.

★ **AI 로 만든 사이트가 여기 걸립니다.** 화면에는 보이는데 검색로봇에게는 빈
페이지입니다. 링크도 마찬가지입니다.

```
<a href="http://www.A.com">Link</a>             로봇이 URL 을 압니다
<span onClick="javascript:goto(A)">Link</span>  로봇이 URL 을 모릅니다
```

### 반영되는 문서 수가 적으면

> 특히, 제출된 사이트맵 및 RSS 내의 링크가 상대 경로로 지정되어 있는 경우, 링크의 호스트가 등록된 사이트와 일치하지 않는 경우 수집을 진행하지 않습니다.

`nofollow` 가 붙어 있으면 그 페이지 안의 링크를 안 따라갑니다.

## 구글은 네이버 다음입니다 (등급이 다릅니다)

**구글 기술 요구사항과 스팸 정책은 A등급으로 확보돼 있습니다.** 다만 비즈니스
프로필 쪽은 아직 B 입니다. 그리고 **한국에서는 순서가 네이버 먼저입니다.**

세 플랫폼이 같은 말을 합니다 — **AI 로 만들었다는 이유만으로 빼지 않고,
검색 순위를 노린 대량 생성은 뺍니다.** 구글은 이렇게 적었습니다.

> 생성 방법에 관계없이

**그러니 네이버용으로 제대로 쓴 글은 구글에서도 따로 손댈 게 거의 없습니다.**

## 사장님이 확인할 순서 (우리가 만든 점검표)

```
□ 주소가 호스트 단위인가 (…/myid 는 안 됩니다)
□ 소유확인이 됐나 — 안 되면 위 다섯 가지
□ robots.txt 와 방화벽이 Yeti 를 막고 있지 않나
□ 지점·행사마다 사이트를 따로 만들지 않았나
□ 페이지마다 제목과 설명이 다른가
□ 메인 제목이 가게 이름인가 — 키워드 나열이 아니고
□ og:image 가 로고 하나로 다 채워져 있지 않나
□ 사이트맵·RSS 를 냈나 (RSS 에는 본문 전체)
□ 일주일 지났나
□ noindex·nofollow 가 붙어 있지 않나
□ 글자가 자바스크립트로만 그려지지 않나
```
