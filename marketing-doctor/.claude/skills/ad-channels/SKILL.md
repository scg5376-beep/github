# 돈 쓰는 자리 — 사장님용

> **광고는 돈이 먼저 나가고 결과가 나중에 옵니다.**
> 그래서 이 스킬은 **켜는 법이 아니라 켜기 전에 볼 것**부터 시작합니다.
> 네이버·메타가 직접 적은 문장은 **원문 전문**에서 옮겼습니다. 큰따옴표가 그것입니다.

## ★ 오늘 당장 돈을 아끼는 것 셋

```
플레이스광고    '길찾기' 만 눌러도 과금됩니다. '저장하기' 도요
                그 안의 '출발' 아이콘은 과금이 아닙니다 — 이름이 비슷합니다

파워링크        네이버 밖 제휴 사이트에도 나갑니다. 매체 설정에서 끌 수 있습니다
                동네 키워드는 자리가 최대 3개입니다 (큰 키워드는 10개)

메타            소재를 바꾸면 머신 러닝 단계가 무조건 다시 시작됩니다
                다시 시작되면 "일반적으로 CPA가 높아집니다"
```

**셋 다 공식 문서에 적혀 있는데 대부분 모릅니다.**

## 순서

```
1단계   어디에 쓸 것인가      references/1-어디에-쓸-것인가.md
        └ 켜기 전 순서 · 광고가 값어치를 갖는 자리 · 대행사 점검표

2단계   네이버 광고           references/2-네이버-광고.md      A등급
        └ 파워링크 · 플레이스광고 과금 · 월정액은 사칭입니다

3단계   메타 광고             references/3-메타-광고.md        A등급
        └ 머신 러닝 단계 · ★ 재시작을 부르는 변경 여섯

4단계   토스 광고             references/4-토스-광고.md        B등급
        └ 지금 우리 판이 아닌 이유 · 온라인을 열면 다시 봅니다
```

## ★ 이 셋 중 하나라도 들으면 계약하지 마십시오

```
"월정액 ○○만원에 상위노출 해드립니다"
  → 네이버 공식: "광고가 클릭되는 경우에만 광고비가 과금됩니다"
     네이버가 사칭 피해 사례 1번으로 '월정액제로 결제 유도' 를 듭니다

"1페이지 보장합니다"
  → 경매 기반이라 성립하지 않습니다

"저희 계정으로 대신 돌려드릴게요"
  → 계정은 사장님 명의여야 하고 과금 내역을 직접 볼 수 있어야 합니다
```

한국인터넷광고재단이 **중소상공인 인터넷광고 계약 피해 주의보**를 내고 있습니다.

## 광고가 값어치를 갖는 자리는 하나입니다

무작위 배정 현장실험 둘에서 나온 것입니다.

> **광고는 '나를 이미 찾는 사람' 에게는 값어치가 없습니다.**
> **값어치는 '나를 모르는 사람' 에게 닿을 때 생깁니다.**

⚠️ 이 한 줄은 **우리가 두 논문을 붙여 만든 것**입니다.

```
1. 가게 이름으로 검색한 사람에게 광고를 붙이는 건 값어치가 낮습니다
2. 값어치는 '업종+지역' 처럼 나를 모르는 사람이 치는 말에서 나옵니다
3. 광고 전에 평점과 리뷰부터입니다 — 빈 가게에 사람을 데려오면 그냥 나갑니다
4. 플랫폼이 보여주는 성과 숫자는 부풀려져 있다고 보는 게 맞습니다
```

## 등급을 섞지 마십시오

```
A등급   네이버 파워링크 순위 · 플레이스광고 과금 영역
        메타 머신 러닝 단계 · 영향이 큰 변경
B등급   네이버 최소 입찰가·매체 설정·브랜드검색 (발췌만 봤습니다)
        토스 전부 — 토스가 낸 문서를 한 장도 못 봤습니다
```

★ **토스 파일의 금액은 글에 쓰지 않습니다.** 우리가 예산 자릿수를 가늠하는 데만
씁니다. 2024년 봄 대행사 소개서이고, 그 문서 스스로 바뀔 수 있다고 적었습니다.

## 이 스킬이 다루지 않는 것

```
소재가 거부되는 이유       naver-blog 스킬의 8-메타광고-거부되지-않으려면.md
                          ("여러분" 을 쓰지 말라 · 비포&애프터 금지 · 계정 제한)
무엇을 세야 하나           product-launch 스킬의 3-세면-헷갈리는-것.md
광고를 켜기 전 법적 절차    product-launch 스킬의 0-팔-수-있는-상태인가.md
왜 광고보다 리뷰가 먼저인가  sales-principles 스킬
```

**규칙을 두 곳에 적지 않습니다.** 겹치는 자리는 가리키기만 합니다.

## 판단은 정산액으로 합니다

```
노출 · 도달 · 클릭 · 순위    플랫폼이 정의하고 플랫폼이 셉니다
정산액                     통장에 찍힙니다. 다투기 어렵습니다
```

**광고비의 값어치는 이 창고에도 없습니다.** 실험은 광고를 무료로 줬고,
잰 것도 구매 의도였습니다. **그 답은 사장님 기록 12주에서만 나옵니다.**
