# 어디에 쓸 것인가

> **광고는 돈이 먼저 나가고 결과가 나중에 옵니다.** 그래서 순서를 뒤집지 않습니다.
> 이 파일은 **매체를 고르기 전에 정할 것**만 다룹니다.
> 매체별 과금은 2·3·4번 파일에 있습니다.

## 켜기 전 순서 — 이걸 건너뛰면 나머지가 무의미합니다

```
1  팔 자리가 열려 있나       아니면 광고를 켜지 않습니다
2  한 건 남는 돈을 아나       모르면 얼마까지 써도 되는지 모릅니다
3  무엇을 셀지 정했나         안 정하면 나중에 효율을 못 따집니다
4  그다음에 매체를 고릅니다
```

**1번은 product-launch 스킬의 `0-팔-수-있는-상태인가.md` 입니다.**
법적 절차가 안 닫힌 채로 광고를 켜면 손님이 늘수록 위험이 커집니다.

## ★ 광고가 값어치를 갖는 자리는 하나입니다

무작위 배정 현장실험 둘이 있습니다. **설계가 가장 강한 자료**입니다.

```
식당 실험     광고 효과가 있었고, 독립 매장·평점 높은 곳·리뷰 많은 곳에서 더 컸습니다
큰 플랫폼 실험  자기 브랜드 이름 키워드 광고는 단기 효과가 측정되지 않았습니다
```

정면 모순이 아니라 **처지가 다릅니다.**

```
이미 다 아는 곳    그 이름을 검색한 사람은 광고가 없어도 옵니다
                  → 원래 올 사람을 돈 주고 다시 산 셈입니다
동네 가게         나를 모르는 사람이 '근처 ○○' 로 찾습니다
                  → 광고가 없으면 아예 안 보입니다
```

> **광고는 '나를 이미 찾는 사람' 에게는 값어치가 없습니다.**
> **값어치는 '나를 모르는 사람' 에게 닿을 때 생깁니다.**

⚠️ 이 한 줄은 **우리가 두 논문을 붙여 만든 것**입니다. 어느 논문도 이 문장을
쓰지 않았습니다.

### 그리고 그 실험이 말하지 않는 것 셋

```
① 잰 것은 '구매 의도' 입니다. 매출이 아닙니다
② 광고를 무료로 줬습니다 — '광고의 효과' 이지 '광고비의 값어치' 가 아닙니다
③ 미국 데이터입니다
```

**사장님이 진짜 알고 싶은 건 ②의 뒷쪽인데, 그 연구는 거기 답하지 않습니다.**
그 답은 **사장님 기록에서만 나옵니다** → product-launch 스킬의 주간 기록.

## 그래서 켜기 전에 확인할 넷

```
1. 가게 이름으로 검색한 사람에게 광고를 붙이는 건 값어치가 낮습니다
2. 값어치는 '업종+지역' 처럼 나를 모르는 사람이 치는 말에서 나옵니다
3. 광고 전에 평점과 리뷰부터입니다 — 빈 가게에 사람을 데려오면 그냥 나갑니다
4. 플랫폼이 보여주는 성과 숫자는 부풀려져 있다고 보는 게 맞습니다
   (실험으로 다시 재면 그 일부밖에 안 남았습니다)
```

## 끄면 사라지는 돈과 남는 돈

광고 캠페인 996건을 분석한 연구입니다.

| | 즉시 판매 | 브랜드 축적 |
|---|---|---|
| 동네 가게의 예 | 파워링크·플레이스 광고·할인 이벤트 | 블로그 글·리뷰·꾸준한 소식 |
| 끄면 | **바로 끊깁니다** | **남습니다** |
| 성과 확인 | 당일 | 몇 달 |

어느 쪽으로 치우쳐도 성과가 떨어졌고 **대략 6:4(축적 : 즉시) 근처가 가장 좋았다고
보고**합니다. 작은 가게는 거의 100% 즉시 판매 쪽에 씁니다.

⚠️ **6:4는 광고 예산 배분 연구입니다.** 무료 채널까지 포함한 비율이 아닙니다.

> **둘 중 하나를 고르는 문제가 아니라 비중의 문제입니다.**

## ★ 이 셋 중 하나라도 들으면 계약하지 마십시오

**네이버·메타·어디든 같은 수법이 돕니다.**

```
"월정액 ○○만원에 상위노출 해드립니다"
  → 네이버 공식: "광고가 클릭되는 경우에만 광고비가 과금됩니다"
     네이버가 사칭 피해 사례 1번으로 '월정액제로 결제 유도' 를 듭니다

"1페이지·상위노출 보장합니다"
  → 경매 기반이라 성립하지 않습니다. 네이버도 메타도 마찬가지입니다

"저희 계정으로 대신 돌려드릴게요"
  → 계정은 사장님 명의여야 하고 과금 내역을 직접 볼 수 있어야 합니다
```

한국인터넷광고재단이 **중소상공인 인터넷광고 계약 피해 주의보**를 내고 있습니다.

## 대행사에 맡길 때 점검표

```
□ 광고 계정이 사장님 명의인가
□ 과금 내역을 직접 볼 수 있나
□ '월정액 보장' 을 말하지 않는가
□ 무엇을 성과로 셀지 계약서에 적혀 있나 — 노출인가 클릭인가 주문인가
□ 그만둘 때 계정과 데이터가 남는가
```

**마지막 줄을 빠뜨리는 경우가 많습니다.** 대행을 끊으면 그동안 쌓인 학습이
같이 사라질 수 있습니다.

## 무엇을 성과로 볼 것인가

플랫폼이 보여주는 숫자와 통장에 찍히는 숫자는 다릅니다.

```
노출 · 도달 · 클릭 · 순위    플랫폼이 정의하고 플랫폼이 셉니다
정산액                     통장에 찍힙니다. 다투기 어렵습니다
```

**판단은 정산액으로 합니다.** 세는 법은 product-launch 스킬의
`3-세면-헷갈리는-것.md` 에 있습니다.
