# 메타 광고 (인스타그램 · 페이스북)

> **A등급입니다.** 「머신 러닝 단계」와 「영향이 큰 변경 및 머신 러닝 단계」
> 전문을 확보했습니다. 큰따옴표는 원문 그대로입니다.
> **소재가 거부되는 이유는 naver-blog 스킬의 `8-메타광고-거부되지-않으려면.md`**
> 에 따로 있습니다. 여기는 **돈이 어떻게 새는가**만 다룹니다.
>
> 용어는 **'머신 러닝 단계'** 로 씁니다. 공식 한국어 표기입니다.
> '학습기'·'러닝 페이즈' 로 쓰지 않습니다.

## 구조가 세 층이고, 돈은 가운데 층에서 갈립니다

```
캠페인      무엇을 얻으려 하는가 (목표)
 └ 광고 세트  누구에게 · 얼마에 · 무엇으로 최적화하는가   ← 여기가 돈이 갈리는 층
    └ 광고     실제로 보이는 이미지·영상·글
```

## ★ 머신 러닝 단계 — 여기서 대부분의 돈이 샙니다

메타 광고는 켜자마자 잘 돌지 않습니다.

> 광고 세트를 안정적으로 게재할 수 있게 되면 즉시 머신 러닝 단계를 종료합니다. 이는 일반적으로 광고 세트가 마지막으로 대폭 수정되고 한 주가 지난 후 약 50건의 결과가 발생하면 이루어집니다.

**두 가지를 정확히 보십시오.**

```
'7일 안에' 가 아닙니다   →  '마지막 대폭 수정 후 한 주가 지난 뒤'
'이벤트' 가 아닙니다      →  '결과(results)'
```

그동안 어떻게 되는지도 공식 문구에 있습니다.

> 머신 러닝 단계에서는 광고 세트의 성과가 안정적이지 못하며 일반적으로 CPA가 높아집니다.

### Shops 광고는 기준이 다릅니다

> Shops 광고의 경우 웹사이트를 통한 최소 17건의 구매, Meta를 통한 5건의 구매가 발생해야 머신 러닝 단계가 완료됩니다.

**50건이 아니라 17건 + 5건입니다.** 제품을 파는 가게라면 이쪽이 현실적일 수 있습니다.

### 그래도 대부분의 동네 가게에는 벅찹니다

```
주 50건 구매가 나오는 가게   →  머신 러닝 단계를 벗어납니다
주 10건 구매가 나오는 가게   →  영영 머신 러닝 단계 안에 머뭅니다 → 계속 비쌉니다
```

**세는 단위는 '광고 세트' 입니다.**

```
광고 세트 1개, 광고 5개   →  다섯 개가 같이 50건을 채웁니다      ⭕
광고 세트 3개, 광고 5개   →  세 세트가 각각 50건씩, 총 150건     ❌
```

50건에 이르지 못하면 광고 관리자 화면에 **'제한된 머신 러닝'** 으로 표시됩니다.
**성과가 안 나오는 게 아니라 아직 배우는 중인 것입니다.** 그런데 그 상태로 두면
비싼 채로 굳습니다.

### 그래서 이렇게 합니다

```
1  더 자주 일어나는 이벤트로 최적화합니다
   구매(주 10건) 대신 → 랜딩 조회 · 문의 · 전화처럼 흔한 것
2  광고 세트를 쪼개지 않습니다 — 하나로 몰아야 채워집니다
3  자주 건드리지 않습니다 — 아래 목록의 항목은 손대지 않습니다
```

## ★ 무조건 다시 시작되는 것 여섯 — 광고비를 가장 직접 아끼는 목록

먼저 안심할 부분이 공식 문구에 있습니다.

> 수정할 때마다 다시 시작되는 것은 아닙니다. 영향이 큰 변경 사항이 있는 경우에만 다시 시작됩니다.

그 '영향이 큰 변경' 이 여섯입니다.

```
1  타게팅에 대한 모든 변경
2  광고 크리에이티브에 대한 모든 변경     ← 소재를 바꾸면 무조건입니다
3  최적화 이벤트에 대한 모든 변경
4  광고 세트에 새 광고 추가              ← 추가만 해도 재시작입니다
5  광고 세트 게재를 7일 이상 일시 중지 (재개하면 재시작)
6  입찰 전략 변경
```

**2번과 4번이 특히 중요합니다.**

```
❌ "반응이 시원찮으니 소재를 바꿔보자"      → 재시작. 다시 비싸집니다
❌ "이 광고도 같이 돌려보자" (세트에 추가)  → 재시작
```

소재를 자주 갈아끼우는 게 좋다고 말하는 사람이 많은데, **공식 문서 기준으로는
그때마다 다시 시작됩니다.** 바꾸려면 **한 번에 제대로 바꾸고 그다음엔 버팁니다.**

### ⚠️ 그렇다고 아예 바꾸지 말라는 뜻이 아닙니다

> "머신 러닝 단계는 게재 시스템이 광고를 가장 최적화하는 데 필요하므로 머신 러닝 단계를 완전히 건너뛰지는 마세요. 새로운 크리에이티브 및 마케팅 전략 테스트는 시간이 갈수록 높은 성과를 달성하는 데 반드시 필요합니다."

**메타가 직접 테스트는 필요하다고 말합니다.** 문제는 바꾸는 것 자체가 아니라
**근거 없이 자주 바꾸는 것**입니다. 공식 권장은 이렇습니다 —
**"수정을 통해 성과가 향상될 것이라고 생각되는 근거가 있는 경우에만" 수정합니다.**

5번도 실무에 바로 걸립니다. **주말에 끄고 주중에 켜는 건 괜찮지만, 일주일 넘게
쉬면 재시작됩니다.** 성수기·비수기가 갈리는 가게는 이걸 알고 계획을 짜야 합니다.

## 규모에 따라 갈리는 것 셋

```
· 광고 세트 지출 한도 금액
· 입찰가 관리 · 결과당 비용 목표 · ROAS 목표 금액
· 예산 금액
```

공식 문서의 예시가 명확합니다.

> 예산을 100달러 → 101달러로 높이면 다시 시작되지 않을 가능성이 높습니다. 하지만 100달러 → 1,000달러로 높이면 다시 시작될 수 있습니다.

**성과가 나온다고 예산을 한 번에 크게 올리면 재시작됩니다.** 조금씩 나눠 올리십시오.

## 캠페인 예산을 쓸 때 — 안심할 셋, 조심할 둘

| 이렇게 하면 | 다시 시작되나 |
|---|---|
| 예산이 광고 세트들에 분배될 때 | 아니요 |
| 한 세트에 큰 변경을 했을 때, 같은 캠페인의 다른 세트가 | 아니요 |
| 캠페인에 새 광고 세트를 추가했을 때, 기존 세트가 | 아니요 |
| **캠페인 입찰 전략을 전환**했을 때 | **여러 세트가 다시 시작될 수 있음** |
| **캠페인 예산을 조정**했을 때 | **여러 세트가 다시 시작될 수 있음** |

**캠페인 단위로 건드리는 것이 세트 단위보다 파장이 큽니다.**

## ★ 한국은 인스타 안에서 결제가 안 됩니다

공식 문서로 확인된 사실입니다. **구매는 우리 쇼핑몰에서 일어납니다.**
그래서 **전환 추적을 쇼핑몰 쪽에 붙여야 이벤트가 잡힙니다.**
이게 안 되어 있으면 **머신 러닝 단계를 영영 못 벗어납니다.**

## 돈 쓰기 전 점검표

```
□ 프로필이 정비돼 있나 — 광고로 보내도 프로필이 비어 있으면 그냥 나갑니다
□ 무료 게시물 중 반응이 좋았던 게 있나 — 그걸 미는 게 새로 만드는 것보다 낫습니다
□ 주 50건이 나올 만한 이벤트가 무엇인가 — 이걸 먼저 정해야 최적화 목표를 정합니다
□ 전환을 어디서 잡을 것인가 — 쇼핑몰에 추적이 붙어 있나
□ 얼마까지 잃어도 되는가 — 첫 달은 배우는 값이라고 보는 게 맞습니다
```

## 아직 확인 못 한 것

```
· 한국의 최소 예산·과금 방식 공식 문구를 못 확보했습니다
· 쇼핑 검수 기간이 자료마다 다릅니다 (1~3일 vs 최대 4주). 둘 다 2차 자료입니다
· 메타는 광고 상품과 최적화 방식이 자주 바뀝니다. 반년마다 다시 봅니다
```
