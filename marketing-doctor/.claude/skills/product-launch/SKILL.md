# 품목 하나 내놓기 — 사장님용

> **이 파일 하나만 순서대로 따라 하시면 됩니다.**
> 여기 인용된 법 조문과 플랫폼 규정은 전부 **원문 전문**에서 나왔습니다.
> 대행사 설명과 다르면 **여기가 맞습니다.**

## 먼저 — 이 스킬이 약속하는 것과 하지 않는 것

```
약속합니다      과태료 맞을 자리를 미리 닫아 드립니다
                무엇을 세야 하는지 정해 드립니다
                성과처럼 보이는 가짜 숫자를 걸러 드립니다

약속하지 않습니다  "이렇게 하면 매출이 몇 % 오릅니다"
                업종별 전환율·객단가의 정상값
```

**후자는 아직 아무 데서도 확인하지 못했습니다.** 없는 걸 있는 척하지 않습니다.
그건 사장님 기록이 12주쯤 쌓여야 나옵니다 — 그게 이 스킬의 목적입니다.

## 순서

```
0단계   팔 수 있는 상태인가        references/0-팔-수-있는-상태인가.md
        └ 시작 전에 닫습니다. 반나절이면 끝납니다

1단계   첫 12주에 무엇을 하나       references/1-첫-12주-무엇을-하나.md
        └ 광고는 9주차 이후입니다. 이유가 있습니다

2단계   기록 쓰는 법               references/2-기록-쓰는-법.md
        └ 주 1회 5분. 이게 이 스킬의 핵심입니다

3단계   세면 헷갈리는 것 여섯       references/3-세면-헷갈리는-것.md
        └ 성과처럼 보이는데 성과가 아닌 숫자들

4단계   품목 레포 만들기            references/4-품목-레포-만들기.md
        └ 품목이 둘 이상이 될 때 봅니다
```

## 손님이 지나가는 자리는 여섯입니다

```
자리 0   팔 수 있나      신고 · 표시 · 처리방침        ← 여기 막히면 뒤가 다 샙니다
자리 1   알게 된다       블로그 · 플레이스 · 메타 · 광고
자리 2   찾아본다        네이버 · 구글 검색
자리 3   들어온다        내 사이트 · 상세페이지
자리 4   산다            결제와 정산
자리 5   다시 온다       리뷰 · 재구매  → 다시 자리 2 로 돌아갑니다
```

**앞 자리가 막혀 있으면 뒷 자리에 쓴 돈은 전부 샙니다.**
순서를 건너뛰지 마십시오.

## 이 스킬을 관통하는 원칙 셋

### ① 한 주에 하나만 바꿉니다

둘을 같이 바꾸면 어느 쪽이 움직였는지 영영 모릅니다.
메타는 광고 소재를 바꾸면 학습 단계가 다시 시작된다고 공식 문서에 적었습니다.

### ② 판단은 정산액으로 합니다

노출·클릭·도달·순위는 플랫폼이 정의하고 플랫폼이 셉니다.
**정산액은 통장에 찍힙니다.** 다투기 어려운 숫자는 이것 하나입니다.

### ③ 마케팅의 값어치는 수수료로 돌아옵니다

스마트스토어 공식 문서입니다.

> · 판매자가 직접 네이버 내부 또는 외부에서 광고 및 홍보를 통해 유입한 고객이 상품을 구매한 경우, 판매자 마케팅 수수료가 적용되어 낮은 수수료가 과금됩니다.

같은 주문인데 판매수수료가 **3%와 1%로 갈립니다.**
그래서 이 스킬이 재는 주 지표는 **"내가 데려온 주문의 비율"** 하나입니다.

## 첫날 할 일

```
□ 0단계를 끝까지 읽고 체크박스를 다 닫는다
□ 품목카드를 채운다 — 특히 "안 하기로 한 것" 셋
□ 달력에 매주 같은 요일, 기록 5분을 잡는다
```

**세 번째가 제일 중요합니다.** 기록이 없으면 12주 뒤에도 느낌으로 정하게 됩니다.
