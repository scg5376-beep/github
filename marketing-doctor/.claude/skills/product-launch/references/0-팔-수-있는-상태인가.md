# 0단계 · 팔 수 있는 상태인가 (시작 전에 닫습니다)

> **이걸 안 닫고 광고를 돌리면 쓴 돈이 전부 샙니다.** 여기 있는 건 전부
> 법령 원문에서 나온 것이고, 안 지키면 과태료가 붙는 자리입니다.
> 반나절이면 끝납니다. 순서대로 하세요.

## ① 사업자등록

```
□ 사업 개시일부터 20일 이내에 신청했다 (개시 전 신청도 됩니다)
□ 간이과세자인지 일반과세자인지 안다
```

**간이과세자면 통신판매업 신고가 면제됩니다.** 기준은 직전 연도 연 환산 공급대가
1억 400만 원(2024-07-01 부터. 부동산임대·과세유흥장소는 4,800만 원).

## ② 통신판매업 신고 — 또는 면제 확인

**면제되는 경우가 둘입니다.** 공정거래위원회 고시 원문입니다.

> 1. 직전년도 동안 통신판매의 거래횟수가 50회 미만인 경우
> 2. 「부가가치세법」 제2조제4호의 간이과세자인 경우

> ② 청약철회 등의 경우에는 제1항의 통신판매의 거래횟수에 산입하지 아니한다.

**★ 취소·반품된 주문은 50회에 안 들어갑니다.** 50회를 아슬아슬하게 넘나드는
가게라면 이 한 줄이 신고 여부를 바꿉니다.

```
□ 면제 대상인지 확인했다
□ 면제가 아니면 신고했다
```

**신고할 때 알아둘 것 (정부24 안내)**

```
어디에      국내 사무소면 시·군·구·특별자치도
처리기간    총 3일
수수료      없음  (등록면허세는 별개입니다)
온라인      대리인 신청은 안 됩니다
낼 서류     구매안전서비스 이용 확인증 — 선지급식 통신판매를 하려는 경우만
```

★ **신고서에 도메인과 호스트서버 소재지가 들어갑니다**(법 제12조 제1항 제2호).
**도메인·호스팅을 정한 뒤라야 신고가 됩니다.** 순서를 거꾸로 하면 막힙니다.

```
□ 변경이 생기면 15일 이내 신고 · 휴폐업은 미리 신고 (안 하면 1천만원 이하 과태료)
```

## ③ 홈페이지에 표시 — 제10조 여섯 가지

법 원문입니다. **여섯 개입니다.**

> 1. 상호 및 대표자 성명
> 2. 영업소가 있는 곳의 주소(소비자의 불만을 처리할 수 있는 곳의 주소를 포함한다)
> 3. 전화번호ㆍ전자우편주소
> 4. 사업자등록번호
> 5. 사이버몰의 이용약관
> 6. 그 밖에 소비자보호를 위하여 필요한 사항으로서 대통령령으로 정하는 사항

```
□ 여섯 가지가 사이버몰에 표시돼 있다
```

⚠️ **신고번호는 여기가 아닙니다.** 신고번호는 **광고에 넣는 것**입니다(제13조 제1항 제3호).

## ④ 광고에 표시 — 제13조 제1항 세 가지

```
□ 상호 및 대표자 성명
□ 주소ㆍ전화번호ㆍ전자우편주소
□ 신고번호와 신고 기관 이름
```

★ **인스타 판매 게시물, 블로그 공동구매 글도 "청약을 받을 목적의 표시·광고" 입니다.**
사이버몰이 없어도 이 조는 걸립니다.

## ⑤ 청약철회 안내

```
□ 청약철회 7일을 안내하고 있다
□ 주문 내역 서면(메일·문자)을 보내고 있다
```

★ **서면을 제대로 안 보내면 7일이 시작조차 안 합니다.** 기간이 무한정 열려 있게 됩니다.

물건이 광고와 다르면 **공급받은 날부터 3개월 이내, 안 날부터 30일 이내**입니다.

## ⑥ 개인정보 — 문의 폼 하나만 있어도 걸립니다

```
□ 개인정보 처리방침을 만들었다
□ 그 처리방침을 홈페이지에 게재했다   ← 원칙입니다. 가게 게시로 대신할 수 없습니다
□ 받는 항목이 정말 필요한 것만이다
□ 문의 폼·로그인이 HTTPS 다
```

**보호책임자는 따로 안 정해도 됩니다.** 시행령이 그 기준을 소상공인으로 정했습니다.
다만 면제가 아니라 **사업주·대표자가 그대로 보호책임자가 됩니다.**
그러니 처리방침에 적는 연락처는 사장님 것이 됩니다.

```
□ 정보가 새면 72시간 안에 손님에게 알려야 한다는 걸 안다
   신고는 세 경우만 — 1천명 이상 / 민감·고유식별정보 / 외부의 불법적인 접근
```
