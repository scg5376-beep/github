# 안 보일 때 — 순서대로 확인

> **네이버 공식 안내가 알려주는 순서 그대로**입니다. 당황하지 마세요.

## 1. 24시간이 지났나

바로 반영되지 않는다.

> ⚠️ **지우고 다시 올리면 처음부터 다시**다. 기다리는 게 빠르다.

## 2. 내 문장으로 검색해 본다  ← 이게 핵심

**키워드 말고, 글에 있는 문장을 그대로** 검색창에 넣어 본다.

```
나오면    →  색인은 됐다. 순위가 낮은 것뿐이다. 미노출이 아니다
안 나오면  →  3번으로
```

> **원하는 키워드로 안 나온다고 미노출이 아니다.**
> 이걸 모르면 멀쩡한 글을 지우게 된다.

## 3. 제한 사유에 걸리는지 본다

`3-하면-안-되는-것.md` 를 처음부터 훑는다.
가장 흔한 순서로 적혀 있으니 위에서부터 보시면 된다.

## 4. 그래도 없으면 제보한다

네이버 검색 고객센터의 **[검색 노출 제보하기]** 를 쓴다.

> 다만 네이버는 이렇게 밝힌다 — 제보의
> "반영 여부 및 시기는 **보장할 수 없으며, 개별적으로 답변드리지 않습니다.**"

## 순위가 떨어졌을 때

**뭘 잘못했다고 단정하지 마세요.** 네이버가 직접 이렇게 말합니다.

> "'**상위 고정 노출**'이라는 개념은 **존재하지 않으며**, 기존에 노출되던
> 게시물도 시점에 따라 순위가 변경되거나 검색 결과에서 제외될 수 있습니다."

> "알고리즘 역시 **매일 업데이트**되므로 어떤 출처도 지속적으로 상위에
> 노출되기 어렵습니다."

플레이스 순위도 마찬가지다.

> "플레이스 검색 결과의 노출 순서는 **고정된 것이 아니며, 수시로 변경될 수 있습니다.**"

**순위가 내려간 것 자체는 사고가 아니다.** 네이버가 그렇게 설계했다고 말한다.

## 그럼 뭘 해야 하나

```
1  지우지 않는다              지우면 쌓인 게 사라진다
2  그 주에 쓰기로 한 글을 쓴다  쉬면 더 내려간다
3  한 달 뒤에 다시 본다        하루 단위로 보면 아무것도 안 보인다
```

**한 편의 순위가 아니라 두 달치 흐름을 본다.**

## 절대 하지 마실 것

```
❌ 글을 지우고 다시 올린다        →  처음부터 다시다
❌ 제목에 키워드를 더 밀어 넣는다  →  공식 스팸 유형이다
❌ 하루에 여러 편을 몰아 올린다    →  '무의미한 대량 발행' 에 가까워진다
❌ 순위 올려준다는 곳에 맡긴다     →  6-이런-제안은-거른다.md
```
