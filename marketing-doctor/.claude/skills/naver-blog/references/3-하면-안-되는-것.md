# 하면 안 되는 것

> 여기 있는 건 전부 **네이버 공식 문서에 적힌 사유**다. 추측이 아니다.
> 큰따옴표 안은 **원문 그대로**다.

## 검색에서 빠지는 사유

### 1. 겪지 않고 쓴 글 ← 가장 흔하다

> "**실제 체험 없이 작성된 비체험 원고 게시물**"

**대행사에 맡긴 원고가 여기 걸린다.** 그 사람은 우리 가게를 겪은 적이 없다.

### 2. 우리 가게 좋다는 말만 있는 글

> "뉴스와 중복되는 기사성 게시물 또는 **단순 홍보성 게시물**"

**사장님이 가장 쓰기 쉬운 글이 정확히 여기 걸린다.**
홍보를 하지 말라는 게 아니라, **읽는 사람이 가져갈 게 있어야 한다.**

### 3. 검색량 많은 남의 브랜드 이름 갖다 쓰기

> "제목이나 본문에 동일 키워드를 의도적으로 반복하거나,
> **실제 명칭 대신 검색량이 많은 키워드로 치환하여 작성**하는 경우"

### 4. 제목과 내용이 다른 글

> "제목·설명과 실제 내용이 **일치하지 않는 것**이 특징입니다."

한 줄로 줄이면 이렇다 — **검색해서 들어온 사람이 찾던 게 글 안에 있어야 한다.**

### 5. 옛날 전화번호·주소가 남은 글

> "**잘못된 전화번호·주소·신청 링크**, 합성 또는 생성 이미지·동영상 등
> 명백히 허위이거나, 사실로 오인되어 사용자에게 혼동 또는 실질적인
> 피해(예를 들면, 잘못된 링크를 통한 개인정보 무단 수집)를 야기할 수 있는 콘텐츠"

**가게를 옮기거나 번호를 바꿨으면 옛 글까지 고쳐야 한다.**
같은 문장에 **AI 생성 이미지**도 들어 있다.

### 6. 남의 글과 비슷한 글  ← 이게 의외로 큽니다

네이버는 순위를 **올려주는** 로직 말고, **걸러내는** 로직을 따로 돌린다고 밝힌다.

> "C-Rank 기술이나 D.I.A. 모델 등 다수의 모델이 적용되었으며,
> **변질·스팸·유사 문서 관련 분석 로직**도 지속적으로 고도화되어 적용되고 있습니다"

**'유사 문서' 는 남의 글과 닮은 것 자체가 걸린다는 뜻이다.**

대행사 원고가 위험한 이유가 또 하나 늘어난다 — **그런 원고는 서로 닮았다.**
같은 업체가 여러 가게에 비슷한 틀로 써주기 때문이다.

```
⭕ 내가 겪은 걸 내 말로 쓴다        →  세상에 하나뿐인 글이 된다
❌ 잘 나가는 글을 참고해서 비슷하게  →  '유사 문서' 로 걸릴 수 있다
```

### 7. 댓글·방문·추천 수 조작

> "여러 계정을 동원하여 **댓글 작성·방문·추천 수를 조작**하거나"

이른바 '품앗이' 가 여기 걸릴 수 있다.

## 체험단·협찬을 받으신다면

### 받은 걸 전부 적어야 한다

> "원고료만 표기하고 **식음료 쿠폰 등 기타 지원은 표시하지 않는 등
> 일관되지 않게 표기**하는 경우에도 불이익이 발생할 수 있습니다."

**일부만 적으면 안 적은 것과 같이 본다.**

### 그리고 이게 진짜 무섭다

> "대가성 후기를 지나치게 반복적으로 게시할 경우, 해당 패턴이 알고리즘에 영향을 주어
> **정상적으로 작성된 게시물까지 함께 노출에 불이익**을 받을 수 있습니다."

**체험단 후기가 우리 가게 글까지 끌어내린다.**
→ 블로그 하나로 둘 다 하지 않는다.

## 사진 규칙 (미용실 기준 · 공식)

미용실 업종은 시술 사진 기준이 따로 공개돼 있다.
**다른 업종에 그대로 적용된다는 근거는 없지만, 방향은 참고할 만하다.**

```
❌ 얼굴을 모자이크·합성·사물로 가린 것 (스티커, 과도한 장식 포함)
❌ 뒷모습만으로 된 것 — 뒷모습은 대표 이미지로 지정 불가
❌ 매장에서 시술한 게 아닌 브랜드 제공 이미지·카탈로그
❌ 분할 컷, 테두리 하이라이트 — 비포&애프터를 한 장에 붙이는 것 포함
❌ 같은 사진을 각도만 바꿔 여러 개로 중복 등록
```

**삭제된 사진은 원상 복구가 안 된다.** 재등록만 된다. 시술 사진은 **300개까지**다.

### AI 이미지 — 네이버가 선을 그어 놨다

> "**AI를 활용한 얼굴 생성은 가능하지만**, 매장에서 **시술하지 않은** 시술 사진일
> 경우 등록 불가"

```
⭕ AI로 모델·마네킹 얼굴을 다른 사람으로 바꾼 시술 사진
❌ AI로 시술하지 않은 헤어스타일을 생성
❌ 타샵의 이미지를 활용
```

**기준은 'AI를 썼느냐' 가 아니라 '우리 매장에서 실제로 했느냐' 다.**

## 반대로 — 걱정 안 하셔도 되는 것

### AI로 초안 잡는 것

> "이 과정에서 **AI나 자동화 프로그램을 활용하는 경우도 포함될 수 있으나,
> 특정 기술의 활용 여부만으로는 판단하지 않습니다.**"

**AI를 쓴 게 문제가 아닙니다.** 걸리는 건 이것입니다.

> 「저품질 콘텐츠 대량 생성」 — "검색 결과를 점유할 목적으로, **동일·유사한 템플릿을
> 활용하여 콘텐츠를 무의미하게 대량으로 발행하는 경우**입니다." 도구가 아니라 **양과 무성의**가 기준이다.

```
⭕ AI로 초안 잡고, 내가 겪은 걸 채워 넣고, 내 말로 고친다
❌ AI가 쓴 걸 그대로 매일 다섯 편씩 올린다
```

**★ 세 플랫폼이 같은 말을 합니다.**

| | |
|---|---|
| **네이버** | "**특정 기술의 활용 여부만으로는 판단하지 않습니다**" |
| **네이버 플레이스** | "**AI를 활용한 얼굴 생성은 가능하지만**, 매장에서 시술하지 않은 사진은 불가" |
| **구글** | 대량 콘텐츠 남용은 **만드는 방식과 무관하게** 적용된다고 전해집니다 |

```
AI를 썼느냐    →  기준이 아니다
무엇을 만들었느냐 →  이게 기준이다
```

> ⚠️ 구글 줄만 **근거가 한 단계 약합니다.** 구글 문서는 원문을 못 열었습니다.
