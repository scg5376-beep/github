# 올리기 전에 2분만

> 하나씩 소리 내어 확인하세요. **다 ⭕여야 올립니다.**

## 필수 — 하나라도 ❌면 고치고 올린다

```
□ 내가 실제로 겪은 내용인가
     └ 아니면 그 문단을 지운다. 공식 미노출 사유다

□ 읽는 사람이 가져갈 게 있나
     └ "우리 가게 좋다" 만 있으면 '단순 홍보성 게시물' 이다

□ 제목과 본문이 같은 것을 말하나
     └ 제목으로 들어온 사람이 찾던 게 본문에 있어야 한다

□ 제목에 남의 브랜드·검색량 많은 딴 말을 끼워 넣지 않았나
     └ 공식 스팸 유형이다

□ 전화번호·주소·영업시간이 지금 것인가
     └ 옛 정보는 '사용자 혼동 및 피해 유발 콘텐츠' 다

□ 사진이 전부 매장에서 직접 찍은 것인가
     └ AI 생성 이미지·카탈로그 이미지가 섞이지 않았나

□ 협찬·체험단이면 받은 걸 전부 적었나
     └ 일부만 적으면 안 적은 것과 같이 본다
```

## 잘 읽히는지 — 고치면 더 좋아지는 것

```
□ 첫 세 줄 안에 답이 나오나
     └ 사람은 평균 20~28%만 읽는다

□ 한 문단이 3줄을 넘지 않나
     └ 폰에서 글자 벽이 된다

□ 소제목만 읽어도 무슨 말인지 아나

□ 이 글이 답하는 질문이 하나뿐인가
     └ 두 개면 둘 다 안 걸린다

□ AI가 뽑아 쓸 문장이 하나라도 있나
     └ 숫자·조건·기준이 든 문장 ("평일 저녁 7시 이후에도 접수됩니다")
```

```
     └ 일상글이 절반이면 우리 주제 신뢰도는 안 오른다
```
