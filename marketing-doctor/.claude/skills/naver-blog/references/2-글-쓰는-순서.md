# 글 한 편 쓰는 순서

> **1번부터 6번까지 순서대로.** 건너뛰지 않는 게 요령입니다.

## 1. 무엇에 답할지 정한다 (5분)

**손님이 실제로 물어본 질문 하나**를 고른다. 지어내지 않는다.

```
이번 주에 손님이 물어본 것 →  그중 두 명 이상이 물어본 것 →  그걸 쓴다
```

한 글에 **하나만** 답한다. 두 개를 넣으면 **둘 다 안 걸린다.**
네이버 검색은 지금 '스마트블록' 이라는 방식으로, **검색 의도별로 블록이 갈리고
블록마다 다른 글이 뽑힌다.** 소구점이 여러 개면 어느 블록에도 안 맞는다.

## 2. 제목을 먼저 쓴다 (5분)

**손님이 칠 것 같은 말**로 쓴다. 사장님이 쓰는 전문 용어가 아니다.

```
⭕ "안경 코받침 내려앉을 때"       ← 손님이 치는 말
❌ "노즈패드 피팅 조정의 중요성"    ← 사장님이 쓰는 말
```

여기에 **지역**을 붙일 수 있으면 붙인다. `○○동 안경원` 처럼.

> ⚠️ **절대 하면 안 되는 것** — 네이버 공식 스팸 유형이다.
> "실제 명칭 대신 **검색량이 많은 키워드로 치환**하여 작성하는 경우"
>
> A 상품을 파는데 검색량이 많다고 B 브랜드 이름을 제목에 넣는 것.
> **이건 요령이 아니라 공식 스팸이다.**

## 3. 첫 세 줄에 답을 쓴다 (5분)

사람은 웹에서 글을 **읽지 않고 훑는다.** 평균 **20~28% 만** 읽는다는
아이트래킹 연구가 있다(상업 UX 연구기관, 2006년 최초 보고 후 20년간 일관).

그러니 **결론을 맨 앞에 놓는다.**

```
❌ "안녕하세요 ○○동에서 20년째 안경원을 운영하는…"   ← 여기서 나간다
⭕ "코받침이 내려앉는 건 대부분 각도 문제입니다. 5분이면 잡힙니다."
```

## 4. 본문 — 겪은 것을 쓴다 (15분)

**이게 이 글에서 가장 중요합니다.**

네이버가 검색에서 빼는 사유에 **"실제 체험 없이 작성된 비체험 원고 게시물"**
이 그대로 있다. 그리고 네이버가 문서를 볼 때 보는 항목에도 **'경험 정보'** 가 들어 있다.

**겪은 것을 쓰면 저절로 통과한다.**

```
⭕ "지난주에도 세 분이 같은 걸 물으셨습니다"
⭕ "저희는 이럴 때 각도를 먼저 봅니다. 90%는 여기서 잡힙니다"
⭕ "이건 저희가 못 고칩니다. 이럴 땐 안과에 가셔야 합니다"

❌ "일반적으로 알려진 바에 따르면…"          ← 겪은 게 아니다
❌ "전문가들은 이렇게 조언합니다"             ← 남의 말이다
```

**못 하는 것을 말하는 글이 오히려 믿음을 얻는다.**

### 형식

```
문단은 3줄 이내      폰으로 보면 글자 벽이 된다
소제목을 문장으로    "코받침 조정법" ❌ / "각도부터 봅니다" ⭕
사진은 실제로 찍은 것 매장에서 찍은 것만
```

## 5. AI가 인용할 수 있게 쓴다 (5분)

네이버는 검색 결과를 AI가 요약해 보여주는 **AI브리핑**을 운영한다.
그 요약에 우리 글이 인용되면 이름이 걸린다.

**AI가 뽑아 쓰려면 문장이 뽑히게 생겨야 한다.**

```
❌ "저희 매장은 친절하게 봐 드립니다"        ← 인용할 게 없다
⭕ "평일 저녁 7시 이후에도 접수됩니다"        ← 인용된다
⭕ "코받침 조정은 무료이고 5분 걸립니다"      ← 인용된다
```

**숫자·조건·기준을 문장 안에 넣는다.**

## 6. 사진을 넣는다 (5분)

```
⭕ 매장에서 직접 찍은 것
⭕ 낮에 창가에서 (형광등 아래는 색이 누렇게 뜬다)
⭕ 배경을 치우고 (행주·박스·전선이 같이 찍히면 지저분하다)

❌ AI로 만든 매장 사진
❌ 브랜드에서 받은 카탈로그 이미지
```

> ⚠️ 네이버는 **"합성 또는 생성 이미지·동영상"** 을
> 사용자 혼동 및 피해 유발 콘텐츠와 같은 문장에 넣어 두었다.
> **매장 사진 자리에 AI 이미지를 넣지 않는다.**
