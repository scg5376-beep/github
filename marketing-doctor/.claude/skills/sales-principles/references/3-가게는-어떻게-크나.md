# 가게는 어떻게 크나

> ⚠️ **전부 B등급이고, 대형 소비재 브랜드 데이터가 바탕입니다.**
> 동네 가게에 그대로 맞는다는 근거는 없습니다. 한계는 마지막 절에 적어 뒀습니다.
> **이 파일의 3번이 블로그 글감이 나오는 자리입니다.**

## 1. 성장은 단골이 아니라 새 손님에게서 옵니다

> **브랜드는 단골을 더 사게 만들어서가 아니라, 안 사던 사람을 사게 만들어서 큽니다.**

대부분의 마케팅이 "단골을 더 자주 오게 하자" 에 쓰이는데, 이 연구는 그쪽 효과가
생각보다 작다고 봅니다. 설명은 명쾌합니다.

> 자주 오는 손님은 **이미 자주 옵니다.** 더 늘릴 여지가 적습니다.
> 가끔 오는 손님은 **수가 많습니다.** 조금씩만 더 와도 총합이 큽니다.

### 널리 도는 그 통계는 원문과 다릅니다

마케팅 글에서 가장 많이 보이는 문장입니다.

```
업계 인용   "유지율을 5%만 올려도 이익이 25~95% 늘어납니다"
원문        "이탈률을 5% 줄였더니 어느 한 은행의 지점망에서 이익이 85% 늘었다"
```

**한 은행의 사례가 법칙으로 둔갑한 것입니다.** 이런 문장을 근거로 돈을 쓰지 마십시오.

### 두 진영은 사실 다른 걸 재고 있습니다

| | 재는 것 | 답 |
|---|---|---|
| 유지율 진영 | **이익률** | 나가는 손님을 막아라 |
| 침투율 진영 | **성장** | 오는 손님을 늘려라 |

**"뭐가 더 중요한가" 는 답이 없는 질문입니다. "지금 뭘 하려는가" 를 먼저 정해야
답이 나옵니다.** 자리를 잡았고 이익률이 문제면 앞쪽, 아직 아는 사람이 적고
매출을 키워야 하면 뒤쪽입니다.

⚠️ **적립 도장을 없애라는 뜻이 아닙니다.** 그게 손님을 붙잡아 준다고
**과대평가하지 말라**는 뜻입니다. 대신 도장판은 **누가 몇 번 왔는지 아는 자료**
로는 값어치가 있습니다.

## 2. 차별점을 못 찾아도 괜찮습니다

"우리 가게는 뭐가 다르지?" 는 사장님이 가장 오래 붙들고 좌절하는 질문입니다.
연구는 **그 질문 자체를 다시 보라**고 말합니다.

> **"다르다" 고 인식되지 않은 브랜드들도, 그렇게 인식된 브랜드만큼 성공했습니다.**

우리가 매일 가는 편의점·미용실·식당 중에 "여기는 확실히 다르다" 고 느끼는 곳이
몇이나 됩니까. 그래도 우리는 거기를 갑니다.

**차별화 대신 독특함입니다.**

| | 무엇을 하나 | 문제 |
|---|---|---|
| 차별화 | 남과 다른 **의미**를 줍니다 | 좋으면 **바로 베껴집니다** |
| 독특함 | 우리 것이라고 **알아보게** 합니다 | 베낄 수 없습니다 |

```
차별화   "저희는 더 꼼꼼하게 봐 드립니다"  → 옆집도 내일부터 그렇게 씁니다
독특함   늘 같은 색 간판 · 늘 같은 첫인사 · 늘 같은 사진 구도
         → 손님이 어디서 봐도 우리라고 압니다
```

**의미가 없어도 됩니다.** 노란 간판에 특별한 뜻이 없어도, 그 노란색을 보면 우리
가게가 떠오르면 제 몫을 합니다. 이건 아이디어가 아니라 **꾸준함의 문제**라서
사장님이 이길 수 있는 싸움입니다.

글에서도 똑같이 만듭니다 — 늘 같은 제목 형식 · 늘 같은 첫 문단 · 늘 같은 사진
구도 · 늘 같은 맺음말. **글마다 바꾸지 않는 게 핵심입니다.**
세 편만 읽어도 "이 집 글이네" 가 되면 그게 자산입니다.

⚠️ **논쟁 중입니다.** "다르지 않아도 성공한 브랜드가 많다는 연구가 있습니다" 까지가
정확하고, "차별화는 필요 없습니다" 는 틀립니다.

## 3. ★ 글감이 나오는 자리 — 손님이 우리를 떠올리는 순간들

브랜드가 하는 일은 둘로 줄어듭니다.

| | 뜻 | 우리 가게로 치면 |
|---|---|---|
| 떠오르기 쉬움 | 살 상황에서 **떠오르는가** | 필요할 때 우리 가게가 생각나나 |
| 사기 쉬움 | 사려 할 때 **쉽게 살 수 있는가** | 찾아오기·연락하기·예약하기가 쉬운가 |

**인지도가 아닙니다.** "우리 가게 알아요?" 에 안다고 답하는 것과, 안경이 부러진
그 순간에 우리 가게가 떠오르는 건 다른 일입니다.

떠오르기 쉬움은 **손님이 우리 업종을 떠올리는 순간들**이 쌓여 만들어집니다.
안경원이라면 이런 순간들입니다.

```
시력이 떨어진 것 같을 때        안경이 부러졌을 때
아이 시력검사를 받고 나서       선글라스가 필요해질 때
코받침이 자꾸 내려앉을 때       렌즈에 흠집이 났을 때
```

**그 순간 하나가 블로그 글 하나입니다.**

"코받침이 자꾸 내려앉을 때" 는 그대로 글 제목이 되고, 그 순간에 사람이 검색창에
치는 말이 그대로 키워드가 됩니다. `1-손님은-어떻게-움직이나.md` 의 **정보형
검색**이 바로 이 자리입니다.

### 글감 뽑는 방법

```
1  손님이 우리를 찾게 되는 상황을 전부 적습니다 (10개 이상)
2  각 상황에서 손님이 검색창에 칠 말을 적습니다
3  흔한 순서로 줄을 세웁니다
4  위에서부터 한 상황에 한 편씩 씁니다
```

**우리가 팔고 싶은 순서가 아니라 손님에게 흔한 순서**로 합니다.

### ★ 흔한 실수 둘

**① 하나를 독점하려는 것.** 손님은 한 상황에 브랜드 하나만 연결하지 않습니다.

```
❌ "'코받침 내려앉을 때' 는 우리 가게로 만들자"
⭕ "떠오르는 몇 곳 중 하나가 되자" 그리고 그런 상황을 여러 개 확보하자
```

**② 목록을 다 적었다고 생각하는 것.** 손님이 정하는 것이라 계속 바뀌고, 우리가
짐작한 게 실제로는 아닌 경우가 흔합니다. **손님에게 물어보는 게 짐작보다
낫습니다** — "어떻게 저희를 찾게 되셨어요" 를 몇 달만 적어도 진짜 목록이 나옵니다.

### 순서가 있습니다

```
1  사기 쉬움부터 고칩니다    주소·번호·영업시간·플레이스 등록. 하루면 됩니다
2  그 순간들을 적습니다      공짜입니다. 한 시간이면 됩니다
3  하나씩 글로 만듭니다      여기가 시간이 듭니다
```

**1번을 건너뛰고 3번부터 하는 사장님이 많습니다.** 안 되어 있으면 나머지가 다 샙니다.
옛 번호가 남은 글 하나가 손님을 놓칩니다.

## 4. 오늘 팔리는 것에만 쓰면 나중에 안 팔립니다

광고 캠페인 996건을 분석한 연구입니다. 광고에는 성격이 다른 두 효과가 있습니다.

```
즉시 판매      빠르고 · 지금 사게 만들고 · 효과가 금방 사라집니다
브랜드 축적    느리고 · 나중에 떠오르게 만들고 · 효과가 오래 갑니다
```

어느 쪽으로 치우쳐도 성과가 떨어졌고, **대략 6:4(브랜드 축적 : 즉시 판매)
근처에서 가장 좋았다고 보고**합니다.

| | 즉시 판매 | 브랜드 축적 |
|---|---|---|
| 동네 가게의 예 | 파워링크·플레이스 광고·할인 이벤트 | 블로그 글·리뷰·꾸준한 소식 |
| 끄면 | 바로 끊깁니다 | 남습니다 |
| 성과 확인 | 당일 | 몇 달 |

작은 가게는 거의 100% 즉시 판매 쪽에 씁니다. **끄면 끊기는 상태에서 벗어나려면
다른 종류의 지출이 필요하다**는 게 이 연구의 말입니다.

⚠️ **6:4는 광고 예산 배분 연구입니다.** 블로그·플레이스처럼 돈이 안 드는 활동까지
포함한 비율이 아닙니다. 그대로 대입하면 억지입니다.

## 5. 동네 가게에는 그대로 안 맞습니다 — 반드시 밝히십시오

| | 대형 브랜드 | 동네 가게 |
|---|---|---|
| 손님을 늘릴 수 있는 범위 | 전국 | **상권 반경 안** |
| 단골 비중 | 낮습니다 | **높습니다** |
| 손님 한 명당 아는 정도 | 모릅니다 | **얼굴을 압니다** |

**동네 가게는 침투율에 천장이 있습니다.** 상권 밖 사람은 아무리 잘해도 안 옵니다.
**이걸 검증한 국내 연구는 못 찾았습니다.** 지금은 "대형 브랜드에서는 이렇다더라"
까지만 말할 수 있습니다.
