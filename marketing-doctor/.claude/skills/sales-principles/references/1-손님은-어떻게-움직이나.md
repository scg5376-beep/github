# 손님은 어떻게 움직이나

> 여기 있는 것은 **몇 년이 지나도 잘 안 바뀌는 것**입니다.
> 플랫폼 규칙은 반년이면 낡지만 이건 안 낡습니다.
> ⚠️ **전부 B등급입니다** — 원문(학술지)을 못 열었고 대부분 **해외 데이터**입니다.
> **숫자는 옮기지 말고 방향만 쓰십시오.** 근거 등급은 `../SKILL.md` 참고.

## 1. 손님은 읽지 않습니다. 훑습니다

UX 연구기관 NN/g 의 아이트래킹 실험에서, 사람은 페이지 내용의 **20~28%만**
실제로 읽었습니다. 1,500자를 쓰면 300~400자만 읽힙니다.

**어느 300자가 읽힐지는 글이 어떻게 생겼느냐가 정합니다.**

```
소제목이 없다  →  왼쪽 몇 줄 훑다 나갑니다 (F 패턴)
소제목이 있다  →  소제목을 따라가다 필요한 데서 멈춰 읽습니다
```

그래서 이렇게 씁니다.

```
1  소제목을 문장으로 씁니다   "키워드 전략" ❌ → "키워드는 하나씩 잡습니다" ⭕
2  문단 첫 줄에 결론을 놓고, 문단은 3줄 안에 끝냅니다
3  중요한 건 왼쪽에 둡니다 (가운데 정렬은 안 읽힙니다)
```

**소제목만 읽어도 뜻이 통하면 그 글은 성공입니다.**

## 2. 손님이 검색하는 이유가 세 갈래입니다

| 갈래 | 원하는 것 | 예 |
|---|---|---|
| 정보형 | 알고 싶다 | "렌즈 언제 갈아야 하나" |
| 거래형 | 지금 하려 한다 | "중앙동 안경 맞추기" |
| 이동형 | 그 가게로 가려 한다 | 가게 이름 |

대부분의 사장님이 **거래형만** 노립니다. 경쟁이 제일 세고 광고비가 몰린 자리입니다.

**정보형이 비어 있습니다.** 아직 살 마음이 없는 사람이라 아무도 안 노립니다.

```
❌ 정보형 검색어로 걸어놓고 본문은 "저희 가게로 오세요"
⭕ 정보형 검색어에는 끝까지 답을 해줍니다 — 파는 건 그 사람이 다시 왔을 때
```

**글 쓰기 전에 한 줄 정하십시오 — 이 글은 어느 갈래인가.**

## 3. 리뷰는 우리 같은 가게에서 가장 크게 작동합니다

미국 매장 리뷰 자료와 세무당국 매출 자료를 붙여 본 연구에서,
**평점 효과가 독립 매장에서만 나타났습니다.** 체인점은 영향이 없었습니다.

손님은 **모르는 가게일 때만** 리뷰를 봅니다. 그게 우리 가게입니다.

전국 체인은 어차피 브랜드로 오니 리뷰의 값어치가 낮고, 우리 동네 가게는
리뷰 말고 판단할 게 없으니 값어치가 높습니다. 다른 도시·다른 자료로 한 재현
연구도 같은 방향이었고, **손님이 참고할 정보가 적을수록 효과가 컸습니다.**
**체인점이 광고비로 만드는 신뢰를 우리는 리뷰로 만듭니다.**

⚠️ 다만 리뷰를 **만들어내는 건 다른 얘기입니다.** 대가성 후기 반복은 네이버가
순위 하락 사유로 공식 문서에 적었습니다.

## 4. 답글은 공짜인데, 정중할수록 효과가 깎입니다

답글을 달기 시작한 곳은 평점과 리뷰 수가 같이 올랐습니다. 크기는 작습니다.
**진짜 값어치는 다른 데 있습니다.**

> 답글을 달기 시작하면 부정 리뷰가 **줄어들되 길어집니다.**

읽고 답할 걸 아니까 짧게 던지고 마는 리뷰가 줄어듭니다.
그리고 길게 쓴 불만은 **고칠 거리를 알려줍니다.**

★ 2025년 연구가 뜻밖의 것을 찾았습니다 — **정중함이 높아질수록 리뷰어가 답글을
'설득하려는 시도' 로 인식**해 효과가 깎였습니다.

```
❌ "고객님의 소중한 의견 진심으로 감사드립니다. 더욱 노력하겠습니다"
   → 정중하지만 내용이 없습니다
⭕ "코받침이 내려앉았다고 하셨는데, 처음 맞출 때 각도를 덜 잡았습니다.
   들러주시면 다시 잡아드리겠습니다. 5분이면 됩니다"
```

**정중함이 아니라 내용이 답글을 만듭니다.**

```
⭕ 구체적 불만      사실 확인 + 어떻게 하겠다
⭕ 좋은 리뷰        짧게. 길면 홍보로 읽힙니다
△  감정만 있는 악평  짧고 담백하게. 반박하지 않습니다
❌ 반박·해명 나열    여기서 악순환이 시작됩니다
```

## 5. "많이 나간 것" 표시는 돈이 안 드는데 효과가 확인됐습니다

중국 식당 현장실험에서 메뉴판에 **"지난주에 많이 나간 5개"** 를 표시하자
그 메뉴 주문이 늘었고, **손님의 만족도도 같이 올라갔습니다.**

마지막 줄이 중요합니다. 주문만 늘었으면 떠민 것입니다.
**만족도가 같이 올랐다는 건 손님이 헤매고 있었다는 뜻입니다.** 도운 것입니다.

```
메뉴판·진열대   "이번 주 많이 나간 것" 을 표시합니다
블로그 글       "가장 많이 물어보시는 것" 을 앞에 놓습니다
상담할 때       "비슷한 분들은 보통 이걸 고르십니다"
```

**단, 사실이어야 합니다.** 허위 정보는 네이버 노출 제한 사유입니다.

⚠️ 늘 통하지는 않습니다. **손님이 이미 뭘 원하는지 알면 효과가 없습니다.**

## 6. 선택지가 많으면 안 팔린다? — 조건부입니다

유명한 잼 실험(6종 vs 24종)은 **2010년에 사실상 반박됐다가 2015년에 조건부로
복원**됐습니다. 조건을 빼고 옮기면 15년 뒤진 글이 됩니다.

효과가 살아나는 조건은 **선택지가 비슷해 비교가 어렵고 · 손님이 자기가 뭘
원하는지 모르고 · 시간이나 정보가 부족할 때**입니다.
동네 가게는 **자주 그 조건에 걸립니다** (안경원·미용실·정비소).

**그래서 가짓수를 줄이는 게 아니라 골라주는 것이 답입니다.**

```
❌ 상품을 30개에서 6개로 줄입니다 — 매출 기회를 버리는 것입니다
⭕ 30개를 두되 "이런 분은 이거" 로 묶어줍니다
⭕ "처음이시면 이것부터" 라는 기본값을 줍니다
⭕ 비교표를 만들어 비교를 대신 해줍니다
```

## 7. 사진은 효과가 있는데, 뒤집히는 지점이 있습니다

숙소 사진을 전문가 사진으로 바꾸자 점유율이 올랐습니다. 그런데
**효과의 절반 이상이 '전문가가 찍었다는 표시' 가 아니라 사진 품질 자체**에서
왔습니다. 사장님이 직접 찍어도 그 절반 이상은 가져갈 수 있습니다.

수요를 가장 크게 움직인 요소는 **색**이었습니다. 가장 싸게 고칠 수 있는 것입니다.

```
⭕ 낮에 창가에서 · 배경을 치우고 · 밝기만 한 단계 올립니다
❌ 형광등 아래에서 찍거나 필터를 세게 먹입니다
```

★ **같은 저자들이 몇 년 뒤 스스로 단서를 달았습니다.**

```
좋은 사진 → 지금 손님을 더 끌어옵니다
         → 실물이 사진에 못 미칩니다 → 실망합니다
         → 나쁜 리뷰를 남기거나 아예 리뷰를 안 남깁니다
         → 나중 손님이 줄어듭니다
```

**"아예 리뷰를 안 남긴다" 가 특히 무섭습니다.** 사장님 눈에 안 보입니다.

> **규칙은 하나입니다 — 사진 품질을 실물 수준에 맞춥니다.**
> 실물보다 좋게가 아니라 **실물만큼 정확하게** 찍습니다.

## 8. 사람은 '흔들린 것' 을 남에게 보냅니다

퍼짐을 이끄는 건 감정이 좋으냐 나쁘냐가 아니라 **얼마나 마음이 흔들렸느냐**
였습니다. 슬픈 이야기는 잘 안 퍼집니다.

높은 각성 감정이 셋인데 **둘은 가게에 쓰면 안 됩니다.**

```
경외(놀라움)  ⭕  유일하게 안전합니다
분노          ❌  퍼지지만 우리 가게에 붙는 감정이 분노가 됩니다
불안          ❌  겁주는 마케팅입니다. 신뢰를 깎습니다
```

**놀라움은 거창한 게 아닙니다. 몰랐던 걸 알게 되는 순간입니다.**

```
⭕ "코받침이 내려앉는 건 대부분 각도 문제입니다. 5분이면 잡힙니다"
❌ "저희 매장은 정성껏 봐 드립니다"  → 흔들릴 게 없어 보낼 이유가 없습니다
```

## 9. 문의는 빨리 답할수록 좋지만, 그 숫자는 가짜입니다

**"하버드 연구에 따르면 5분 안에 답하면 100배"** 라는 말이 돕니다.
**그 숫자는 하버드 연구가 아닙니다.** 다른 기관의 2007년 연구 숫자가 더 유명한
이름에 붙어 떠도는 것입니다. **방향은 맞으니 배수만 빼고 쓰십시오.**

## 이 파일을 쓸 때의 규칙

**방향은 옮기고 숫자는 옮기지 않습니다.** "독립 매장일수록 리뷰가 중요합니다" 는
써도 되고 "별점 1개 = 매출 5~9%" 는 안 됩니다. 전부 해외 데이터이고 원문을
확인하지 못했습니다. 한국 매장에서 같은 크기로 나온다는 증거가 없습니다.
