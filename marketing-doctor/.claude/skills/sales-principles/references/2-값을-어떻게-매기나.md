# 값을 어떻게 매기나

> ⚠️ **B등급이 대부분이고 해외 데이터입니다. 방향만 옮기고 숫자는 옮기지 마십시오.**
> 예외가 하나 있습니다 — **1번의 순서(값 < 양 < 질)는 A등급 원문**에서 나왔습니다.

## 1. 원가가 올랐을 때 — 답은 예상과 반대입니다

길이 셋입니다. **값을 올린다 · 양을 줄인다 · 질을 낮춘다.**
같은 사람에게 셋을 다 물어본 실험에서 손님이 "불공정하다" 고 답한 비율입니다.

| 사장님이 한 일 | 불공정하다 |
|---|---|
| **값을 올렸다** | **가장 적었습니다** |
| 양을 줄였다 | 그 세 배 가까이 |
| **질을 낮췄다** | **압도적으로 많았습니다** |

제품을 바꿔가며 여덟 번을 다시 물었는데 **순서가 한 번도 안 뒤집혔습니다.**
논문의 결론이 이렇습니다 — **질을 낮추는 것은 선택지가 아닙니다.**

```
값 인상   →  눈에 보입니다        →  "속이지는 않았다"
양 줄이기 →  잘 안 보입니다        →  "몰래 했다"
질 낮추기 →  잘 안 보입니다 + α    →  "이건 딴 물건이잖아"
```

**"양을 줄이면 손님이 모른다" 는 말은 반만 맞습니다.** 당장은 덜 티가 납니다.
문제는 **알아챈 다음**이고, 동네 가게는 **같은 손님이 매주 옵니다.**

## 2. 올리는 방법 — 이유가 전부입니다

같은 인상폭인데 **이유가 바뀌면 손님 반응이 바뀝니다.**

```
⭕ "재료값이 올라서 올립니다"      →  받아들여집니다
❌ "요즘 잘 팔려서 올립니다"       →  받아들여지지 않습니다
```

손님 머릿속에는 **'가게가 가져가도 되는 몫'** 이 있습니다.
그 몫을 **지키려는** 인상은 봐주고, **늘리려는** 인상은 안 봐줍니다.

### ★ 그런데 "원가 올랐어요" 만으로는 부족합니다

여기가 대부분의 글이 빠뜨리는 대목입니다.

> 손님은 **우리 가게 원가를 원래 과소평가하고 있습니다.**
> 가게가 무는 비용의 전부를 세지 않고, 가격 차이를 대부분 '이익' 으로 돌립니다.

그래서 "재료비가 올랐습니다" 라고만 하면 **속으로 안 믿습니다.**
**그 요소들을 눈에 보이게 해주면** 공정하다는 판단이 올라갑니다.

```
❌ "부득이하게 가격을 인상하게 되었습니다. 양해 부탁드립니다."
   → 이유가 없습니다. '그냥 더 받겠다는 거네' 로 읽힙니다

⭕ "작년 이맘때 한 통에 3만 원 하던 것이 지금 4만 8천 원입니다.
    2년을 버텼는데 더는 못 버티겠습니다. 1,000원만 올리겠습니다."
   → 무엇이 얼마나 올랐는지가 보입니다
```

**어떤 비용을 대느냐도 다릅니다.** 재료비·원가는 가격과 바로 이어지고,
임대료·관리비는 덜 이어진다고 느낍니다. *(이건 C등급이라 참고만 합니다.)*

### 한국 손님은 더 엄격할 수 있습니다

집단주의 문화의 손님은 가게에 **선의**를 기대해서, "원가 오르면 올리고 내려도
그대로 두는 것" 을 더 나쁘게 본다는 연구가 있습니다.

> ⚠️ 한국에 그대로 적용된다는 건 **우리가 붙인 추론**입니다. 확인하지 못했습니다.

다만 해법은 같습니다 — **원가가 내려가면 도로 내리겠다고 말하고, 실제로 그렇게
하는 것**입니다.

### 정리

```
1. 질은 절대 건드리지 않습니다
2. 양을 줄이는 것도 차선이 아닙니다
3. 값을 올리되 이유를 댑니다      '잘 팔려서' 가 아니라 '원가가 올라서'
4. 말로만 말고 보이게 합니다      얼마가 얼마로 올랐는지
5. 재료비를 댑니다                임대료·관리비보다 잘 통합니다
6. 내려가면 내리겠다고 말합니다   그리고 실제로 그렇게 합니다
```

**미리 알리는 게 낫습니다.** 계산대에서 처음 알게 되면 그건 '몰래 한 것' 이 됩니다.

## 3. 끝자리 9 — 먹힙니다. 조건이 둘입니다

실제 소매점 현장실험 셋에서 **9로 끝나는 가격이 수요를 늘렸고, 신상품에서 효과가
더 컸습니다.** 손님이 적정 가격을 모를 때 끝자리 신호에 더 기댄다는 뜻입니다.

**조건 하나 — 앞자리가 바뀔 때만입니다.**

```
⭕ 19,900원 vs 20,000원    앞자리가 1 → 2 로 바뀝니다. 효과 있습니다
❌ 19,900원 vs 19,800원    앞자리가 그대로입니다. 효과 없습니다
```

**19,800원으로 200원 더 깎는 건 헛돈입니다.**

**조건 둘 — 고급으로 파는 가게는 역효과일 수 있습니다.** 명품·고급 영역에서는
9로 끝나는 가격이 **저품질이나 기만적 수법으로 인식**되는 경향이 있습니다.

```
싸게 파는 게 강점인 가게    9로 끝냅니다        (분식·잡화·생필품)
전문성·품질로 파는 가게     떨어지는 숫자를 씁니다 (안경·미용·정비·병원)
```

**우리 가게가 무엇으로 파는지가 먼저입니다.** 끝자리는 그다음입니다.

⚠️ 이건 **매장 가격표 얘기**입니다. **블로그 본문에 금액을 박는 것과는 다른
문제입니다.** 블로그는 몇 년을 남고 AI가 인용해 퍼뜨립니다. 본문에는 금액 대신
**무엇에 따라 달라지는지**를 쓰십시오. 잘못된 가격 정보는 네이버 '사용자 혼동'
항목에 걸립니다.

## 4. 공짜는 할인이 아니라 다른 종류의 사건입니다

초콜릿 두 개 실험입니다. 둘 다 **1센트씩** 내려 가격 차이는 그대로 뒀는데,
한쪽이 **공짜가 되는 순간** 선택이 뒤집혔습니다.

> **0으로 내리는 것은 '1원 싸진 것' 이 아닙니다.**

배송비 무료가 왜 그렇게 센지가 여기서 설명됩니다.
**같은 1,000원을 쓴다면 할인보다 사은품이 더 셀 수 있습니다.**

**★ 함정도 같이 있습니다.** 공짜가 걸리자 사람들이 **더 비싸고 좋은 쪽을 안
샀습니다.** 마진이 큰 쪽입니다.

```
❌ 공짜 사은품을 걸었더니 손님이 늘었습니다 — 그런데 다들 싼 것만 샀습니다
⭕ 공짜는 '안 오던 사람을 오게 하는 데' 쓰고, 와서 고를 때는 좋은 쪽이
   눈에 들어오게 합니다
```

**경계도 좁습니다.** 금액이 크고 중요한 결정, 필요해서 사는 것, 가격 비율을
같이 보여줄 때는 효과가 약하거나 사라졌습니다.

```
⭕ 커피 한 잔 · 작은 사은품 · 배송비 · 기본 점검   가볍고 싼 것
❌ 안경 · 시술 · 수리처럼 금액이 크고 필요해서 하는 것
```

## 5. 쓰지 말아야 할 두 가지

**① "놓치면 손해" 는 2배가 아닙니다.** 널리 인용되는 '손실 회피 2배' 는
2018년에 정면으로 반박됐습니다 — 현장 연구에서는 차이가 거의 없는 경우가
많았습니다. 재반박도 있어서 **끝난 논쟁이 아닙니다.**

```
⭕ 널리 인용되는 '2배' 는 근거가 약하다는 반박이 있습니다
❌ 손실 회피는 2배입니다   ❌ 손실 회피는 없습니다
```

**겁주는 문구는 신뢰를 깎습니다.** 사실을 사실대로 말하는 것과는 다릅니다.

```
⭕ "옛 번호가 남은 글이 있으면 손님이 헛걸음합니다"   일어나는 일입니다
❌ "지금 안 고치면 큰일 납니다"                    근거 없는 공포입니다
```

**② 앵커링을 기둥으로 삼지 마십시오.** 방향은 재현됐지만 **크기가 과장**됐고,
**손님이 시세를 아는 물건에는 약하며**, 무엇보다 **실제 돈이 걸리면 안 나타난다는
연구**가 있습니다. 매장은 실제 돈이 오가는 곳입니다.

**비교표를 만드는 것은 앵커링과 다릅니다.** 앵커링은 판단을 끌어당기고, 비교표는
판단을 돕습니다. 뒤쪽이 손님도 이득이고 오래 갑니다.

## ★ 이 파일 전체를 관통하는 한 줄

| 무엇 | 언제 크게 작동하나 |
|---|---|
| 리뷰 | 모르는 가게일 때 |
| 인기 표시 | 처음 온 손님일 때 |
| 선택지 정리 | 손님이 뭘 원하는지 모를 때 |
| 끝자리 · 앵커링 | 낯선 물건일 때 |

**전부 "손님이 잘 모를 때 크게 작동한다" 고 말합니다.**
그래서 할 일은 하나로 모입니다 — **손님이 잘 모른다는 걸 전제로, 판단할 근거를
제대로 주는 것.** 블로그 글이 하는 일이 정확히 그것입니다.
