# 안 낡는 것 — 사장님용

> **플랫폼 규칙은 반년이면 낡습니다. 여기 있는 건 잘 안 낡습니다.**
> 그래서 이 스킬은 **'오늘 뭘 눌러라' 를 말하지 않습니다.**
> 대신 **왜 그게 되는지**를 말합니다. 그걸 알면 규칙이 바뀌어도 안 흔들립니다.

## ★ 먼저 — 이 스킬의 가장 중요한 규칙

**여기 있는 숫자를 글에 옮기지 마십시오.**

```
⭕ 방향을 옮깁니다      "독립 매장일수록 리뷰가 중요합니다"
❌ 숫자를 옮기지 않습니다 "별점 1개가 오르면 매출이 5~9% 오릅니다"
```

이유는 셋입니다.

```
1  대부분 해외 데이터입니다 (미국 식당 · 호주 소비재 · 영국 광고)
2  원문(학술지)을 못 열었습니다. 초록과 2차 자료로 확인한 것입니다
3  한국 동네 가게에서 같은 크기로 나온다는 증거가 없습니다
```

**방향은 여러 연구가 같이 가리킵니다. 크기는 아무도 보장하지 않습니다.**

## 무엇이 들었나

```
1  손님은 어떻게 움직이나     references/1-손님은-어떻게-움직이나.md
   └ 훑는 방식 · 검색 세 갈래 · 리뷰 · 답글 · 인기표시 · 선택지 · 사진 · 퍼짐

2  값을 어떻게 매기나         references/2-값을-어떻게-매기나.md
   └ 원가가 올랐을 때 · 올리는 방법 · 끝자리 9 · 공짜 · 쓰지 말 것 둘

3  가게는 어떻게 크나         references/3-가게는-어떻게-크나.md
   └ ★ 여기서 블로그 글감이 나옵니다

4  지금 한국은 어떤가         references/4-지금-한국은-어떤가.md
   └ ★ 여기만 해마다 갈아끼웁니다. 채널을 고르는 숫자
```

## 이 스킬을 관통하는 한 줄

| 무엇 | 언제 크게 작동하나 |
|---|---|
| 리뷰 | 모르는 가게일 때 (체인점은 효과 없음) |
| 인기 표시 | 처음 온 손님일 때 |
| 선택지 정리 | 손님이 뭘 원하는지 모를 때 |
| 끝자리 · 앵커링 | 낯선 물건일 때 |
| 광고 | 나를 모르는 사람에게 닿을 때 |

> **전부 '손님이 잘 모를 때 크게 작동한다' 고 말합니다.**

우연이 아닙니다. **판단할 근거가 없을 때 사람은 밖에서 단서를 찾습니다.**
그리고 동네 가게는 대부분 **손님이 잘 모르는 곳**입니다.

그래서 할 일이 하나로 모입니다 —
**손님이 잘 모른다는 걸 전제로, 판단할 근거를 제대로 주는 것.**
블로그 글이 하는 일이 정확히 그것입니다.

## ★ 잘못 인용돼 떠도는 것 넷 — 이걸 거르는 게 이 스킬의 값어치입니다

```
"손실 회피는 2배다"              2018년에 정면 반박됐습니다. 재반박도 있어 논쟁 중입니다
"유지율 5% 올리면 이익 25~95%"    원문은 '어느 한 은행에서 85%' 입니다. 사례가 법칙이 됐습니다
"하버드 연구, 5분 안에 답하면 100배"  하버드 연구가 아닙니다. 다른 기관 숫자가 붙어 떠돕니다
"선택지가 많으면 안 팔린다(잼 실험)"  2010년 반박 → 2015년 조건부 복원. 조건을 빼면 15년 뒤진 글입니다
```

**남이 인용한 숫자를 그대로 받아쓰지 않는 것.** 이게 이 창고가 다른 마케팅
자료와 다른 점입니다.

## 광고를 켜기 전에 알아야 할 것

무작위 배정 현장실험 둘이 있습니다. **설계가 가장 강한 자료**입니다.

```
식당 실험     광고 효과가 있었고, 독립 매장 · 평점 높은 곳 · 리뷰 많은 곳에서 더 컸습니다
eBay 실험     브랜드 키워드 광고는 단기 효과가 측정되지 않았습니다
```

정면 모순이 아니라 **처지가 다릅니다.**

> **광고는 '나를 이미 찾는 사람' 에게는 값어치가 없습니다.**
> **값어치는 '나를 모르는 사람' 에게 닿을 때 생깁니다.**

⚠️ 이 한 줄은 **우리가 두 논문을 붙여 만든 것**입니다. 어느 논문도 이 문장을
쓰지 않았습니다.

그리고 **식당 실험이 잰 것은 구매 의도이지 매출이 아니고, 광고를 무료로
줬습니다.** 그러니 이건 '광고의 효과' 이지 **'광고비의 값어치' 가 아닙니다.**
사장님이 진짜 알고 싶은 건 후자인데, 이 연구는 거기 답하지 않습니다.

```
1. 가게 이름으로 검색한 사람에게 광고를 붙이는 건 값어치가 낮습니다
2. 값어치는 '업종+지역' 처럼 나를 모르는 사람이 치는 말에서 나옵니다
3. 광고 전에 평점과 리뷰부터입니다. 빈 가게에 사람을 데려오면 그냥 나갑니다
4. 플랫폼이 보여주는 성과 숫자는 부풀려져 있다고 보는 게 맞습니다
```
