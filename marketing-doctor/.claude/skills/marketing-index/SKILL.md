# 어느 스킬을 언제 꺼내나

> **여기는 새 사실을 만들지 않습니다.** 어디에 무엇이 있는지, 그리고 그걸 어떻게
> 읽어야 하는지만 적습니다. 규칙을 두 곳에 적지 않기 위해서입니다.

## 상황별로 고르십시오

| 지금 상황 | 꺼낼 스킬 |
|---|---|
| 이제 온라인으로 팔아 보려 한다 | **product-launch** 0단계부터 |
| 블로그를 시작했는데 글이 안 걸린다 | **naver-blog** |
| 홈페이지를 만들려 한다 / 만들었는데 안 보인다 | **homepage-shop** |
| 글감이 안 나온다 · 값을 올려야 한다 | **sales-principles** |
| 광고 대행사에서 제안이 왔다 | **ad-channels** |
| 무엇부터 할지 모르겠다 | 이 파일 아래 「순서」 |

## 순서 — 앞이 막히면 뒤에 쓴 돈이 샙니다

```
자리 0   팔 수 있나      신고 · 표시 · 처리방침       product-launch
자리 1   알게 된다       블로그 · 플레이스 · 광고     naver-blog · ad-channels
자리 2   찾아본다        네이버 · 구글 검색           homepage-shop · naver-blog
자리 3   들어온다        내 사이트 · 상세페이지       homepage-shop
자리 4   산다            결제와 정산                 homepage-shop
자리 5   다시 온다       리뷰 · 재구매               sales-principles
```

**자리 0 을 건너뛰고 자리 1 부터 하는 경우가 가장 많습니다.**
손님이 늘수록 위험이 커지는 구조라 순서를 지켜야 합니다.

## ★ 근거 등급 읽는 법 — 축이 두 개입니다

한 축으로는 못 가릅니다. **누가 그렇게 말했는지**와 **그 말이 맞는지**는 다른
문제입니다.

```
        근거 ──────────────────────────────────────────►
출처    │     실증          공식         실무        추측
 │      │  (대규모 데이터) (본인이 밝힘) (해봤더니)  (그럴 것)
 ▼      │
  A     │  단정해도 됨    "~라고 밝힘"  "~라고 함"  쓰지 않음
  B     │  "~라고 한다"   "~라고 밝힘"  "~라고 함"  쓰지 않음
  C     │  쓰지 않음      쓰지 않음     쓰지 않음   쓰지 않음
```

| 등급 | 뜻 | 스킬 안에서 어떻게 보이나 |
|---|---|---|
| **A** | 원문·공식 문서 전문을 확인함 | **큰따옴표로 옮겨져 있습니다** |
| **B** | 2차 자료 여럿이 일치. 원문 미확인 | **"전해집니다" · "~라고 합니다"** 로 적혀 있습니다 |
| **C** | 출처 불명 | **글에 쓰지 않습니다.** 스킬에는 "모른다" 고만 적혀 있습니다 |

★ **큰따옴표와 "전해집니다" 를 섞지 마십시오.** 그 구분이 이 스킬 묶음의
값어치입니다.

### 어느 스킬이 어느 등급인가

```
product-launch   법령·플랫폼 규정은 A. "광고는 9주차 이후" 같은 판단은 우리가 붙인 것
naver-blog       네이버·메타 공식 문서 A. 구글 쪽은 이제 A (2026-09-02 확보)
homepage-shop    네이버 4문서·구글 Web Vitals·수수료 표가 A. 도메인·호스팅·보안 도구는 B
ad-channels      네이버·메타 A. ★ 토스는 전부 B — 토스가 낸 문서를 못 봤습니다
sales-principles ★ 거의 전부 B이고 해외 데이터입니다. 숫자를 옮기지 마십시오
```

## ★ 숫자를 옮겨도 되는지 판단하는 법

```
⭕ 옮겨도 됩니다
   공식 문서에 적힌 규칙·요율·기준     "판매수수료 3%와 1%로 갈립니다"
   연도와 조사기관을 같이 붙인 국내 조사  "2026년 기준 네이버 81.6% (오픈서베이, 2천 명)"

❌ 옮기면 안 됩니다
   해외 연구의 효과 크기              "별점 1개 = 매출 5~9%"
   대행사 자료의 성과 숫자             토스 소개서의 오픈율·CTR
   출처를 특정 못 한 채 도는 통계       "손실 회피 2배" · "유지율 5%" · "100배 응답"
```

**모르면 "못 찾았다" 고 적습니다.** 없는 걸 있는 척하지 않는 것이 이 묶음의
유일한 자산입니다.

## 언제 낡나

```
법령            개정마다        시행일이 유효기간입니다
플랫폼 규칙      반년           실제로 크게 바뀐 적이 있습니다
광고 상품·단가   반년           과금 방식이 자주 바뀝니다
토스 자료        3개월          판본이 이미 두 해 반 낡았습니다
국내 조사 숫자   1년            AI 항목은 1년에 10%p 넘게 움직입니다
안 낡는 원리     필요할 때      새 반박이 나오면 그때
한 매장 사례     사례가 셋 넘으면  그때 원리로 승급을 검토합니다
```

**연도가 붙은 숫자는 연도 없이 옮기지 마십시오.**

## 스킬을 고치거나 새로 만들 때

```
1  같은 규칙을 두 파일에 쓰지 않습니다 — 겹치면 가리키기만 합니다
2  숫자에는 출처를 붙입니다. 없으면 안 씁니다
3  우리가 붙인 해석은 "우리가 붙인 것" 이라고 밝힙니다
4  반증을 찾아보고, 못 찾았으면 못 찾았다고 적습니다
5  가게 이름·지역·전화번호를 넣지 않습니다 — 어느 가게에도 종속되지 않습니다
6  파일이 커지면 상한을 올리지 말고 성격으로 나눕니다
```

**5번이 특히 중요합니다.** 이 스킬들은 여러 레포로 배포됩니다.
한 가게 이야기가 섞이면 다른 가게에서 못 씁니다.

## 여섯 스킬이 다루지 않는 것

```
업종별 전환율·객단가의 정상값     신뢰할 만한 자료를 못 찾았습니다
광고비의 값어치 (얼마 써서 얼마)  실험은 광고를 무료로 줬습니다
네이버쇼핑 검색 순위             원 문서를 못 찾았습니다 (C등급)
플레이스광고 순위 산정 기준        과금 방식만 확인했습니다
토스 오프라인 매장 기능           원문 0건. 가장 중요한데 가장 모릅니다
도구·빌더 비교와 요금             반년이면 다 바뀝니다
```

**없는 채로 두었습니다.** 이 목록이 채워지는 유일한 길은
**사장님 기록이 12주쯤 쌓이는 것**입니다 — product-launch 스킬이 그걸 합니다.
