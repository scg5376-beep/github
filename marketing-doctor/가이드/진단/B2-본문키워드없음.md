## 이게 뭔가요?

제목에는 넣은 검색어가 **본문에는 한 번도 없습니다.**

## 왜 고쳐야 하나요?

검색엔진은 제목과 본문을 **같이** 봅니다.
제목에만 있고 본문에 없으면 *"제목만 그럴싸하게 붙인 글"* 로 판단합니다.

제목과 본문이 따로 노는 글은 검색에 잘 걸리지 않습니다.

> 반대로 너무 많이 넣으면 `A1` 에 걸립니다. **3~5번**이 적당합니다.

## 이런 경우입니다

**제목**
```
중앙동 미용실 봄 단발 세 가지
```

**이런 본문은 안 됩니다**
```
봄이 되면 머리를 짧게 자르고 싶어집니다.
저희를 찾아주시는 분들이 요즘 많이 하시는 스타일을 모아봤습니다.
```
`중앙동`도 `미용실`도 본문에 없습니다.

**이렇게 고칩니다**
```
봄이 되면 머리를 짧게 자르고 싶어집니다.
중앙동 미용실을 찾는 분들이 요즘 많이 하시는 스타일을 모아봤습니다.

...

중앙동 미용실 중에 어디를 갈지 고민이시라면
편하게 들러서 상담만 받고 가셔도 됩니다.
```

## 고치는 방법

1. **제목에 쓴 검색어를 확인합니다**
   보통 `지역 + 업종` 입니다. 예: `중앙동 미용실`

2. **본문 세 군데에 자연스럽게 넣습니다**

   | 위치 | 예시 |
   |---|---|
   | 첫 문단 | "중앙동 미용실을 찾고 계신가요" |
   | 중간 | "중앙동 미용실 중에서도 저희는…" |
   | 마지막 | "중앙동 미용실 예약은 전화로 받습니다" |

3. **억지로 끼워 넣지 마세요**
   문장으로 자연스럽게 읽혀야 합니다.
   읽었을 때 어색하면 검색엔진도 어색하게 봅니다.

4. **소제목에 한 번 넣으면 효과가 큽니다**
   `## 중앙동 미용실 찾아오시는 길` 처럼요.
