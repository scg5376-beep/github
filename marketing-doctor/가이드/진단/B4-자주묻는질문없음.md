## 이게 뭔가요?

글 끝에 **손님이 자주 묻는 것 + 답**을 정리한 부분이 없습니다.

## 왜 고쳐야 하나요?

요즘은 사람들이 검색창에 문장으로 묻습니다. "중앙동 미용실 주차 되나요" 처럼요.
질문과 답이 글에 있으면 **그 부분만 따로 검색 결과 맨 위에** 뜹니다.
AI 검색에도 이 부분이 제일 먼저 잡힙니다.

## 이런 경우입니다

**이렇게 쓰면 됩니다**
```
## 자주 묻는 질문

Q. 예약 없이 가도 되나요?
A. 네, 바로 오셔도 됩니다. 다만 주말 오후는 대기가 있어
   전화 주시면 편하게 봐 드립니다.

Q. 주차는 어떻게 하나요?
A. 건물 안 주차장에 2시간 무료로 대실 수 있습니다.

Q. 안경 맞추는 데 얼마나 걸리나요?
A. 보통 당일에 찾아가십니다. 도수가 특수한 경우 2~3일 걸립니다.
```

## 고치는 방법

1. **손님이 실제로 물어본 것 3개를 떠올립니다**
   지어내지 마세요. 오늘·어제 들은 질문이 제일 좋습니다.

2. **글 맨 끝에 붙입니다**
   소제목은 반드시 `자주 묻는 질문` 이라고 씁니다.
   (`FAQ` 보다 한글이 검색에 잘 걸립니다)

3. **답은 2~3줄로 짧게**
   길면 검색이 안 뽑아 갑니다.

4. **질문은 손님 말투 그대로**
   "주차 가능 여부" ❌ → "주차 되나요?" ⭕

### 업종별로 이런 질문이 많습니다

| 업종 | 자주 나오는 질문 |
|---|---|
| 음식점 | 주차 / 예약 / 포장 / 아이 동반 / 단체석 |
| 미용실 | 예약 필수 / 시간 / 주차 / 남성 가능 |
| 병의원 | 예약 / 보험 / 주차 / 진료 시간 |
| 학원 | 상담 / 수업 시간 / 셔틀 / 레벨테스트 |
