## 이게 뭔가요?

글 안에 **등록해두신 번호가 아닌 번호**가 들어 있습니다.
대부분 예전에 쓰던 번호가 남아 있는 경우입니다.

## 왜 고쳐야 하나요?

두 가지 손해가 한꺼번에 납니다.

**첫째, 손님이 전화를 못 겁니다.**
안 쓰는 번호로 걸면 그 손님은 그냥 다른 가게로 갑니다.

**둘째, 검색이 우리 가게를 헷갈려 합니다.**
검색엔진은 **상호·주소·전화번호 세 가지가 어디서나 똑같은지**로 진짜 가게인지 판단합니다.
번호가 제각각이면 같은 가게로 안 봅니다. 플레이스와 블로그가 따로 놀게 됩니다.

## 이런 경우입니다

**이렇게 되어 있으면 안 됩니다**
```
예약 문의: 02-1234-5678

...

궁금한 점은 010-9999-1111 로 연락 주세요.
```
윗줄은 지금 번호, 아랫줄은 옛날 번호입니다.

**이렇게 고칩니다**
```
예약 문의: 02-1234-5678

...

궁금한 점은 02-1234-5678 로 연락 주세요.
```

## 번호가 두 개인 게 잘못은 아닙니다

매장 번호와 휴대전화를 **둘 다 쓰시는 건 괜찮습니다.**
다만 **어디서나 그 두 개만** 나와야 합니다.

| | 쓰는 번호 |
|---|---|
| 블로그 | 02-1234-5678 / 010-1234-5678 |
| 플레이스 | 02-1234-5678 / 010-1234-5678 |
| 인스타 | 02-1234-5678 / 010-1234-5678 |

세 곳이 똑같아야 합니다. 한 곳만 달라도 문제가 됩니다.

## 고치는 방법

1. **진단 결과에 어떤 번호가 낯선지 나옵니다**
   "등록 안 된 번호: 01099991111" 처럼요.

2. **그 번호를 지금 쓰는 번호로 바꿉니다**

3. **표기 형식도 통일하세요**

   | | 예시 |
   |---|---|
   | 좋음 | `02-1234-5678` |
   | 피하기 | `02)1234-5678` `0212345678` `02 1234 5678` |

   **하이픈(-)으로 끊는 형식**으로 통일하는 게 가장 안전합니다.

4. **다른 글도 확인하세요**
   번호를 바꾸셨다면 예전 글에도 옛 번호가 남아 있습니다.
   블로그에서 옛 번호로 검색해 한 번에 찾아 고치세요.
