## 이게 뭔가요?

이 글로 **잡으려는 키워드**가 제목에 통으로 들어가 있지 않습니다.
"공략 키워드" 칸에 적으신 그 말이 제목에 그대로 있어야 합니다.

## 왜 고쳐야 하나요?

손님은 이렇게 검색합니다.

```
중앙동 미용실
시청 근처 미용실
중앙동 파마 잘하는 곳
```

손님이 검색창에 치는 **말 그대로**가 제목에 있어야 합니다.
쪼개서 넣으면 안 됩니다. "중앙동 미용실" 을 잡으려는데 제목이
"중앙동에서 예쁜 미용실 찾기" 면 그 말이 통으로 없는 것입니다.

검색엔진은 제목을 가장 먼저, 가장 무겁게 봅니다.
본문을 아무리 잘 써도 제목이 비면 시작부터 밀립니다.

## 이런 경우입니다

**이렇게 쓰면 안 됩니다**
```
봄맞이 헤어 스타일 추천
```
예쁜 제목이지만 **어느 동네 무슨 가게인지 없습니다.**
"봄 헤어스타일"로 검색하는 전국 사람과 경쟁하게 됩니다. 이길 수 없습니다.

```
미소미용실 봄 이벤트
```
가게 이름만 있습니다. **우리 가게를 이미 아는 사람만** 찾습니다.
새 손님은 가게 이름을 모릅니다.

**이렇게 쓰면 됩니다**
```
중앙동 미용실 봄 헤어 스타일 세 가지 — 미소미용실
```
- `중앙동` 지역 ✅
- `미용실` 업종 ✅
- 무슨 내용인지 ✅
- 가게 이름 ✅

## 제목 만드는 공식

```
지역 + 업종 + 오늘 글 내용
```

| 업종 | 제목 예시 |
|---|---|
| 미용실 | 중앙동 미용실에서 추천하는 봄 단발 세 가지 |
| 음식점 | 시청 근처 점심 맛집, 중앙동에서 30년 된 집 |
| 헬스장 | 중앙동 헬스장 3개월 다니면 생기는 변화 |
| 학원 | 역전동 영어학원 겨울방학 특강 안내 |

## 고치는 방법

1. **제목 맨 앞에 동네 이름을 넣습니다**
   `봄 헤어 스타일` → `중앙동 봄 헤어 스타일`

2. **업종을 넣습니다**
   `중앙동 봄 헤어 스타일` → `중앙동 미용실 봄 헤어 스타일`

3. **길이는 20~60자로 맞춥니다**
   너무 짧으면 검색어를 못 담고, 너무 길면 폰에서 많이 잘립니다.

4. **앞쪽에 중요한 말을 둡니다**
   폰에서는 뒷부분이 잘립니다. **지역과 업종을 앞에** 두세요.

## 다 고쳤는지 확인하기

고친 글을 다시 붙여넣고 진단하세요.
`B1` 이 사라졌으면 끝입니다.

## 제목 만드는 구조

```
[ 후킹부 ]  |  [ 키워드부 ]
 궁금해서        잡을 키워드를
 누르게 만드는    정확히 박는 자리
```

예를 들면 이렇습니다.

```
투명 뿔테, 부담 없을까요 — 코블스톤 두 가지 | 중앙동 미소미용실
```

앞쪽은 클릭을 만들고, 뒤쪽은 검색에 걸리게 합니다.

**업종어를 억지로 넣을 필요는 없습니다.**
브랜드 이름이 업종을 대신하는 경우가 많습니다.
손님이 그 브랜드로 검색한다면 그게 곧 업종어입니다.

> 후킹이 잘 됐는지는 진단기가 판정하지 않습니다.
> 규칙으로 잴 수 없는 영역입니다.
