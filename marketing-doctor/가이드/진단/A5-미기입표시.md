## 이게 뭔가요?

`[여기에 가격]` `■` `○○` 같은 **나중에 채우려던 표시**가 그대로 남아 있습니다.

## 왜 고쳐야 하나요?

이게 그대로 올라가면 손님이 바로 알아봅니다.
**"대충 쓴 가게"** 로 보입니다. 한 글자 때문에 신뢰를 잃습니다.

다른 문제와 달리 **2분이면 고칩니다.** 제일 먼저 처리하세요.

## 이런 경우입니다

**이렇게 올라가면 안 됩니다**
```
저희 매장은 [영업시간] 에 문을 엽니다.
가격은 ○○원부터 시작합니다.
주차는 ■ 가능합니다.
```

**이렇게 고칩니다**
```
저희 매장은 오전 10시에 문을 엽니다.
가격은 2만원부터 시작합니다.
주차는 건물 앞에 하시면 됩니다.
```

## 고치는 방법

1. **진단 결과에 어떤 표시인지 나옵니다**

2. **실제 값을 넣습니다**

3. **값을 모르겠으면 문장을 지웁니다**
   빈칸으로 두는 것보다 **아예 없는 게 낫습니다.**
   나중에 알게 되면 그때 추가하세요.
