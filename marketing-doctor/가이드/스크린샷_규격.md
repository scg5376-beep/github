# 스크린샷 촬영 규격

가이드마다 직접 찍으실 사진의 기준입니다. **이 규격만 지키면 나중에 다시 안 찍어도 됩니다.**

## 기본

| 항목 | 규격 | 이유 |
|---|---|---|
| 기기 | **휴대폰 세로** | 사장님 대부분이 폰으로 봅니다 |
| 가로 크기 | **1080px** | 더 크면 로딩만 느려집니다 |
| 형식 | **PNG** | 글씨가 안 뭉갭니다 |
| 최대 장수 | **항목당 3장** | 4장 넘으면 안 봅니다 |
| 파일명 | `항목ID-순번.png` | 예: `A2-1.png`, `A2-2.png` |
| 저장 위치 | `가이드/이미지/` | |

## 표시 방법

찍은 화면 위에 두 가지만 그립니다.

```
┌──────────────────────┐
│  네이버 블로그        │
│                      │
│  ①┌────────────┐     │   ① 번호 원 — 빨강, 지름 60px
│   │  글쓰기     │     │   □ 빨간 사각형 — 선 굵기 4px
│   └────────────┘     │
│                      │
└──────────────────────┘
```

- **누를 곳**에만 빨간 사각형. 여러 개 그리지 않습니다.
- 순서가 있으면 번호 원을 붙입니다. 없으면 사각형만.
- 화살표·글자 설명은 넣지 마세요. 설명은 본문에 씁니다.
  (이미지에 글자를 넣으면 나중에 문구 고칠 때 다시 찍어야 합니다)

## 반드시 가릴 것

찍기 전에 확인하세요.

- [ ] 다른 사람 이름·전화번호·주소
- [ ] 손님 리뷰에 나온 실명
- [ ] 결제 정보·사업자번호
- [ ] 다른 가게 상호가 크게 보이는 부분

가릴 때는 **검은 사각형으로 완전히 덮습니다.** 흐리게(블러) 처리는 복원될 수 있습니다.

## 찍는 순서 요령

1. 고치기 **전** 화면을 먼저 찍습니다 (나쁜 예로 씁니다)
2. 누를 곳을 순서대로 찍습니다
3. 고친 **후** 화면을 찍습니다 (결과 확인용)

이렇게 하면 한 번에 3장이 나옵니다.

## 안 찍어도 되는 경우

글만으로 충분한 항목이 있습니다. `스크린샷: 0` 으로 두세요.

- 문장을 고치면 되는 것 (A1 키워드 반복, E1 과장 표현 등)
- 내용을 추가하면 되는 것 (B4 자주 묻는 질문)

**화면을 눌러서 이동해야 하는 것만** 찍으면 됩니다.
