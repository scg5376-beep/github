## 자막 받을 때 막힌 것

- yt-dlp 기본 호출이 「Sign in to confirm you're not a bot」·429 로 막혔다. `--extractor-args "youtube:player_client=android"` 로 받았다. 셋이 동시에 받으면 더 잘 막힌다.
- `vtt2txt.py` 출력을 Windows 콘솔 `>` 로 받으면 cp949 로 깨진다. 파이썬에서 UTF-8 로 직접 쓴다.
- PlayMCP 유튜브 검색은 하루 한도 초과(2026-10-12). 채널 목록은 `get_playlist_items`(업로드 재생목록 `UU…`)와 yt-dlp 로 받았다.
