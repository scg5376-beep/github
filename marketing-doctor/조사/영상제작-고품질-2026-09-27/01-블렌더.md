### 1-1. Cycles vs EEVEE(5.x) 선택 기준

| 항목 | 내용 | 등급 | 출처 |
|---|---|---|---|
| 엔진 정의 | Cycles = 물리기반 경로추적(patht racer, 레이 수백만 개를 쏴서 반사·굴절 시뮬레이션). EEVEE = 실시간 래스터라이저를 근사 기법으로 보강한 엔진 | B | [Strayspark: Cycles vs EEVEE Next 2026](https://www.strayspark.studio/blog/cycles-vs-eevee-next-2026) |
| 엔진 명칭 변경 | Blender 5.0부터 엔진 식별자가 `BLENDER_EEVEE_NEXT` → `BLENDER_EEVEE` 로 변경(구 EEVEE는 폐기, EEVEE Next가 곧 "EEVEE") | A | [Blender 5.0 Release Notes – EEVEE](https://developer.blender.org/docs/release_notes/5.0/eevee/) |
| EEVEE Next 개선점 | 화면 밖에서도 무너지지 않는 레이트레이스 반사/굴절, 스크린스페이스 GI + 라이트 프로브 자동 갱신, 면광 페눔브라가 있는 레이트레이스 소프트 섀도, 향상된 볼륨과 라이트 링킹 | C(스튜디오 블로그, 공식 릴리스 노트와 교차 확인 필요) | [Strayspark](https://www.strayspark.studio/blog/cycles-vs-eevee-next-2026) |
| 선택 권장 | 제품컷·건축 최종본·광고용 히어로 프레임처럼 시간을 들여서라도 반사·간접광 품질을 높여야 하면 Cycles. 스타일라이즈드·프리비즈·빠른 카메라 스터디는 EEVEE | C | 상동 |
| 운영 권장(본 프로젝트) | 아파트 분양 광고 최종 렌더는 **Cycles 기준으로 잡는다.** EEVEE는 카메라 앵글·조명 배치를 빠르게 확인하는 프리뷰 용도로만 쓴다 | 판단(설계자 확인 필요) | — |

## 핵심 10줄 요약

1. 아파트 광고 최종 렌더는 **Cycles** 기준(광고용 정지 이미지·히어로 프레임에 적합), 앵글·조명 확인용 프리뷰만 EEVEE(5.x부터 정식 명칭 `BLENDER_EEVEE`, 옛 EEVEE는 폐기).
2. 색 관리는 **AgX**(Blender 4.0부터 기본값)로, 창밖이 날아가는 실내 컷에서 Standard보다 하이라이트가 자연스러움. 최종 저장은 EXR로 두고 후반에서 룩 조정.
3. 디노이즈는 Cycles 전용 — 프리뷰/단일 프레임엔 **OptiX**(빠름, 시간축 불안정), 애니메이션·정밀 보정엔 컴포지터의 **OIDN** 병행. Color+Albedo 패스 최소 사용.
4. 인테리어 조명은 창문마다 **면광(Area Light) + 포털 라이트**로 자연광 흉내. 클로즈업엔 미세한 디테일(먼지·비대칭)을 일부러 남겨야 "CG 티"가 줄어듦.
5. 카메라는 초점거리·센서·조리개(F-Stop)·심도를 실제 카메라 값에 맞추고, 셔터 타임은 프레임레이트 2배 분의 1 근처(예: 24fps → 셔터 0.5)로 모션블러 설정. 파티클/물리는 렌더 전 베이크 필수.
6. 렌즈 효과(색수차·비네트·글레어)는 컴포지터 노드로 처리하되 **약하게** — 과하면 "필터 낀 CG"처럼 보임(구체 강도 수치는 미확인, 육안 검수 필요).
7. 조경은 Geometry Nodes의 **Scatter on Surface**(공식 노드) 또는 Distribute Points on Faces → Instance on Points 조합, 밀도는 Poisson Disk로 겹침 방지. 대기감은 Volume Scatter(안개) + Sky Texture(하늘), 단 볼륨은 샘플 수요가 높아 렌더 시간이 늘어남.
8. 무료 에셋은 **Poly Haven(CC0, 광고 포함 완전 자유)**을 1순위로. BlenderKit 무료는 광고 렌더 판매까지는 되지만 모델 자체 재판매는 금지. **Fab/Quixel은 EULA 원문 확인 실패 — 광고용으로 쓰려면 사람이 로그인해서 직접 확인**.
9. 렌더 시간: GPU는 큰 타일(256×256↑), 적응형 샘플링 임계값 0.01부터, 최종 스틸 300~800샘플+디노이즈가 통용값(모두 2차 출처, 우리 PC 실측 아님). **우리 PC의 GPU/VRAM 사양이 확인 안 돼 구체 권장치는 미정 — 운영자 확인 필요**.
10. bpy 자동화는 절대경로로 Blender 호출, 애드온 경로는 `bpy.utils.user_resource`로 물어서 쓰기(하드코딩 금지), stdout은 필터링해서 보기. bpy는 프로세스당 1회 import 제약이 있어 배치 렌더 설계 시 고려.
