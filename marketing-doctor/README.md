# 사장님 마케팅 지식창고

장사하시는 **사장님께 마케팅을 알려주는 블로그**를 위한 자료 창고입니다.
네이버 블로그부터 시작해 넓힙니다.

**글을 대신 써주는 곳도, 점수를 매기는 곳도 아닙니다.**
출처가 확인된 것만 모아 두고, 글 쓸 때 여기서 꺼내 씁니다.

> **작업을 시작하기 전에 [`CLAUDE.md`](CLAUDE.md) 의 표부터 보세요.**
> 무슨 일을 할 때 어느 파일을 보는지가 거기 적혀 있습니다.
> 그 표를 안 보고 폴더를 뒤지면 **규칙이 섞이고 빠집니다.**

## 이 창고가 다른 마케팅 자료와 다른 점

**남이 인용하는 걸 그대로 옮기지 않고, 원문까지 따라가서 확인합니다.**

실제로 확인해 보니 이런 것들이 나왔습니다.

| 널리 도는 말 | 확인해 보니 |
|---|---|
| "저품질 블로그에 걸렸다" | 네이버 공식 문서: **"네이버에서 만든 개념이 아닙니다"** |
| "유지율 5% 올리면 이익 25~95% 증가" | 원문은 **어느 한 은행의 사례** (85%) |
| "선택지를 줄이면 더 팔린다 (잼 실험)" | 2010년 메타분석에서 **효과 거의 0** → 2015년 조건부 복원 |
| "VIEW 탭 상위노출" | VIEW 는 **2024년 2월에 없어졌습니다** |

확인 기록은 `지식/원전/확인기록/` 에 남아 있습니다.

## 출처 등급

두 축으로 봅니다. 자세한 건 `지식/출처등급.md`.

```
출처   S  원문확인 + 독립출처 수렴 + 반증시도 + 숫자에 연도·표본
       A  원문 확인
       B  2차 자료 여럿이 일치
       C  출처 불명 → 쓰지 않는다

근거   실증 (대규모 데이터) · 공식 (본인이 밝힘) · 실무 (해봤더니) · 추측
```

**애매하면 등급을 낮추는 게 아니라 조사를 계속합니다.**

## 커밋 전에 반드시

```bash
python3 엔진/file_audit.py    # 파일 크기 · 중복 · 깨진 링크 · 라우팅 등록
python3 엔진/brand_check.py   # 매장 이름·전화번호 유출 검사
```

이 레포는 **어느 특정 매장에도 종속되지 않습니다.**
상호·지역·전화번호·취급 브랜드가 들어가면 안 됩니다.
`.brandcheck.local.example` 을 `.brandcheck.local` 로 복사해 금지어를 적어 두세요
(이 파일은 커밋되지 않습니다).

예시가 필요하면 중립 세트만 씁니다 — 미소미용실 / 중앙동 / 02-1234-5678 / 중앙로 123.
